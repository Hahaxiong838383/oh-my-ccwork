# tasks — 跨会话任务追踪

> **cc 在此目录创建/修改文件前，必须先读取本 README 并遵守以下规则。**

## 定位

存放需要多个 session 才能完成的任务文件。这是**临时工作区**，不是永久存储。

## 什么放这里

- 多步骤任务的待办清单和进度记录
- 需要跨 session 追踪的工作计划

## 什么不放这里

- 项目级别的计划 → `2-Projects/`
- 已完成的任务 → 删除或归档到 `5-Archive/`
- 系统状态 → `0-System/`

## 强制规则

1. **命名格式**：`任务主题.md`（简洁明了，如 `重构飞书通道.md`）
2. **任务文件结构**：
   ```markdown
   # 任务名
   > 创建：YYYY-MM-DD | 状态：进行中/已完成

   ## 目标
   一句话说清楚要做什么。

   ## 待办
   - [ ] 步骤 1
   - [ ] 步骤 2

   ## 进度记录
   - YYYY-MM-DD：完成了什么
   ```
3. **完成即清理**：任务完成后，文件要么删除，要么移到 `5-Archive/`
4. **不要堆积**：此目录同时不应超过 5 个活跃任务文件。超了说明需要聚焦
5. **每次进入先 `ls`**：看看有没有遗留的旧任务需要清理
