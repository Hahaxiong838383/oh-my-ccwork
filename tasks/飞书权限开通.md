## 使用说明

- **左边的 scope 标识符是权威的**——飞书开发者后台「权限管理」页可以直接搜这个字符串定位。
- **右边的中文功能说明是 cc 写的，不是飞书官方权限名**。飞书未在 API 中暴露权限的中文名称，
  `lark-cli` 全命令树也没有 scope→中文名的映射，所以这里只能按语义说明用途，供你判断该不该给。
- ⚠️ 权限只能在**开发者后台勾选 + 企业管理员审批**，没有任何 API 能申请。让用户反复点授权卡对
  「应用未配置」完全无效。
