## 2. P0 契约修复

首次分配曾把实名字段写成姓名字符串，和审核工作簿要求的结构化 Principal 契约不一致。发现后立即修复为 JSON 单元格：

```json
{
  "displayName": "脱敏姓名",
  "principalRef": "company-directory:脱敏唯一标识",
  "role": "业务角色",
  "decision": "pending"
}
```

P003 `reviewParticipants` 使用上述对象的 JSON 数组；所有参与者决定保持 `pending`，不得用预填分配冒充人工批准。

为建立可用的记录级最小权限，`categoryKey` 已从 Text 安全转换为 SingleSelect。飞书读取接口会把单选值返回为单元素数组，正式 CSV 导入器现在只接受并归一化“单元素字符串数组”；空数组、多元素数组、非字符串选项或非法 JSON 均失败关闭。转换后重新读取 36 条记录并逐字段比对，除读取形态从字符串变为单元素数组外，候选 Hash 和全部业务字段零漂移。
