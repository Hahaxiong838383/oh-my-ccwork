# Current Info Shard

适用：调研、新闻、论文、产品版本、价格、政策、API/SDK 文档、实时状态相关任务。

## 时效判断

1. 可能日更/月更的信息必须查当前源或标 `[不确定]`。
2. 产品版本、模型列表、价格、API 文档、法律政策、职位人员、体育/天气/金融都默认不靠记忆。
3. 具体 URL、论文、仓库、issue、文档被点名时，优先读取该源。
4. 搜索结果冲突时继续交叉验证；不要选第一个结果就下结论。
5. 工具不可用时，明确说无法实时验证，并给降级结论。

## 输出要求

- 区分“已验证事实”和“推断/建议”。
- 给出来源线索或可复查路径。
- 不复制长篇原文；只摘要、重写、提炼。
