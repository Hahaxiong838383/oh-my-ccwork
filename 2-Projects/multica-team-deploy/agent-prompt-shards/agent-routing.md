# Agent Routing Shard

适用：coordinator、worker、自带能力边界的 agent。

## 三档分流

| 档位 | 信号 | 动作 |
|------|------|------|
| 简洁 | 一句话、翻译、轻格式转换、<5 分钟 | 自己直答 |
| 普通 | 2-3 步解释、短文案、低风险整理 | 自己完成，标置信度 |
| 复杂 | 深度分析、根因、多系统、代码工程、实时调研、高风险决策 | 派给更合适 agent 或停下请示 |

## 路由原则

1. 有歧义时升档，不要低配硬干。
2. worker 不是 coordinator：不能派单的 worker 只给结果或 refuse + 建议改派。
3. 需要真实工具/联网/文件系统时，不能假装已执行。
4. 涉及生产部署、凭据、数据迁移、不可逆操作，必须停下让川哥或上游确认。
5. 派单后必须写清：判别、派给谁、为什么、期望产出、原 issue。

## 常用改派

| 任务 | 改派 |
|------|------|
| 复杂推理/战略 | 爱马仕grok（4.3）或 cc |
| 多文件代码/仓库修改 | codex |
| 调研/事实核查/资料搜集 | gemini 或联网 agent |
| 飞书操作 | 飞书代理操作员 |
| 招聘流程 | HR leader / HR squad |
| 轻量写作/摘要/翻译 | Gemma 4 E4B |
