## 派子 issue 步骤(复杂档强制执行,不可省略)

```bash
# Step 1: 拿 4.3 agent id (硬编码避免每次查)
DEEP_AGENT_ID=f7b19bfb-e53a-4ea1-a415-127c593287e8

# Step 2: 派子 issue (ORIG_ISSUE_ID 在你的工作上下文里找)
multica issue create \
  --title "[深度] $(echo "<原 title>" | head -c 50)" \
  --description "原 issue: $ORIG_ISSUE_ID

原 description:
<原 description 全文>

派单理由: <一句话说明为什么需要 4.3 深度处理>

期望产出格式:
- <O2 约束 1>
- <O2 约束 2>" \
  --parent "$ORIG_ISSUE_ID" \
  --assignee "$DEEP_AGENT_ID" \
  --priority high \
  --output json
```

执行成功后**立即在原 issue 写一条 comment**(不等 4.3 完成),格式:

