### 2. 架构方向重大转变（6 轮讨论推导）

**从 PROPOSAL 的方向 → 讨论后的方向：**

| PROPOSAL 原方案 | 讨论后共识 |
|---|---|
| brain.yaml 规范 + 模型无关 | **大脑=机制×模型，不追求完全解耦** |
| 靠 prompt 规则约束模型 | **协议下沉到代码，模型只做"填空"** |
| 所有认知功能都在 prompt 层 | **经验流→记忆结晶→行为适应的自动闭环** |
| 7B 也能跑完整大脑 | **双模式：完整模式(前沿API)+生存模式(本地14B)** |
| 静态规范 | **活的大脑，被经验持续修改** |

### 3. 关键架构共识

#### 3.1 经验流架构（Experience Stream）
- 统一 JSONL 格式，汇聚所有信息源（任务轨迹/用户交互/cc-eye 感知/环境事件）
- 每条经验带惊讶度评分（1-5），由本地小模型实时打分
- 高惊讶度事件立即标记，低惊讶度流过不处理

#### 3.2 三循环时间架构
- **实时循环**：感知+捕获（代码+本地小模型，毫秒级）
- **日终循环**："睡眠"整合，强模型处理标记事件→结晶为记忆（异步，每日）
- **周期循环**：行为规则沉淀，高 confidence 适应→固化为 rules/（每周）

#### 3.3 双模式大脑
- **完整模式**：Claude Sonnet API，负责深度思考+记忆整合+元认知
- **生存模式**：本地 Qwen3-14B，负责日常任务执行，只读取已有适应

#### 3.4 热修复机制（Hot Patches）
- 用户纠正→代码实时捕获→写入 hot-patches.jsonl
- 下个 session 启动时立刻注入，不等日终整理
- 类比：工作记忆(立刻生效,临时) vs 长期记忆(延迟生效,永久)

#### 3.5 微调闭环（数据反哺模型）
- 第一层：prompt 进化（天级，不需要微调）
- 第二层：SFT 微调（月级，本地 MLX QLoRA，Qwen3-14B）
- 第三层：DPO 偏好对齐（季度级，用户纠正=天然偏好对）
- 第四层：GRPO 自博弈（远期研究）
- 核心价值：prompt 从 3000 行压缩到 300 行，模型内化了行为模式

## 四、本次讨论的核心洞察（供评审参考）

1. **规范≠配置**：配置是确定性的，规范是概率性的，不能混为一谈
2. **完全解耦是幻觉**：认知能力和模型能力是共生关系，类比脑硬件和认知软件
3. **感知和学习要分离**：实时感知靠本地小模型+代码，真正学习靠强模型但异步
4. **经验数据是核心资产**：模型来来去去，经验和记忆永远是你的
5. **微调是终极闭环**：prompt 进化→经验积累→微调模型→prompt 负担减轻→更高层进化
