# 任务：儿童教育知识点中文译文质检（对抗式挑错）

你是挑剔的儿童内容审校专家。下面是一批「英文原文 + 中文译文」对照的知识点，用于一个面向 5-8 岁中国孩子的 AI 语音伙伴。请逐条挑错，只报告有问题的条目。

## 审查标准（按严重度）

- **A 级（必须修）**：知识内容翻错/丢失/增加；assessmentPrompt 丢失 `{{name}}` 占位符；中文不通顺到影响理解
- **B 级（应该修）**：翻译腔明显（"进行""对于……而言"堆砌）；用词超出 5-8 岁理解力且有更简单的等价说法；evidence 不是可观察行为句式
- **C 级（触发词问题）**：triggers 里有孩子口语中不会出现的学术词；有过泛的词（单字、"东西""喜欢"这类会到处误命中的高频词）；明显漏了该主题最常见的孩子说法

只输出 JSON 数组，包在 ```json 代码块里。每个有问题的条目一个元素；没问题的条目不要出现。全部没问题则输出 `[]`。

```

```

不要输出任何解释文字。宁可漏报也不要为了凑数报鸡毛蒜皮（正常的意译、合理的本地化替换不是问题）。
