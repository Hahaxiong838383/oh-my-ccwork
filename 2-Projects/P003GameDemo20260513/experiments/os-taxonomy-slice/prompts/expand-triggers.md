# 任务：为儿童知识点补充「场景化触发词」

背景：一个面向 5-8 岁中国孩子的 AI 语音伙伴，靠触发词子串匹配识别孩子聊到了哪个知识点。实测发现：现有触发词偏"话题名词"，但**孩子聊天不报话题名，说的是现象和场景**。比如：
- 知识点"影子的形成"——孩子说的是"它一直跟着我走""太阳一躲起来它就没了"→ 应补触发词：跟着我走、太阳躲起来、影子不见
- 知识点"物体的浮沉"——孩子说"我的小鸭子不会沉下去呀"→ 应补：沉下去、浮起来、飘在水上
- 知识点"防止侵蚀"——孩子说"土被雨水冲跑了"→ 应补：土被冲走、留住土

## 你的任务

为下面每个知识点补充 **3-5 个场景化触发短语**，规则：

1. 站在孩子视角想：这个知识点对应的**日常现象/场景/动作**，孩子会怎么脱口而出？补的是那些说法里的**特征性片段**（2-8 个字）。
2. 与现有触发词不重复，侧重补"现象描述"而非"话题名词"。
3. **严禁**下列几类：
   - 纯句式词（为什么 / 怎么办 / 是什么 / 真的吗 / 长什么样 / 不会做）
   - 单字
   - 日常高频泛词（东西、喜欢、老师、玩具、开心、睡觉、声音、朋友、下雨、石头、分类、公平、能量、死了、大声）
   - 与本知识点弱相关、其他话题也常说的词
4. 特征性 > 覆盖面：拿不准就不补，宁缺毋滥。

## 输出

只输出 JSON 数组包在 ```json 里：`{ "idx": 0, "add": ["…", "…"] }`，数量、顺序、idx 与输入完全一致（idx 原样照抄输入的数字）。add 可以为空数组（实在没有好补的）。不输出解释。
