5. **时间必须有来源**：occurred_at决定历史先后，received_at只标记到账；同发生时间不同绝对值冲突保守unknown。历史按14天收件范围/最多512条读取，正事实同时约束发生14天内及授权水位，水位前行仅用作GM否决；超过全部降级unknown，不拿部分结果冒充完整钱包。after/quantity取绝对值，不累加delta。只核实C-FAMILY-001、M-CARD-001的事件映射，历史星尘未知。
