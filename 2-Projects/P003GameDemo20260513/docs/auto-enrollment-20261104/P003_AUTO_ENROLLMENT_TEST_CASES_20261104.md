## 二、端侧正常联调顺序

下面所有真机项均为**待测**，按顺序执行。A 为拟绑定 C 的既有短信测试账号，B 为另一个既有账号；使用原测试手机号登录，不新造替代账号。

| 编号 | 操作 | 通过标准 | 取证 |
|---|---|---|---|
| C01 | 原样读取 C 的 SN、key_id、公钥指纹与版本 | 与合同 C 身份一致；私钥留在设备 | 版本/指纹/北京时间，不含私钥 |
| C02 | 运行自动初始化链，不手工编辑逐台材料 | 工位签发 200，声明被自动保存到同一 C；重启仍可读取 | 签发 RID、声明摘要与有效期、设备保存成功；不发凭据 |
| C03 | 重复自动初始化同一身份 | 公共身份一致，幂等可用，不生成不同身份 | 第二RID、相同声明摘要/指纹/有效期；后台按RID核idempotent和无重复身份。适配器stdout不输出idempotent |
| C04 | A 短信登录，建立真实 BLE 会话，读新能力 | token 为原 A，设备报新协议和真实声明；B 原设备不变化 | 账号脱敏标记、协议/会话摘要 |
| C05 | A 发新 enrollment challenge | HTTP 200；此时 C 仍没有永久台账和 owner | challenge RID/ID，后台只读确认 pending |
| C06 | 设备本机明确确认 | 核验新 14 行用途和本机会话，通过后输出 P1363 签名；不触发旧 12 行逻辑 | 设备确认状态/算法/长度；无需回传签名全文 |
| C07 | A 提交 confirm | 200 bound；C 台账、公钥、策略、owner 在同一事务出现且一致；Brain 进入 ready 或可重试初始化 | confirm RID/binding_id/public_id/version；后台核归属 |
| C08 | 同一 confirm 网络重试 | 同一个 binding_id/version，不能多建设备/账号 | 两次 RID 与回执对比 |
| C09 | C 配 Wi-Fi 后按 ble-key-v1 claim | 600 秒内成功，凭据解密与落盘；未鉴权为pending_device_auth，已鉴权可直接activated，不要求捕获短暂中间态 | claim 状态/code/binding_version；禁止记录 token |
| C10 | C 用保存凭据真实鉴权，再查回执 | 鉴权成功，activation_state=activated | 鉴权时间/RID、回执状态 |
| C11 | C 重启，再次鉴权与读声明 | 同一长期身份/声明，业务凭据有效，无重新人工登记 | 重启时间、鉴权状态 |
| C12 | 设备产生一条真实数据，A 查 dashboard | 同一设备、时间/字段可对账；空值不伪造为0 | 设备上报 RID、后台记录 ID/更新时间、页面字段 |
| C13 | B 登录，读 A 的 binding_id/public_id | 不返回 C 的回执/数据，不展示 A 的缓存 | HTTP状态/error/RID、页面无越权数据 |
| C14 | B 对已归属 A 的 C 发挑战 | 409 device_already_bound；A 归属与凭据不被改动 | RID、后台 owner/version 前后只读核验 |

C 的自动签发必须来自设备真实公共身份；不要把服务端隔离测试的 SN/声明/密钥作为 C 的材料。无需通过群消息传完整公钥来“补台账”。

## 三、低风险现场补测与隔离测试边界

| 编号 | 操作 | 预期 | 执行位置 |
|---|---|---|---|
| N01 | 未登录调用新 challenge | 401，带 request_id | 小程序/公网可测 |
| N02 | challenge 后取消本机确认 | 不提交签名，后台不建档、不绑定 | C 首次绑定前可测 |
| N03 | 等待 challenge 满120秒再提交 | 410，不建档；重新挑战可恢复 | C 首次绑定前，与同事明确排期 |
| N04 | 重复同一次 claim | 900秒恢复窗口内安全幂等，不改owner | C 正常联调可测，不输出凭据 |
| N05 | 声明/签名篡改、跨SN同key、伪造工位权限 | 拒绝，无部分登记 | 已在隔离环境通过；不向真实 C 注入伪造身份 |
| N06 | 数据库事务中断/双进程抢绑/每账号挑战容量 | 回滚、唯一获胜或限额拒绝 | 已在隔离环境通过；全局4096上限仅源码核对，本轮未做全局容量实测；不对生产故障注入 |
| N07 | 总闸关闭、过期、撤销、换key/owner | 新接入拒绝；既有回执按实际状态保护 | 已在隔离环境通过；本窗口不临时关闭其他人接入或改真实owner |
