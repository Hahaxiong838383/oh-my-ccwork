## 已交付能力

- 受控初始化工具自动提交设备公共身份，后台签发身份声明；无需运营逐台录入。
- 小程序转发声明及本次BLE材料，后台验证来源和长期密钥持有证明。
- 正确确认后，在同一事务中完成设备台账、公钥登记、BLE策略与账号归属；已绑定设备不会被别人覆盖，停用/删除设备不会被自动复活。
- 复用既有 claim 领证、Device Bearer 鉴权与家长数据权限；明确区分 bound、pending_device_auth、activated。
- 新接口逐次返回 request_id，并记录阶段/拒绝码，便于之后按 RID 定位。

| 接口 | 使用方 |
|---|---|
| `POST /v1/device/provisioning/identity` | 授权初始化工具，专用认证 |
| `GET /api/parent/device-enrollments/capabilities` | 已短信登录的小程序 |
| `POST /api/parent/device-enrollments/challenge` | 小程序创建自动登记挑战 |
| `POST /api/parent/device-enrollments/confirm` | 小程序提交设备本机确认签名 |
| `GET /api/parent/ble-bindings/{binding_id}` | 查询绑定/激活状态，沿用现役接口 |
| `POST /v1/device/pairing/claim` | 设备联网后领证，沿用 `ble-key-v1` |

窗口只允许持有受控签发声明且通过设备签名的身份接入，不是匿名提供任意SN就放行。14天结束后不影响已经绑定的正常设备使用。
