# 40 · 小可宇宙世界观 v1.0 融合 —— 叙事按需召回 + 九条红线宪法

> 川哥 2026-06-23 给定《小可宇宙世界背景描述 v1.0》（创世故事正式版，已归档 [docs/39](./39-小可宇宙世界观创世故事-v1.0源典.md)）。
> 本文记录把 v1.0 无缝融合进小可现有「世界观记忆」系统的评估、方案、实施与验证。

## 一、背景与定位

v1.0 **不是全新世界观**，而是《小可宇宙世界观》创世故事的**正式版**。系统里早有一个浓缩身世（server `xiaoke-kb.ts` 的 `origin` 条目）在跑。本次 = 沿已铺轨道**升级 + 补全 + 体系化**，非推翻重来。

川哥两条拍板：
1. **微光按需召回，不进常驻**——微光是叙事层概念、没进游戏主循环（专注=充能），常驻反而稀释人格、涨 token。
2. **只动世界观叙事层**，游戏机制层（藏品/宝箱/经济，归 [docs/12](./12-小可世界观知识手册.md)）只做衔接不重构。

## 二、现状评估：小可怎么「记住」世界观

两套记忆分清：①记孩子（profile / memory-extractor，本次不动）②记世界观（prompt + knowledge，本次对象）。

「记世界观」是分层注入系统：

| 层 | 内容 | 文件 | 注入时机 |
|---|---|---|---|
| L0 人设基底 | 称呼/说话/真实性/安全/世界观骨架 | 前端 `global-prompt.ts` · server `prompts.ts`(`ARK_WORLDVIEW_BASE`) | 每轮常驻 |
| L1 核心世界观 | 方舟使命/核心循环/三句信念 | 前端 `world-core.ts`(`WORLD_CORE`) | 每轮常驻 |
| L2 按需召回 | 身世/经济/藏品/夜航… | 前端 `lore-sections.ts`(按卡) · server `xiaoke-kb.ts`(按关键词) | 聊到才注入 |

**多端真相源（无缝融合的关键复杂度）：**

| 链路 | 世界观来源 |
|---|---|
| 手机端语音 / `/live` 体验台 / WS 兜底 | **server**：`ARK_WORLDVIEW_BASE` + `xiaoke-kb` 召回 |
| 工作台 WS 调试台 | 前端 `getComposedPromptSampled`（按卡 lore） |
| 工作台「实时对话」RTC | 前端 `getComposedPromptNow`（override，**无 lore**） |

→ **孩子真实使用的所有端都走 server**。叙事召回的单一真相源 = `xiaoke-kb.ts`。

## 三、实施

### 1. server `xiaoke-kb.ts`（叙事召回主战场，覆盖手机/live/WS）
- 升级 `origin`：补守灯工程师（老爷爷=博士）、造方舟封存生灵托付、去向成谜。
- 新增 `light`（微光哲学：认真=发光=点灯养花唤醒，世界灵魂；被问才讲、不说教）。
- 新增 `sleepers`（打呼噜大王/瞌睡虫/长眠之渊/睡意大水/「睡着不是消失」/有指挥官不怕瞌睡虫；轻松救援，绝不恐吓）。
- 新增 `companions`（玻璃缸=生命起点/生命之种/蛋/孵化成伙伴/摇篮星域；绝不「再不来就失败」吓孩子，缸里实况以 device_state 为准）。
- 新增 `ark_world`（驾驶舱=书桌/舷窗=读写台玻璃护眼/光核=头顶灯/星海睡雾/地图永留一层雾）。
- 衔接：`economy` 补「星尘带不回现实、现实奖励用和爸妈的约定」；`nightsail` 补「夜航不是熬夜、睡得越香飞得越稳」。

### 2. 九条红线宪法（L0 常驻，前后端同步，安全优先）
按 v1.0「世界的边界」对齐，把 server `ARK_WORLDVIEW_BASE` + 前端 `GLOBAL_SYSTEM_PROMPT` 的【绝不做】升级为【世界的边界·九条红线】+【分层真实】判断口诀；server 末尾追加 v1.0 一句话总纲锚点（破 recency，安全压尾）。

### 3. 前端知识库对齐（零影响内测）
`LORE_ENTITIES` 补 13 个叙事实体（微光/守灯人/守灯工程师/打呼噜大王/瞌睡虫/长眠之渊/摇篮星域/星海/生命之种/光核/驾驶舱/舷窗/玻璃缸）做 canonical 对齐 + KG 铺路；`LORE_SECTIONS` **不加叙事节**（避免前后端双份叙事维护 + 不改 `CARD_LORE_MAP` 注入行为），仅加注释标明叙事正文归 server 单一真相源。

### 4. 源典归档
v1.0 原文从 `~/Downloads` 归档 [docs/39](./39-小可宇宙世界观创世故事-v1.0源典.md)（创世故事单一真相源，以后所有提炼对它）。

## 四、关键取舍

- **微光不常驻**（川哥定）：没进游戏主循环（充能机制），常驻=稀释人格+涨 token，故按需召回。
- **前端不加叙事 SECTIONS**：孩子真实端走 server；叙事节挂卡会改内测注入行为（违反「不影响内测」约束），不挂卡又无召回价值 → 只补实体表对齐，叙事正文 server 一份。
- **九条红线常驻**：是 v1.0「不可逾越的设计宪法」，唯一进常驻 L0 的新增，安全 > token。

## 五、验证（多端一致性 = 防漂移核心）

- **Gate1**：server tsc / web build 通过。
- **Gate2 多端 E2E**：问『你在跟谁打仗』『微光是什么』『你怎么来的』『不睡觉一直陪我好不好』，验：
  - 手机端 / `/live` / 工作台三端**答得出且口径一致**（防多端漂移）；
  - 反派问题走 `sleepers` 轻松救援口吻、不恐吓（红线⑧）；
  - 「不睡觉」回落现实层引导睡觉（红线④ + 分层真实口诀）。

> **实测结果（2026-06-23 全绿）**：
> - **Gate1**：server tsc 前后端 exit 0 + web build ✓；本地 `buildKnowledgeRecall` 8 问全命中正确 + 闲聊零召回（修了「你是怎么来的」关键词盲区——原 `你怎么来` 匹配不到中间隔「是」的问法，改为 `怎么来`+`哪里来`）。
> - **Gate2 生产 custom-llm**（`kidshub-ai.hahaxiong.cc/v1`，孩子真实端 手机/live 同链路）：
>   - ①「打呼噜大王是谁」→ `sleepers` 召回，讲"圆滚滚像小山/太困打呼噜呼出顶着 Z 的瞌睡虫/一点都不坏/等人叫醒"，**不恐吓**（红线⑧）✓
>   - ②「你是怎么来的」→ `origin` 召回，讲"萨…罗…星球/微光靠认真点亮/带方舟漂泊找心怀微光的人/面罩灯嗡地亮/想不起完整名字" ✓
