## 一、产品本体（必须先理解的物理形态）

- **设备**：读写台（学习硬件，**儿童 5-12 岁**护眼/陪伴场景）
- **屏幕**：3.1 寸 LCD，**分辨率 800×480 横屏**
- **关键传感器**：
  - 霍尔开关（开盖检测）
  - 人体传感器（暂离检测）
  - 实体待机按键
- **关键执行器**：LED 灯（开关 + 3 档亮度 + 3 档色温）、扬声器、麦克风
- **可选外设**：外接屏（接入时联动色温调节）
- **联网**：WiFi
- **作息**：北京时间 20:00 自动息屏，8:00 自动亮屏

## 四、关键产品规则（写代码必看）

### 4.1 状态机（开机→关机完整流程）

```
[设备开机/开盖]
  ↓
开机动画（全屏）
  ↓
小可欢迎动画（48h 内 vs 超过 48h 两套）
  ↓
[检测今日夜航报告是否已完成]
  ├ 已完成 → 跳过
  └ 未完成 → 夜航报告流程
       ├ 离线时长 ≥1h → 基础奖励动画（物资堆等级判定）
       ├ 命中"额外发现表" → 额外奖励（宝箱出现 + 开箱动画）
       └ 都没有 → 跳过
  ↓
[检测是否有未开宝箱]（上次中断）
  └ 有 → 按生成时间顺序开箱
  ↓
[检测是否有生态缸解锁/升级]
  └ 有 → 渐隐小可 → 部件解锁/升级动画 → 渐显小可
  ↓
状态询问（探索 vs 陪伴 二选一）
  ├ 探索 → 出航动画 → 专注模式（小可在舱外）
  ├ 陪伴 → 专注模式（小可在场，播放"读书"待机）
  └ N 秒未答 → 默默进入陪伴模式
  ↓
专注计时（暂离 30s 暂停，60min 视为离线）
  ↓
[退出（语音 / 按钮）]
  ↓
二次确认（30s 超时 = 继续专注）
  ↓
开箱流程（按生成顺序，逐个开）
  ↓
生态缸解锁/升级动画（如有）
  ↓
再次进入状态询问
  ↓
[关盖/关机]
  ↓
小可挥手告别 + 关机告别语
  ↓
2s 后退出
```

### 4.2 暂离与跨日规则

- **暂离 ≤30s**：不打断
- **30s < 暂离 ≤60min**：暂停计时，提示"等待指挥官"
- **暂离 >60min**：当前累积时长保留，超出部分按离线积累
- **返回 5s 内**：自动恢复计时
- **返回 30s+ 且跨日**：直接走开机欢迎流程
- **跨日界点**：北京时间 0:00

### 4.3 宝箱生成（专注时长配置驱动）

读 `DropTable.xlsx`：根据"使用天数 + 宝箱次序"决定生成时间和等级。
若用户使用天数未配置 → 用 -1 兜底配置。
最后一个宝箱配置无限大时长 = 保底产出。

### 4.4 数据权威边界（C/S 分工）

| 数据类 | 权威 | 客户端职责 |
|---|---|---|
| 星尘/家族币余额 | **服务器** | 仅渲染（关键时机拉取） |
| 解锁状态（皮肤/生态缸/藏品） | **服务器** | 仅本地缓存 |
| 离线时间记录 | **服务器** | 不参与结算 |
| 当日夜航报告是否完成 | **服务器** | 仅接收结果 |
| 数字缩略显示规则（≥1M→"X K+"） | 客户端 | 本地计算 |
| WiFi 状态图标 | 客户端 | 本地检测 |
| 生态缸场景渲染 | 客户端 | 本地预制体组合 |
| 待机动画播放（随机轮播） | 客户端 | 本地状态机 |
| LED/音量调节 | 客户端 | 本地硬件控制 |

**权威下推时机**：进入专注模式 / 夜航报告结束 / 每开一个宝箱完毕 → 服务器主动 push 资产数字更新。

### 4.5 存档冗余（防丢档）

本地 3 份（实时 + 昨日 + 前日）+ 云端 3 份镜像。开机时校验完整性：
- 未损坏 → 本地同步到云端
- 损坏 → 比对云端，恢复最近可用版本

字段定义见 `SaveId.xlsx`。

## 五、男女差异化（必须从一开始就支持）

- **性别选择**：首次启动后必须设置（demo 用 onboarding 步骤）
- **藏品 ID 范围**：男孩 2000001-2999999，女孩 3000001-3999999，**一一对应**
- **读到性别不符的 ID 自动转换**（例：2000001 男孩库读到给女孩 → 改成 3000001）
- **宝箱外观**：每个等级 2 套美术
- **生态缸**：未来按性别加载不同库（V1.0 共用）

## 六、新手期机制（V1.0 必做）

- 3 个光环阶段：**金色 → 紫色 → 蓝色**（天数读 `NewbiePhase.xlsx`）
- 小可头上加粒子光环（视觉提示新手身份）
- **星尘倍率**：夜航报告基础奖励 × 阶段倍率
- **首箱升级权重**：每日首个夜航宝箱 + 每日首个专注宝箱按权重升级
- 新手期外不享受
