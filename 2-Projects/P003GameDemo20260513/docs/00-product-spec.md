# 00 · 产品规格摘录（Demo 范围）

> 完整框架见飞书 wiki [K1产品游戏路线框架](https://futurus.feishu.cn/wiki/PFELwNaTmi5CXskD2PDc5lfWncb)。
> 本文档仅摘录 V1.0 demo 需要落地的部分。

## 世界观

> "你是飞船科学家，通过舷窗观测一个封闭的生态缸。"

- 主视图 = 飞船舷窗 → 生态缸场景
- 用户专注产生的能量 = 生态缸的养分

## V1.0 核心循环

```
开盖
  ↓
离线收益弹窗（自动）—— 每离线 1h 积 1 份，上限 12h
  ↓
进入专注模式（语音 / 按钮）
  ↓
每 15 min 攒 1 个宝箱（上限 3 个）
  ↓
退出专注 / 下次开盖 → 自动开箱
  ↓
生态缸视觉成长（解锁植物/动物/装饰物）
  ↓
关盖 → 进入下一轮离线计时
```

## 角色：K1 机器人

- 贯穿引导、开箱、情绪反馈
- V1.0 用**帧动画**（AnimatedSprite），后续换骨骼动画
- 表情/动作：开心、鼓励、欢迎、专注陪伴

## V1.0 必做的系统（demo 范围）

| 系统 | demo 是否做 | demo 简化策略 |
|---|---|---|
| 新手引导 | ✅ | 单页式 3 步介绍 |
| 生态缸（家园养成） | ✅ | 3 个可解锁物件占位（植物/小鱼/石头） |
| K1 角色 | ✅ | 1 套帧动画（idle + 开心 + 鼓励） |
| AI 陪伴（语音） | ⚠️ 弱化 | Web Speech API 试 + 按钮 fallback |
| 开宝箱 | ✅ | 完整循环（积累/动画/奖励） |
| 离线收益 | ✅ | 用 IndexedDB 时间戳模拟 |
| 新手福利 | ⏸ | demo 不做 |
| 主界面 | ✅ | 生态缸背景 + K1 + 资源条 + 今日目标 |
| 藏品 | ⏸ | demo 仅展示生态缸物件，不做藏品图鉴 |
| 设置 | ⚠️ 弱化 | 仅放音量/重置入口 |
| UI 层级规范 | ✅ | 在代码里落地，见 tech-architecture.md |

## V1.0 不做（推后到 V1.5+）

- 家长端小程序
- 数据埋点 / 双端同步
- 家长任务系统
- 收藏馆 / 家族币 / 沙盒 / 宠物 / 社交 / 医生端

## demo 不打算覆盖但要注意的设计点

- **时长积累规则**（暂离/过短/跨次补完）：demo 用最简单的"暂离 5min 内不打断"策略
- **宝箱等级**：1-3 级 demo 都做，但配置写死，不接后台
- **离线收益内容**：demo 用 "家族币" 单一币种占位
- **设备开盖**：demo 用"启动 App / Tab 重新激活"模拟

## 验收标准（V1.0 demo 完成）

- [ ] 手机扫码可访问，能添加到主屏幕
- [ ] 完成新手引导 3 步
- [ ] 可启动专注，15s（demo 时间压缩）攒 1 个宝箱
- [ ] 关闭 Tab 一段时间后重新打开能看到离线收益弹窗
- [ ] 开箱有动画 + 生态缸有可见变化
- [ ] K1 至少有 3 个状态动画（idle/开心/鼓励）
