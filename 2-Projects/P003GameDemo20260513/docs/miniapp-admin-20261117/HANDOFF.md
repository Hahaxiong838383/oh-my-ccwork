## 数据与解绑口径

- 使用时长只采用 `usage.today/daily`：缺测 `null` 显示暂无数据，有效 `0` 正常展示，不回退旧兼容字段。历史 usage 缺失仍是上报/采集边界，本次没有修复设备或补造历史。
- 最近上报不是实时探活；资产快照不是实时钱包；非 normal 资产不可用。baseline 不计收入或新获得；流水只有本页已加载条数，没有总 count。对话按消息计数，覆盖不完整不称全部历史，不写死历史快照数量。
- 对话与 Ark 保留现有授权范围；用时仍按 SN 汇总，未实现全部数据的跨家长历史隔离。流水准入开关不等于历史已授权。
- 列表与旧 Brain 家长解除入口共用两次点击确认。弹窗冻结 public_id、家长账号、binding_version；确认后以条件更新提交，陈旧确认/ABA/重放返回 409，缺条件返回 400。取消不写，提交时禁重复。
- 解绑仅解除家长关联，保留设备/public_id、Brain 账号、档案、存档、原始对话、流水与遥测。旧家长该设备访问失效；同人重绑不自动恢复对话/Ark 历史授权。源码不清设备未 ACK 队列，不执行恢复出厂；设备队列保留尚未实机端到端验证。
- 旧预授权及已确认未 claim 会话按创建时 owner/version 校验，最终注册表事务 CAS 兜底；历史 null-version 意图失效。固定 SN 的 legacy v2/v3 受保护，v1 无固定 SN 快照兼容路径未扩展为全量撤销凭据。
