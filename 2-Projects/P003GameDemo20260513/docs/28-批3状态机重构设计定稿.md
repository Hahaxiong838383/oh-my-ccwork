## 三家共识（高置信，必做）
1. **6 态 FSM**（5 态 + CLOSING）：`SLEEPING / LISTENING / THINKING / SPEAKING / AWAITING_FOLLOWUP / CLOSING`。CLOSING 独立态确保关麦原子性。
2. **转移表** `state × event → (newState, action[])`，action 仅原子操作（startRecording/stopRecording/pauseWakeListening/startWakeListening/playThinkingCue/cancelTTS/finalizeExit）。
3. **有界续问窗**：AWAITING_FOLLOWUP **显式禁止** stopRecording + pauseWakeListening（麦连续开），窗内 VAD 续监听，静音 6-8s 超时 → CLOSING；MAX_FOLLOWUP 轮数上限保留。
4. **versioned state**：`turnVersion` 递增（每 beginTurn ++），统一存 FSM state，收编 3 补丁（capturedTurnMeta/playbackGeneration/activeTurn）；ASR 异步 final / barge-in / 退出先比对 version，不匹配直接 discard。
5. **7 个 timerRef 全收编**为状态内 timeout 动作（进状态启、出状态必 clear），消灭散落。

## ① 6 态 FSM 转移表（grok 骨架，实施时按 gpt/gem 补全边界）
| 当前态 | 事件 | → 新态 | 动作 |
|---|---|---|---|
| SLEEPING | 唤醒词/PTT 按下 | LISTENING | pauseWakeListening + startRecording |
| LISTENING | vad.speech_end / asr.final | THINKING | stopRecording（PTT 松手亦此）|
| LISTENING | 吐槽按下 | THINKING | feedback 路径（captureMode=feedback）|
| THINKING | llm.delta/tts.audio | SPEAKING | cancelThinkingCue + 播 TTS |
| THINKING | 超时(THINKING_TIMEOUT) | CLOSING/SLEEPING | 无回复兜底 |
| SPEAKING | playback_end | AWAITING_FOLLOWUP | **不关麦**（turnCount<MAX）/ CLOSING（超限）|
| SPEAKING | 孩子打断(vad/asr.partial) | LISTENING | bargeIn（barge-in 活跃）|
| AWAITING_FOLLOWUP | asr.partial(接话) | LISTENING | 无缝（麦本就开）|
| AWAITING_FOLLOWUP | 静音超时(6-8s) | CLOSING | finalizeExit |
| 任意态 | llm.done[EXIT] / 退出词 L1 | CLOSING | sayDirect 告别 |
| 任意态 | error | CLOSING | cleanup |
| CLOSING | 告别播完(playback_end)/兜底超时 | SLEEPING | stopRecording + startWakeListening（关麦回待唤醒）|

**关键**：麦克风互斥（铁律）只在 2 处转移触发——进 LISTENING 时 `pauseWakeListening`（原生唤醒让麦给 Web），回 SLEEPING 时 `startWakeListening`（Web 还麦给原生唤醒）。AWAITING_FOLLOWUP **不碰麦**（窗内连续开）= 消灭频繁开关麦。

## ② 有界续问窗（解问题3 核心）
- AWAITING_FOLLOWUP 进入：**不 stopRecording、不 pauseWakeListening**，启单一 `followupTimer`（6-8s 童声）。
- 窗内 VAD 继续（复用 vad.speech_end + 能量兜底）；孩子接话 → asr.partial 事件 → LISTENING（无缝，麦没关过）。
- 静音超时 → CLOSING（finalizeExit 告别）。MAX_FOLLOWUP_TURNS 4 轮上限保留（防无限）。
- 合并现有散落超时：WAKE_RECORD_MS 6000 / IDLE_NUDGE_MS 9000 → 窗内统一 followupTimer。

## ③ versioned state
```ts
interface TurnState {
  turnVersion: number;        // 每 beginTurn ++，单一真相
  capturedMeta: SessionMeta;  // 收编 server capturedTurnMeta
  playbackGen: number;        // 收编 voice-client playbackGeneration
  activeTurn: number;         // 收编 activeTurn + discardTurnAtOrBelow
}
```
- ASR 异步 final / barge-in / 退出：先比对 turnVersion，不匹配 → discard（防旧轮污染当前）。
- 统一 version 根治竞态（现 3 个补丁分散，易漏）。

## ④ React 落地（cc 判断 + 三家参考）
- **手搓 `useReducer` + 单一 `fsmStateRef`**（不引 xstate——儿童 demo 不值额外依赖；reducer 够）。
- FSM state = `{ state: VoiceState, turnVersion, followupCount, ... }`，timer 收编为 reducer 副作用（useEffect 监听 state 启/清 timer）。
- 保留为 ref：`clientRef`（VoiceClient 实例）。其余 20+ 散落 state/ref 收敛进 FSM state。
- UI 派生：listening/thinking/speaking 从 FSM state 映射到 app-store voiceStatus（保持现有 UI 不改）。

## ⑤ 实施策略（保现有功能不破）
1. 先画 Mermaid 状态图（6 态全转移）→ 川哥 review 转移完整性。
2. 实现 reducer + 转移表，**单测每条转移**（state×event→newState+action，覆盖 error/vad/退出边界——grok 强调遗漏会麦泄漏/死锁）。
3. 现有事件 handler（asr/llm/tts/vad/error/唤醒/PTT/吐槽）改为 dispatch 事件到 reducer（渐进迁，不一次重写）。
4. **现有功能全保**：唤醒/PTT/吐槽/填充音/退出 L1L2L3/VAD/麦互斥——逐个验证映射到 FSM 后行为不变。
5. 部署 + 真机验（FSM 转移日志 + 麦互斥不死锁 + 频繁开关麦消失 + 告别干净）。

## ⑥ 风险（三家共识）
- 转移表遗漏 error/vad 路径 → 麦泄漏/死锁（**单测每条转移兜底**）。
- 续问窗 VAD 误判 → 无限续问/卡死（followupTimer 单一 + 出态必 clear + MAX 轮数）。
- 重构破坏现有功能（渐进迁 + 现有功能逐个回归）。
- turnVersion 初始化/溢出（从 0 始，每 beginTurn++）。
