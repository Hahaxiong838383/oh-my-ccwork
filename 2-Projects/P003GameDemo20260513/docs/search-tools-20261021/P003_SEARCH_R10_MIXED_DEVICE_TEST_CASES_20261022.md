## 本轮变化与边界

明确天气地点可经百度天气查询；未说地点时沿用设备网络的城市级定位，网络出口可能与实际所在地不同，不是GPS。地点字典包含3220项，但不是3220项全部实测；同名地点不能确认时会请补省份，取数/地点/时效校验失败会明确说明。空气质量和旧源回退仍限原七城，不能把区县换成市中心。当前只专门支持今天、明天、后天预报及实时温度；更长时间仍属于通用搜索探索。

REA已验证央视国内新闻栏目和文章可读，本轮尚未接入独立央视新闻源。近期新闻查询仍可能返回可靠资料不足，须单独标记，不能把这类提示当成有效新闻答案。

服务端扩大话术后发现：后置“帮我查一下”的句子被拆分时，查询结果已返回，稍后聊天仍可能补答旧问题。请把用例07与13连续做一次记录；日常测试可优先把“帮我查”放句首，但这不是该问题已修复。科普答复偶有术语偏多，也请反馈是否听得懂。

## 异常时怎么做

说“取消搜索”停止当前任务；若持续异常，用设备返回/结束对话退出，再重新进入正常使用。重复出现时停止测试，把时间和设备SN给服务端同事，请关闭这台灰度后再退出重进；设备持有人无需改后台配置或提供凭据。

窗口到期后不再派发新灰度会话；已有灰度会话会被结束，需要退出重新进入正常链路，不会在同一个会话里无感切换。不可把正常到期退出与窗口内异常自动退出混记。

每项记录北京时间到秒、用例编号、完整话术、实际听到的回复（尤其是否漏字/无声/重复/错城市/旧结果）、搜索期间能否聊天、退出原因；能截图时保存字幕/错误画面和版本页。不要发送密码、Bearer、原始凭据。服务端“已发送/已完成”不等于你实际听到。
