## 实施内容与边界

- 大脑新增独立任务API、SQLite账本、有界并发与设备/全局日配额、Search/Fetch/Tool Calls执行器、管理员开关与脱敏审计。原chat/completions与模型竞速实现未改。
- Worker新增会话后台actor、明确意图路由、接单回执、800ms空闲播报门、取消/改查/退出、打断后仅显式续讲；HTTP不在音频tick中await，不把搜索结果加入普通对话历史。
- 复用现有管理员登录，独立页面/admin/search.html；没有改后台首页。该页面当前仅在隔离实例验证，公网尚不存在新入口。
- 源码双侧默认关闭。启用必须同时具备大脑env、热总闸及非空SN白名单、Worker env及非空SN白名单；普通device/parent token不能冒充固定worker通行证。
- 首版Worker每房只接一个活动查询，第二个查询提示使用“改查”；大脑上限每会话2个未领取任务、同时执行1个，全局执行2、排队8。
- 人格整理复用设备基础世界观与addendum；没有把整段对话、孩子画像、长期记忆、成长特质全量交给搜索任务。本文不承诺首版搜索语气已覆盖全部动态人格层。
- 错误保护：402暂停新单5分钟；429暂停30秒；连续3次5xx暂停30秒。执行器无自动网络重试，避免重复付费；Worker仅在提交传输状态不确定时用原幂等键重试一次。配额持久化，熔断状态为进程内状态。
- 暂未实现共享搜索缓存、按token精确成本计账、多查询语义消歧、任意URL抓取、额外业务工具、思考模式工具历史。按次限额是预算保护，不是财务账单。
- Query和网页过滤为首版保守规则，不能代替完整儿童内容安全评测；首发仅允许经确认的公开来源域名。

### 本轮发现并修复

1. 不能只靠模拟上游：实测发现“150汉字”与逐字符校验口径不同，英文参数堆积导致超长；改为两句、40～80总字符，仍保留150硬上限，拒绝不合格答案。
2. 明确要求搜索时，工具首步须指定search_web，避免模型先凭知识直接答。Fetch仍按需要选择；没调用Fetch的实测不能写成Fetch通过。
3. 账本每250ms扫描不能重复读库解析全部记录。改为持久账本＋有界内存索引，每次tick按设备复用授权判定，清理降到每分钟；失败/重启仍按账本恢复，不重放外网工作。
4. 先校验替换查询能否入队，再取消旧查询；队列满时保留原查询。
5. 续讲有效期固定在原ready后5分钟，不因打断反复延长；每次续讲先回云端校验，关闸/设备撤销/退出后不得用本地旧结果续讲。
6. TLS测试要沿main初始化crypto provider；不把测试环境缺初始化误判成线上TLS问题。

受控Fetch实测：第二轮由测试指定fetch_page，真实Search→Fetch→整理五个请求均HTTP200，耗时4012ms；此项验证执行链，不代表自动规划Fetch的选择率。技术样本检索到了Responses API文档，不能把模型总结当成Chat Completions能力的完整结论，内容质量仍待评估。
