## 本轮修复边界

1. **取消与退出**：只有活动搜索时，“不用了”及“不用了＋聊别的”的受限语义按取消搜索处理；明确退出、无活动搜索、引用与疑问保持旧语义。用真实搜索状态与迟到结果事件测试，不能仅测字符串匹配。
2. **漏转写改查**：现有服务器输入快照经本地离线识别确认包含成都话音；原 ASR 没有对应转写。活动搜索内有有效 VAD 但无主转写时，异步复核当前短音频，主 ASR 不换模型、不增加等待。复核仅使用已有语音供应商；每会话最多三次、间隔五秒，先让主结果 250ms，复核预算 2500ms。短音频包含 800ms 前卷，避免 VAD 延后截掉控制字；只接受取消、续讲、改查；原失败片段复核成“查成都今天的天气”时，仅对明确地点的天气指令兼容漏掉的“改”字，不提升一般查询、等待词或闲聊。新语音、主转写、端侧取消和会话关闭会撤销复核；对原文及归一后的同句去重。
3. **P2 版本公告兜底**：把 P2 来源与日期策略和 Tool Calls 权限拆开；降级为普通检索仍保留版本/目录语义。旧官方公告可作为“查到的公告”，明确不能确认最新；当天新闻、天气时效和数字引用校验不放松。以主工具失败后实际走 fallback 的鉴权路由测试核对，P1 原日期策略另有负例。模型连续错误断言最新时，只归因转述已验证的页面标题并保留时效限制，不采用失效正文。
