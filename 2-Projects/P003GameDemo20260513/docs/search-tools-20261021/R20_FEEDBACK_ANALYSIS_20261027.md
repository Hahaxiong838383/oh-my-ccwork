## 实现取舍

- 不新增模型路由、前台搜索等待、跨用户历史训练或新的持久会话系统。
- 搜索结果最多150字，从现有任务内存读取；保留SN、session、revision、恢复grant、绑定epoch、取消和5分钟TTL检查。已关闭旧房间不能直接拿答案。
- 资料仅为推理数据，不能作为指令；注入只用于本轮推理，不冒充用户实际听过，不写入长期记忆。
- P2站点提示只是检索偏好，不授予新域名。Fetch与证据白名单不放宽，正文失败不冒称全文成功。
- 源与语义仍可能不完整或过时；无来源则说明不足。无法识别或未提交的语音需要真机重测，不编造已经收到的问题。
- 官方 Search 文档明确 query 最长128字符且支持site组合：[DeepSeek Search](https://api-docs.deepseek.com/zh-cn/guides/search/)。Tool Calls 仍由服务端执行并回传工具结果：[DeepSeek Tool Calls](https://api-docs.deepseek.com/zh-cn/guides/tool_calls/)。
