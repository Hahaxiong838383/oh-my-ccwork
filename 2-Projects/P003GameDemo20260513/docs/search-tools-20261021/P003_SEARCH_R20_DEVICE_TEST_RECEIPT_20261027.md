## 开始前

结束当前聊天，回到主界面，再唤起小可。先说一句“我今天打球赢了一次”，确认能正常来回聊天，再从下面用例开始。更新前的搜索不作为本轮恢复用例，先重新发起查询。

每项做一轮即可，失败也保留记录，不要一直重复直到成功。听到过渡词不等于搜索完成；记录后续是否真正听到正文，字幕是否一致。一般先等10秒观察，30秒仍无结果记异常并继续普通聊天，不必一直等。

## 可照读的用例

| 编号 | 话术与操作 | 预期表现 |
|---|---|---|
| 01 红石 | “帮我查一下，我的世界里红石有什么用。” | 接受公开游戏问题，说明用途；不再把作品名当个人信息而拒绝 |
| 02 体育及追问 | “帮我查一下，羽毛球双打的后发球线是哪条？”听完后问：“那我发到那条线外是不是就出界了？” | 先区分后发球线与底线，再直接回答发球范围；不跳回足球等旧闲聊 |
| 03 恐龙及追问 | “帮我查一下，恐龙为什么会灭绝？”听完后问：“那植物没了，吃植物的恐龙怎么办？” | 追问衔接食物链，别忽然聊生态缸或之前的个人话题；资料不确定应说清楚 |
| 04 改查 | “帮我查一下，最近中国航天有什么新闻？”听到过渡词后说：“不用查这个了，改查歌曲大鱼是谁唱的。” | 停止旧题，转到歌曲演唱者；不继续把航天结果当作歌曲答案。若字幕把“改查”写成“改茶”，截图保留，不必故意读错 |
| 05 搜索中继续聊天 | “帮我查一下，最近中国航天有什么新闻？”随后说：“我今天打球赢了一次。”继续聊两轮，再安静下来 | 普通聊天照常响应；搜索不应卡住对话或抢播长段结果，空闲时可补播 |
| 06 插话与续讲 | 任一结果开始播时说：“先停一下，我想问别的。”聊一句，再说：“继续刚才的搜索结果。” | 插话后不顶着人声继续长播；明确续讲后继续原结果，不重搜无关题目 |
| 07 取消 | 发起航天查询，马上说：“取消刚才的搜索，不用查了。”再聊天约20秒 | 不再补播被取消的结果；不要把已完整播出的内容倒算成取消失败 |
| 08 后置与拆句 | “羽毛球双打的后发球线是哪条……帮我查一查。”中间正常短停顿；另试“帮我查一下我的世界基岩版……最近有什么更新？” | 能把紧邻片段组成同一查询；游戏版本需说明日期或资料限制，不假称确定是最新版本。不要人为长停超过5秒 |
| 09 退出重连续讲（重点） | 新查“恐龙为什么会灭绝”，听到正文刚开始就退出聊天；1分钟内重新唤起，清楚说：“继续搜刚才的搜索结果。” | 重新进入后先不自动抢播；说完后继续刚才恐龙结果，不能先说“没有结果”又突然补播，不能转到别的查询。不要等超过5分钟，也不要中间换账号、取消或另查新题 |
| 10 普通聊天基线 | 新开聊天，依次聊“我今天打球赢了一次”“我想和同学聊动漫”“我最近喜欢搭积木”“周末想出去玩”。可与另一台设备对比 | 没有明确搜索需求时正常聊天，不无故说“我去查查”，不额外等搜索；记录明显变慢的轮次 |

如果只说“为什么会灭绝”而无法确定对象，小可应澄清；请补“恐龙”，不要把澄清算成拒绝搜索。

## 本轮仍需重点观察

- 搜索后追问是否准确衔接、是否最后又跳回旧话题，必须听完整段。
- 退出重连后的原结果是否真正听到，单有字幕不算通过。
- 普通聊天是否变慢。自测仍出现过一次语音等待约5秒，尚未收口；请记“说完话→过渡词→正文”的实际间隔。
- 歌曲、新闻、体育是否仍频繁“资料不足”。一次自测答案因引用不完整被拒，不能保证每次都有答案；保留失败原话与时间。

## 异常记录和停止测试

记录北京时间（尽量精确到秒）、设备末8位、用例编号、你说的话、屏幕识别文字、真正听到的内容、是否退出重连；能录屏就保留发生前后约30秒，避免拍到账户或凭据。
