- 已使用home-studio REA 6.7.0浏览 https://tool.lu/ip/ 与 https://www.ip9.com.cn/#快速接入 。独立浏览器，只读页面和网络元数据。

- IP9公开GET https://ip9.com.cn/get?ip=指定IP ，无需注册，IPv4/IPv6；主页免费限制为每来源IP每分钟60次。返回国家、省、市、查询IP；经纬度是城市中心，不是设备坐标。区县/ip_type为VIP字段，本次不依赖。

## 采用的路径

1. 已认证设备请求会话时，仅对当前有效灰度完整SN记录本轮会话网络上下文。只信指定设备域名、直连loopback Nginx写入的X-Real-IP；不信任客户端X-Forwarded-For，不使用Worker/Brain出口IP。读取失败按未知处理。
2. 服务端异步IP9定位，最多3.5秒，响应16KiB，上游每分钟最多30次、同IP合并、成功缓存6小时、失败冷却60秒。签发/普通聊天不等待网络。
3. 独立候选数据库只保存SN+本轮room+城市/省份+来源+状态/观测/失效时间；不保存原始IP，不将SN或用户正文发给IP9。会话记录到期失效，新会话重新取当前网络IP。长会话中网络变化需退出重进，不能承诺无接入请求时实时探知。
4. 路由新增独立auto_location_enabled，默认关。自然天气没有城市时生成后台自动定位天气任务，Brain在任务后台等就绪；明确城市优先，不被自动定位覆盖。取消、改查及日期固定仍按既有合同。
5. 城市已验证且在墨迹七城内才读对应天气；未知/过期/未支持城市明确报告，绝不借用北京、服务器城市或其他设备位置。首版不扩大天气城市覆盖，不把城市中心坐标当精确定位。
6. 后台搜索灰度显示自动定位开关、当前设备会话城市、来源、时间、状态和失败原因；不展示完整IP。配置发布、回滚沿用原版本机制，已有任务固化策略。
