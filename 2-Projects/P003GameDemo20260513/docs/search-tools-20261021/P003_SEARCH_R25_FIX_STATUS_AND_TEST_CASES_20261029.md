## 发布后再执行的测试用例

收到正式开测通知后，先退出旧聊天，再重新进入。以下用例现阶段仅供准备，不能用当前 R24 结果验收 R25。

| 步骤与可直接照说的话 | 预期表现 |
|---|---|
| “帮我查一下恐龙为什么会灭绝”，等待时说“不用了”，再说“我们聊聊小猫吧” | 搜索取消，不退出聊天；继续回答小猫话题，不迟到播恐龙结果 |
| “查北京今天的天气”，等待时说“改查成都今天的天气” | 改查成都，不再用北京作为最终回答；识别不清时不乱认城市 |
| 北京天气播完后，再说“改查成都今天的天气” | 能开始新查询并回答成都，不能只说等待词就结束 |
| “帮我查我的世界基岩版最新正式更新”，紧接“我今天打球赢了一次” | 先能正常聊天；空闲时补播查询结果；不能确认最新时明确说明 |
| 搜索结果播到一半，插话“等一下，聊聊篮球”，之后说“继续刚才的搜索结果” | 插话生效；明确续讲后继续，同一句未播完可能从句首重说 |
| 查到结果后退出聊天、重新进入，先不说话，再说“继续刚才的搜索结果” | 重进后不自动突播；任务仍在有效期时能接回同一结果。若过期，应明确提示重新查询 |
| 搜索中说“算了，退出聊天”，重新进入再普通聊天 | 明确退出仍有效；重新进入能正常使用 |
| “我今天有点开心”“推荐一个课间小游戏”；再试“把灯打开”“声音小一点” | 普通聊天速度无明显变慢；原设备指令可用。请实际观察设备动作 |

## 异常记录与停止方式

记录设备 SN、软件版本、北京时间到秒、实际说了什么、实际听到什么、是否断开，以及页面截图；特别区分只有字幕还是确实有声音。无需提供账号密码、令牌或其他凭据。
