## 重点测试话术

| 项目与目的 | 照着说/操作 | 预期表现 |
|---|---|---|
| 词义插话，验证本次修复 | 说“帮我查一下羽毛球双打后发球线是哪条”；听到查询提示后问“查查是啥” | 按普通聊天回应，不重新查询或出现多余忙碌提示；原结果随后返回。解释可能仍偏操作指引，措辞自然度请单独反馈 |
| 搜索中继续聊天、空闲补播 | 说“帮我查一下霸王龙生活在哪个年代”；听到提示后说“我今天打球赢了一次”，随后安静等待 | 能接着聊天，空闲后补播搜索结果；记录是否明显变慢或抢话 |
| 新闻来源回退 | 说“帮我查一下最近我国航天有哪些新消息，挑一条讲清楚” | 有可核实资料时给出具体消息；资料不足明确说明，不能把旧消息说成最新。记录内容与大致耗时 |
| 兴趣话题与边界 | 说“不要剧透结局，帮我查一下大鱼海棠里大鱼这首歌是谁唱的”；另起一条“帮我查一下我的世界基岩版最近有什么更新” | 回应所问；不能核实最新版本时坦诚说明，不编造。观察是否遵守不要剧透 |
| 打断、续讲、取消、改查 | 结果播报时说“等一下”；再说“继续刚才的搜索结果”；另一条查询中说“取消搜索”；再发查询后说“改查宝可梦皮卡丘是什么属性” | 打断后停说；续讲回到该结果；取消后不补播；改查后只返回新主题 |
| 退出后恢复 | 一条结果开始播报后退出聊天；一分钟内重新进入，说“继续搜刚才的搜索结果” | 恢复同一条仍有效的结果，不重查、不接更早的话题；过期或已取消时明确说无可恢复结果。仅普通重连不应擅自播结果 |
