## 已定位的部分原因

R16p的声明过滤器会按完整句缓存输出，但调用点只在输入含“查/搜/天气/温度”等词时启用。普通科普“天气为什么会变化”和家电问题“烤箱的温度怎么调”也会触发，Worker原本可在逗号短分句提前开始合成的能力被上游整句缓冲抵消。

本地红测直接加载R16p已提交源码：输入“烤箱温度要看食谱，”返回空；新实现立即返回该安全分句。真实CustomLLM路由的本地SSE测试让模拟上游只发前半句、由测试显式扣住尾句；确认候选过滤器实际开启，并在尾句释放前收到安全分句。原先测试夹具漏配允许域名，导致过滤器未启用；该失败日志保留，修正夹具并增加启用断言后才通过。
