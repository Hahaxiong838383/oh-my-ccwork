已确认的原因与边界：

1. 当前Worker要求明确查询意图。裸天气主题路由返回None，没有任务。该约束用于防止普通闲聊被擅自联网；丢失前缀后，应有澄清承接，不能编造查询或否认已经存在的能力。
2. `custom-llm.ts`仅在用户文本含“查/搜/上网/联网”时启用执行承诺过滤，裸主题绕过该过滤。当前源代码回放已确认：同一人工构造的假承诺，对裸主题原样放行，对含“查”的输入替换为澄清。此处是确定性测试，不是伪称那段假承诺由新会话实际说出。

4. 历史第1/8轮的首句日志均为wake_only→RTC，catchup_samples=0、catchup_skipped=disabled。结合识别残句，有首句切换丢词的嫌疑；尚不能区分端侧采集/发送、Worker交接或ASR识别的责任。没有证据前不全局打开追补，不改现有首句合同。
