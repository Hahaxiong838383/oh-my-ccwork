## 如何进入测试

保持设备联网、音量适中。结束已有对话并返回主界面，等待约10秒，然后按平时的入口重新进入小可。无需重新安装APK。旧会话不会在中途自动切为搜索测试。

如果刚重进暂时没体现搜索能力，再彻底退出并等10秒重进一次；仍不正常就记录时间反馈，不要连续反复建连。首次说“帮我查一下今天北京的天气”，观察是否得到真实检索结果或明确失败说明；只听到“我去查查”不算搜索完成。

## 异常取证与停止测试

记录北京时间（精确到秒）、用例编号、具体话术、实际听到什么、等了多久、字幕是否一致。方便时截屏/录屏，保留原始时间；避免拍到无关个人信息。**服务端显示已发送，不等于设备扬声器实际听到了。**

卡死、持续无声、串台等严重问题：停止继续发搜索，退出对话并告知川哥。服务端关闭该设备灰度并结束候选会话后，重新进入即可恢复普通小可。**窗口仍开着时，单纯重连仍可能再次进入测试，不能把重连当成关灰度。** 无需卸载APK、清空设备数据或改其他设备开关。

固定截止后会自动关闭灰度并结束尚未退出的测试会话；返回主界面重新进入即回到正常链路，不是在原会话内无缝迁移。明日实际到期状态需届时核验；现已完成短窗口到期自动关闸与断开验证。不会自动延长或扩大设备范围。
