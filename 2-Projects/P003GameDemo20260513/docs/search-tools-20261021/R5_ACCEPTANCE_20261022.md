## 集成自测追加发现（未隐去失败）

- 候选systemd环境把JSON的 `\uXXXX` 当作字面文本传给进程，7个中文配置（打招呼、提示词、5类热词）与现役行为不一致。解码后的值逐项等于现役内容；仅将这7项改为UTF-8双引号值，其余配置/凭据逐行不变。须验证运行中 `/proc/.../environ`，不能只检查文件的JSON反序列化结果。新增 `verify_text_environment.py` 和2项回归，输出仅键名及状态，不打印值。
- 真实ASR“取消”整句省略逗号，原精确匹配漏掉；补无逗号变体，失败测试复现后修正，Linux360项与构建重跑通过。
- 10秒延迟第一次探针35秒便结束，账本仍claimed，不能计完整补播通过；延长合成客户端观察时间重测。受控延迟只在生产灰度派单关闭期间注入候选，完成后恢复原运行文件哈希；没有对现役或用户会话注入故障。

取消复测还发现：打断回执后actor把current任务号清空，而待处理列表不返回delivered任务，紧接的明确取消会误报无任务。已用空待处理列表的HTTP集成回归复现，改为停止轮询但保留已知任务号，直到新Submit/成功取消等明确状态转换；真正取消的证据必须来自离房前任务状态/取消确认，不能用离房cleanup后的cancelled冒充口头取消成功。
