## 为什么上轮自测通过仍漏出问题

上轮主要证明固定前缀、后台任务、播放回执和打断合同，未充分覆盖持有人自然表达；提示词约束被当成了过强的保证。只测intent函数也漏掉了普通LLM在没有任务时仍承诺查询的跨模块路径。ASR会省略标点并拆分一句话，文本断言不等于语音端到端。此次承认覆盖不足，不把旧测试全部作废，也不把旧通过范围扩大成所有表达都可靠。
