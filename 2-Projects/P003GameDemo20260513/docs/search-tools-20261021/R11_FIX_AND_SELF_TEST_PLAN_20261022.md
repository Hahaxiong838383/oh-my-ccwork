## 已复现与修改

1. 后置分句把前一个问题交给后台，却留下前台未结算的user消息。仅在1.5秒内明确空查询绑定、且任务成功进入本地派单队列时登记移交；下一普通轮拿到现有LLM锁后，精确移除末尾同问题及其回答。保留其他聊天，查询失败/取消也由独立任务通道结算；不把网页正文注入聊天或记忆。移交按turn边界消费一次；旧轮不得消费，主音频循环不等待模型锁，待移交期间跳过可能读旧上下文的投机。
2. “最新预约”被误用七天新闻过滤；“今天新闻”却可接受旧日期。预约规则保留官方公告的一般方式与适用日期限制，不能承诺今天有效/有票；当天新闻只接当天来源。国博与故宫优先对应官方站。
3. 央视指定新闻此前没有域名/正文链。新增固定央视国内栏目读取：最多两页索引、两篇文章；JSONP仅JSON.parse；动态正文仅解码固定contentdate单字符串，不执行JavaScript、不接受拼接表达式；精确HTTPS域/路径、标题/发布时间/正文一致性、话题/日期验证，航天报道标题也需命中主题，背景偶然提及不算来源。六秒总预算、256KiB/响应、60秒缓存、并发请求复用与独立取消、30请求/分钟上限。仅国内简报和中国航天近况，其他问题仍原通用搜索。不启用P2通用Fetch/Tool Calls。
4. 科普生成面向6–10岁，讲清核心因果，不添未问精确比例或术语串；凭实际多主题回答验收，prompt修改本身不算通过。
