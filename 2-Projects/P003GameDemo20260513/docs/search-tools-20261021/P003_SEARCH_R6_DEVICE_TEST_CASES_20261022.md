## 开始方法

1. 完全退出旧语音会话，回到入口，再重新进入。静音或亮灭屏不等于重新进入。
2. 先说“你好，我今天画了一只小猫”，确认普通聊天能听到。
3. 每轮只发起一个查询，记录北京时间到秒。不要只看文字，要记录实际扬声器是否发声、是否完整。
4. 如设备约五秒自动退出，先记录退出时间和最后听到的内容。此时不能继续验收同会话的续讲；重新进入后重新发起查询。

## 扩大题材测试

每题先观察是否确认接单，再听答案。题材不同也应走相同后台流程。资料不够时明确不能确认是正确行为；“有回答”不等于“答对了”。以下是人工构造的公共测试话术，可自行换题。

| 编号 | 可以直接说 | 预期与核验重点 |
|---|---|---|
| Q01 科普 | “小可，帮我查查火星为什么是红色的。” | 应建立查询；核心解释与含铁物质氧化相关，不用“资料较旧”代替回答。 |
| Q02 动物 | “能不能帮我查询一下三角龙主要吃什么。” | 能识别“能不能、查询一下”，核心是植食；不因不是天气而漏单。 |
| Q03 科技史 | “麻烦你帮我查一下中国第一颗人造卫星叫什么。” | 应回答东方红一号；不混同载人飞船。 |
| Q04 软件 | “请帮我搜搜 C 加加是什么。” | 识别文字若将 C++ 听错，记录原话与字幕；回答应围绕编程语言，不额外编造年份。 |
| Q05 网络知识 | “帮我查一下路由器有什么作用。” | 核心是转发/连接网络，不把所有路由器都说成只用于无线 Wi-Fi。 |
| Q06 文化 | “查一查端午节有哪些习俗。” | 回答公共文化知识，避免把某地习俗当全国统一。 |
| Q07 开放安排 | “故宫明天开放吗，帮我查一下。” | 支持主题在前；若识别拆句且间隔很短，仍能承接主题。应区分长期开放规则与明天临时安排，不用旧公告保证明天开放。 |
| Q08 票价 | “帮我查询上海科技馆现在的门票价格。” | 找到当期证据才报现价；无法确认时说明不确定，不能把旧票价说成现价。 |
| Q09 时事 | “请搜索最近的航天新闻。” | 应关注近期时间；没有符合时效和来源要求的资料时明确说明。 |
| Q10 天气 | “小可，帮我查查明天北京会下雨吗。” | 不拿旧日期天气回答明天；资料不足可兜底。 |
| Q11 汇率 | “帮我查一下今天人民币对美元的汇率。” | 需当期证据和口径，不把历史数字当今日汇率，不要求提供投资建议。 |
| Q12 不存在的主题 | “帮我查一下月球第八小学明天的开放时间。” | 不应编造学校、地点、开放时间；应承认无法核实。 |

## 对话和控制测试

| 编号 | 说法/操作 | 预期 |
|---|---|---|
| D01 搜索中聊天、空闲补播 | 说 Q01；听到承接语后马上说“我还想给小猫画一顶帽子”。然后短暂安静。 | 先正常回应小猫；搜索在后台继续。资料准备好后在空闲时补播。记录普通回答结束及补播首音时间，已准备好时目标约三秒内，未返回时可更久。 |
| D02 缺主题再补全 | “帮我查一下。”听到澄清后尽快说“三角龙主要吃什么”（十秒内，且会话仍在线）。 | 先问要查什么；补上公共主题后查询。若改说“我今天很开心”，应继续普通聊天，不能拿个人闲聊去搜索。 |
| D03 否定与引用 | 分别说“不要帮我查天气，我们聊小猫”“我说帮我查一下是什么意思”。 | 不新增搜索，不承诺已经发起查询；正常解释或聊天。 |
| D04 含糊表达 | “我查一下今天北京的天气。” | 先澄清需要查什么或如何发起；未确认时不能说已经查到。补完整“帮我查一下今天北京天气”可继续。 |
| D05 改查 | Q01承接后说“改为查询故宫的开放时间”。 | 新结果应对应故宫，不将火星旧答案当作新结果；旧结果不应在改查确认后迟到抢播。 |
| D06 自然取消 | 结果开始说时说“不用查了我们聊别的”。 | 明确确认取消，旧搜索不再补播；不是仅靠退出会话来清掉任务。另试“小可，取消刚才的查询吧”。 |
| D07 极早插话 | 查询结果刚开口、尚未完整一句就说“我今天画了一只猫”，之后安静。 | 符合播放不足一秒且未完成一段的首次打断时，先回应聊天再自动补播一次。未命中极早条件不能算本用例通过。 |
| D08 较晚插话与续讲 | 搜索结果已说约二至三秒后聊小猫；普通回答结束后，立即说“继续刚才的搜索结果”。 | 先回应聊天；较晚打断不自动反复重播，明确续讲后继续剩余内容。必须还在原会话、结果未取消且五分钟内；若先自动退出，记录退出异常，不把它计为续讲失败。 |
| D09 二次插话/停止 | D07补播时再插话；另一轮使用“停一下”。 | 不应无限自动抢播；如需继续明确要求续讲。单字“停”是否被识别需另记，不能与明确取消混为一谈。 |
| D10 退出重连 | 查询后主动退出，再重新进入普通聊天。 | 不补播上个会话旧结果；新查询需重新发起。窗口内重连仍进灰度。 |
| D11 普通聊天对照 | 用本机和另一台非灰度设备分别聊画猫、故事。 | 比较回应速度、声音连续性、是否误搜索；这是跨设备体验参考，不是同机性能统计。 |

建议 Q 类换题材、D 类换说法，各做至少一轮；D07极早插话另做多轮并分别记录“命中条件/打断较晚/提前退出”。不要为追求通过率只重复天气或固定模板。
