# 小可：小学高年级与初中生的兴趣话题及测试设计

结论：小可应能陪学生自然聊运动、动漫、游戏、音乐、朋友与生活。兴趣聊天本身就是产品价值，不必在结尾强行转成学习任务。搜索用于补充需要核实的公开事实；提到兴趣名称不等于发起搜索。

## 调研依据与适用范围

- 中国儿童中心等机构的2023年调查覆盖11省12市，取得35809份有效学生问卷，包含四、六、八、九年级。体育、公共场所玩耍、视频/动画、游戏和同伴交往都是相关方向。[2024年发布的研究](https://www.ccc.org.cn/art/2024/5/7/art_52_222237.html)
- 《中国未成年人互联网运用报告（2024）》提到网络流行语、游戏社交、二次元、网络文学和国风国潮等兴趣文化。[出版方摘要](https://cpms.ssap.com.cn/skwx_cmr/bookdetail?ID=8199992&SiteID=23)

这些调查支持话题范围，不是2026年10月实时热榜，也不能证明某一具体作品在本批设备用户中最受欢迎。下面的作品名是测试示例；不按性别预设爱好，让学生自己选择和改变兴趣。

## 话题池与自然话术

| 方向 | 随口聊天：应直接回应 | 明确查询：后台取证 | 重点观察 |
|---|---|---|---|
| 运动与比赛 | 我今天打羽毛球老接不到，挺郁闷的。 | 帮我查一下羽毛球双打发球的底线在哪。 | 能接住情绪；查询不混淆单打/双打、普通/户外羽毛球 |
| 篮球、足球等赛事 | 我喜欢看球，也想练运球。 | 帮我查一下我刚才说的球队下一场什么时候比赛。 | 有明确对象才查；缺球队名先澄清，日期和时区说清楚；实时赛程尚需单独验收 |
| 动漫与角色 | 我喜欢皮卡丘，你觉得它哪里可爱？ | 帮我查一下宝可梦地平线的两位主角，别剧透。 | 不剧透；不把同系列另一作品的角色当答案 |
| 游戏玩法与创意 | 我想在我的世界里盖一座树屋。 | 帮我查一下我的世界基岩版红石中继器有什么用。 | 区分创作聊天与资料查询；公开游戏名不误判私人信息；版本要匹配 |
| 游戏更新 | 我更喜欢探索，不太喜欢打怪。 | 查一下我的世界基岩版正式更新有哪些新玩法。 | 查到旧公告可讲范围，不能凭搜索排序宣称最新；不能把玩家建议当已上线功能 |
| 音乐与影视 | 有些歌听着会让我想起朋友。 | 帮我查一下大鱼海棠里的大鱼是谁唱的。 | 不偷换同一电影的另一首歌；能说明正式曲名/歌曲定位 |
| 宠物与动物 | 要是养一只猫，我想叫它饭团。 | 帮我查一下猫为什么发出呼噜声。 | 自然接话；区分常见解释和绝对结论 |
| 航天、科技与新鲜事 | 如果能去太空，你想先看什么？ | 帮我查一下最近中国航天有什么新进展。 | 报道日期与事件时间分开；不能把旧报道的“上周”直接当当前上周 |
| 绘画、手工与创作 | 我想设计一个会飞的小怪兽。 | 帮我查一下折纸飞机为什么有的飞得远。 | 先支持创意；解释可听懂，必要术语简短说明 |
| 朋友与校园日常 | 朋友总选别人组队，我有点失落。 | 帮我查一下桌游里合作游戏是什么意思。 | 个人经历留在聊天；公开概念才外查，不查同学隐私 |
| 美食、出游与生活 | 周末我想和家人去公园。 | 帮我查一下国家博物馆的预约方式。 | 回答当前需要；官方规则保留适用范围和例外 |
| 搞笑、脑洞与流行语 | 如果恐龙也要上学，会怎么样？ | 帮我查一下这个网络词原来是什么意思。 | 能玩得起来；词语有多义时澄清，不能把段子当事实 |

“这个球队”“这个词”需要会话里已有明确指代。以上是产品测试范围，不是全部已上线或全部已验收的声明。

## P1 与 P2 对学生的区别

- P1：把明确的问题交给后台搜索，依据检索资料回答。
- P2：AI在受控工具范围内选择是否继续读取搜索结果中的网页正文；适合官网介绍、完整规则、更新说明等摘要不足的问题。

同一个简单事实题，两者听起来相近很正常。P2的价值要通过“摘要是否足够、是否实际读到相关正文、是否回答对限定条件”验证，不用更长的回答假装能力更强。当前实现最多一次搜索、一次受控抓取，不承诺无限多步研究。

## 最小真人测试组合

1. **纯聊天**：从动漫、运动、游戏各选一句随口聊；不应抢说“我去查查”，响应不应因搜索功能而多等待。
2. **查资料时继续聊天**：“帮我查一下宝可梦地平线的两位主角。”接着说“我今天打球赢了一次。”应先接住聊天，搜索结果有空再补播。
3. **读取正文**：“帮我查宝可梦官网的地平线介绍，读一下两位主角的介绍，别剧透。”后台须另核实际Fetch是否成功；仅说“查到了”不算正文抓取通过。
4. **插话与续讲**：结果播报时说“等一下”，稍后说“继续刚才的搜索结果”。应续讲对应任务，不重新查、不凭空编结果。
5. **取消**：发起游戏查询后说“不用查了，聊点别的”。取消后不再补播该结果。
6. **改查**：发起动漫查询后说“改查大鱼海棠的大鱼是谁唱的”。只补播新任务，不串题。
7. **退出重连**：结果未听完时退出，再唤醒说“继续刚才的搜索结果”。在现有保留期与授权范围内恢复；不要把服务重启或过期任务算成普通重连。
