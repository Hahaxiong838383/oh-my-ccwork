## 可直接照读的话术

| 项目 | 操作/话术 | 预期表现 |
|---|---|---|
| 日常聊天 | “我今天画了一只小猫。”接着“我给它画了一顶蓝帽子。” | 正常接话，不无故说去搜索；反应不应明显比平时慢 |
| 搜索中继续聊 | “帮我查一下火星为什么是红色的。”紧接“我今天画了一只小猫。” | 有简短查询承接语；小猫话题可以继续，不能等搜索结束才接话 |
| 安静补播 | “帮我查询中国第一颗人造卫星叫什么。”说完安静等待 | 获得结果后补播实际答案；失败应说明，不能一直等或把“我查查”当答案 |
| 插话、续讲 | “帮我查一下恐龙为什么会灭绝。”播结果时说“先停一下”，随后说“继续刚才的搜索结果。” | 插话后停播；明确续讲能接回同一条可用结果，不能转成无关聊天 |
| 取消 | “帮我查一下火星为什么是红色的。”随后“不用查了，我们聊别的。”再聊小猫 | 取消搜索，正常聊天；等待约30秒，不应突然补播已取消的结果 |
| 改查 | “帮我查一下北京明天的天气。”随后“改查上海明天的天气。” | 最后按上海查询，不再把旧北京任务作为最新结果播报 |
| 退出重连续讲 | 查恐龙，结果播到一半时结束聊天；1分钟内重新唤醒，说“继续刚才的搜索结果。” | 在同设备、结果仍有效且未取消的前提下接回剩余结果。不要等半小时再当同一用例；当前保留时效约5分钟 |
| 天气与普通科普 | 分别问“今天天气怎么样？”和“天气为什么会变化？” | 前者可按设备网络估计城市，位置不确定应说明；后者正常聊天，不误当实时天气任务 |
| 非天气信息 | “帮我查一下中国国家博物馆的预约方式。” | 回答相关的预约信息；查不到或信息有时效问题应如实说明 |
| P2正文读取，仅两台 | “帮我查中国政府网国家节水行动方案的具体节水做法，读一下原文。” | 按需调用工具并尝试读取受控来源，给出相关做法；记录是否答非所问、把一句话拆丢、抓取失败却声称已读全文 |

最后一项可以自然完整地说，不用念内部工具名称。网页读取不是每次查询都必做，天气等固定查询也不一定调用P2工具。
