收到明确开窗通知后，先结束旧对话，确认已经退出，等待2—3秒，再唤醒小可进入新对话。按下面顺序测试，用手机记录北京时间到秒；分别记录“听到什么”和“字幕显示什么”。

## 可直接照着说

| 编号 | 话术/操作 | 预期表现 |
|---|---|---|
| 1 普通聊天 | “我今天画了一只小猫。”→“我想给它画一顶蓝帽子。” | 正常连贯回应，体感速度无明显变慢；可与其他内测设备对比，不把等待词当完整回答 |
| 2 搜索中继续聊天、空闲补播 | “帮我查一下火星为什么是红色的。”紧接“我今天画了一只小猫。” | 简短查询承接后正常聊天；结果到达时若正在说话，应等空闲再播，不抢话 |
| 3 附和 | “帮我查一下恐龙为什么会灭绝。”正文开始后轻声说“嗯嗯”；另两轮分别试“哦”和“对”，每词各两次 | 继续当前搜索结果，不突然接回此前猫或帽子的话题，不新开一轮查询 |
| 4 不完整表达 | 先聊猫的帽子，再查恐龙；结果播完后说“我想聊” | 询问想聊什么，不自行回答之前帽子的问题。接着说“聊聊大海”，应正常转到大海 |
| 5 完整插话 | 查询结果播报时说“我想聊聊我的新画。” | 真正的新话题可以打断搜索，正常回应新画，不把整句话吞作附和 |
| 6 同会话停止与续讲 | 搜索正文播到一半说“停”；静默后说“继续刚才的搜索结果” | 先停止，明确续讲后继续原结果；允许重说未确认完成的当前句，不应无端变成没有结果 |
| 7 先停再退出重连 | 重复第6项的“停”，随后结束对话；2—3秒后重新唤醒，静默10秒，再说“继续刚才的搜索结果” | 静默期间不自动播放；明确续讲后回到同一查询的剩余内容 |
