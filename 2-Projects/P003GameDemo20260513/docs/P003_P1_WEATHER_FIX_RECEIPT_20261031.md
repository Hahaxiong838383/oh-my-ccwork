## 修改内容

1. Worker 改成仅从句首、句尾剥离天气和请求语法，保留“冷水江、会同”等完整地名。地点字典在接单前预热，避免首次查询在音频循环中构建大字典。
2. 覆盖“请你告诉我、请你提供一下、就查……吧、啊北京”等口语；不完整的“天天气预报”保守追问城市，不发明地点。
3. 北京经开区等未收录开发区，仅当句子明确包含唯一城市时，播报“暂时无法细化到……，先提供……市级天气参考”。来源、站点和日期仍显示真正查询的城市。
4. 已有区县取数失败不降成市级；同名歧义、多地点、外国地点、空气质量不扩大支持；不借设备 IP 擅自确定显式模糊地点。缓存不会被降级说明污染。
5. 管理后台使用的路由预览二进制与 Worker 同步，预览结果与实际解析一致。

搜索仍在后台执行；本次没有改变普通聊天、首句音频、取消/续讲或搜索播报调度。
