## 0. 一句话诊断（川哥判断对了）
小可现在所有交互 bug（退出识别不全、判停忽快忽慢、填充音、**频繁开关麦、告别不干净**）**不是 bug，是同一个缺失的症状：缺一个「对话生命周期状态机」+ 一套「对话设计原则」**。业界叫 **Conversation Design**，是语音 AI 的顶层设计（地位等同 GUI 产品的信息架构）。头痛医头是因为没这张图——每个交互问题都在 case-by-case 打补丁，本该由一个统一状态机推导。

## 1. 产品定义 8 维度（必须显式定义）
用户与场景 / **核心价值主张** / 交互范式 / **对话生命周期(状态机)** / **对话设计原则** / **人设边界** / 记忆 / 多模态。痛点全集中在 4/5/6（生命周期/原则/人设），业界有成熟答案。

## 2. 最高杠杆动作：5 态对话生命周期状态机
**一个状态机同时解决判停 + 频繁开关麦 + 告别不干净 + 退出识别四个痛点**（它们本就该由这一个机制推导）：

```
SLEEPING（待唤醒，麦克风关）
  └─唤醒词/按钮→ LISTENING（聆听，麦克风开）
        └─判停→ THINKING（思考，可播填充音）
              └─→ SPEAKING（说话/TTS，barge-in 活跃）
                    ├─说完→ AWAITING_FOLLOWUP（续问窗，6-8s 静音窗，麦克风保持开）
                    │         ├─孩子接话→ LISTENING
                    │         └─静音超时/告别词→ CLOSING
                    └─孩子打断→ LISTENING
  CLOSING（干净告别：一句收尾 TTS → 关麦 → 回 SLEEPING）
```

- **频繁开关麦根治（问题3）**：不要「每轮结束关麦→唤醒词再开」，而是**一个会话窗内麦克风保持开**（LISTENING+AWAITING 连续），只在 CLOSING 才关。窗内多轮零唤醒、零开关麦。
- **告别不干净根治**：CLOSING 是显式态，告别永远走它（一句收尾→关麦→SLEEPING）。
- **判停统一（问题）**：THINKING 入口统一调参；STT 语义判停为主、VAD 兜底（业界判停三档，固定 VAD 静音超时是最差档=忽快忽慢根因）。
- **结束信号（任一触发 CLOSING）**：① 退出词 ② 续问窗静音超时(6-8s，儿童比成人长) ③ 方舟任务自然终点 ④ 孩子离开。

## 3. 核心决策表（选项→推荐→理由）

| 决策 | 推荐 | 理由 |
|---|---|---|
| **对话生命周期** | 有界会话窗（5 态状态机） | 兼顾连续感 + 干净边界，一次解 4 痛点 |
| **多轮 vs 一问一答** | 一问一答为底 + 有界续问窗（**非无尽多轮**） | 无尽多轮对 5-10 岁过载+折腾麦+隐私；续问窗内麦连续开消灭频繁开关 |
| **退出/打断** | 词库快路径 + 语义兜底；**退出永远优先于内容理解** | 快+全；打断(barge-in,转 LISTENING)≠退出(转 CLOSING) |
| **人设边界** | 场景化主动（默认被动，仅世界观锚点有限主动，有日上限） | 学习场景防打扰；**不刻意制造"我会想你/真朋友"依赖**(Moxie 倒闭+Hello Barbie 停产教训) |
| **记忆** | 单一真相源(DB)+家长 App 可查看/编辑/删除 | Curio/Replika 标配；PIRG 2025 安全底线 |

## 4. 一页纸「小可产品定义 v0.1」草案（docs PRD 种子）
- **一句话定位**：小可是方舟上陪 5-10 岁指挥官一起专注学习的数字伙伴——被唤醒时是聪明应答伙伴，专注学习时是默默充能的同伴。（核心价值：**陪伴式专注养成**，不是百科问答机，不是话痨玩具）
- **交互范式**（一次性定死，停止 case-by-case）：唤醒词「小可小可」+按钮兜底；一问一答为底+有界续问窗；会话窗内麦连续开。
- **三角排序**：安全（一票否决，家长可见全部对话+记忆，PIRG 2025 生死线）＞ 教育引导（主动注入）＞ 陪伴语气（包装层）——**分层非平衡**。
- **对话设计原则**（写进 system prompt）：① 简洁相关一口气听完 ② 推动对话前进（别给字面正确的废话，Grice 合作原则）③ 善用上下文 ④ 纠错友好（听不清自然重问不报错）。

## 5. 两条护城河 + 两个坑
- **护城河**：安全护栏 + 家长可见性（PIRG 2025《Trouble in Toyland》实测 AI 玩具被诱导讲色情/教找刀，家长控制缺失=生死线）。
- **坑1**：别做「无尽多轮」（孩子停不下来+折腾麦）。
- **坑2**：别刻意制造情感依赖（Moxie 倒闭后孩子哭着告别"朋友"；Hello Barbie 因"几周后突然提孩子说过的话"被批"装人"停产）。
