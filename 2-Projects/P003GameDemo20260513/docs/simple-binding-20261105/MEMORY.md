- 用户2026-11-05明确要求当前内测按已登录家长手机号账号+SN自动建档绑定；普通路径不引入工位声明、预置JSON、长期SPKI登记或人工初始化。这覆盖先前自动登记方案的产品前提，旧代码测试通过不能反证产品设计合适。
