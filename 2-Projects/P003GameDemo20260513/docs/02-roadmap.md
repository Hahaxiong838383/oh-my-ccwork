# 02 · V1.0 Demo Roadmap

> 5 个 milestone，每个 1-2 天工作量，依次推进。

## M0 · 脚手架打通（0.5 天）

- [x] 目录结构
- [x] 架构文档
- [ ] `pnpm install` 跑通
- [ ] `pnpm dev --host` 手机能看到 Hello K1
- [ ] PWA manifest + Service Worker
- [ ] Tailwind + 一个 mobile-first 测试页

**验收**：扫二维码手机能打开，看到 K1 占位图 + 一行 "Hello K1"。

## M1 · 生态缸 + K1 渲染 (1.5 天)

- [ ] PixiJS canvas 全屏自适应（safe area）
- [ ] 生态缸背景层（占位：渐变 + 几何形状）
- [ ] K1 帧动画（idle 循环，用 6 帧占位 PNG）
- [ ] 资源条 UI（家族币占位）
- [ ] 今日目标卡片（带入场动画 + 自动收起）

**验收**：主界面长这样：生态缸背景 + K1 在中间呼吸 idle + 顶栏家族币数字 + 5 秒后今日目标自动入场。

## M2 · 专注模式 + 宝箱系统 (1.5 天)

- [ ] `systems/focus-timer/`：start / pause / resume / stop，可暂离 5 min 内不打断
- [ ] `systems/treasure-box/`：每 N 秒（demo 用 15s 代替 15min）生成 1 箱，上限 3
- [ ] 主界面按钮：开始专注 / 退出
- [ ] 宝箱图标在 K1 旁边累积可视
- [ ] 退出专注自动开箱（动画占位：粒子 + scale up + 数字飙）
- [ ] 开箱奖励落到生态缸：解锁 1 个物件（先做 3 个占位物件）

**验收**：点"开始专注" → 等 15s → 看到宝箱图标 +1 → 点"退出" → 开箱动画 → 生态缸多了 1 个物件。

## M3 · 离线收益 + 持久化 (1 天)

- [ ] `systems/offline-reward/`：基于 IndexedDB 时间戳计算
- [ ] App 启动检测离线时长 → 弹窗 → 一键领取
- [ ] 关闭 Tab → 30s 后重开应该看到弹窗（demo 缩到 30s 代替 1h）
- [ ] 上限 12h（demo 缩到 6 min）
- [ ] Zustand 状态全部 mirror 进 IndexedDB

**验收**：刷新页面、关 Tab 再开、长时间不开 → 都能看到符合预期的离线收益弹窗。

## M4 · 新手引导 + AI 语音 (1 天)

- [ ] `scenes/Onboarding/`：3 页式（世界观 / 核心玩法 / 邀请专注）
- [ ] 首次进入自动触发，完成后写 IndexedDB 标记
- [ ] Web Speech API 试：识别"开始学习" / "我学完了" / "开箱"
- [ ] 所有语音指令必须有等效按钮
- [ ] K1 语音播报：开箱、离线、欢迎（先用 Web Speech TTS 占位）

**验收**：清缓存重进 → 看到引导 → 完成 → 主界面 → 喊"开始学习" / 点按钮都能进专注。

## M5 · 打磨 + 部署 (1 天)

- [ ] Lighthouse Mobile 跑分 > 90
- [ ] 三种网络（4G/3G/慢）冷启动验证
- [ ] iOS Safari + Android Chrome 真机各跑一遍
- [ ] 部署 Vercel + 配置预览域名
- [ ] 二维码放进 README
- [ ] 录一段 60s demo 视频

**验收**：扫码就能完整跑通一遍 V1.0 核心循环，川哥拿手机给非开发同学看不卡。

## 不在 demo 范围

明确推后，避免范围蔓延：
- 数据埋点 / 双端同步（V1.5）
- 家长端 / 任务系统（V1.5）
- 藏品图鉴页（V1.5+）
- 沙盒/宠物/社交（V2.0+）
- 真 STT/TTS（硬件版）
- 真骨骼动画（依赖美术）
