# 02 · V1.0 Demo Roadmap (V0.2 · 重写)

> 基于产品定义重新拆解。每个 milestone 1-2.5 天，总约 **2.5 周** 单人全速。

---

## M0 · 脚手架与基础设施（0.5 天）

- [x] 目录结构
- [x] 架构文档 V0.2
- [ ] `pnpm install` + 装上 MSW / XState / Zod / react-spring / Dexie
- [ ] `pnpm dev --host` 跑通，手机扫码 hello
- [ ] PWA manifest + Service Worker
- [ ] **设备外壳骨架**（手机视口铺满 + 内嵌 800×480 屏幕区域）
- [ ] LayerManager 雏形 + 9 层 z-index 测试

**验收**：手机扫码看到读写台模拟器（外壳+黑屏），屏幕区域是真实 800×480 比例。

## M1 · 状态机框架 + 配置表系统（1.5 天）

- [ ] XState 4 个机器骨架（boot/focus/reward/voice）
- [ ] root-machine 顶层编排，hydrate from Dexie
- [ ] `config/` 目录 + 9 张 JSON 配置占位（先填 Dictionary + DropTable + EcoTank 三张关键的）
- [ ] Zod schema + loader + `pnpm config:validate`
- [ ] Dexie schema（saves / config_cache / voice_log）
- [ ] 3 份存档冗余 + 校验恢复逻辑

**验收**：状态机可视化能看到完整流程图；改 dictionary.json 里的 NoanswerTime，行为跟着变；强制损坏 current 存档可恢复 yesterday。

## M2 · 生态缸 + 小可（2 天）

- [ ] 5 个生态缸部件占位（每个 3 级 = 15 个预制体）
- [ ] LayerManager 把 0/10/20/30 层 Pixi Container 接好
- [ ] 小可 AnimatedSprite + 3 套待机动画随机轮播（不连续重复，参考 1.6 §三）
- [ ] 新手期粒子光环（金色阶段）
- [ ] 主界面静态 UI（双货币胶囊 + 设置按钮 + WiFi 图标）
- [ ] 数字格式化系统（≥1M→"X K+"，6 位封顶）
- [ ] 开机动画 + 小可欢迎动画（48h 内 / 超 48h 两套）

**验收**：扫码看到完整主界面 —— 生态缸背景 + 5 个部件分散 + 小可在中间随机轮播 idle + 顶栏双货币 + 数字滚动测试通过。

---

## M3 · 夜航报告 + 开箱系统（2.5 天）

- [ ] Mock server 起步：`/api/user/me`、`/api/night-report/claim`、`/api/treasure/open`
- [ ] 夜航报告完整流程：
  - 离线时长判定（≥1h 才有基础奖励）
  - 物资堆 3 级外观（Low/Middle/High）
  - 基础奖励动画（粒子飞向胶囊 + 数字滚动跳动）
  - 额外发现判定（按使用天数查表）
  - 中断处理（未完成不发奖励，下次重头来）
- [ ] 开箱流程：
  - 4 级宝箱外观（普通/精品/史诗/传说）
  - 男女差异化（2 套美术占位）
  - 序列奖池保底（4 级宝箱按序列发放）
  - 多箱按生成时间顺序逐个开
  - 中断恢复（开到一半关 Tab，下次接着开）
- [ ] FeedbackQueue 队列调度（夜航 > 状态询问 > 开箱 > toast）

**验收**：关 Tab 30s 后重开 → 夜航报告完整跑一遍 → 命中额外发现 → 开箱动画 → 数字跳动 → 进入下一步。

---

## M4 · 专注模式 + 暂离机制（1.5 天）

- [ ] 状态询问 scene（探索/陪伴二选一 + N 秒未答默认陪伴）
- [ ] 专注界面 3 种随机布局（宝箱大 / 宝箱+小可 / 小可主）
- [ ] focus-timer 系统：
  - 暂离 30s 内不打断
  - 30s-60min 暂停 + "等待指挥官" 提示
  - 60min+ 强制转离线（写 last_offline_start）
- [ ] 宝箱累积可视化（虚线剪影 → 渐显，无音效不打断）
- [ ] 退出二次确认（30s 超时 = 继续）
- [ ] 出航动画（1-2s 飞船过镜头）→ 探索模式
- [ ] 陪伴模式小可"读书"待机

**验收**：探索/陪伴各跑一遍；离开手机 30s 再回来不打断；离开 60min（demo 用按钮模拟）触发离线；按"退出" → 二次确认 → 30s 不点会自动续。

---

## M5 · 生态缸解锁动画 + 新手福利（1.5 天）

- [ ] 生态缸解锁/升级动画 scene：
  - 渐隐小可（0.3s）
  - 按"先解锁后升级"顺序播放
  - 同级按 ID 顺序
  - 每个部件聚焦 + 特效 + 语音
  - 上报"动画播完"给 mock server
  - 渐显小可
- [ ] 中断恢复：服务器记 pending_anims，下次进入主界面继续播
- [ ] 新手福利完整：
  - 3 阶段（金色/紫色/蓝色）按天数切换
  - 星尘倍率（夜航基础奖励 × 倍率）
  - 首箱升级（按权重 4 选 1）
  - 升级宝箱播暴击动画
  - 小可头上光环 + 每日首次开盖播阶段语音

**验收**：连续跑 demo 7 天（mock 跳天）能完整看到 3 阶段切换；首箱升级 4 级时播放强暴击动画。

---

## M6 · 语音 + 设置 + 关机（1.5 天）

- [ ] 唤醒词试 "小可小可"（Web Speech API）
- [ ] VAD 监听 + 命令解析（开始/结束/开箱/换装/关闭设置）
- [ ] 所有语音命令必须有等效按钮 fallback
- [ ] 设置面板（80 模态层）：
  - LED 开关（外壳上的灯随之亮灭）
  - 亮度 3 档（外壳灯亮度变化）
  - 色温 3 档（外壳灯色温变化）
  - 音量 0-100% 滑动柄（步长 5%）
- [ ] 关机告别：小可挥手 + 告别语 + 2s 退出

**验收**：手机喊"小可小可"能（尝试）唤醒，喊"开始学习"或按按钮都能进专注；设置面板调亮度，设备外壳上 LED 灯真的变；点关机看到小可挥手离场。

## M7 · 性别 + 藏品 + 打磨部署（1 天）

- [ ] Onboarding 加性别选择（影响藏品库 + 宝箱外观）
- [ ] 藏品掉落：开箱有概率掉藏品，首次获得 → 家族币奖励
- [ ] 藏品 ID 范围保护（男孩库读到女孩 ID 自动转换）
- [ ] Lighthouse Mobile 跑分 ≥90
- [ ] iOS Safari + Android Chrome 真机各跑一遍
- [ ] 部署 Vercel + 二维码进 README
- [ ] 录 90s demo 视频

**验收**：男女不同账号扫码看到不同宝箱外观和藏品库；公网二维码非开发同学也能跑完整循环不卡。

## 不在 demo 范围（V1.5+）

明确推后，避免范围蔓延：
- 真后端（用 mock server 跑完 demo，未来切真服务器零代码改动）
- 真硬件接入（设备外壳模拟到 V1.5 上真机时切硬件 SDK）
- 家长端小程序、数据埋点、双端同步
- 完整换装系统（demo 仅默认皮肤）
- 藏品图鉴/收藏馆 UI
- 沙盒建造/光灵/坐骑/社交/医生端
- 真 STT/TTS（V1.5 接 MiniMax/Whisper）
- Spine 骨骼动画（V1.5 美术资源到位后切换）
- 自动息屏/北京时间作息
- 外接屏联动色温
