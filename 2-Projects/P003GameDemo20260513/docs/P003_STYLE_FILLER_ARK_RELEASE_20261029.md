每档可配置 0–100%。这是全局按风格配置，影响使用该风格的所有设备；保存或切档后退出并重新进入语音生效，已开始的会话使用签发时快照。0% 关闭 Worker 普通衔接语，打断轮也不能强制绕过；100% 仍只在原来允许衔接的场景触发。搜索任务确认、真实设备操作结果和 Android 本地提示不受此概率控制。概率是长期分布，不是固定每 N 轮播放一次。

减少“好呀、收到、我在听”等密集衔接；最短短语模式会避开近期使用的文案。未修改端侧断句/VAD，不能据此承诺所有插话问题均已消失。

方舟知识按本轮问句在本地内存中召回，不新增网络检索或阻塞语音的外部请求：
- 星尘：用于小可换装；“星辰”按资源语境识别为常见口语/识别写法。
- 家族币：记录亲子约定奖励，由家长按约定兑现；不是真实货币、不承诺提现或固定汇率。
- “金币”存在口语歧义：简短介绍两类用途后确认，不直接断言金币等于星尘。
- 装饰、生态缸部件、补勤/补签卡：说明已确认用途；补勤仅适用符合条件的历史节点，奖励仍需按页面领取。
- 实时余额、库存、价格目前不可读取，明确引导看设备页面，不编造具体数字、不声称已经兑换。
- 明确天文、其他游戏语境不误用方舟知识；取消/换查搜索命令保持原本优先级。
