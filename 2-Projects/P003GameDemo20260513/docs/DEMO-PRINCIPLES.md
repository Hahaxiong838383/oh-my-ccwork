# DEMO 目标与原则（锚定文档）

## 一、4 个绝对目标（不可变更）

### 1. 形态：手机横版 800×300 模拟器

- 用户在**手机上**通过 Web 浏览器体验
- **横版**（手机横置或自动横屏）
- 屏幕区域**严格模拟真实硬件 800×300 像素**（aspect ratio 8:3，**不是之前的 480**）
- 外壳可见或可隐藏，但内部画布永远是 800×300

### 2. 核心功能：小可 AI 实时语音对话

- 像**豆包式**实时语音交互（用户说话 → 小可几乎实时回应）
- 不只是命令理解，**是真正的对话陪伴**
- 这是 demo 的核心卖点 —— 没有它就不是这个 demo
- 端到端延迟目标：**理想 < 1.5s，可接受 ≤ 2.5s**

### 3. 时间：4 天交付

- 4 天 = **4 个工作日**，不是 4 周
- 不能延期，砍范围而不是砍时间
- 后端**先本地跑通**（电脑作服务器），川哥验收后**再迁云端**让手机能公网访问
- 部署链路简单，能跑就行

### 4. 第一原则：demo 优先，不考虑生产

- 跑起来 > 优雅
- 单机能用 > 集群可扩
- 直接调通 > 完美架构
- 砍配置表、砍 9 层抽象、砍 3 份存档冗余、砍状态机泛化 —— 一切为速度让路

## 二、由此带来的范围裁剪（已决策）

### 砍掉的（demo 不做）

| 之前规划 | 砍掉理由 |
|---|---|
| 9 层 LayerManager | 用 z-index 直接写，不抽象 |
| 9 张配置表 + Zod 校验 | 留 1-2 张关键的，其余 hardcode |

| XState 4 个机器 | 用 Zustand + 简单状态字段，状态机过度设计 |
| 完整 Mock Server (MSW) | 真后端服务（Node/Bun）直接起 |
| 唤醒词 + VAD + 二次确认完整流程 | push-to-talk（按住说话）或 VAD 自动检测，简化版 |
| 4 级宝箱 + 男女差异 + 序列奖池 | 1 级宝箱 + 简单概率 |
| 5 个生态缸部件 × 3 级 | 2-3 个部件 × 1 级，纯视觉占位 |
| 性别选择 + 男女藏品库 | 单一通用风格 |
| 新手期 3 阶段 + 暴击 | 不做 |
| 夜航报告物资堆 3 等级 + 额外发现 | 简单"欢迎回来 + 给点奖励"动画 |
| 设置面板（LED/亮度/色温/音量） | 全砍，外壳 LED 灯保留视觉效果 |
| PWA + Service Worker | 不做，普通网页 |
| 多设备同步 | 不做 |
| 配置表 Zod 校验 | 不做 |
| 状态机可视化 SVG | 不做 |

### 保留的（demo 必须做）

| 功能 | 优先级 | 验收点 |
|---|---|---|
| **设备外壳 + 800×300 横屏画布** | P0 | 手机横置看到读写台形态 |
| **小可 AI 实时语音对话** | P0 | 喊一句话能听到小可几乎实时回答 |
| 主界面：生态缸 + 小可 + 双货币 UI | P1 | 视觉成立，不需要实际可点 |

| 简单宝箱动画 + 奖励发放 | P2 | 有反馈即可 |
| 通用 Tips + 简单二级弹窗 | P2 | 复用 V0.3 已写的 |
| 本地存档（localStorage 单份） | P2 | 刷新不丢 |

## 三、技术选型原则（4 天内能落地的）

| 维度 | 选择 | 理由 |
|---|---|---|
| 前端 | Vite + React + TS + Tailwind | 之前已选，不变 |
| 状态 | **Zustand 直接用**（XState 砍） | 简单 |
| 渲染 | PixiJS（仅生态缸 + 小可帧动画） | 4 天能学会的最强 2D |
| 后端 | **Node + Hono / Express**（本地 → 云端） | 单文件起服务，部署简单 |
| 实时语音通道 | **WebSocket 流式** | 比 HTTP 轮询低延迟，比 WebRTC 简单 |
| STT | 待定（codex 调研） | 候选：豆包 / MiniMax / Whisper |
| LLM | 待定（codex 调研） | 候选：豆包 / Gemini Flash (川哥代理) / MiniMax-M2.5 |
| TTS | 待定（codex 调研） | 候选：豆包 / MiniMax Speech / 火山 |
| 部署 | 本地 → Cloudflare / Vercel / 川哥 VPS | 4 天交付要求快 |

## 四、复盘检查清单（每次开 session 前必读）

1. **手机能不能横屏看到 800×300 画布？** 不能 = 偏离目标 1
2. **能不能跟小可说话听到回应？** 不能 = 偏离目标 2
3. **从今天起到交付还剩几天？** 超出 4 天 = 偏离目标 3
4. **是不是在为"生产化"做事？**（配置表/抽象/可观测/容错）是 = 偏离目标 4

任一偏离 → **立即砍范围，不要继续投入**。
