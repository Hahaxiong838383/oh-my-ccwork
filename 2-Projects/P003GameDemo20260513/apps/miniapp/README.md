## 真实连接能力的边界

添加设备页有单独的真实蓝牙检查入口：

- 网页检查安全上下文及navigator.bluetooth；具备支持时由用户选择设备后尝试BLE GATT连接，并可断开。
- 微信端调用适配器、扫描与BLE连接API，扫描约5秒。真机权限和固件兼容尚未验收。
- 这是连接检查，尚未读取最终设备服务/证明，不代表已绑定或已联网。
- UUID、设备身份校验、加密信道、Wi-Fi扫描/写入、云端成功回执均待正式协议；不把草案中的建议UUID当成最终值。
- 系统浏览器不能自动视为支持BLE。尤其iPhone/Android及目标浏览器组合需验证；不支持时需要与硬件确认替代配网方案，不能用演示流程替代真实配网。

分享图片：网页生成PNG下载，支持文件分享的浏览器可调用系统分享；微信端使用Canvas生成并保存/预览，需真机验收。推广二维码尚未提供，不生成虚假二维码。
