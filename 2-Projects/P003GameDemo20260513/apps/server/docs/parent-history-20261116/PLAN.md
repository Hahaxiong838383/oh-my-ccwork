# C机历史数据接入与使用时长排查

用户要求：历史对话接入后台；查清使用时长为何缺失；确保C测试时小程序可见相关数据与历史。

## 实施选择

- 为家长设备接口新增 conversations 分页及 dashboard 轻摘要，直接读取已有对话，不复制/改写原消息。
- 旧对话没有归属代际，单C显式固定 public_id/SN/parent/device-account/binding_version/epoch 授权元组；换绑、换账号、换代或删除重建失效，默认其他设备不开放。不动语音写入链，不推断未知归属。
- 分页只输出 id/role/text/ts，固定高水位、过滤及游标签名；计数是消息数，不把固定rtc字段当会话数。新到消息刷新首屏可见。
- 从既有 miniapp 联调工作树快照复制到当前任务独立目录；只改真实数据页，接 usage/ark/records/conversations，缺测null不补0。原工作树未提交内容保留。
- 时长先查原始门状态、版本与拒绝证据；不根据对话时间跨度、token TTL、presence事件间隔编造计时。
