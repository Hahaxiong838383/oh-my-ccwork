## 破坏性变化与迁移影响

| 变化 | 采用前必须处理 |
|---|---|
| Node 门槛提高 | `^22.23.4 || ^24.22.1 || >=26.12.1`；Node 23/25 不支持。实测专用 v24.22.0、默认 v22.14.0 均不满足。安装器不会升级 Node。 |
| 函数分析默认输出 | MCP `analyze_function` 默认 retained summary；需要旧内联完整结果时传 `detail: "complete"`。CLI 仍默认 complete，选 summary 时要求 `--evidence_output`。 |
| MCP 输入 schema | 默认 compact；确需完整提示/嵌套约束时按实际客户端评估 `REA_MCP_INPUT_SCHEMA_PROFILE=full`。 |
| JSONL | 改为对象集合行加 `$rea: "jsonl/v1"`、`type: "metadata"` 控制记录；旧整文档处理改用 JSON，行处理须分离控制记录。 |
| Frida | JSON 直接返回 canonical Evidence；清理错误移到 `normalized_result.cleanup_error`。 |
| 环境服务 | 默认提供派生状态及由记录证据确认的写工具；无状态回放需显式 `--replay-only`，停止摘要字段改读 `state`。新 read-back 数据需要 REA ≥6.8.0。 |
| 浏览器历史捕获 | 旧 hashed storage 仍可读，但比较需双方重新捕获后才有确定结果；不得把 unknown 判作一致。 |
| 重建证明/汇总 | 仅 ID 数组不再建立 verified/ready；需实现/修订绑定和逐项 claim 结果；原 source-state 统计移到 `summary.by_source_state`，依赖旧摘要的 ledger digest 需重建。 |

其余协议变化：accessibility 的 value 允许数值/布尔；Mach-O import name、Swift 绑定名、WebSocket opcode、浏览器时间戳/console 参数、资源类 Evidence subject/digest 等允许空值或显式 unknown；消费者须保留不确定性。Interface Builder keyed-archive 图身份改用十进制 UID；引用源根枚举失败改读 rootFailure；文件系统遗漏原因新增 entry_unavailable/identity_changed；APK 数字地区选择器使用 es-419 或 b+es+419；未知 XML plist scalar 改为带 `$plist_type: "unknown"` 的包装。完整 21 条 breaking changes 见证据 JSON 的 release.body。
