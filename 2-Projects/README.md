# 2-Projects — 进行中项目

> **cc 在此目录创建/修改文件前，必须先读取本 README 并遵守以下规则。**

## 定位

存放**正在推进**的项目。每个子目录 = 一个独立项目。

## 什么放这里

- 有明确目标、正在执行的项目
- 项目的设计文档、执行记录、配置文件

## 什么不放这里

- 想法阶段（还没决定做）→ `1-Inbox/`
- 已完成/已放弃的项目 → `5-Archive/`
- 通用工具/模板 → `4-Assets/`
- cc 的 skill 代码 → `.claude/skills/`

## 强制规则

1. **一个项目一个目录**，不要散落文件在 `2-Projects/` 根目录
2. **项目目录命名**：简洁英文，用 `-` 连接（如 `ai-commit`、`futurus-rebuild`）
3. **每个项目目录建议包含**：
   - `README.md`：一句话说清这个项目是什么、当前状态
   - 其他文件按项目需要组织
4. **项目状态流转**：
   - 新项目：从 `1-Inbox/` 提升到这里
   - 完成/放弃：整个目录移到 `5-Archive/`
5. **不要在这里存代码仓库**。独立代码项目应该有自己的 git 仓库，这里只放项目管理文件
   - 例外：`cc-remote-v4/` 这类 mycc 内部子项目可以在这里
