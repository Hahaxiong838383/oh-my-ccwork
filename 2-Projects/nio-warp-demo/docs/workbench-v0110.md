# NIO Warp v0.11.0：单窗口工作台与 ProtoPie 联动

2026-09-17。用户已验收 v0.10.0 的几何功能，本版保留算法与原有校正参数，集中解决多窗口遮挡和预览联动配置。构建与测试结果见 [验收记录](workbench-acceptance-20260917.md)。

## 工作台

一个普通层级控制窗口；默认不置顶，可在右上角主动开启“保持置顶”。外屏仍由独立输出窗口渲染。

模块顺序固定：**画布与输入 → 整体校正 → 局部微调 → 标定与画质 → 预设与历史 → ProtoPie 联动**。ProtoPie 位于最右侧；⌘1～⌘6 切换模块。

- 左侧共用预览区域，右侧为各模块参数，可调整分隔线。建议窗口1120×720，最小内容尺寸1040×650；长参数独立滚动。
- 贝塞尔曲面与交点精调位于“局部微调”内，直接切换两个工具，不开新窗口。选点、物理视口、缩放及未提交文本保留，交点放大镜移入右栏。
- 切模块不启停修正层、不重启捕获、不保存草稿。退出工具取消未提交拖动，已经提交的曲面校验继续执行。
- 当前工具连续微调继续合并校验；校验期间暂缓其他工具和全局几何提交，避免旧基线覆盖。校验失败保留上一有效画面，并显示原因。
- 顶部始终提供撤销、显示原始桌面、置顶。校验中的撤销只取消候选修改，不消耗历史；离线撤销不可用。输入框的文本撤销仍由系统处理。
- 多项式增量收进整体校正的高级折叠区，保持原有能力。底部显示已启用的修正层。
- 关闭主窗口先隐藏输出，应用仍可由菜单“显示 NIO Warp 工作台”或重新打开 App 恢复；最小化保持输出。退出程序恢复原桌面。
- 显示器重连保留模块、相机、选点与主参数草稿；换另一显示器不套用上一个显示器的草稿与选点。

## ProtoPie 联动

在最右侧 Tab 选择来源：

1. **云端链接**：粘贴 `https://cloud.protopie.io/p/…` 链接。使用专用 Chrome 配置和窗口播放，可配置等比适配、隐藏工具栏。
2. **本地 .pie**：选择或替换文件。由 ProtoPie Studio 打开，识别该文件的 Preview 窗口；需要 NIO Warp 辅助功能权限。不会上传、转换或修改文件。

“保存配置”只保存来源和开关；“启动 / 应用并切换”才改变预览。新来源加载并取得有效捕获首帧后接入 Warp，保留现有校正参数；替换失败尝试恢复旧来源。本地 Studio 可能复用窗口，切换期间会暂时隐藏覆盖层，不能承诺视频级无缝切换。

可以开启“打开 NIO Warp 时自动联动”和“意外中断后自动恢复”。恢复最多三次；缺文件、需要登录或权限时等待用户处理。手工“停止联动”取消本次恢复并隐藏输出，不退出用户播放器。全局“显示原始桌面”只暂停覆盖输出。

没有外屏时仍可编辑、保存来源，或点击“打开播放器 / 登录”；自动捕获等待外屏。手工打开云端播放器会把专用窗口移到内屏可见范围并激活，自动联动不主动抢焦点。

联动配置独立于几何预设和撤销历史。云端链接只保存在当前用户偏好中，不随校正预设导出。捕获绑定本次预览窗口及所属进程，不因其他应用获得焦点而转移。

## 与开发机旧流程的关系

开发机保留的 v0.9.10 使用旧 Chrome profile、固定 test1 链接及1900×1030 pt窗口。本次重新实现其云端联动能力，消除了固定标题、端口和窗口坐标，并增加本地文件路径。

本版默认空来源、关闭自动启动。后续替换开发机安装版前应先迁移旧完整链接和自动启动意图；新专用 profile 可能要求重新登录。新窗口按目标屏幕布局定位，源构图需实屏复核，不把“参数没变”当作旧构图已通过验收。本轮未替换开发机 v0.9.10，也未重新安装 Air。
