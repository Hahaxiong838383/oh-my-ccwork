# v0.14.2（70）：启动鼠标映射时提醒关闭标定网格

## 行为

用户要求标定网格开启时启动鼠标映射弹窗提醒。此前守卫把网格开启合并成“演示输出与捕获来源不一致”，原因不明确，外屏点击入口还会直接关闭。

现在手动启动、脚本手动取点和已接通演示的外屏首次点击统一检查当前实际测试图。开启网格时，在内屏工作台显示“请先关闭标定网格”，提供“知道了”和“前往标定与画质”；前往只切换Tab，由用户决定关闭网格。当前鼠标映射保持关闭，不连接或发送输入到网格背后的原型，不修改参数/网格。

临时未校正网格、抗锯齿对比分别提示返回校正画面或结束对比。回车默认“知道了”，连续操作不叠加弹窗；提醒与退出、外扩确认互斥，使用工作台sheet避免落到不可见内容屏。周期监测不会自行弹窗；自动脚本遇到测试图直接返回明确错误，交原调度器记录和有限恢复，不弹无人处理的提醒，也不空等输入连接超时。

外屏提醒入口仍要求合法Cloud会话、活动实体/自有内容屏、窗口/进程匹配和完整捕获元数据；允许网格仅用于承接提醒点击，真实输入验证仍禁止测试图。阻挡期间保留外屏接收表面处理mouse-up，避免点击穿透。
