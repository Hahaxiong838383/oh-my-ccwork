# NIO Warp 2.0.0-rc.1 实施与交付回执

结果：已实现独立 Connect 来源及输入二开 SDK；最终全套 Native 测试实际执行 771 项，766 方法通过、3 跳过、2 方法失败（20 条布局断言，与 V1 基线逐条相同）。新增 Connect 39 项和生产 JavaScript Stage fixtures 13 项全部通过。release App 构建与严格签名检查通过，2.0.0（78，rc.1）、arm64、最低 macOS 14。安装包哈希以交付 manifest 为准。保持候选版，未安装到客户开发机。

## 实现范围

- App version 2.0.0、build 78、release channel rc.1；从 V1.0.0（77）固化标签建立独立工作区，原共享主目录未切换或重置。
- 新增 Connect 完整 HTTP(S) 播放器链接、测试页面、显式打开本机 Connect、播放列表和轮播来源。页面身份严格包含 origin、`/pie` 和 `pieid`。
- 沿用原浏览器租约、持久控制连接、切换/取消和自有页面回收；不停止 Connect 或客户其他 Chrome 页面。新旧来源配置使用独立 `.v2` 存储，旧 `.v1` 只读迁移。
- Connect 2.13 页面为 `#pie-screen` / Stage / D3，与 Cloud 页面不同。本版只验证并使用原生 transform，支持 `fitToScreen` / `originalSize`；不修改 D3 坐标状态。Connect 横向铺满、原型内部取景不可用，界面明确禁用。Cloud 原有铺满与取景设置在来源切换中保留。
- 鼠标输入来源适配与页面身份验证沿用原控制器和映射数学；Connect 原生光标为 `auto` / `none`，不另造圆圈，也不把 Cloud 圆圈承诺为 Connect 功能。整幅 Warp 物理 Y 位置与校畸变核心不变。
- 独立 Node 22+ SDK 提供 JSON-lines 输入、消息约定、限速、脱敏日志轮转、有界连接重试及断线动作丢弃。它没有 Warp 配置写入接口，也不会自动登录或上传原型。`connected` / `submitted` 不表示真实 Receive 已生效。

## 基线和回退保护

V1 标签 `nio-warp-v1.0.0-frozen-20260921`，解析提交 `e010f964a50a52f36e9afca8df211bdc63ffe3f9`。已安装 V1（77）的 ZIP 与补制 DMG 都是软件回退介质，不包含客户最新参数或 macOS 授权。客户升级前另行私有导出当前配置与全部预设；默认回退只替换 App，保留最新几何和预设。

Air 的 V1 安装备份显示问题已定位为签名变化导致录屏授权不匹配。保持固定安装路径，仅重置该 Bundle ID 的录屏记录，用户重新授权、退出重开后手动确认显示正常；记录见 [Air 排查回执](air-v1-installation-diagnosis-20261010.md)。没有据此宣称 V2 Connect 现场验收通过。

## 验证与限制

源文件核心保护逐项对照 50 个 V1 旧文件，39 个字节一致、11 个允许整合修改，保护核心修改为 0；`main.swift` 除版本显示外字节一致，见 `v2-core-protection-20261010.json`。这项源码保护不代替现场功能验收。

完整 Native 测试、真实失败/跳过计数、基线对照和构建 SHA-256 见 [Native 回执](native-v2-verification-20261010.md)。Connect 页面 JavaScript fixtures 使用生产 Swift 输出，依据公开 Connect 2.13 页面结构运行；不是业务原型现场测试。

SDK 本地 13/13 测试通过，使用真实 loopback Socket.IO 2.x / 4.x 服务。依赖审计生产链有 3 个中危受影响项、无高危/严重；legacy2 限本机可信输入，详细公告与限制见 `connect-sdk/DEPENDENCY-REVIEW.md`。用户实际 Connect 协议和 Enterprise Bridge 权限未测试，不能只凭已有订阅认为兼容。

未验收项目：真实 Connect 原型/消息闭环、输入硬件、客户屏幕与反射玻璃、Connect 焦点及原生交互、合盖/开盖/重启和长时间负载。未提供真实 `.pie`；提供合法 Studio 制作步骤，不使用伪原型文件。包为 arm64、最低 macOS 14、ad-hoc 签名且未公证，不能作为已签名正式分发版或 Intel 通用版。

## 交付边界

交付 V2 DMG、SDK 源码及 lock、客户说明、验收表、AI Skill、V1 回退 DMG/ZIP、manifest 和 SHA-256。SDK 与文档可用于输入二开；不包含 App 校畸变核心源码、账户、订阅密码、私有原型/链接、现场参数、内部记忆、客户日志或 node_modules。

部署由客户按文档安装执行，不远程替换其当前软件。正式 2.0.0 发布要在客户完成授权、消息、硬件和显示验收后另行冻结版本。
