# v0.10.0 贝塞尔曲面与对齐吸附

状态：功能分支实现；此版源自 v0.9.2 数学/界面基线。开发机已安装的 v0.9.10 ProtoPie 自启动版未被修改，其完整源码尚未回收，本分支没有把该自动启动流程合入。待用户授权安装 Air 后再做实屏体验验收。

## 功能入口和操作

在「基础配置 → 4. 基础校畸变」打开“贝塞尔曲面控制网”。原 Warp 强度、上下弧度、垂直压缩、倾斜和水平弯曲继续控制整体；先确定画布大小，再细调贝塞尔曲面。

1. 启用贝塞尔曲面叠加，默认5列×3行；支持2～9列、2～7行。
2. 选择控制点，拖动圆点改变该区域位置；拖动橙色水平/垂直方形手柄改变曲率。两侧手柄共线保持平滑连接，所有变化作用于实际画面，不仅是网格线。
3. 选择联动方式：等量联动使所选列的多行同步移动；渐变联动随纵向距离平滑衰减。横向始终按影响范围衰减。“贯穿画面”覆盖纵向全深度，“指定分区”由纵向范围控制。
4. 数值偏移以外屏物理像素计；方向键1px、Shift 10px、Option 0.1px。开启居正后仍按屏幕方向操作。
5. 拖动期间编辑器显示候选曲面；松手后异步校验再应用到外屏、保存偏好并记录一次历史。Escape取消本次拖动；网格折叠等非法候选保留上一有效输出。
6. 增加行列以曲面细分保形，不重置已有节点。减少行列会弹出确认并清除本层曲面修正后重建，可撤销。单点复位仅清该点约束，联动到其他点的历史变化不会一并删除；整层复位清除贝塞尔修正，原整体/局部交点仍保留。
7. 无外屏或临时校准/A-B预览期间此编辑器只读，避免误改已保存的现场参数。
8. 两种局部编辑器共用输出配置。快速切换编辑器时，以最新提交为准；另一窗口尚未校验完成的候选会取消，已生效的另一层修正保留。

## 吸附

- 倾斜零点吸附：滑杆/已启用时的值在 ±0.002 内设为精确0。
- 水平弯曲零点吸附：±0.001 内设为精确0；默认关闭，避免更改现有校正。
- 画面水平/垂直居中：按最终曲面边界采样包围框对齐AA中心。
- 参考轴居正：使曲面中心横线两端的连线水平，不把曲线拉直。对齐使用物理像素中的刚体平移/旋转，保留曲率和点间距；开启后每次编辑重新计算。
- 一键居中居正开启上述三个几何选项，不启用“弯曲归零”。不会自动缩小画面，AA外仍按原逻辑裁切；物理玻璃观察位仍需现场验收。

## 兼容和边界

- 新schema为12。旧配置缺少新字段时两层默认关闭，保留原渲染；参数及节点/手柄随完整配置JSON、显示器配置、预设/历史一起保存。
- 贝塞尔控制网绑定归一化画布坐标；改变画布尺寸会改变节点覆盖区域，物理像素位移幅度保持不变。先定画布再细调，变更画布后应复核。
- 影响范围控制本次编辑传播到哪些节点；已存在的相邻面片会平滑插值，不承诺半径外所有像素绝对为零。界面标为编辑传播范围。
- 曲面由二维分段三次Hermite插值表示，节点切线等价于贝塞尔手柄；不是把强度增至极端的高阶全局多项式。
- 不增加点击坐标反向映射；原Warp覆盖层的输入边界不变。
- 回滚记录见 [开发前回滚点](bezier-rollback-20260917.md)。
