## 根因与改动

浏览器及网页视口始终为7680×936，原型设计3840×1400。ProtoPie `scaleToFit=true` 使用宽高最小比例，按高度缩至0.668571倍后仅宽2567.31，因而反射画面缩在中间。此前加载识别只说明原型存在，不能证明内容铺满；全屏检测也遗漏内容尺度。

新增「ProtoPie 联动 → 横向顶满（等比例）」。播放器布局容器按设计比例扩为7680×2800并居中，由ProtoPie自己的resize逻辑计算2倍缩放。保留原生transform状态、viewport、DPR、圆形cursor及事件坐标链，不直接覆盖光标或额外缩放CDP点击。视口只显示居中936像素高的部分，未将画面非等比拉成超宽。

准备捕获与自动恢复都核对内容宽度、等比和居中；刷新后重建监听，resize/根节点变化时更新。只在配置对应的HTTPS Cloud路径执行，SPA换路径时恢复原样式并卸载监听。关闭选项可回到原有适配。新增独立上下位置滑块/输入（-1到1，负上正下）；改草稿后应用生效、保存持久化，未改Warp裁切滑块。旧配置缺fillWidth时默认false、缺位置字段时居中0，不丢链接、书签及原选项。
