# v0.11.3 (30)：九圆标定与垂直压缩 / 拉伸

2026-09-18，按用户要求增加九圆比例标定，将垂直调节范围扩至用户确认的 **0.12～5.50**，上下弧度上限调整为 **3.00**。

## 操作

1. 在「标定与画质」勾选「显示标定网格、九圆、中心线和边界」。左中右、上中下共九个琥珀色圆与原网格一起显示。
2. 切换「整体校正 → 4. 基础校畸变」，用「垂直压缩 / 拉伸」调节，右侧显示当前倍率。小于1压缩、大于1拉伸。
3. 在最终观察位置检查九圆是否等宽等高，并结合局部、贝塞尔微调处理不同区域的剩余偏差。一个整体倍率不保证能消除各处不同的光学畸变。
4. 「恢复垂直基准（1.00×）」只复位新倍率，保留原有基础校正。超过黄色 AA 区的图形仍会被裁切；极端参数仍须通过既有曲面安全检查。

九圆按**网格基准画布的逻辑像素**绘制，横纵直径相等，中心为每个方向的1/6、1/2、5/6，半径为基准画布短边的0.28/3。它们经过同一镜像和 Warp 渲染路径，变形后允许成为椭圆，以反映实际比例；扩展画布不会重新铺满或放大九圆。中心线、边界与方向角标保留。

## 数据与几何兼容

新增 `manual.verticalAspectScale`，默认1，范围0.12～5.5。原 `manual.verticalScale` 继续按旧光学模型使用，不覆盖已有校正值。简单放大旧字段范围会在反向模式下产生方向反转或被边界归一化抵消，因此新倍率在基础、局部和贝塞尔位移之后、自动居中居正之前作用于整幅曲面。关闭基础校畸变时，新倍率暂不生效，数值保留。

配置 schema 12→13；缺少新字段的旧配置、预设与历史按倍率1读取。首次加载后活动配置可能正常写为 schema 13，不能用保存字节不同推断旧参数丢失。回滚旧App须配对旧schema偏好，不能将schema13直接交给旧版本。

扩展画布下缩放围绕固定画布基准的物理中心，调整 AA 只改变裁切。局部交点和贝塞尔编辑器将物理像素位移转换到倍率前的模型坐标，保持方向键及拖动含义一致。
