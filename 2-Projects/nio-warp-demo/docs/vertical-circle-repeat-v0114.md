## 渲染规则

横向圆心固定在基准画布1/6、1/2、5/6，纵向圆心为`(n + 0.5) / 3`，其中`n`可为负数或大于2。Shader只限制横向单元索引，纵向使用`floor`连续重复；圆半径与原版相同，按基准画布短边的0.28/3计算。

以本次网格基准12000×1500、完整画布13000×2800为例，圆直径280逻辑像素、行距500逻辑像素：源画布包含5行完整圆，上下边缘另各有一行残弧。最终反射可见数量仍由当前Warp、AA与玻璃可视边界决定；重复提供更多可选标定圆，不把裁切边缘的残圆重新变成正圆。
