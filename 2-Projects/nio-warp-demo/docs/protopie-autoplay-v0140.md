## 使用

1. 左侧添加、改名、复制、排序、启用来源；「预览所选」只打开该来源。
2. 为每个链接编辑初始化和演示步骤，支持等待、按键、长按、鼠标移动、单双击、长按、拖动、滚动。提供数字小键盘 `2 → 0 → 1 → 2 → 3 → 4` 模板。
3. 鼠标取点保存源画面的百分比坐标；执行前检查位置可见性，不把不可见按钮吸附到其他位置。在线原型按钮布局改变后，需重新取点或试播。
4. 各链接设置驻留时长，整场设置小时、分钟、秒，或明确勾选无时限。单项只算就绪后的演示时间；整场截止包含加载、暂停、重试。
5. 本机手动操作暂停自动演示。继续时刷新并从初始化重新执行；Esc 停止自动任务并按原方式返回工作台。总截止可保留预览或停止联动返回工作台；保留预览不等于冻结原型动画。

脚本支持普通 DOM 键名并区分主键盘/数字小键盘；不提供任意 JS/Shell，Esc、Cmd、Ctrl 不能用于自动脚本。原手动输入的 IME、高级手势及系统快捷键边界不因此扩大。

## 稳定性设计

- 同一个输入连接串行处理脚本与人工接管；先平衡旧按键/鼠标，再重放真人首动作。
- 离开预览与重新进入也按顺序处理，缓存超限安全停止，避免遗留按住状态。
- 切换来源取消旧任务并等待清理；旧 driver 迟到完成时释放未提交的窗口，不能重新夺焦点。
- 自动模式由播放调度器统一管理恢复预算；旧 Coordinator 不同时重试。连续失败按有限预算跳过，全部失败暂停。
- 总时限、准备和动作都有独立看门狗；停止或暂停会同步使旧代次失效。没有开机自动恢复自动脚本。
- 显示器真实重建时暂停计划；原有稳定外屏合盖保留逻辑继续使用。参数手调时暂停自动任务。
