# NIO Warp v0.4.0 自动全屏内容跟随验收

验收时间：2026-08-13

## 实施结果

- 输入源支持“整个外接屏幕”和“自动跟随全屏窗口”。
- 自动模式每 0.5 秒扫描一次 ScreenCaptureKit 可捕获窗口。
- 候选窗口必须位于目标外屏、不是 NIO Warp 自身、覆盖外屏至少 82%，并连续两次稳定命中。
- 命中后使用 `SCContentFilter(desktopIndependentWindow:)` 动态切为单窗口捕获，不重启 Metal 输出。
- 窗口退出全屏或关闭后，连续两次未命中即恢复整屏捕获。
- 单窗口尺寸按 ScreenCaptureKit 的 point-to-pixel scale 计算，保持源比例后继续使用既有“铺满裁切”映射。
- 外屏覆盖窗口增加 `.fullScreenAuxiliary`，可随第三方全屏 Space 显示。

## 动态切换探针

使用覆盖外屏 98% 以上的独立 AppKit 窗口模拟播放器全屏：

1. 初始状态为“整个外接屏幕（等待播放器进入全屏）”。
2. 探针窗口出现后成功切到单窗口捕获，捕获尺寸为 5088×2848 px。
3. 探针退出后成功恢复整屏等待状态。
4. 连续执行 5 轮切入/退出，5/5 通过，无状态卡死或进程退出。
5. 第 3 轮采样：NIOWarpApp CPU 约 11.8%，RSS 约 135 MB。

## 验收边界

- 已证明 ScreenCaptureKit 能稳定完成“整屏 → 大窗口 → 整屏”的动态切换。
- 仍需用户用实际播放器（IINA、QuickTime Player、图片查看器）进行视觉验收，确认播放器自身控件、字幕和黑边策略符合预期。
- 自动模式不会改变“不压扁”的原则。16:9 内容铺满约 8.2:1 画布时必然大幅裁掉上下区域；若要求完整内容，只能改用完整显示并接受黑边。
- 播放器视频帧内部自带的黑边目前不会自动识别，属于后续 P1。
- 鼠标点击坐标逆 Warp 仍未实现。
