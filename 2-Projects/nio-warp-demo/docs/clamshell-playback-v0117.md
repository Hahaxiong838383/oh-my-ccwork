# v0.11.7 (34)：合盖保持外屏演示

## 根因

v0.11.6 修复了存活预览退出全屏的恢复，但原显示会话策略仍要求至少两块屏幕。用户实际合盖后，现场只有 AUO 外屏 id4（7680×936），`AppleClamshellState=Yes`、外屏 active=true/asleep=false，系统和显示器自动休眠均为0。应用却因 `screens.count < 2` 返回无可用拓扑，停止捕获并隐藏 Warp，显示等待内屏的工作台。这是应用逻辑缺陷，不是电脑睡眠。

## 修复行为

- 唯一外屏支持合盖运行和冷启动，控制屏可为空；只剩内屏时仍不会捕获/覆盖内屏。
- 已选外屏优先保留，不因主屏变化或屏幕数组顺序变化改换输出。
- 原外屏仍活跃、未休眠且像素尺寸/缩放不变时，保留原 renderer、capture、ProtoPie 页面与 session epoch。仅调整输出窗口 frame；桌面原点从(1512,0)变为(0,0)不会销毁会话。
- 合盖自动隐藏工作台，不抢焦点；开盖后工作台迁回内屏。用户在单外屏状态主动打开工作台时，明确暂停输出以便操作；点击恢复输出会隐藏工作台继续演示。
- 睡眠通知独立核对目标外屏的 CoreGraphics 状态，使用缓存输出 ID 应对 NSScreen 的短暂缺失，不将内屏休眠或正在重建误认成外屏休眠。
- 外屏真实断开、休眠或像素模式变化仍重建；短暂 inactive 后即使原外屏很快返回，也要完成这次重建，避免临时隐藏后永久不可见。
