5. 因而能定位到旧输入模式切换后，反向开关继续保留的配置组合。该时间段没有完整设置变更审计，不能归因给某个人、某次点击或某个代码提交。
6. 鼠标设置是全局 `nioWarpMouseMapping.settings.v1`，不包含在各屏幕 WarpConfiguration 或命名预设内。换屏/恢复屏幕预设可以改变画面镜像，却仍沿用原鼠标模式与方向。这是后续按屏配置需要解决的边界，本轮不扩展实现。

旧 v0.12.2 的方向确认针对后来被用户否定的新增圆圈十字，不能作为原生圆圈的确认依据。本轮明确验证原 ProtoPie CSS 圆圈与真实玻璃方向。
