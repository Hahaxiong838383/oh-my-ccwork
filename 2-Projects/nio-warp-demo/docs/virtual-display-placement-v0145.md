## 修复边界

- 自有虚拟屏创建或换尺寸前记录非自有屏的身份、模式、主屏/镜像和位置。模式就绪后恢复该次资源操作前的实体布局，将本实例持有的虚拟内容屏安置在外侧。
- 保留捕获中的旧来源直到新来源首帧验收；释放旧源后再次有界复核。协调器等待这一阶段完成后才发布running、开放输入；失败或被取消不能发布过时的就绪。
- 热插拔、模式、主屏或镜像变化使旧快照失效，不把旧布局覆盖到新硬件状态。只调整本次资源操作周围的排列，最多有限次尝试；同尺寸稳定复用不强排，无持续布局监控、不改永久系统设置。
- 不修改AA、曲线、镜像、取景、预设和鼠标方向，不删除用户的虚拟屏。其它进程的屏幕作为不可移动锚点。
