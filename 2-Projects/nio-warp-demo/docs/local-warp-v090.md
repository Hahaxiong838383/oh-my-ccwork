# v0.9.1 整体幅度增强与局部交点精调

## 范围

用户确认采用“保留现有基础/多项式 + 独立局部修正层”的路线。旧参数不乘倍数；强度上限由 1.5 放宽至 2.25，弧度上限由 0.20 放宽至 0.30，后台强度限幅同步至 2.25。其他基础滑块范围不变。

数据流为基础映射 → 局部物理像素位移 → AA 裁切，局部层之后不重新归一化全画布。桌面、视频、标定图共用最终网格。

## 坐标与插值

schema 10 增加 `localWarp`，默认关闭；旧配置缺省为无局部修正。局部参考记住网格基准尺寸、参考域和当时格距；锚点以中心为原点的参考坐标存储，而不是只记行列号，位移以外屏物理像素保存。扩大画布、改变网格密度和重设外扩起点都不重建此参考。

使用有限支撑平滑径向基函数求解锚点约束。多个锚点联合求解，不采用简单相加导致已校点漂移；影响范围以冻结格距为单位。参考边界保护使用固定域内的平滑衰减，外扩时不移动保护域。解除锁定是显式操作；边界上已有非零修正时不能无声强制锁定或清空。

局部位移只在基础映射完成后加入，不乘全局强度、也不再适配 AA。渲染网格的采样轴纳入已编辑锚点，非均匀单元按源坐标跨度计算形变条件数，避免把正常的细分单元错判成危险缩放。首次设点补偿旧渲染网格的插值残差，使首个 1 / 0.1 px 步进以实际显示位置为起点。

## 编辑与系统保护

- 独立内屏窗口使用已验证的生产网格进行命中定位和绘图，不依赖外屏鼠标逆映射。已保存锚点优先命中，变更网格密度后仍可选择旧锚点。
- 提供方向键、Shift/Option 步长、箭头按钮、缩放/平移、放大对比、参考边界锁定、复位、移除和撤销。单纯打开窗口不保存局部参考或开启修正。
- 计算由后台串行队列执行，25 ms 合并窗口和取消令牌丢弃过期任务；主线程只安装验证通过的网格。未通过或等待计算时保持旧画面，不重启捕获或覆盖当前多项式。
- 连续按键使用编辑草稿累积目标，避免后台尚未应用时多次按键只剩一步；已通过的结果自动保存，按键重复合并历史。
- 原始反射网格和 A/B 预览同时关闭局部层但不删除数据；进入这些模式、修改主配置、关闭编辑窗口或断屏时取消未应用请求，避免旧结果回写。
- 新窗口使用 ARC 所有权，`isReleasedWhenClosed=false`；主控制台替换时关闭旧编辑窗口，保持既有拔屏恢复策略。编辑窗口优先并保持在内屏。
- 参数页与新编辑侧栏使用覆盖式滚动条，避免传统滚动条出现后占去 17 pt 导致首次布局宽度不一致；没有修改系统的滚动条设置。

当前最多 64 个锚点，位移每轴 ±1000 px、影响范围 0.5～4 参考格；更早触发几何危险时直接拒绝，不能用上限替代安全校验。局部层不是多项式拟合器，完整 JSON/预设包含局部数据；单一多项式输出仍需另行拟合和误差评估。

## 自动验证

111/111 测试通过：旧配置迁移、扩展强度上限、多锚点插值、有限支撑、边界锁定、B 外扩/重设起点/AA 裁切不漂移、实际网格锚点定位、首个亚像素位移、反查命中、异步合并/取消、失败不保存、撤销、预设往返、待机只读和窗口布局。

0.9.0 候选版实机检查发现放大图向主预览区域越界绘制。0.9.1 在自绘视图中显式建立并恢复裁切区，避免依赖 AppKit 的默认绘图裁切行为；新增像素回归用例在修复前发现 950 个外区像素被改变，修复后要求外区保持不变。该问题位于编辑窗口绘图，不改变外屏网格或校正参数。

生产 Metal shader 的离屏像素读回证明：同一个局部修正同时移动桌面纹理标记与标定网格，不只是修改测试图。局部 CPU/网格测试验证 1 px 与 0.1 px 的实际渲染坐标变化，GPU 纹理标记验证 +6/+4 px 位移。抗锯齿与实际显示采样仍影响像素覆盖，不把子像素参数等同于肉眼可分辨度。
