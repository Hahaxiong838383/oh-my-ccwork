## 1. 打开哪个程序

控制台窗口标题和页面顶部都应该显示 `v0.9.2 (17)`。在笔记本内屏操作控制台，外接屏负责显示校正后的画面。不要运行源码目录或备份中的其他 App。

**没有外接屏时也可以打开程序。** 界面显示“等待外屏”，可查看已保存参数、切换完整曲面/AA 内预览及导出备份。修改参数、标定和画质按钮暂时灰显，这是待机而不是权限错误；程序不会捕获或覆盖笔记本内屏。接上外屏后自动恢复可操作。仅合盖外屏一块屏幕时也保持待机，避免接管唯一的操作屏幕。

## 2. 日常操作：按这个顺序

先切到顶部 **“基础配置”** 页面。三个页面的位置如下；顶部版本和简要状态不随页面切换隐藏。

| 页面 | 在这里操作 |
|---|---|
| 基础配置 | 输入源、AA 的 X/Y/宽高、逻辑画布与外扩起点、基础校畸变滑杆 |
| 光学标定 | 水平/垂直翻转、多项式系数、抗锯齿、网格行列/线宽、临时未校正和左右对比 |
| 属性设置 | 保存/应用预设、撤销设置、暂停输出、导入/导出、重置、退出程序 |

切换 Tab 只是换页，不是“保存并应用”；没有保存的输入会保留，但不生效。每页可以单独滚动。

例外：新增加的网格行列和线宽是实时控件，合法输入直接生效并自动保存，不需要另外点击保存。AA、画布和多项式的原保存流程不变。

1. **先确认当前校正画面。** 在旧模式下设置好 AA、弧度、镜像和逻辑宽高。输入中的宽高必须先保存，再开启曲面延伸。
2. 勾选 **“让画布沿当前曲线向外延伸”**。首次开启自动记住当前曲面、位置和画布大小；重复开关不会重新记起点。平时不必额外点击“把当前画面记为外扩起点”。
3. 修改宽、高，点击 **“保存并应用上面的宽和高”**。加宽沿长边向左右延伸，加高沿短边向上下延伸；中心不动，不把扩展结果重新缩回 AA。加减按钮按其提示立即应用。
4. **如果希望视频或桌面内容铺满新画布**，再点 **“把内容按当前画布重新铺满”**。它只重新计算内容的等比缩放和裁切，不改变曲面。只增加画布时，原内容大小不变，可能仍有黑区。
5. 选择 **“看完整曲面（含超出 AA 的部分）”**，检查外扩后的青色边缘；选择 **“只看 AA 内的几何范围”**，检查哪些区域会被裁切。

预览中的黄色线是 AA，青色线是当前画布，灰色虚线是记住的起点。小预览会自动缩放以便查看，这不代表外屏画布被缩回去了。

## 3. 这些按钮不要混用

| 控件 | 做什么 | 不会做什么 |
|---|---|---|
| 把当前画面记为外扩起点 | 重新标定后，把当前已保存画面作为新的扩展基准；操作前会确认 | 不改变当前曲线或内容大小 |
| 恢复到起点的宽高 | 把画布尺寸恢复为记住的起点尺寸 | 不清空弧度、多项式、镜像或 AA |
| 把内容按当前画布重新铺满 | 等比缩放桌面或视频，裁掉多余部分 | 不重设外扩起点，不把画面压扁 |
| 暂时显示原始桌面 | 隐藏外屏的 Warp 覆盖层；按钮随后可恢复校正画面 | 不清空参数 |
| 撤销上一次设置 | 恢复最近记录的一组参数 | 不是回退软件版本 |
| 重置全部参数 | 确认后恢复当前显示器的默认参数，包括外扩起点 | 不删除已保存的命名预设 |
| 退出程序，恢复原始桌面 | 退出 NIO Warp，移除覆盖层 | 不删除已保存配置 |

关闭“让画布沿当前曲线向外延伸”后使用旧的 AA 适配方式；再次开启仍使用之前记住的起点。只有明确重新设置起点，才会改写基准。

## 4. AA 和逻辑画布怎么区分

- **AA 是固定矩形显示窗口**：X 距外屏左边，Y 距外屏上边，宽高是物理输出像素。开启外扩后，修改 AA 只改变裁切范围，不自动缩放曲面。
- **逻辑画布是内容坐标范围**：宽沿弯曲长边，高沿倾斜短边。逻辑宽高不是外接矩形的投影跨度，也不要求上下、左右两边的实际弧长分别相等。
- **允许曲面越出 AA，不代表点亮 AA 外区域**：真实外屏始终只显示交集，AA 外保持黑色。青色边缘移到 AA 外后，在外屏看不到它是正常的，要到完整曲面预览中检查。

### 尺寸示例

先设 AA 为 **5000×1300**，将 **5000×1000** 的逻辑画布作为起点，再改为 **8000×2000**：

- 左右各增加 `(8000−5000)/2 = 1500` 个逻辑像素。
- 上下各增加 `(2000−1000)/2 = 500` 个逻辑像素。
- 当前多项式、曲率趋势和物理映射尺度继续生效，多余部分在 AA 边缘裁切。

**计算依据是记住的逻辑起点，不是 AA 尺寸。** 如果记住的是其他尺寸，扩展量也会不同；不要直接用 `2000−1300` 推算纵向扩展量。

## 5. 调试与玻璃拍摄

镜像、多项式、抗锯齿和测试图在 **“光学标定”** 页面；黄色 AA 与青色画布边界开关仍在 **“基础配置”** 页面。

### 编辑粗白线网格

1. 接上外屏，进入“光学标定”，勾选“显示标定网格、中心线和边界”。
2. 填“基准横向列数”和“基准纵向行数”（各 1～200）。这是网格基准画布的大格数，细灰线和红绿中心线不计入。
3. 填“白线宽度 px”（1～32，可填小数）。这是外屏物理像素的标称完整线宽，抗锯齿保留边缘过渡；过粗时相邻线可能连成块。
4. 输入合法数字或按加减按钮后，外屏实时更新并自动保存；空值或无效输入保留上一组有效画面，不改写其他输入框。
5. 查看下方“网格基准画布 / 每个大格 / 当前完整画布覆盖”说明。开启曲面外扩后，增加画布只续格，不拉伸原格子；基准行列数不会自动跳成当前覆盖量。改变校正曲线或重新设定显示映射本身仍会改变屏幕上的格子形状。

例如，网格基准为 5000×1000，设 20 列×8 行，每格为 250×125 逻辑像素；画布扩大到 8000×2000 后覆盖约 32 列×16 行，旧格点位置与格距不变。AA 裁切后看到的格数可能更少，边缘也可能只显示半个格子。

“临时显示未校正网格”在 AA 内展示基准行列数，也能实时调节，不会因此退出临时模式；由于此模式关闭曲面外扩，其实际画面与正常 Warp 模式不同。抗锯齿 A/B 使用专用图案，不受网格行列和线宽影响；基础配置页的小图也仍然只是几何示意。配置导入、导出、预设和撤销包含网格设置。

### 其他调试按钮

- **显示黄色线 / 显示青色线**：调试时打开，正常观看可关闭。
- **显示标定网格、中心线和边界**：用网格代替桌面内容检查曲面和镜像；关闭后回到桌面或视频。
- **临时显示未校正网格**：暂时关闭基础校正、多项式和外扩，供拍摄玻璃的原始反射；不会覆盖保存参数。点击“返回校正画面”恢复。
- **对比抗锯齿：左关 / 右开**：左右是相同图案，只比较平滑效果。结束对比后回到进入前状态，包括之前的未校正预览状态。
- **紧急恢复原桌面**：按 `⌃⌥⌘Esc`（Control + Option + Command + Esc）。

## 6. 遇到问题先看这里

| 现象 | 先检查 |
|---|---|
| 改了数字但没变化 | 是否保存了宽高；曲面延伸开关是否开启；是否仍在临时未校正模式 |
| 画布扩了，但视频没跟着铺满 | 画布扩展与内容缩放分开控制；需要时点击“把内容按当前画布重新铺满” |
| 青色边界消失 | 可能已移到 AA 外；切换到“看完整曲面”查看，不要直接重设起点 |
| 报告有采样点在 AA 外 | 正常裁切提示，不等于算法失败 |
| 报告翻折、自交或不安全缩放 | 该次参数不会应用；减小尺寸或系数，上一组有效设置仍保留 |
| 外扩量与示例不一样 | 查看“记住的起点”，它可能不是 5000×1000 |
| 拔出外屏后 App 退出 | 先确认运行的是 v0.6.2 (12) 或更新版本；v0.6.1 的输出窗口关闭释放缺陷已修复。若再次发生，记下发生时间便于查崩溃记录 |

## 8. 局部交点精调：先整体，再局部

1. 在“基础配置”把整体曲率大致调到位。Warp 强度最大 2.25、上下弧度最大 0.30；这只是上限增加，旧值不自动变化，危险组合仍会拒绝。
2. 需要观察网格时，到“光学标定”开启标定网格，再回到“基础配置 → 基础校畸变”，点击“打开局部交点精调”。也可保持桌面/视频输出，局部变化同样作用于它们。
3. 在独立内屏窗口勾选“启用局部修正”。首次启用会记住局部参考域和格距，没有锚点时画面不变；单纯打开窗口不会保存新参数。
4. 点击预览网格交点，橙点即当前选择。使用方向键或箭头按钮移动；默认 1 px，Shift 为 10 px，Option 为 0.1 px，也可用步长选项。方向以物理外屏为准，玻璃反射后的方向需现场观察。
5. “放大/缩小/适合窗口”控制预览；拖动或双指滚动只平移视图，不拖动交点。下方是局部放大图，灰十字代表基础位置。网格过密时先放大；预览会抽样显示密网格，选点仍依据完整网格。
6. 连续按键会合并后台计算；显示“正在验证”时外屏保留上一有效画面。通过后自动保存，原多项式不改。若出现折叠、自交或不安全缩放，整步拒绝，不把坏数据送到外屏。

| 操作 | 含义 |
|---|---|
| 影响范围 | 原“平滑范围”，决定带动周围多远；以建立局部参考时的格距为单位，可选 0.5～4 格 |
| 过渡平滑度 | 一级标准（保留旧效果）、二级高阶、三级更高阶；改变锚点之间的过渡曲线，已定位的锚点目标保留。不是全局多项式阶数，也不是抗锯齿开关 |
| 打开全局多项式设置 | 跳到“光学标定”的多项式部分，只导航不修改参数；该部分也有返回局部精调的入口 |
| 微调时锁住参考边界 | 默认开启；锁定的是首次局部标定时的参考域，不跟随之后的画布增长重新移动。编辑新增外侧区域前可解锁 |
| 复位此点到基础位置 | 把该点偏移设为零，并保留这个约束；不是删除整个局部层 |
| 移除当前锚点约束 | 删除该点约束，其他锚点仍可能影响此处；可撤销 |
| 撤销上一次设置 / Command-Z | 使用现有完整设置历史，恢复最近一次修改前的数据，不是回退软件版本 |
| 关闭“启用局部修正” | 仅关闭该层，保留所有锚点与原多项式，便于对比 |

最多保留 64 个锚点；偏移上限为每轴 ±1000 px，实际可用幅度还受防翻折限制。改变显示网格的行列数不重新定位已存锚点；改变整体曲率会改变基础映射，已有局部偏移仍保留，建议重新复核。参考坐标与基准格距是冻结的，后续扩大画布只续格，不重设锚点。

无外屏或处于“临时未校正网格 / 抗锯齿 A/B”时，编辑窗口只读；先恢复正常校正输出再编辑。关闭编辑窗口不会退出主程序；断屏重建会关闭旧编辑窗口、取消未应用请求，已保存的锚点仍保留，接屏后可重新打开。全局紧急隐藏仍为 Control-Option-Command-Esc。

这里只实现编辑预览的命中定位，没有接管外屏鼠标坐标。请继续在内屏操作。完整备份和预设包含局部层；不能把它冒充成已经重新拟合好的单一多项式。

### 如何比较三级平滑

先启用局部修正，选一个交点产生可观察的偏移，然后保持交点偏移和影响范围不变，依次切换一级、二级、三级。观察该点周围的曲线，而不是等待交点再次移动；其他已经约束的锚点也应保持原位置。没有锚点、偏移全部为零、局部层关闭或处于临时未校正/A-B 模式时，看不到等级差异是正常现象。

这里的三级分别采用 C2、C4、C6 局部插值核，不是一次、二次、三次全局多项式。更高阶强调核函数的高阶连续性，不代表影响更远、幅度更大或一定更适合当前玻璃；最终仍受参考边界保护、网格离散化和防翻折限制。想带动更大片区域，调整“影响范围”；想调整整幅画面趋势，再去多项式设置。不要同时改这两类参数做比较。

v0.9.2 使用 schema 11；原 schema 10 配置缺少平滑字段时默认为一级，保留原画面、锚点与多项式。回滚入口为 `.rollback/20260908-183806-local-smoothing-baseline/RESTORE.md`，包含用户已确认基本功能正常的 v0.9.1 (16)。降级前先保护最新参数，再恢复旧版支持的兼容快照。
