## 判断边界

| 现象 | 处理 |
|---|---|
| health 超时、页面通信失败、捕获不匹配、输出持续不可见 | 保存异常与持续时间，不能只看 UI 的“正在播放” |
| 切换期短暂两个页面 | 正常候选与旧页交接；持续多于两个页面才作为疑似积累 |
| Chrome 多个 Renderer/GPU 进程 | 按专用 profile 的进程树统计，不能把多进程当多个播放器 |
| 静态画面、媒体 ended/paused | 不直接判卡死；结合来源切换、页面响应和业务状态 |
| GPU FPS 约 60 | 只证明渲染循环，不能证明源内容或光学画面正常 |
| 内存单次峰值 | 先观察暖机与回落；持续趋势才标记疑似增长，不直接认定泄漏 |
| 用户暂停、主动退出、改参数或换屏 | 单独记录中断/分段，不能混报为崩溃，也不能继续声称固定基线 |
