# v0.8.0 固定格距的可编辑标定网格

## 用户确认的 B 口径

基准行列数决定基准画布上的格距。开启曲面外扩后，增大逻辑画布只扩大取样坐标域，旧格点位置和格子尺寸保持，新增部分沿当前曲率续格，不把固定数量的格子拉大。

- 网格基准沿用既有 `canvasReference.gridCanvas`，修改画布尺寸、重新设置外扩起点、重新铺满内容或调整 AA 裁切不改写它。
- `格宽 = 基准宽 / 列数`，`格高 = 基准高 / 行数`。行列数各支持 1～200；修改行列数是用户主动重新分格，会改变格距。
- 完整画布覆盖量 = 当前画布尺寸 / 格距，可为小数；不等于 AA 裁切后可见的格数。端点按既有中心对称相位延伸，未强制把残格挤成整数格。
- “格子不变”针对保持当前光学映射的画布外扩，不表示不同位置的曲面格子必然有相同物理弧长，也不阻止用户主动修改多项式/曲率或改变显示映射。
- 外扩关闭时保留原来的 AA 适配逻辑；临时未校正图也关闭外扩，在 AA 内展示基准行列数。

## 数据与渲染

schema 9 增加 `render.calibrationGrid`：`columns`、`rows`、`lineWidthPixels`。旧配置缺省为 10×10 和 2 px，保留旧网格基准及相位，不更改 AA、画布、曲线、镜像或多项式。

Metal 每帧读取格数与线宽；主网格仍走镜像后的同一 Warp UV。细灰线按每个大格 5 等分；红绿中心线、方向角标与画布外轮廓保持独立，不纳入主网格数量或线宽设置。标称完整线宽用局部屏幕导数的欧氏长度换算，以外屏物理像素而非 Retina points 计；抗锯齿只改变边缘覆盖，不改变格点中心。

`updateCalibrationGrid` 只更新绘图参数，不重建网格或重置自动降级状态。控制台合法文本变化立即更新并自动保存，单次编辑/连续微调合并历史；新网格字段使用严格整数解析，不复用会四舍五入的旧尺寸解析器，也不让 NumberFormatter 改写半输入文本。原 AA、画布及多项式的手动保存行为不变。

临时未校正模式下可调整网格，但不退出预览、不保存临时关闭 Warp 的状态。A/B 专用诊断图不受网格参数影响。无外屏继续只读，不启动内屏捕获。

## 验证

- 93/93 自动测试通过，新增 14 项涵盖配置迁移/验证、格距与旧格点保持、AA/重设起点/内容重铺不影响网格、预设往返、原生文本编辑实时回调、无效输入、加减边界、历史合并和待机只读。
- 用生产 Metal shader 在离屏目标实际渲染并读回像素：行列变化可见，2/4/8 px 白线在抗锯齿开关两种状态下满足 ±1 px 采样容差；避开彩色中心线的覆盖区域计量。扩大画布后原区域的白线位置与线宽不变。
- A/B 专用图在改变网格参数前后逐像素相同；网格编辑期间 renderer 的 meshRevision 不增加，临时标定不退出，捕获回调未触发。
- 3840×2160 离屏 GPU 对照，预热 4 轮、记录 20 轮：旧版中位 3.472 ms / P95 10.206 ms，新版中位 3.496 ms / P95 10.238 ms。该微基准没有发现明显 GPU 增量，但不代表包含屏幕捕获、桌面合成和呈现的稳定 60 FPS，也不替代外屏长稳与真实玻璃验收。

可设置 `NIO_WARP_GRID_PREVIEW_DIR` 输出合成网格 PNG；可设置 `NIO_WARP_GRID_BASELINE_SHADER` 指向改版前 shader 原文运行可选 GPU 对照。图片、基准提取文件和日志仅存本机临时目录，不上传 Git。
