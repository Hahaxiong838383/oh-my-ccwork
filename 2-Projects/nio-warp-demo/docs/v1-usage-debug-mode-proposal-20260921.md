## 界面与操作

1. 启动默认「使用模式」，默认选中最右侧「ProtoPie 联动」。七个Tab的名称、顺序和位置保持，只有「预设与历史」「ProtoPie 联动」可选择；其余五项置灰并带锁标识。
2. 顶部保留当前版本、模式状态和原「退出程序」二次确认；新增「调试模式」按钮。点击后在工作台弹出密码输入框，使用用户指定的口令，密文输入。错误或取消均保持使用模式，不改变配置或播放计划。
3. 验证成功显示「调试模式」，解锁原有全部功能。顶部按钮变为「退出调试」。模式区别使用文字和锁图标表达，不只依赖颜色。
4. 解锁只存于当前App会话，退出重开或重启电脑后恢复使用模式；合盖、翻盖、显示器刷新和控制台重建沿用本次会话，避免打断正在进行的调试。
5. 点击「退出调试」重新锁定，当前若在受限Tab则回到「ProtoPie 联动」。保留已保存参数和既有演示状态；临时网格/A-B预览、进行中的调试拖动和异步编辑应先有界结束或撤销未提交部分，避免锁定后留在无法关闭的调试画面。
6. 使用模式持续按原参数进行Warp、全屏恢复、原圆圈接管、AA边缘限制、键鼠透传和自动轮播。模式权限限制用户编辑，不拦截必要的运行恢复。

## 推荐权限细分

下表中两个开放Tab内部的保护属于本方案的**额外细分建议**，已随预览由用户确认；两个Tab保持日常操作能力。

| 操作 | 使用模式 | 调试模式 |
|---|---|---|
| ProtoPie 链接添加/编辑/命名/选择、预览、重试、轮播、脚本、播放时长、日志 | 可用 | 可用 |
| ProtoPie 页面内的取景/适配 | 可用；只改原型播放配置 | 可用 |
| ProtoPie 内「整幅画面上下位置」 | 灰锁：实际写入屏幕Warp参数 | 可用 |
| 预设查看、选择、应用 | 可用；应用前确认预设名称和当前屏幕，沿用尺寸兼容检查 | 可用 |
| 导出当前参数备份 | 可用 | 可用 |
| 保存/覆盖/删除预设、导入参数、重置全部、撤销/版本回退 | 建议灰锁，避免改坏已验收配置和备份 | 可用 |
| 画布与输入、整体校正、局部微调、标定与画质、鼠标映射Tab | 不可进入 | 可用 |
| 顶部校正撤销、暂停校正等调试入口 | 灰锁 | 可用 |
| 已有预览播放/暂停、Esc返回、紧急退出、退出程序二次确认 | 保留 | 保留 |

「应用已有预设」是使用模式有意允许的整套配置切换，不能被通用“禁止写入参数”误封。切换模式本身不建立一套新校正数据，两个模式共用当前已验证参数和预设。

## 实现边界

- 新增App级模式状态、密码校验及操作权限枚举。暂定产品版本 `1.0.0`，build递增为77；正式实现前复核最新build，避免与并行发布冲突。
- UI启用条件统一为「当前运行条件满足」且「模式允许该操作」；页面刷新、等待外屏和切源完成回调都须沿用该判断，不能刷新后意外启用。
- Tab、Cmd+数字、菜单、直接selector、跳转按钮、工作区恢复及鼠标拖动入口统一校验；具体写动作再次校验，避免仅有视觉置灰。
- 参数写入按操作来源区分：日常应用已有预设、用户调试编辑、既有运行恢复。保留运行恢复与使用模式允许的预设应用，不重写几何算法、CDP、虚拟屏生命周期或原生输入映射。
- 异步曲面编辑任务携带模式代次，退出调试后取消/拒绝过期回调落盘；已经接受保存的参数保持。
- 密码以校验值保存，不写日志、配置导出或共享记忆；本方案文档不存口令明文。解锁状态不导入/导出，也不从历史偏好恢复。
- 密码弹窗期间增加工作台输入独占：释放当前演示持键/鼠标，临时禁止自动接管、切链重绑和外屏点击抢走密码框焦点；保留页面、CDP和播放计划。密码只进入本地密文框，不透传给ProtoPie，也不记为人工接管或脚本输入。弹窗内Esc仅取消；关闭后恢复“点击外屏接管”的就绪状态，不自动抢焦点或启动原本暂停的计划。不借用会停止计划的 `returnToWorkbench`。
- 调试网格属于现有持久配置。退出调试时在运行时渲染副本中收起网格/辅助线、退出临时A/B画面，磁盘配置不变；再次调试恢复其设置。原圆圈接管的网格判断须依据实际渲染状态。异步草稿取消后回显 `lastAppliedConfiguration`，不通过历史回退或额外保存实现退出调试。
- 日志仅记录解锁成功/失败、退出调试、权限拦截及操作类别；不记录输入内容。

## 执行与验收

1. 在已固化基线之上独立实现模式与权限层，先完成权限矩阵、认证和会话生命周期验证。
2. 接入现有页面、顶部工具、快捷键、预设例外操作及异步编辑取消；不发布新的几何/轮播实现。
3. 验证使用模式仅两Tab可进入、错误密码与取消无副作用、正确密码解锁、重新锁定、重开App恢复锁定；覆盖直接动作与刷新绕过。
4. 验证使用模式的预设应用/导出、链接切换、脚本与轮播、全屏、原圆圈方向/点击/键盘、按当前配置的闲置光标隐藏、AA边缘与Esc、合盖/翻盖和退出确认；密码框保持打开跨越一次轮播切链，验证密码和焦点不进入预览页面。
5. 对比安装前后9组现有参数，确认升级不重置、模式切换不改值；使用已固化标签与最新参数配对备份演练回滚。
6. 用户确认方案后再构建安装V1.0并进行实机验收。当前开发机继续使用v0.14.8。
