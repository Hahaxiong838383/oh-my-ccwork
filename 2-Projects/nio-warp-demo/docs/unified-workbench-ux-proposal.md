# NIO Warp 单窗口工作台 UX 提案

状态：单窗口设计及 ProtoPie 联动模块已获用户认可，2026-09-17 已完成 v0.11.0 原生实现和197项软件测试，待安装体验。用户指定 ProtoPie Tab 放在最右侧。2026-09-17 用户已在 Air 体验 v0.10.0 并确认“功能没问题”，本轮问题集中在窗口遮挡、功能切换与预览联动配置。

## 推荐方案

单一普通层级工作台，6 个一级模块 Tab，共享几何预览画布，右侧随模块切换参数。外屏继续显示 Warp 输出；不把专用输出窗口作为用户调节窗口。主窗默认不置顶，提供主动“保持置顶”开关，记忆窗口位置和尺寸。

改版前主控制台和交点精调窗口均为 `.floating`，贝塞尔窗口为 `.normal`，层级不一致导致普通编辑窗口被遮挡。改版只调整内屏工作台层级，保留外屏覆盖窗口的既有策略。

| 一级模块 | 内容 |
|---|---|
| 画布与输入 | 捕获来源、AA 矩形、逻辑画布、外扩、适配/裁切、镜像 |
| 整体校正 | 强度、上下弧度、垂直压缩、不对称、倾斜/弯曲、吸附与居正；多项式置于明确的高级折叠区 |
| 局部微调 | 贝塞尔曲面、交点精调两个工具；在同一画布上切换相应操作覆盖层和参数，不再打开窗口 |
| 标定与画质 | 测试网格、临时无畸变/抗锯齿 A-B、格数/线宽、采样档位、性能状态 |
| 预设与历史 | 预设保存/应用、统一历史回退、参数导入导出、重置 |
| ProtoPie 联动 | 云端链接 / 本地 .pie 文件、自动启动与恢复、目标屏幕、立即启动/替换/重试、来源与捕获状态 |

初版为 5 模块；按用户追加需求增加独立 ProtoPie 联动入口，按用户要求放在最右侧，保持前五个模块的顺序。贝塞尔与交点仍保持同一模块的两种工具。6 个标签在 Air 的最小工作台宽度下必须完整可见，不把 ProtoPie 藏入更多菜单；更窄的说明原型可换行，原生 App 保持最小宽度。

## 固定区域

1. 标题/工具栏：版本、外屏与捕获状态、全局撤销、显示原始桌面、可选置顶。停止输出入口在所有模块可达。
2. 一级 Tab：只用于导航；选择态不能表示某个修正层已启用。
3. 左侧主要区域：同一几何预览，保持比例、观察中心与缩放；模块改变工具覆盖层，保留最终合成曲面。几何预览不包装成已经实现的实时桌面/ProtoPie 预览。
4. 右侧参数区：默认366 pt，可在350–440 pt调整（原提案280–310 pt经原生控件适配后加宽），可调分隔线，独立滚动；常用参数靠上，高级项和说明展开查看。
5. 底部：有效修正层摘要、正在校验/已保存/修改拒绝状态、当前选点信息。状态配文字，不仅依靠颜色。

建议初始约 1120×720 pt，并根据 Air 实际 visibleFrame 限制大小。支持 1040×650 的可达布局，记忆各模块参数栏的滚动位置。工作台整体无需随参数区滚动。

## 状态与交互约定

- 切 Tab 不重开窗口、不重启捕获、不修改图层开关、不新增历史；外屏持续输出。主窗口不因切 Tab 重新置前。
- 保留选中点/手柄、锚点、联动范围、精调步长、画布缩放与观察位置。模块未提交的数字输入也保留；点击 Tab 不能悄悄提交或丢弃草稿。
- 延用已验收逻辑：拖动是本地候选预览，释放后校验，成功后才替换外屏与保存；失败显示原因并保持上一有效输出。
- 几何修改校验中允许切 Tab，固定状态栏说明正在处理哪个模块。第一版短暂锁住其他工具和全局几何提交以避免跨模块旧基线覆盖；当前工具连续微调继续合并校验，导航/暂停/紧急恢复始终可用；不能将旧窗口的 onClose 取消逻辑直接用于切 Tab。
- 撤销为一条全局历史，按钮或提示明确“撤销：贝塞尔节点上移”等操作对象；输入框焦点内优先处理文本撤销。
- 清楚区分“仅内屏原曲面对照”与“外屏临时标定/A-B”。进入 Tab 本身不替换外屏内容，只有显式动作改变预览模式。
- 无外屏时保持工作台和所有模块可查看，顶部常驻“等待外屏 · 校正参数只读”，导出可用。ProtoPie 来源与自动联动配置仍可编辑、保存和检查文件/链接格式；自动输出等待目标外屏，用户可单独打开播放器完成登录或预览。重连恢复当前模块、观察位置与该显示器配置，不套用笔记本内屏标定。
- 关闭控制工作台前的输出处理必须明确：建议窗口关闭时先暂停输出，App 菜单可重新打开；显式退出恢复原桌面。最小化可保持输出。具体与现有退出保护统一实现，避免不可控的隐形输出。
- 快捷键：建议 ⌘1～⌘6 切模块，保留方向键/Shift/Option 精调及既有紧急隐藏组合键；数值框编辑时不触发画布方向键。

## ProtoPie 联动模块

### 已有能力与新增范围

依据 [2026-09-16 工作流检查](protopie-workflow-inspection-20260916.md)，开发机 v0.9.10 安装版使用专用 Chrome 窗口打开 ProtoPie Cloud，等待内容加载、调整窗口位置，再由 Warp 捕获。当前 v0.10.0 源码没有该 Bootstrapper；不能把安装包存在的功能当作本分支已合入，也不能覆盖开发机保留的可用安装版。

本地 `.pie` 通过 ProtoPie Studio 打开并获得 Preview 窗口，是新增路径，需要后续实机验证应用版本、登录、窗口识别及所需辅助功能权限。Cloud 路径与 Studio 路径使用不同启动适配器，共用配置和状态界面；无需为了播放云端链接强制启动 Studio。

### 布局和操作

共享画布位置保持不变，表示有效 Warp 曲面；下方增加来源、加载、捕获、输出四步状态。此画布仍是几何预览，不假装已嵌入 ProtoPie 实时画面。右侧按以下顺序布局：

1. **预览来源**：可见分段按钮“云端链接 / 本地 .pie”。链接可粘贴、编辑；文件可选择或替换并显示文件名和路径。分别保留两种来源的草稿，切类型不立即切换正在播放的内容。
2. **自动联动**：“打开 NIO Warp 时自动启动预览”；可选“意外中断后自动恢复”。关闭自动开关只改变后续行为，不立即停止本次播放。停止操作暂停本次恢复，用户主动重启后才恢复自动管理。
3. **播放与目标**：默认沿用“画布与输入”的目标显示器，允许在此修改同一个共享选择，禁止维护两份屏幕配置。云端提供等比适配、隐藏播放工具栏；原型尺寸与 Warp 逻辑画布不同须提示，由用户显式选择调整，不重置标定参数。
4. **操作区**：“保存配置”与“启动预览”分开；运行时主按钮为“应用并切换”，另有“重新加载”“停止联动”。替换来源后先检查、加载候选源，验证捕获收到帧后再切换；失败保留仍有效的旧来源。若无法并存两个 Studio 预览，切换期间隐藏覆盖层，失败按已保存旧来源恢复，不承诺视频级无缝切换。
5. **状态与排障**：分别显示播放器/页面、捕获对象、外屏输出的真实状态，区分未启动、启动中、等待登录、等待预览窗口、等待外屏、运行中、已停止、失败。失败提供相应“打开播放器 / 重新选文件 / 修改链接 / 重试”入口。

### 运行与配置约定

- 自动流程：加载已保存来源 → 确认播放器与权限 → 打开候选预览 → 校验目标窗口和有效帧 → 接入既有 Warp → 恢复可用外屏输出。ProtoPie Tab 本身只导航，不触发启动。
- 窗口位置按当次目标显示器布局计算，兼容负坐标与 Retina points/pixels；不沿用旧脚本的固定坐标、固定标题或图片最小尺寸判断。来源身份与本次会话的窗口绑定，避免捕获编辑器、登录页或用户普通浏览器窗口。
- 重复点击不会产生多个播放器；同一启动器统一管理会话。后台有界重试，不抢焦点、不强制退出用户的 Chrome/Studio，不再与旧入口同时抢占调试端口。
- “停止联动”取消本会话重试、隐藏并停止该来源 Warp 输出，恢复原桌面；不退出用户播放器、不丢弃未保存的 .pie 编辑。全局“显示原始桌面”只暂停覆盖输出，不关闭 ProtoPie、不关闭自动开关。
- 运行状态来自当前进程、窗口、加载与捕获实测，不能读取历史 ready 值直接显示“运行中”。等待登录/权限时暂停自动尝试，给明确入口，用户完成后点重试。
- 来源配置独立于几何预设与撤销栈；保存校正预设不携带私有预览链接，来源切换不重置任何 Warp 参数。文件访问用持久文件引用，移动失效后要求重选；自动重载本地文件默认不启用，避免打断未保存编辑。
- 联动开关、来源草稿、最后成功来源和目标屏幕分开保存。保存配置不会改变当前输出；应用并切换成功才更新最后成功来源，失败可回退。

### 联动验收

至少覆盖：链接与文件各自冷启动；替换成功/失败及旧源保留；文件丢失、链接失效、需要登录、权限缺失；重复启动不重复开窗；无外屏等待与重连；切 Tab、改几何参数不重启播放；手动停止后不被恢复机制拉起；普通浏览器/未保存 Studio 项目不受影响；停止联动与全局暂停的 UI/实际输出一致。Air 与开发机分别验证，不能由一台的成功推断另一台成功。

## 改版范围与验收

把现有两个编辑器拆成可嵌入视图，共用配置、有效网格、校验队列与历史状态。沿用用户刚验收的变形算法与参数含义；不借本轮重做算法或迁移现场标定。

验收重点：只有一个调节窗口；切工具不改变外屏结果；同点跨工具精调、统一撤销、未确认输入不丢；异步校验时切页无旧结果覆盖；窗口失焦/最小化/关闭行为明确；Air 最小窗口所有控件可达；无外屏和临时测试图仍保持只读边界。

聊天中的交互示意仅展示布局及导航，图形和参数为示例，不连接设备，不代替原生界面或变形算法验收。本轮没有修改或替换 Air 安装版。
