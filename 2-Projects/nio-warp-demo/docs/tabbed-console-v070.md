# v0.7.0 三页 Tab 控制台

## 分组与范围

| 顶部 Tab | 原区域 | 保留的功能 |
|---|---|---|
| 基础配置 | 0、1、2、4 | 输入源、AA、画布/外扩/边界、基础校畸变 |
| 光学标定 | 3、5、6 | 镜像、多项式增量、画质与标定 |
| 属性设置 | 7、8 | 预设与版本回退、安全控制与配置文件 |

按用户明确列出的迁移范围，未指定迁移的“基础校畸变”保留在基础配置。没有需要改变算法或数据含义的冲突。

第 8 区域的所有原按钮、详细状态、紧急快捷键说明和退出入口都在属性设置。顶部另保留共享的简要运行状态，避免待机、权限或错误信息因切换 Tab 而不可见。

## 行为约束

- 使用原生 NSTabView，固定顶部导航，不把 Tab 放入长滚动内容。
- 三个页面各自拥有滚动容器和原控件实例，共用同一份配置与回调。
- 切换页面不重启捕获、不更新 Warp、不写入配置或历史，不重设画布起点；未应用的输入文本保留。
- 没有外屏时三个 Tab 都可切换；所有页面的参数修改控件保持禁用，只有原先允许的预览、导出、退出可用。
- 窗口默认宽度及最小宽度调整为 600，以容纳原生 Tab 边框和原有控件；校正算法、坐标、画质采样及窗口释放策略不变。

## 验证

新增测试覆盖 Tab 名称和顺序、区域分配、未应用输入保留、离线全页只读、全局状态可见、独立滚动及最小宽度布局。测试可用 `NIO_WARP_UI_PREVIEW_DIR` 输出合成参数的原生界面预览，仅用于布局检查，不捕获用户桌面。

本机回滚点：`.rollback/20260907-221000-tabs-baseline/RESTORE.md`。基线为 v0.6.2 (12)；回滚包、配置及截图均不提交 Git。
