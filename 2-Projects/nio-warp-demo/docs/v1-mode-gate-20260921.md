# V1.0 使用／调试模式锁（2026-09-21）

状态：v1.0.0(77) 已安装 nio-war-mac 固定路径，权限回归和真实 App 无外屏界面验收通过。开发机当前只有内屏，外屏预览、真实玻璃鼠标、合盖及长时间轮播尚未复验；不把 v0.14.8 的人验和4小时压测当作本版新验收。

## 改动范围

- 启动为使用模式，默认 ProtoPie 联动且保持最右侧；仅该页与预设与历史可进入，其余5页显示锁标识并置灰。
- 顶部调试模式使用 NSSecureTextField 校验用户指定密码，只保存带命名空间的 SHA-256 校验值；不输出口令，不把授权写入配置或日志。
- 调试模式恢复原编辑入口；退出调试重新锁定，保留已经应用的参数。AppDelegate 共享会话，窗口重建不丢失已解锁状态，App退出后失效。
- 使用模式保留链接、轮播、脚本、播放器取景及日志；物理整幅上下位置受保护。预设可选择、确认应用及导出，保存／删除／导入／重置／撤销和历史回退需调试授权。
- 权限同时覆盖Tab、快捷键、实际action、刷新及异步曲面提交；旧编辑结果不能跨越锁定后落盘。网格和辅助边界仅在使用模式运行副本收起，不覆盖保存值。
- 密码框临时隔离物理键鼠并保持原CDP脚本通道；释放旧人工按键，继续消费对应物理松开，不把密码操作当成人工接管。绑定跨过密码框后也不迟到抢焦点。关闭框不自动启动鼠标或改变计划。
- 控制屏消失时取消未提交密码，避免合盖后藏在高层输出之下；重建前先取消旧认证，避免共享认证状态让新窗口永久置灰。

生产Swift只变更 main、WorkbenchAccess、MouseMappingController、MouseMappingPanel、NativeMouseInputCapture；其余43份Swift保持原字节，含Warp数学、捕获、虚拟屏生命周期、播放器/轮播调度、CDP持久连接与原鼠标坐标算法。鼠标新增内容限权限和认证期间输入/焦点隔离。
