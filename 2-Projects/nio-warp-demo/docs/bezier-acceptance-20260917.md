## 交付内容

- 原整体 Warp、弧度、压缩等参数保留，新增二维贝塞尔叠加层。
- 默认 5 列 × 3 行，支持 2～9 列、2～7 行；增点保形，减少已编辑节点需确认重建。
- 节点与水平/垂直切线均支持多行联动、左右分区、等量/渐变传播和物理像素精调。
- 倾斜及水平弯曲近零吸附；曲面按 AA 居中、参考轴居正，保留已有曲率。
- 拖动本地预览、释放后校验；非法网格不覆盖输出，配置保存、历史撤销与旧配置迁移已接入。
- 修复开启居正后旧局部交点方向键斜移、新锚点跳动，以及两个编辑器并行提交/关闭时的任务冲突。

操作入口：「基础配置 → 4. 基础校畸变」。详细规则见 [操作说明](bezier-curve-v0100.md)。
