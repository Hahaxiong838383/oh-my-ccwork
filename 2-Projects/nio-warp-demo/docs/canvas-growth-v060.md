# v0.6.0 曲面画布扩展

## 数据与映射

配置 schema 升级为 8，增加 `canvasReference`，独立保存逻辑尺寸、内容尺寸、网格标尺、物理位置及多项式计算域。第一次启用时捕获基准；重复开关、调宽高、修改 AA 不重设基准。明确重新设起点时保持当前物理曲面和内容尺度不变。

当前画布的中心化逻辑坐标经过固定基准映射到屏幕，不再对扩展边界做 min/max 重归一化。物理 AA 最后使用 Metal scissor 裁切，青色辅助描边也使用相同矩形裁切。内屏完整预览允许显示越界几何，自动缩放只作用于小预览。

关闭外扩保留旧的 AA 适配行为。schema 7 已开启的外扩配置在迁移时捕获旧参数域和归一化变换；已有形状不会在启动时突然改变。schema 7 未开启的配置保持原样，等待用户主动开启。来源未改动 v0.5.1 数学代码的九个坐标作为迁移 golden test，覆盖非零多项式及反向趋势。

## 内容与诊断

画布扩展不会隐式缩放现有桌面或视频。内容 UV 以独立保存的内容尺寸计算；重新铺满是显式操作，始终等比缩放并裁切，不改变曲面。捕获源本身有限，扩展画布不会自动制造新的 macOS 桌面像素或窗口排版空间。

标定网格也保留固定标尺；重新记起点不改变网格间距。无畸变拍摄和抗锯齿左右对比都临时关闭外扩，不污染保存参数或历史。内屏预览随临时模式显示对应几何。镜像只改变内容方向，不改变物理 AA 或曲面形状。

## 防错与回滚

- 数字一起保存，拒绝非法或超范围尺寸；加减按钮有步长说明。
- 保存配置之前检查网格两个三角形的方向、非有限值、过度压缩以及边界自交。
- 不安全的参数拒绝应用，GPU 继续显示上一组有效几何，不先写入 defaults。
- 不把正常 AA 越界当成失败，也不通过 clamp 将越界几何拉回矩形。
- 起点重设和全部参数重置有白话确认；可从历史撤销。
- 应用只安装到 `~/Applications/NIOWarpApp.app`。构建目录及安装暂存目录隐藏，旧安装压缩为 ZIP，避免第二个可启动图标。
- 本机基线 `.rollback/20260907-143200-canvas-domain-baseline/` 支持只读校验；含源码、旧签名包及配置。该私有目录不提交。

## 验收清单

- 5000×1300 AA，5000×1000 起点：只加宽到 8000、只加高到 2000、同时扩展到 8000×2000。
- 原逻辑坐标映射漂移小于 0.003 物理像素（Float 数值测试门槛）。
- 增加宽高后真实几何越出 AA，未重新归一化；四边继续弯曲或倾斜。
- 改 AA 仅改变裁切范围；恢复宽高、重复开关、重设起点、JSON 重载没有意外漂移。
- 旧配置迁移坐标与未修改 v0.5.1 对照误差小于 0.000001 AA 归一化单位。
- 拒绝异常系数，渲染器的最后有效配置不变。
- 抗锯齿开关只改变采样，不改变几何网格；网格密度根据外扩幅度增加，上限 512×256。
- Swift 全量测试、Metal 实际着色器编译、Release 构建、签名及固定安装路径检查。
- 外屏 UI 操作、网格模式、临时未校正、左右抗锯齿对比，以及 GPU 平均/P95 和帧率实测。

自动化结果与实机结果分别记录，不能用模拟或编译成功替代玻璃反射验收。本次没有实现虚拟显示器、点击坐标逆映射或实测玻璃标定。

### 性能项：尚未完全验收

系统读取确认内外屏均为 60 Hz。恢复用户原桌面参数后，短期界面读数约 57.7～58.9 FPS，GPU 平均约 8.03～9.46 ms、P95 约 9.87～11.15 ms。外扩网格测试的静置截图约 49.4 FPS，GPU 平均 6.64 ms、P95 9.24 ms，不能因此宣称“所有场景稳定 60 FPS”或“刷新率完全不受影响”。

30 秒、10 次进程采样 CPU 平均 9.79%，RSS 约 110～124 MiB（RSS 不等于含 GPU 资源在内的全部内存占用）。3 秒调用栈采样主要停留在 `CAMetalLayer nextDrawable` 的等待路径；这只是定位线索，尚未完成对显示调度、缓冲区可用性及场景差异的归因。没有通过随意降低网格密度、修改曲线或关闭抗锯齿掩盖问题。

后续应对相同参数、相同输入内容做关闭外扩/开启外扩的独立对照，测量 drawable 等待、实际呈现间隔、GPU 时间，并完成至少 10 分钟连续验证。本项保留为待办，不与本轮功能验收混在一起。
