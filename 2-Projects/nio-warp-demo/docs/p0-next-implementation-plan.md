## 实施状态（2026-08-12）

## 结论

下一阶段先处理三个直接影响真实标定和观看效果的问题：

1. **保持画面原始宽高比，超出目标画布的内容裁切，禁止非等比拉伸。**
2. **增加“一键原始反射标定”模式，临时关闭几何校正并显示未预畸变网格。**
3. **把抗锯齿改成明确的总开关，并增加 A/B 对比测试图，使开关差异可见、可拍、可量化。**

三项均列为 **P0**。实施顺序为：比例与裁切 → 原始反射标定 → 抗锯齿可视化与质量优化。

## P0-1 保持比例并裁切多余画面

### 实施前问题

默认配置的 `contentMode` 是 `stretch`。该模式把捕获源强制拉伸到逻辑画布比例；当外屏桌面、逻辑画布和 AA 区宽高比不一致时，会产生非等比缩放，表现为人物、圆形、字体和 UI 被压扁或拉长。

几何 Warp 与内容适配当前容易混在一起判断：

- **内容适配**只负责保持原画面比例和决定裁切范围；
- **几何 Warp**只负责抵消玻璃反射造成的空间畸变；
- 几何 Warp 参数不应被用来补偿内容层的非等比拉伸。

### 目标行为

- 默认使用“保持比例、铺满裁切”。
- X/Y 使用同一个缩放因子，不允许分别缩放。
- 目标区域无法容纳的部分从边缘裁掉，不再压缩进画布。
- 默认中心裁切；同时预留水平、垂直裁切锚点，范围为 `-1...1`，便于保留驾驶信息重点区域。
- AA 区外继续保持纯黑。
- schema 3 及更早配置中的 `stretch` 自动迁移为等比裁切，但完整保留 AA、Warp、多项式和镜像参数；schema 4 仍允许用户主动选择拉伸调试模式。

### 映射规则

设捕获源尺寸为 `Ws × Hs`，逻辑画布或观察目标尺寸为 `Wt × Ht`：

```text
scale = max(Wt / Ws, Ht / Hs)
scaledWidth  = Ws × scale
scaledHeight = Hs × scale
cropX = scaledWidth  - Wt
cropY = scaledHeight - Ht
```

只允许 `scale` 这一项统一作用于 X/Y。`cropX` 或 `cropY` 中大于 0 的方向执行裁切。

### UI 调整

- 将“内容适配”主选项简化为：
  - `保持比例·铺满裁切（推荐）`
  - `保持比例·完整显示`
  - `拉伸铺满（调试，不推荐）`
- `拉伸铺满` 增加橙色警告：“会改变画面比例”。
- 增加“裁切位置”：水平、垂直两个微调滑杆；默认均为 0，代表中心裁切。
- 状态栏实时显示：源比例、目标比例、统一缩放倍数、实际裁切像素。

### 验收方式

1. 显示标准圆、正方形和 16:9 测试卡；Warp 前后圆不能变椭圆、正方形不能变成长方形。
2. 以网格单元宽高比计算比例误差，中心区域和四角的比例误差均不超过 `1%`。
3. 源画面和目标画布比例不同时，只允许边缘内容消失，不允许内容整体变形。
4. 裁切锚点移动时只改变被裁掉的区域，不改变缩放比例。
5. 在当前已保存 Warp 参数下复验，确保修复内容比例不会破坏几何校正参数。

## P0-2 一键原始反射标定模式

### 定义

新增按钮：**“进入原始反射标定”**。该模式用于在没有任何预畸变补偿的情况下，把规则网格显示到物理屏幕上，再通过挡风玻璃拍摄反射后的原始畸变，为后续控制点提取提供基准图。

这不是“恢复默认配置”，也不能覆盖用户已经调好的 Warp 参数。

### 进入模式时

- 内存中保存当前完整运行状态。
- 临时关闭基础 Warp。
- 临时关闭多项式 Warp。
- 使用规则矩形网格、中心十字、白色边界和四色角标。
- 保留当前 AA 区尺寸和位置，确保拍摄区域与最终使用区域一致。
- 镜像状态默认保留，避免反射方向和最终显示方向不一致；UI 提供明确提示。
- 内容适配强制采用保持比例模式，禁止拉伸。
- 控制台进入醒目的“原始反射标定中”状态。

### 退出模式时

- 按钮切换为 **“返回校正状态”**。
- 一键恢复进入前的完整配置和运行时状态。
- 临时标定状态不写入默认配置、不写入预设、不增加历史版本。
- App 异常退出或外屏重建后，默认回到正常校正状态，避免长期停留在旁路模式。

### 建议拍摄流程

1. 固定 MacBook、外屏、玻璃、相机和观察位。
2. 进入原始反射标定模式。
3. 依次拍摄全屏网格、细网格和四色角标图。
4. 保存外屏分辨率、AA 区、相机位置和拍摄时间元数据。
5. 返回校正状态，再拍摄相同机位的校正后网格进行前后对比。

### 验收方式

1. 进入标定模式后，物理屏网格必须是未预畸变的规则矩形网格。
2. AA 区位置、大小和镜像方向与进入前一致。
3. 连续切换 20 次，原 Warp 参数、预设和历史记录不能变化。
4. 返回校正状态后，画面与进入前逐项配置一致。
5. 外屏拔插或 App 重启后不得意外保留临时旁路状态。

## P0-3 抗锯齿总开关与可视化验收

### 实施前问题

当前已有“关闭、性能、质量”下拉选项，但用户很难看出差异，原因包括：

- “关闭”仍使用线性纹理采样，不是真正完全关闭平滑；
- 标定网格自身使用 `fwidth + smoothstep` 做解析抗锯齿，导致开关对网格几乎没有影响；
- 当前网格主要是水平和垂直线，最容易出现锯齿的斜线、圆弧和细小文字不足；
- 自动性能降级可能改变实际档位，但用户只看到保存档位。

### UI 调整

- 增加独立总开关：**“抗锯齿：开启 / 关闭”**。
- 总开关关闭时，档位选择禁用；总开关开启时再选择“性能 / 质量”。
- 同时显示：
  - 保存设置；
  - 当前实际生效设置；
  - 是否由自动性能保护降级。
- 增加 **“抗锯齿 A/B 对比”** 按钮。

### 渲染调整

- 真正关闭时使用 nearest/point 采样，并关闭额外多点采样。
- 开启时使用线性采样和 Warp 足迹驱动的多点采样。
- 优化采样范围，重点覆盖 Warp 后的高曲率边缘，避免简单模糊整张画面。
- 对 UV 边界采样做 clamp/mask，防止多点采样把 AA 区外黑边带入有效画面。
- 自动降级只能在“开启”状态下从质量降至性能，不能把用户明确关闭的状态重新打开。

### A/B 对比测试图

新增专用诊断图，包括：

- 多组 1 像素和 2 像素斜线；
- 放射状线束；
- 同心圆和高曲率弧线；
- 黑白棋盘格；
- 小字号数字和方向标记；
- 左右半屏分别映射到相同的局部 `0...1` 坐标，图案、颜色和线宽完全一致；
- 左半屏强制关闭、右半屏使用当前开启档位，唯一变量是抗锯齿算法。

诊断图只用于对比，不影响正式标定网格和保存配置。

### 验收方式

1. A/B 分屏中，斜线和圆弧边缘必须能肉眼看到开启侧阶梯减少。
2. 关闭侧保持真正 point sampling，不能被标定网格自身的平滑掩盖。
3. 开启侧不能通过明显模糊换取“无锯齿”；1 像素线仍可辨识。
4. 性能模式在 `5120×2880 @ 60 Hz` 保持 `60 FPS`，GPU P95 小于 `14 ms`。
5. 质量模式优先保持 `60 FPS`；自动降级触发时 UI 明确显示实际生效档位。
6. 在真实桌面文字、窗口边框、标定网格和专用诊断图四种内容上分别截图对比。

- 抗锯齿开启/关闭的差异能够在专用 A/B 图上稳定复现。
- 性能模式继续满足 5K 60 Hz 和 GPU P95 门槛。
- Swift 单元测试、Release 构建、代码签名和回滚演练全部通过。
