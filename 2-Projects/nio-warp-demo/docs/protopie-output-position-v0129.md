# v0.12.9：ProtoPie 页整幅画面上下位置

## 问题与修复

用户在 ProtoPie 页拖动原有“画面上下位置”时，数值改变而画面不动。现场确认该入口更新的是 `widthFitVerticalPosition`，播放器内容和视口都为 7680×2800；内部移动量等于位置值乘以溢出高度的一半，因此实际位移恒为 0。此前新增的整幅输出平移仅在画布页，未覆盖用户正在操作的入口。

ProtoPie 页顶部新增“整幅画面上下位置（物理 px）”。滑块、输入和归零共用画布页的 `applyOutputVerticalOffset`，以实际应用的 WarpConfiguration 为唯一值源。拖动实时应用并保存，负值上移、正值下移；不改变宽度、曲面形状、源画布、镜像或 AA。超过实体屏幕边缘的部分不可见。

旧 −1～1 控件改为默认折叠的“高级 · 原型内部取景”，原配置继续保留。原型保存、重载和面板刷新不应重置整幅位置。输入框已聚焦但没有编辑时也随实际值更新，避免失焦回写旧值；正在编辑的草稿保留。
