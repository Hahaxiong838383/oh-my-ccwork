# P0 离线验收记录

## 结论

2026-08-12 先完成离线验证，随后在 AU16O Retina 外屏完成联合验收。比例裁切、无畸变预览、抗锯齿总开关、相同图案 A/B、外屏配置隔离和反向预畸变趋势均通过；真实玻璃最终光学效果仍未验收。

## 已完成

### 保持比例与裁切

- 默认内容模式改为保持比例铺满裁切，X/Y 使用同一个缩放倍率。
- 增加水平、垂直裁切锚点，范围限制为 `-1...1`。
- schema 3 及更早的默认拉伸配置自动迁移为铺满裁切，同时保留 AA、镜像、基础 Warp 和多项式参数。
- 状态栏显示真实尺寸计算出的统一缩放倍率和源画面裁切像素。

### 一键无畸变标定

- 临时关闭基础 Warp 和多项式 Warp，强制显示规则标定网格。
- 保留 AA 区与镜像状态，避免改变最终拍摄口径。
- 临时预览不保存配置、不增加历史、不覆盖预设。
- 原始标定与抗锯齿 A/B 可以直接互切；任意正常参数修改会退出临时预览。

### 抗锯齿开关与 A/B

- 增加独立抗锯齿总开关；关闭时使用真正的 nearest 点采样。
- 开启后保留 4 点性能档和 9 点质量档，自动降级只在总开关开启时工作。
- 增加左右分屏诊断图：左右分别映射到完全相同的局部坐标，图案、颜色、线宽和位置一致；左侧强制无平滑，右侧按当前开启档位显示平滑边缘。
- 标定网格本身严格跟随抗锯齿总开关，避免网格始终解析平滑造成“开关无差异”的假象。
- 多点采样 UV 做边界限制，避免 AA 区外黑色污染有效边缘。

### 外屏兼容与趋势控制

- ScreenCaptureKit 使用外屏物理像素尺寸并开启 `scalesToFit`，Metal drawable 固定为物理像素，viewport/scissor 从实际 drawable 读取。
- 配置按 vendor/model/serial 独立保存；不同显示器首次连接使用安全默认值，同一外屏重连恢复自己的配置。
- 反向预畸变会统一反转基础 Warp 与多项式增量，并在反向后重新归一化铺满 AA 区。

## 离线证据

- Swift 单元测试：`27/27` 通过。
- Metal Shader：在无外屏环境中由 `WarpRenderer` 实例化并真实编译通过。
- Debug 构建：通过。
- 配置迁移、比例映射、裁切锚点、临时标定无污染和抗锯齿关闭策略均有自动测试覆盖。

## 外屏联合验收结果

1. 宽高比不一致时只裁切边缘，不出现整体压扁；裁切锚点只改变保留区域。
2. 一键无畸变标定显示规则网格；从该模式进入 A/B 后退出，能返回无畸变模式。
3. 抗锯齿 A/B 左右使用同一图案，开启侧斜线、圆弧和放射线更连续，用户确认通过。
4. AU16O `3840×2400 px @ 60 Hz` 质量档稳定 `60 FPS`，GPU 平均约 `6.34 ms`，P95 `10.60 ms`。
5. 外屏分辨率变化时按物理像素重建，不再因 Retina points/pixels 混用黑屏。
6. 临时预览前后配置哈希一致，不污染保存配置。
