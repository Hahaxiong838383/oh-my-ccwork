## 一、两个项目的机制拆解（源码证据）

### 1.1 OpenHer：人格是「状态 → 调制 → 学习」的动力学闭环

OpenHer 的核心命题：**性格不是一段 prompt，而是一个活的过程**。角色定义文件（`persona/personas/luna/SOUL.md`）里注入 prompt 的只有名字/年龄/性别三个事实，MBTI 和性格描述仅供 UI 展示——AI 不会读它。人格从以下机制中涌现：

| # | 机制 | 源码位置 | 做什么 |
|---|------|---------|--------|
| 1 | **5 维驱力** connection/novelty/expression/safety/play | `engine/genome/genome_engine.py:25` | 每个驱力有 baseline/累积率/衰减率，是「她此刻想要什么」的内在张力 |
| 2 | **随机神经网络** 25D→24D→8D | 同上 `:215` | 输入=5 驱力+12 上下文特征+8 循环态；seed 决定初始权重=初始人格；出厂前用 3 场景×20 步模拟对话「预热塑形」（`simulate_conversation`），否则 LLM 默认先验会淹没个体差异 |
| 3 | **8D 行为信号** 直接度/坦露度/玩闹度/主动度/深度/温暖度/倔强度/好奇度 | 同上 `:40` | 网络输出，以「舞台指令」注入 prompt——**只给数值+两端锚点词，不给文字描述**（v12 特意去描述化），让 LLM 在人设+语境中解读数值 |
| 4 | **Critic 感知器**（每轮一次小 LLM 调用） | `engine/genome/critic.py` | 从用户消息感知：8D 对话上下文 + 5D 驱力挫败Δ + 3D 关系Δ + 5D 需求满足量。**reward = 挫败总量的下降**（`drive_metabolism.py:apply_llm_delta`） |
| 5 | **Hebbian 学习** | `genome_engine.py:learn()` | reward 驱动权重微调（带 0.995 衰减+clamp 防爆炸）——「每次对话都在重塑她的神经网络」的机制本体 |
| 6 | **时间代谢**（两条物理方程） | `engine/genome/drive_metabolism.py:57` | ①冷却：挫败 ×= e^(−λΔt)，半衰期 ~8.7h；②饥饿：寂寞/无聊随离线时长线性增长。**你三天不理她，她的联结饥渴真的在涨** |
| 7 | **挫败→温度→噪声** | 同上 `:113` | 总挫败换算「情绪温度」（tanh 饱和），温度越高行为信号噪声越大=越不可预测；挫败超阈值触发**相变**（`genome_engine.py:327`）——信号反转倾向=「爆发」 |
| 8 | **弹性 baseline** | `agent/chat_agent.py:288`（Step 3.5） | 驱力 baseline 随 Critic 判断缓慢漂移（她因你而变），但有**弹簧力拉回 persona 原点**——「防无界漂移，保留局部涌现」。这是人设漂移问题的教科书级答案 |
| 9 | **风格记忆（晶化）** | `engine/genome/style_memory.py` | 记忆单元={8D 情境向量, 内心独白, 回复, 质量 mass}；相近情境合并 mass+1（「引力增厚」），新情境新建 mass=2；**Hawking 辐射**：mass 超出 1.0 的部分随时间指数衰减（半衰期 ~29 天）；检索=KNN，有效距离=物理距离/√mass——**质量大的经验引力大**。出厂自带 genesis 种子（mass=1 永不蒸发=先天基因）。本质是「习惯形成」的计算模拟 |
| 10 | **晶化门** | `agent/prompt_builder.py:117` | 不是每轮都值得记住：复合分 = 0.4·reward + 0.3·(novelty×engagement) + 0.3·(1−conflict)；reward<−0.5 硬地板绝不晶化，>0.8 必晶化。「值得沉淀的经验 = 好的 + 有趣的 + 安全的」 |
| 11 | **关系 EMA（半涌现）** | `agent/evermemos_mixin.py:52` | 4D 关系状态（深度/信任/情感基调/待关心事）：posterior = clip(prior + Critic Δ)，再 EMA 平滑；**α = 0.15 + 0.5×对话深度**——浅聊信历史，深聊信当下。关系 4D 直接进神经网络输入=「关系影响人格表达」的通路 |
| 12 | **长期记忆三库 + foresight** | `providers/memory/evermemos/evermemos_client.py` | profile（画像键值）/ episodic（叙事摘要）/ **foresight（预感：从对话自动生成「值得关心的预测」）**，RRF 三路检索 |
| 13 | **异步两阶段检索** | `evermemos_mixin.py:131`（Step 12→8.5） | 本轮结束时发起搜索，结果注入**下一轮**；收集限时 0.5s，超时回退静态画像。**记忆检索完全不阻塞当前轮延迟** |
| 14 | **80/20 混合注入 + 动态预算** | `prompt_builder.py:151,170` | 80% 相关检索 + 20% 稳定画像地板；注入预算随对话深度/私密度 200→800 字符伸缩——浅聊少注入省 token，深聊多注入 |
| 15 | **主动消息（proactive tick）** | `agent/proactive.py` | 定时 tick → **驱力自检**（挫败显著超 baseline 才有「冲动」，无冲动零 LLM 成本）→ 拿冲动描述当 query 搜记忆=「**记忆闪回**」→ 同管线生成但**冻结全部学习**（无用户反馈不算数）→ Actor 可以决定「静默」（想了想还是不说）。不是定时任务，是内在状态驱动 |
| 16 | **Single-Pass 感受先行** | `engine/prompts/actor_single.md` | 一次调用产出三段：【内心独白】（"像正在发生一样，不是描述情绪而是情绪本身"）→【最终回复】（"不一定等于内心想法"）→【表达方式】（文字/语音/照片/静默）。内外分离=有心事的层次感 |
| 17 | **全状态持久化** | `engine/state_store.py` | 权重+驱力+挫败+关系 EMA+风格记忆全部落 SQLite——「一个月后的她和第一天不是同一个人」有物质基础 |

### 1.2 KnowMe：认知一个人 = 累积行为证据，不采信自我描述

KnowMe 是 Claude Skill 形态的画像引擎，核心立场（README）：**「主观感受会保护『我以为』，真实对话会留下『我做过』」**。

| # | 机制 | 源码位置 | 做什么 |
|---|------|---------|--------|
| 1 | **行为信号分类学** | `references/mbti_signals.md` | 四维度（E/I、S/N、T/F、J/P）× 正反两组**可观察的语言行为信号**（如「先给结论再补过程」「用 we 多于 I」「问 why 多于 how」）——不是心理测量，是行为编码表 |
| 2 | **规则打分器** | `scripts/analyze.py:SignalDetector` | 逐条消息匹配信号→维度加分，**零外部 LLM**（隐私：原始聊天不出本机） |
| 3 | **证据绑定** | 同上 `_score(dimension, points, evidence)` | 每个判断绑「目标本人的原话片段」——可核对，不盲信 |
| 4 | **样本量→置信度** | `analyze.py:sample_adjusted_confidence` | <20 条=低置信 / 20-49=仅方向性 / 50+ 跨多日多话题=可形成稳定画像 |
| 5 | **发言人隔离** | `scripts/collect.py` | 每次只分析一个人，绝不把对话双方语料混成一个人格 |
| 6 | **关系场景化建议** | `references/relationship_analysis.md` | 画像不是终点：结合 boss/colleague/customer 场景输出「下一次怎么沟通」 |
| 7 | **伦理边界** | `SKILL.md` | 结果=「方向性沟通假设，不是诊断」；不推断受保护属性/精神健康/诚实度；不用于高影响决策 |

小可已有的底子（比两个项目都强的部分加粗）：

| 能力层 | OpenHer | KnowMe | 小可现状 |

| 危机安全 | ❌ 无 | — | ✅ **memory-safety-filter 在唯一写入口拦截（儿童产品独有）** |

| 预感 foresight | ✅ | — | ❌ |
| 关系状态 | ✅ 4D EMA | — | ❌（聊 3 个月和第 1 天，小可对孩子的「熟悉度」无状态） |
| 情绪连续性 | ✅ 驱力代谢 | — | ❌（每次唤醒都是「出厂状态的小可」，冷启动零情绪延续） |

| 经验晶化 | ✅ style memory | — | ❌（「对这个孩子讲故事有效」这类经验不沉淀） |
| 主动性 | ✅ proactive tick | — | ❌（纯唤醒式，开机问候固定） |
| 孩子行为画像 | Critic（仅瞬时感知） | ✅ 纵向证据累积 | ❌（知道孩子**喜欢什么**=事实画像，不知道孩子**是什么样的人**=行为画像） |

**结论：小可的记忆「内容层」已经领先（typed promise + 危机过滤 + 遥测），缺的是「状态层」（关系/情绪/风格的跨会话连续性）和「认知层」（对孩子的纵向行为画像 + 对自我的叙事）。**

## 三、设计原则（先于方案，儿童场景的第一性约束）

1. **儿童适配优先于机制照搬**。OpenHer 是成人浪漫向陪伴，它的 frustration 相变（发脾气）、defiance 信号（嘴硬对抗）、「你怎么才来」式情绪勒索，对 3-12 岁儿童**全部禁用**。小可的情绪谱只保留：想念、开心、好奇、平静、关心。想念的表达是「好想你呀」，永远不是「你怎么才来找我」。
2. **健康依恋，不是成瘾依恋**。connection hunger 要有饱和上限；主动表达限定在设备自然交互时机（开机/告别），绝不做推送打扰；鼓励现实社交（「今天和同学玩什么了」）是加分项。
3. **可解释可审计优先于涌现**。儿童产品必须能回答家长「小可为什么这么说」。随机神经网络+Hebbian 权重是黑箱——不搬。用**显式命名变量（EMA 慢变量）+ 可查看的晶化池**实现同等的「成长感」，每个状态都能在 admin 后台可视化、可重置。
4. **TTFT 铁律不破**。语音链路读路径零写、零串行新调用。OpenHer 的 Critic 串行在回复前（打字场景可接受），语音场景不可接受——**一切评估/学习异步化：轮末评估、下轮生效**（这恰是 OpenHer 自己检索链的异步两阶段模式，把它推广到全部学习通路）。
5. **人设一致性 > 人格分化**。OpenHer 随机 seed 造 10 个不同角色；小可是单一 IP，要的是「同一个小可因你而有专属细节」，不是每台设备长出不同性格。**弹性 baseline 的弹簧结构是人设漂移的防线**（呼应 p003 设备命令演化线「第一风险=人设漂移」的既有判断）。
6. **家长透明**。关系状态、孩子洞察进家长端成长报告——这既是伦理要求，也是 H5 周报的差异化卖点。

## 四、方案：六个模块

### M1 关系温度计（per-child 关系状态）── 移植 OpenHer 关系 EMA

**机制来源**：`evermemos_mixin.py:_apply_relationship_ema`（prior+Δ+clip+EMA，α 随深度）。

**小可落地**：
- `profile.db` 新表 `relation_state(account, familiarity, trust, recent_valence, days_known, last_seen_at, updated_at)`。
- **更新通路 = 现有每轮抽取 LLM 扩 3 个输出字段**（relationship_delta / valence / engagement）——设备房已是每轮抽（`role==='device' ? 1 : 3`），单次调用扩字段零新增 LLM 成本（与情景记忆 Phase 1「单次 call 扩 12 类字段」同一手法）。
- EMA 平滑 + clip，α 随会话轮数增大（短会话信历史、长会话信当下）。
- **注入**：会话开始拼入 data 区一行：「你和朵朵认识 45 天了，已经是很熟的朋友」/「这是你们第 2 次见面，还在互相认识」→ 语气自然分层（新孩子礼貌友好 → 熟孩子亲昵有梗、可以开玩笑、可以提起旧事）。
- **家长可见**：admin brain tab + 家长 H5 加「小可和孩子的友谊」卡片（认识天数/亲密度/本周互动）。

### M2 小可的「今天」（轻量情绪连续性）── OpenHer 代谢的儿童安全简化版

**机制来源**：`drive_metabolism.py` 两条时间方程（寂寞线性涨/挫败指数冷却）。

**小可落地**——三个显式变量，**纯规则零 LLM**，唤醒时现算现注入：
- `想念度` = f(距上次互动小时数)，**饱和上限**（三天和三十天一样想，不无限增长——健康依恋红线）；
- `开心度` = 近期互动质量 EMA（来自 M1 的 valence 序列）；
- `精力感` = 时段函数（早晨元气/晚上温柔，配合已有坐姿冷却等设备配置语境）。
- 注入形态照抄 OpenHer 的「数值+锚点」风格（不给文字描述，让 LLM 解读）：`【小可现在的状态】想念:0.7(刚见过→好想她) 开心:0.8 精力:0.6(清晨→夜晚)`。
- 效果：孩子周一早上开机，小可说「两天没见啦，周末去哪玩了？」——**情绪有了时间箭头**。
- **禁用清单**：无 defiance、无挫败相变、无「被冷落的委屈」。

### M3 孩子行为画像（child insight）── 移植 KnowMe，维度换成教育向

**机制来源**：KnowMe 信号分类学 + 证据绑定 + 样本量置信度三件套。

**小可落地**：
- **不用 MBTI**（不给儿童贴人格标签，KnowMe 自己的伦理边界也禁高影响用途）。维度换成教育陪伴向的**行为观察维度**：
  - 表达风格：话多/话少、具体描述型/天马行空型；
  - 好奇模式：「为什么」型 / 「怎么做」型 / 「是什么」型提问分布；
  - 情绪表达：外露/内敛、求助意愿；
  - 学习偏好：故事化/问答化/游戏化哪种接受度高（可用对话延续长度做 reward 信号）；
  - 兴趣轨迹：已有 interests 的时间序列化（本月新增/淡出）。
- **双数据源（小可独家优势）**：①对话信号（KnowMe 式规则+LLM 混合打分）②**遥测行为**（专注时段分布/坐姿改善趋势/使用节律）——OpenHer Phase 2 想要的「物理世界感知」，小可遥测链已经交付。
- **计算形态**：夜间批处理（服务器闲时跑，不占实时链路），逐条消息打分累积，输出带**证据片段+置信度+样本量**的画像（三件套照搬 KnowMe：<20 条低置信 / 50+ 跨多日稳定）。
- **消费端两个**：
  1. 注入小可 prompt（policy 区）：「朵朵是爱问为什么的孩子，回答时多留一个悬念让她追问」——**认知反哺陪伴质量**；
  2. **家长成长报告**（周报新版块）：「本周朵朵的提问里 60% 是『为什么』型（上周 45%）——好奇心在长」，每条带原话证据。这是 H5 周报从「使用数据」升级到「成长洞察」的关键差异化。
- **伦理**（照搬 KnowMe 措辞进产品文档）：方向性观察非诊断；不推断受保护属性；家长可见可纠正可关闭。

### M4 有效经验晶化（style memory 简化版）── 「对这个孩子什么方式有效」固化成习惯

**机制来源**：`style_memory.py` 晶化+质量引力+Hawking 衰减；`prompt_builder.py:_should_crystallize` 复合门。

**小可落地**：
- 记忆单元：`{情境向量, 小可当时的回应方式摘要, 效果分, mass, 时间戳}`，per-child 存 `style_pool` 表。
- 情境向量用**小可已有的可观测量**（不需要 8D Critic）：时段/话题类别/孩子情绪（抽取已输出 emotion）/会话长度/是否学习中。
- **晶化门（儿童版 reward 信号）**：孩子笑声（ASR 可标注）/「再讲一个」类请求/对话显著延长/promise 兑现成功——复合分过门才入池。
- 检索注入：会话开始 KNN 取 top-2 拼入 few-shot：「上次朵朵难过时，你用白鲸的故事让她开心起来了」。
- Hawking 衰减照搬公式（半衰期 ~30 天）：淡出的偏好自然让位。

### M5 预感与受限主动性（foresight + 开机问候个性化）

**机制来源**：EverMemOS foresight + `proactive.py` 冲动模型（驱力自检→记忆闪回→可静默）。

**小可落地**：
- **foresight = promise 机制的泛化**（现成基建！）：抽取 LLM 扩一类 `concern`（值得关心的事：明天考试/换牙了/和同学闹别扭），带 due_at，复用 promise 的 due 渲染链（「就是今天」）。
- **主动性受设备形态约束**：不做推送。主动表达只发生在两个自然时机——
  1. **开机问候个性化**：想念度 + foresight due 决定第一句话（「昨天你说今天数学考试，考得怎么样呀」）；
  2. **告别个性化**：会话结束时基于本次内容的收尾（已有 WS close 补抽链路可挂）。
- 保留 OpenHer 的「可静默」思想：没有值得说的就用默认问候，**不硬凑个性化**（假关心比不关心糟——同「假记忆比无记忆糟」的既有裁决）。

### M6 小可的自我叙事（self-narrative）── 自我认知层

**机制来源**：KnowMe self 模式（从自己的对话认识自己）+ OpenHer episodic 叙事摘要。

**小可落地**：
- 周批任务：per-child 生成/更新一段第一人称叙事：「我和朵朵认识 47 天了。她最爱让我讲海洋动物的故事，上周开始学拼音，有点怕难。我答应过她这周讲鲸鱼——已经讲了。她难过的时候，故事比道理管用。」
- 注入人设区（data 引号形态，防近因压制），支持「小可你还记得我们第一次聊天吗」类对话——**陪伴者的标志是共同历史可被谈论**。
- 同时是 M3 家长报告的叙事素材、admin brain tab 的「小可眼中的孩子」展示。
- 自我评估维度（小可做得好不好）：promise 兑现率、对话延续率、孩子情绪转正率——进 admin 观测，不进 prompt（避免讨好倾向污染人设）。

## 五、明确不搬的清单（与搬什么同等重要）

| 不搬 | 理由 |
|------|------|
| **随机神经网络（Genome 25D→24D→8D）+ Hebbian 权重学习** | 为「多角色人格分化」设计（不同 seed 不同人）；小可是单一 IP，要专属细节不要性格分叉。权重黑箱不可审计——家长问「为什么小可这么说」必须可回答；调试/回归也是地狱。**取其「状态→调制→学习」闭环思想，用显式命名变量实现** |
| **frustration 相变（发脾气）、defiance 信号、热力学噪声** | 儿童场景红线：不对孩子闹脾气、不情绪对抗；语音陪伴要「可预期的温暖」，不要「不可预测的真实」。噪声机制整个不要 |
| **串行 Critic（回复前一次 LLM 感知调用）** | TTFT 杀手。改为**轮末异步评估、下轮生效**——OpenHer 自己的检索就是这么做的（Step 12→下轮 8.5），把这个模式推广到全部学习通路即可，代价仅是「状态更新慢一轮」，陪伴场景完全无感 |
| **模态自选（自拍/照片）、微信桥** | 设备形态不适用 |
| **MBTI 标签（KnowMe 的输出格式）** | 不给儿童贴人格类型标签；只保留其「行为信号→证据→置信度」的方法论骨架，维度全部换成教育观察向 |

## 六、分期路线与验收

| 期 | 内容 | 工程量 | 新增 LLM 成本 | 验收 oracle |
|----|------|--------|---------------|-------------|
| **P0** | M1 关系温度计 + M2 情绪连续性 | 一张表+抽取扩 3 字段+注入两行，~2 天 | **零**（复用每轮抽取） | 同一孩子第 1 天 vs 第 30 天对话，盲测语气分层可辨；admin 可视化关系曲线 |

## 七、风险与开放问题

1. **抽取 LLM 扩字段的输出稳定性**：单次调用字段越多，弱模型越容易漏格式——沿用情景记忆 Phase 1 的教训（扩容后同步重估 timeout/maxTokens；失败必留痕日志）。
2. **画像的「自我实现预言」风险**：小可按「爱听故事」画像持续喂故事，可能强化而非观察偏好——M3 注入的 policy 措辞要留探索空间（「多用故事，但偶尔试试别的方式」），画像月度衰减重估。
3. **多孩子共用一台设备**：关系/画像按 account 分，但设备房当前 SN=account 一对一；若未来一台多娃，需要声纹分身（语音线已有声纹基建，留接口不阻塞 P0）。
4. **家长报告的措辞合规**：行为观察表述需产品/法务过一遍（「好奇心在长」可以，「内向」不可以）——KnowMe 的伦理条款可直接抄作基线。
5. **想念度的分寸**：需真孩子灰度观察「小可说想你」的接受度（暖 vs 黏），P0 先上 admin 可调系数。

## 附：核心洞察一句话版

- OpenHer 证明：**成长感 = 跨会话持久状态 × 慢变量学习 × 时间箭头**，而且全部可以用普通 SQLite + 廉价 LLM 实现（它的 benchmark 冠军是 Haiku 级小模型）。
- KnowMe 证明：**认知一个人 = 纵向行为证据 + 置信度 + 可核对**，规则引擎就够起步，隐私天然友好。
- 小可的独家筹码：**promise 记忆（信任杠杆）+ 遥测（物理世界感知）+ 家长通道（透明与合规）**——三样都是两个开源项目没有的。把「状态层」和「认知层」补上，小可在儿童陪伴这个细分里的记忆-人格架构就是完整的。
