**《P003 Web 后台产品定义》整合方案（V1.0）**

**北极星**：留存（D30 孩子主动使用占比 ≥40%）。一切后台模块服务「看数据（A16）+ 运营动作（KidsHub 15/16/17）+ 散落管家（ACT-01/MSG-01）」。

**铁律引用**：PRD 功能 15/16/17 云端职责 + A16 §二 6 页数据后台 + 口径纪律（双时钟、退货 SN 剔除、有效使用=收益+互动）。

### D.0 定位
Web 后台 = ①数据看板（看，A16 既有）+ ②KidsHub 运营台（动，PRD 15/16/17 核心增量）+ ③运营操作台（管，ACT-01/MSG-01）。

**推荐**：**一个统一后台**（理由：A16「单独制作」指登录体系，非架构；KidsHub 需用户上下文、激活质量分、贡献数据与数据看板重叠；统一登录 + 共享用户档案减少重复，PRD KIDSHUB-01 明确要求 Web 后台承载状态机/账本/决策）。

### D.1 角色与权限
**推荐拆 3 角色**（理由：KidsHub「版本决策/采纳」需产品判断，纯管理员无法覆盖；客服工单需专业话术）：

- **管理员**（销售/产品/运营）：全数据 + KidsHub 决策（采纳/版本发布）。
- **运营**（KidsHub 专属）：状态推进、主题池打标、贡献账本查看、金点子库管理、L1-L4 复访触发。
- **客服**：工单处理（T+5 介入 + 蓝牙日志）。

登录页角色自动识别（账号密码配置）。

### D.2 数据看板（A16 6 页保留 + 4.3 推导看板）
**模块**：
- 登录页
- 数据概览（关键指标卡 + 每日新增 + 设备/状态分布 + 全国地图）
- 单用户查询（搜索→列表→详情：关键指标卡 + 各模块原始埋点 + 时间筛选）
- 全部用户列表（多条件筛选 + 分页 + 排序）
- 统计页面（数值均值/总计 + 省份筛选 + 导出）
- 日期范围查询（期间注册/活跃/激活 + 型号分布）

**留存逻辑链**：服务 PRD 0.1 北极星量化目标（闸门 1/2 独立统计、首周 ≥4 有效使用日、D30 主动占比）；做砸了 → 激活率/留存率是假数，迭代全偏（A16 §4.3 + PRD 0.1）。

**P0 必须**：A16 6 页 + 4.3 激活双指标/首周留存看板（数据是 KidsHub 基础）。

### D.3 KidsHub 运营后台（PRD 15/16/17 云端核心，P0 最小集）
**每个模块**：做什么 / 操作者 / 关键约束 / 对应 PRD 条 / 留存逻辑链。

**反馈工单台**  
做什么：issue 状态机（已收到 → 评估中 → 已采纳/进金点子库，全正面，无「被拒」）；列表 + 详情 + 状态推进。  
操作者：运营/管理员。  
关键约束：单条全链路可查、可审计；来源端标签（孩子/家长）。  
对应：PRD 功能 15 KIDSHUB-01。  
留存逻辑链：服务 PRD 15「被听见 + 状态可见 + 贡献累积」；做砸了 → 孩子「说了白说」，D30 主动使用占比掉（PRD 15 C1-C4 闸门）。

**主题池**  
做什么：情绪极性 + 主题双标签聚合；列表 + 搜索 + 人工/自动打标入口。  
操作者：运营。  
关键约束：按被采纳质量驱动贡献值（非提交量）；防灌水。  
对应：PRD 功能 15/16。  
留存逻辑链：服务 PRD 15 主题聚合 + 16 活跃度监控；做砸了 → 无法定位共性痛点，迭代盲目。

**贡献账本**  
做什么：按质量记贡献值/等级/称呼；时间线 + 汇总。  
操作者：运营/管理员。  
关键约束：被采纳质量驱动；家长首次昵称作为署名兜底。  
对应：PRD 功能 15。  
留存逻辑链：服务 PRD 15「越攒越离不开」+ C3 沉没成本；做砸了 → 高贡献孩子留存无抬升。

**金点子库**  
做什么：未采纳正面兜底库（非回收站）；支持后续翻牌/征集。  
操作者：运营。  
关键约束：状态终态始终可见；与已采纳并列正面归宿。  
对应：PRD 功能 15。  
留存逻辑链：服务 PRD 15「表达被珍视」；做砸了 → 孩子表达热情熄灭。

**版本决策与致谢**  
做什么：采纳后打「小改/大功能 + 规划中/开发中/已上线」；升版时更新说明署名（昵称）。  
操作者：管理员（产品决策）。  
关键约束：署名 = 孩子昵称；只对已采纳。  
对应：PRD 功能 15/17。  
留存逻辑链：服务 PRD 15「真的改了 + 署名」+ 17 闭环出口；做砸了 → 信任闭环断，复提率掉。

**复访闭环（L1-L4）**  
做什么：14 日未提交 / 24h 未查看 → 小可 AI 主线场景软触发（L2/L3）；长期初级 → 访谈（L4）。  
操作者：系统触发 + 运营查看。  
关键约束：不走推送/家长 App；只在主线场景。  
对应：PRD 功能 15。  
留存逻辑链：服务 PRD 15 C2「被感受到」+ 防沉睡；做砸了 → 月活提交率掉，KidsHub 成一次性。

**KidsHub 度量看板**  
做什么：孩子侧漏斗（曝光→提交→升级）+ 家长侧（PV→UV→孩子 7 日提交率）+ 金点子库 vs 已采纳比 + 高贡献留存抬升。  
操作者：管理员/运营。  
关键约束：分层自然观察（高/中/低/零贡献）。  
对应：PRD 功能 15 验证方法。  
留存逻辑链：服务 PRD 15 两道闸门（单次可追踪 + 留存价值兑现）；做砸了 → 无法证明「说了被听见真的改了」。

**16 活跃度监控判流失 + 推送网关**  
做什么：流失规则命中 + 30 天首次 → 软化单选题；即时挽回 + 原始记录 → 主题池（带来源端标签）。  
操作者：运营（规则配置）/系统触发。  
关键约束：30 天频控；含「暂时没空」选项。  
对应：PRD 功能 16。  
留存逻辑链：服务 PRD 16「流失前拿到为什么走」；做砸了 → 家长默默退货，错失唯一干预窗口。

**17 回告路由 + 状态回写 + 送达监控**  
做什么：打标签 + 回告路由（小改定向/大功能公开）；状态回写 + 送达/打开回写；7 天未开 → 周报二次 + 消息中心红点。  
操作者：管理员（决策）/系统执行。  
关键约束：孩子端回告归 15；17 只管家长端 + 全体预告；措辞「因为你的建议」。  
对应：PRD 功能 17。  
留存逻辑链：服务 PRD 17「你说的 → 我们听到了 → 真的改了」；做砸了 → 反馈石沉大海，比不收更伤。

**AI-01 边界**：AI 话术生成/自动聚类（辅助）；人工必须拍板（采纳决策、版本发布、最终打标）。AI 双标签聚类赶不上 → 人工打标合格降级（PRD 未禁止）。

**P0 最小集**：反馈工单台 + 主题池 + 贡献账本 + 金点子库 + 版本决策 + 复访 L1-L4 + 度量看板（PRD 15 是 P0）；16/17 活跃度/回告路由可 P0 最小 MVP（状态机 + 路由骨架）。

### D.4 运营操作台（散落需求）
**推荐**：SN/订单管理（ACT-01 退货 SN 剔除 + 重置）**收进本版 P0**（理由：A16 激活率分母质量依赖，数据看板基础）；客服工单（功能 3 T+5 + 蓝牙错误日志）**放 P1**（理由：激活阶段 P1，P0 焦点 D1-7 + KidsHub）。

**模块**：SN 绑定/退货剔除/重置 + 客服工单列表（带日志）。

### D.5 横切约束
- 口径四件套（A16 §数据口径 + PRD 0.1）：双时钟、退货 SN 剔除、有效使用判定、离线补传 ≤7 天。
- 数据来源 = A16 埋点；三端一致。
- 状态机全正面；贡献按质量；来源端标签必带。

### D.6 优先级（对照 PRD 6.30 P0 / 7.30 P1）
**P0（6.30）**：D.2 数据看板全 + D.3 KidsHub 15 最小集 + ACT-01 SN 管理（数据质量）。  
**P1（7.30）**：D.3 16/17 完整 + 客服工单 + 角色细化 + 导出/地图增强。

**评审点站队**：
1. 一个后台（统一，理由见 D.0）。
2. 角色拆 3 个（管理员/运营/客服）。
3. KidsHub P0 最小集 = 工单台 + 主题池 + 账本 + 金点子库 + 决策 + 复访 + 度量（人工打标可降级）。
4. AI-01 边界：生成/聚类辅助，决策/最终打标必须人拍板。
5. SN 管理本版 P0，客服工单 P1。
