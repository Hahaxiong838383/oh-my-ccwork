# 《P003 小程序产品定义》整合方案

## 一、九个对账点裁决

### 1. 积分 vs 家族币：推荐 **b. 保留底层能力，切换产出口径，统一叫“家族币”**
- **裁决**：不做双轨；不保留“使用时长 1 分钟=1 积分”。现有积分页、奖励创建、兑换记录、余额账本可复用，但前台文案统一为“家族币”，产出来源改为夜航收益、迎新礼、任务/学习行为、生态缸相关收益。
- **理由**：时长换积分会诱导刷时长，和护眼定位、D30 主动使用指标冲突。双轨会让孩子和家长困惑，账本也难强一致。
- **迁移路径**：
  1. 老余额 1:1 转为“历史家族币”，流水标记“历史积分迁移”；
  2. 停止新增“时长产出”；
  3. 原“创建奖励”改为“新建亲子约定”；
  4. 原兑换记录改为“家族币记录 + 兑现记录”；
  5. Max/Ultra 文件夹名、界面文案统一为“家族币”。

### 2. 信息架构：由三 Tab 演进为五 Tab
- **裁决**：采用附录 C 五页架构：**首页 / 周报 / 兑换 / KidsHub / 我的**。
- **理由**：周报、兑换、KidsHub 是 PRD 留存机制的家长侧核心，不宜深藏；现有“设备、积分、我的”可平滑改造，不推倒重做。
- **对齐**：
  - 设备 tab → 首页；
  - 积分 tab → 兑换；
  - 我的 tab 保留；
  - 周报、KidsHub 新增一级 Tab；
  - 消息中心放“我的”二级，同时首页顶部有铃铛红点入口。

### 3. 现有但 PRD 未写功能：保留并归位
- **视光报告**：保留，归入“我的-孩子档案-视力档案”，并进入周报的“护眼价值”数据源。
- **智能建议 VID**：保留，归入“首页-设备状态/操作建议”，作为静态护眼指南，不做强智能承诺。
- **使用帮助说明书**：保留，归入“我的-帮助与客服”。
- **设备管理**：保留，归入“我的-设备管理”。
- **理由**：这些都是已开发资产，可增强家长价值感，不与 PRD 冲突。

### 4. 配网/建档增强：在现有蓝牙配网基础上改造
- **保留**：登录、隐私协议、蓝牙权限、搜索设备、WiFi 配置、失败态、被绑定态、一账号一设备。
- **改造**：
  - 配网 loading 间隙异步建档；
  - 孩子信息可跳过，系统生成随机昵称；
  - 昵称作为小可 D0 首次称呼来源；
  - 首页保留“补全孩子信息”轻提示。
- **新增**：
  - 未激活 T+1/T+3/T+5 提醒与客服介入；
  - 激活双闸门埋点：闸门 1 设备激活，闸门 2 孩子首次有效使用；
  - 配网五步漏斗与错误码上报。
- **理由**：现有流程能跑，不能重做；只补 PRD 要求的留存与数据口径。

### 5. 分期：P0 先补留存闭环最小集
- **裁决**：P0 不是重做小程序，而是把现有三件事纠偏：家族币、周报壳、KidsHub 可见。
- **P0 必做**：
  1. 停用时长换积分，切家族币；
  2. 兑换页改为亲子约定 + 待兑现/已兑现状态；
  3. 首页加入夜航收益、护眼守护、生态缸快照；
  4. 周报基础版，承接弱召回；
  5. KidsHub 家长主页；
  6. 消息中心；
  7. 夜航助攻推送、弱召回频控、回告落消息中心。
- **P1**：完整周报、反馈入口、流失拦截、视力趋势、分享卡、坐姿参数设置等。

### 6. “小未” vs “小可”
- **裁决**：统一为“小可”。“小未”视为旧名，唤醒词、角色名、UI、语音、后台字段展示都改“小可”。
- **理由**：PRD 和《小可 AI 产品定义》为最高事实源；双命名会破坏孩子认知。

### 7. “记录&分享”与周报关系
- **裁决**：记录&分享模块并入“周报/价值报告”，不另做一套报告。
- **复用内容**：今日柱状图、周/月记录、使用日历、健康数据报告、视力折线。
- **分享**：作为周报分享卡，落到家长晒单/转介绍；默认保护儿童隐私，先支持保存图片、微信分享，朋友圈/小红书可作为 P1/P2。

### 8. LED 远程控制冲突
- **裁决建议**：不做“实时遥控开关灯/调亮度/调色温”。  
- **可接受折中**：做“场景参数预设下发”，例如阅读/绘画/夜读推荐参数，由设备端确认执行；坐姿采样间隔、提醒频率可由小程序配置。
- **理由**：PRD 明确“小程序不直接控设备实时交互”，避免家长把小程序变成远程监工。最终是否允许远程开关灯，留 PM 终裁，但需标红冲突。

### 9. 视力档案数据线
- **裁决**：接入周报“护眼价值硬数字”，但不能宣称改善视力。
- **可展示**：坐姿提醒次数、用眼/专注时长、视光报告趋势、近视档案变化。
- **口径**：说“记录与守护”，不说“治疗、改善、控制近视”。
