## 一、问题拆解：现在缺的到底是什么

现有六模块每个其实**都有因果，但因果是隐式的**：

| 已有结果（后台可见） | 隐式的因（代码里有，账面上没有） |
|---|---|
| 关系档位「渐渐熟悉」 | 46 次会话 × 8 天累积——但**哪些会话贡献了什么**没有记录 |
| 相处气氛 0.56 | 每轮 LLM 情绪评分的 EMA——但**是哪几句话把气氛推上去的**不可追溯 |
| 经验池一条「讲恐龙故事」 | 某轮孩子开心+投入过了晶化门——但**那一轮发生了什么**没留痕 |
| 行为画像「爱问为什么」 | 有证据原话（这是唯一带因果的）✓ |

更深一层的缺位：**小可自己没有会成长的人格维度**。现在小可的「变化」全是围绕孩子的状态（关系/记忆/画像），小可本体的表达倾向（活泼、话多话少、爱不爱讲故事）仍由静态人设决定。「人格成长」四个字里，真正的「人格」层还是空的——V1.0 里我把 OpenHer 的 8D 信号砍掉时（不可审计），只留了状态层，没有补一个可审计的特质层。这次补上。

## 二、理论调研：人格「因果成长」的五条主流因果律

人格心理学对「人格为什么会变」有成熟的因果理论，每条都可以翻译成小可的可计算规则。以下按「因果强度证据」排序（均为教科书级稳定结论，出处标注供核对）：

### T1 · 状态→特质固化律（本方案的主干理论）
**理论**：Fleeson 密度分布模型（2001）——特质不是固定值，而是「状态的密度分布」：一个人「外向 0.7」的真实含义是他的外向状态多数时间落在 0.7 附近。**Wrzus & Roberts 的 TESSERA 框架（2017）**给出完整因果链：`触发情境 → 期望 → 状态表达 → 反应结果`，这个短期序列**重复发生**，通过两条通路固化为长期特质：①联结式（habituation，重复即固化）②反思式（记忆与叙事强化）。
**一句话因果**：**反复处于某状态 → 该状态变成特质**。
**小可翻译**：某种表达方式（讲故事/开玩笑）反复出现且反复获得正反馈 → 该表达从「这次的选择」固化为「小可对这个孩子的稳定倾向」。M4 晶化池已实现「联结式」，M6 叙事已实现「反思式」——但两者没有汇入一个显式的特质数值。

### T2 · 效果律 / 强化学习（行为主义）
**理论**：Thorndike 效果律（1911）→ Skinner 操作性条件反射（1938）：**带来好结果的行为频率上升，坏结果的下降**。这也是 OpenHer 整个 reward→Hebbian 闭环的理论本体。
**一句话因果**：**正反馈 → 行为倾向增强**。
**小可翻译**：小可讲了个故事 → 孩子说「再讲一个」（投入 0.9）→ 「故事倾向」+δ。已实现一半（晶化门就是这个判定），缺的是把「过门事件」记账并推动特质数值。

### T3 · 社会学习 / 镜像趋同律
**理论**：Bandura 社会学习理论（1977）——行为经由观察他人习得；语言心理学的**语言风格匹配**（LSM, Language Style Matching, Niederhoffer & Pennebaker 2002）——长期对话的双方会不自觉趋同（语速、句长、词汇、情绪基调），且趋同度预测关系质量。
**一句话因果**：**长期相处 → 表达风格互相靠近**。
**小可翻译**：孩子话少且句子短 → 小可的「话痨度」缓慢下调（简洁陪伴）；孩子爱用拟声词打闹 → 小可「活泼度」上调。这是「小可因你而变」最直观可感的形态，当前完全没有。

### T4 · 依恋 / 安全基地律
**理论**：Bowlby 依恋理论（1969）+ Ainsworth 安全基地（1978）：稳定可预期的回应 → 安全依恋 → 孩子更敢探索；关系深度决定互动风格（陌生阶段礼貌试探 → 安全阶段放松真实）。
**一句话因果**：**可靠陪伴的累积 → 关系深化 → 互动风格换挡**。
**小可翻译**：M1 关系温度计已实现（会话数+天数→档位→语气分层）；promise 兑现率就是「可靠性」的直接操作化。已实现，缺展示因果。

### T5 · 荣格类型 / 用进废退律（MBTI 的理论底座）
**理论**：荣格《心理类型》（1921）：人有先天功能偏好（感知用 S 还是 N、判断用 T 还是 F），**偏好的功能因被反复使用而分化发展，非偏好功能弱化**——MBTI 的因果内核就是「先天倾向 + 使用强化」。注意学界共识：MBTI 作为**测量工具**信效度有限（二分法、重测漂移），但其「偏好—使用—强化」的因果直觉与 T1/T2 相容。
**一句话因果**：**先天基线 + 反复使用 → 偏好定型**。
**小可翻译**：①对孩子：M3 观察维度就是 MBTI 维度的「行为化改造」（好奇模式≈S/N 的行为面、表达风格≈E/I 的行为面、情绪表达≈T/F 的行为面）——保留因果、**坚持不输出类型标签**（儿童伦理，V1.0 已裁决）。②对小可：特质向量要有「人设默认值」当先天基线，成长=在基线上的有界偏移（呼应 OpenHer 弹性 baseline 与人格心理学的 set-point 弹性——人格变化围绕基线回归，Ormel 2017）。

**理论综述小结**：五条因果律两两相容，共同指向一个工程结构——**「触发事件 → 状态评分 → 重复累积 → 特质漂移（有弹性基线）→ 表达变化」**，且每一跳都应留账。这正是下面的模型。

## 三、小可人格成长因果模型（核心交付）

### 3.1 因果五环链（每环都可观测、环环留账）

```
① 交互事件           ② 感知评分            ③ 状态累积             ④ 特质漂移              ⑤ 表达变化
孩子说了什么     →   本轮情绪/投入评分   →   气氛EMA/晶化/画像   →   小可特质向量微调    →   下一轮语气与方式
(trigger_quote)      (turn_valence等)        (M1-M4 已有)           (新增,弹性拉回)         (prompt 注入,已有)
     └────────────────────────── 每一跳写入成长账本 growth_ledger ──────────────────────────┘
```

理论对应：①→② 是 TESSERA 的「触发→状态」；②→③ 是效果律的强化累积；③→④ 是 Fleeson/TESSERA 的「状态重复→特质固化」；④ 的弹性拉回是 set-point 律；③里的镜像通路是 Bandura/LSM；关系档位对语气的调制是依恋律。

### 3.2 新增之一：小可特质向量（真正会「长」的人格层）

per-child 五维显式特质，每维 [0,1]，**人设默认值 = 先天基线**（荣格律），变化=EMA 慢漂移+**弹簧拉回基线**（set-point 律，人设漂移防线，弹性系数可 admin 调）：

| 特质维度 | 默认 | 上行因果（什么让它涨） | 理论 | 下行因果 |
|---|---|---|---|---|
| 活泼度 | 0.6 | 孩子玩闹/笑声轮次（镜像）+ 玩笑获正反馈（强化） | T3+T2 | 孩子长期低落/安静 → 缓降 |
| 话语量 | 0.5 | 孩子话多句长 → 镜像上调 | T3(LSM) | 孩子简短应答 → 镜像下调（简洁陪伴） |
| 故事倾向 | 0.5 | 讲故事后孩子投入↑/「再讲一个」 | T2 | 故事后孩子敷衍 → 缓降 |
| 温柔度 | 0.7 | 孩子情绪敏感/低落时轻柔回应获得情绪好转 | T2+T4 | （地板 0.5——温柔有下限，儿童红线） |
| 好奇引导 | 0.5 | 孩子追问链变长（悬念式回答有效） | T2 | 追问链变短 → 缓降 |

- **更新时机**：轮末抽取链（已有 turn_valence/engagement 处），零新增 LLM 调用——镜像规则用规则量（句长/字数/拟声词计数），强化规则用已有评分+表达方式标记。
- **每次调整 |δ|≤0.02**（慢变量），弹簧拉回 0.01/日 → 特质是「几周尺度」的成长，不是一轮一变——符合 T1「重复才固化」。
- **注入**：数值+锚点一行（同 M1/M2 风格）：`【小可对这个孩子的相处倾向·数据】活泼:0.72 话语量:0.44(偏简洁) 故事:0.81 …`+policy「按倾向自然表达,不复述」。
- **儿童红线继承**：温柔度有地板；全维度有界 [基线±0.35]；admin 一键重置。

### 3.3 新增之二：成长账本 growth_ledger（因果的物质载体）

每次状态/特质变化写一条**因果记录**（现有各写入点顺手记，零新链路）：

```sql
CREATE TABLE growth_event (
  id TEXT PRIMARY KEY, account_id TEXT NOT NULL, ts INTEGER NOT NULL,
  module TEXT NOT NULL,     -- relation|style|trait|insight|narrative|concern
  dimension TEXT NOT NULL,  -- 具体维度：valence_ema / 故事倾向 / 经验池 …
  from_val TEXT, to_val TEXT,
  trigger_quote TEXT,       -- 触发的孩子原话片段 ≤50 字（危机过滤后；这是「因」的锚）
  rule TEXT NOT NULL,       -- 机制规则 id：ema_valence / crystallize / mirror_lsm / reinforce_story …
  theory TEXT NOT NULL,     -- 理论标签：state_to_trait / reinforcement / social_mirror / attachment / setpoint
  note TEXT                 -- 人话一句：「朵朵连续追问三次恐龙 → 好奇引导 0.52→0.54」
);
```

- 记账范围：气氛 EMA 更新、会话切档、晶化入池/合并、特质每次 δ、画像维度新增/变化、叙事更新、concern 入库/到期触发、弹簧回拉（也是事件——「一周没讲故事，故事倾向 0.81→0.79 回落」）。
- 治理：per-account 上限 800 条环形淘汰；trigger_quote 过既有危机过滤；不记 SN/手机号。

### 3.4 后台可视化（Worker Brain「人格成长」tab 增强为三视图）

1. **成长时间线**（默认视图，因果日志流）：`8-25 21:33 因为孩子说「再讲一个白鲸的」 → [强化律] 故事倾向 0.50→0.52 ↑`——每条=时刻+触发原话+理论标签+维度变化，可按模块/维度筛选。**这就是川哥要的「因为什么成长成什么」**。
2. **特质雷达**：五维当前值 vs 人设基线双层雷达；点任一维展开「把它推到这里的 top5 贡献事件」（从账本聚合）——人格快照+归因。
3. **机制因果图**：五环链静态图（①→⑤），每环节点挂该环实时数（本周事件数/当前 EMA/池大小/特质偏移量），环上标注理论出处——把「说明书」画在数据旁边，白盒的理论层。
- 现有六卡保留（结果层），三视图是新增的因果层；「注入实况」卡加特质行。

## 五、边界与风险

1. **不做的**：不输出 MBTI 类型标签（对孩子/对小可都不）；不做「人格测试」产品形态；特质不进家长报告 P0（先内部观察，措辞合规后再出——「小可变得更爱讲故事了」是可爱的家长卖点，但先验证一个观察周期）。
2. **理论标签的诚实性**：账本里的 theory 字段是「机制的理论出处」不是「科学证明」——后台文案写「依据 XX 理论设计」，不写「符合 XX 理论证实」。
3. **镜像规则的度**：LSM 趋同是温和的（δ≤0.02+弹簧），且话语量镜像有下限——孩子极端沉默时小可不能也沉默（陪伴产品的主动性底线）。
4. **账本的观察者效应**：账本是观测不是机制，绝不让「为了好看的时间线」反向驱动规则设计。
