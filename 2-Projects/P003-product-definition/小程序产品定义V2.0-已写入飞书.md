## 一、定位与原则

**小程序是什么**：家长端唯一载体——家长的所有触点（配网、看状态、定约定、看周报、看孩子的 KidsHub 成长、收回告）都在这里。它的使命是让家长持续觉得「**这钱花得值**」（家长端北极星），从而不退货、愿推荐。

**五条体验原则（所有页面与推送共同遵守）**：

| 原则 | 规则 | 为什么 |
| --- | --- | --- |
| 微信闭环 | 全功能在小程序完成，绝不强制下载 App | D0 家长很疲惫，门槛多一步漏斗掉一截 |
| 报喜不粉饰 | 周报以亮点为主；报忧必须配可操作的解法 | 全是冷数据给家长添堵；报假喜被识破更伤 |
| 极低打扰 | 推送频控铁律见 4.2；召回责任主要在设备端 | 老催家长 = 关通知 → 失联 → 退货 |
| 孩子被看见 | 孩子的努力（家族币）和表达（KidsHub）必须呈现给家长 | 家长看见 → 线下鼓励 → 二级沉没成本 → D30 留存 |
| 不碰钱不监工 | 现实奖励只记录提醒、绝不代付；不做实时遥控、不做监控画面 | 守住信任与定位底线 |

| 模块 | 做什么 | 规则 |

## 四、关键机制规格

### 4.1 家族币体系（头号改造 · 从「时长积分」切换）

**为什么必须改**：现行「1 分钟 = 1 积分」直接诱导孩子刷时长——撞护眼定位、撞北极星（要的是主动使用占比不是时长）、撞小可「不诱导过度使用」红线。

| 项 | 规格 |
| --- | --- |
| 产出 | **只来自**：夜航收益（主）、迎新礼、任务 / 学习行为事件。**彻底停用使用时长产出** |
| 命名 | 全端统一「家族币」（Pro 的「积分」文案一并更换） |
| 消耗 | 仅用于亲子约定兑现；设备内皮肤等虚拟奖励**不占**家族币（靠学习行为解锁，PRD 既有） |
| 迁移 | 老积分余额 1:1 转为家族币，流水标记「历史积分迁移」；老奖励自动归入约定模板分类 |
| 铁律 | 家族币**永不清零**；**不做审批流**；现实奖励**家长绝不代付**（小程序只记录 + 提醒） |

**兑现状态机（云端统一定盘，三端一致）**：

| 状态 | 进入条件 | 各端表现 |
| --- | --- | --- |
| 进行中 | 约定创建 | 兑换页进度条 |
| 已达成 | 攒够家族币 | **设备先告诉孩子**「达成啦」 |
| 待家长兑现 | 孩子在设备端点击 / 语音确认兑换 | 云端同步 → 小程序 + 微信提醒家长（责任感措辞） |
| 已兑现 | 家长线下兑现后点「已兑现」 | 落打卡流 |
| 待兑现（安抚） | 提醒后 24h 家长未处理 | 自动转入，设备端由系统话术安抚孩子，不让孩子空等；小程序置顶提醒 |

### 4.2 推送纪律（红线，违反即 bug）

夜航助攻 ≤1 条/天 ｜ 周报 ≤1 条/周 ｜ 弱召回只并入周报、永不单独发 ｜ 流失拦截 30 天频控 ｜ 夜间（22:00-8:00）静默 ｜ 一切重要内容必须落消息中心可重看（推送只是提醒）｜ 未读的兜底走「下期周报二次提示」，**不允许加推**。

### 4.3 配网与建档增强（改造现有流程，不重做）

| 项 | 现状 | 改造 / 新增 |
| --- | --- | --- |
| 配网全流程 | 已开发可跑（扫码 → 蓝牙 → WiFi，含全部异常态） | 保留 |
| 异步建档 | 配网后单独建档页 | **改造**：连接 loading 间隙浮层填「孩子昵称 / 年龄」 |
| 建档可跳过 | 不可跳过 | **改造**：可跳过，跳过时云端从预设词库生成随机昵称兜底；首页保留「补全孩子信息」轻提示 |
| 称呼链路 | 昵称仅展示用 | **改造**：昵称下发设备端 = 小可对孩子的称呼源（家长预设 > AI 随机兜底） |
| 未激活提醒 | 无 | **新增**：T+1 / T+3 推送（扣周末），T+5 转人工客服 |
| 埋点 | 基础 | **新增**：闸门 1（设备激活）/ 闸门 2（孩子首次有效使用）双事件 + 配网五步漏斗与错误码上报 |

### 4.4 命名统一（已拍板）

AI 伙伴全端统一叫「**小可**」。已开发体系中的「小未」（唤醒词「你好小未 / 小未小未」、「小未AI 规划」等）为旧名，本版起 UI 文案、语音词库、推送话术、后台字段展示全部更换；改名工程节奏由 AI 团队排期，小程序侧文案本版直接用「小可」。

## 五、P0 / P1 交付切分

**P0（6.30 · 七件事）**：

1. 家族币改造：停时长产出 + 口径切换 + 1:1 迁移 + 兑现状态机 + 「新建亲子约定」；
2. 首页改造：夜航收益透出 + 坐姿守护次数 + 生态缸快照 + 消息铃铛；
3. 周报基础版：高光 + 护眼硬数字 + 弱召回位；
4. KidsHub 家长主页基础版：时间线 + 等级 + 署名；
5. 消息中心基础版（回告落点 + 红点）；
6. 夜航助攻推送（频控 + 夜间静默）；
7. 配网增强：异步建档 + 跳过 + 随机昵称兜底 + 双闸门埋点 + T+1/3/5 提醒。

P0 降级预案：若资源吃紧，流失拦截软弹窗可降至 P1 首项；其余六件不降。

**P1（7.30）**：流失拦截完整版（答题 + 即时分流挽回：嫌没用→价值解读 / 太贵→挽留权益 / 不会用→教程）；定向回告完整闭环；周报历史详情页（柱状图 / 日历 / 周月记录 / 视力折线）；分享卡（含朋友圈 / 小红书渠道评估）；VID 智能建议升级（按视力档案动态推荐）；周报分层推送完整策略。

## 六、边界与暂缓项（明确不做，防止跑偏）

| 项 | 决策 | 说明 |
| --- | --- | --- |
| 远程控制（开关灯 / 亮度 / 色温 / VID 遥控） | **当前版本不上**（已拍板） | 后续版本若重启，方向为「场景参数预设下发、设备端确认执行」，不做实时遥控；多维表格 V2.0 中相关 P0 条目按本决策调整 |
| 多孩子 / 多设备 | **暂不考虑**（已拍板） | 维持一账号一孩子一设备；切换设备（V2.0 P2）一并暂缓 |
| 实时监控类 | 不做 | 无摄像头画面、无实时锁屏——小程序不是监工工具 |
| 内容安全 / 虚拟支付 | 边界 | 家族币仅限行为兑换，不接入任何资金流与虚拟支付 |
| AI 对话 / 录音转录 / 图文识别（V2.0/V2.1 规划） | 不在本版定义 | 待 AI 路线明确后单独立项，命名统一用小可 |
| 医疗合规 | 红线 | 视力数据展示只说「记录与守护」，禁说「治疗 / 改善 / 控制近视」 |

## 七、验收指标（效果看数，不看感觉）

- 配网前引导转化率 85% / 配网成功率 75%（PRD 0.1 口径）；
- 夜航助攻点击 → 当日孩子开盖率；周报打开率 + 连续未读率；
- 亲子约定创建率、待兑现 24h 内家长处理率（核心：孩子不空等）；
- KidsHub 家长主页 UV、家长访问后孩子 7 日提交率；
- 定向回告打开率、回告后家长再次反馈率；
- 红线监控：推送频控违规数 = 0、家长关通知率不升高。
