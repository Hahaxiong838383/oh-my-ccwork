**📐 原型与交互 · 兑换（家族币）**

**交互逻辑（开发口径）**：

1. **余额区**：显示家族币余额 + 来源摘要；点「记录 >」→ 收支流水页（历史积分迁移条目带「历史积分迁移」标记）；
2. **待兑现置顶区**（本页核心新增）：存在「待家长兑现」事项时永远置顶，醒目色；按钮「标记已兑现」→ 二次确认弹窗 →（确认）状态转「已兑现」落打卡流 + 云端同步设备端告知孩子；超 24h 未处理的事项显示「孩子在等你哦」安抚提示（设备端同步安抚话术由云端负责）；
3. **新建约定**：入口「+ 新建约定」→ 新建页：先选模板（6 个，可改）→ 表单（名称 / 所需家族币 / 分类 / 图标）→ 创建成功回列表；
4. **约定列表**：每条显示进度条（当前币 / 目标币）；进度达成时云端触发「已达成」状态 →（设备端先告诉孩子 → 孩子确认 → 转待兑现，流程见 4.1 状态机，小程序端不需要「家长发起兑换」入口）；
5. **删除/编辑约定**：长按或右滑 → 编辑 / 删除（删除二次确认；进行中有进度的约定删除时提示「孩子攒的进度会保留为家族币余额」）；
6. **迁移兼容**：升级首次进入显示一次性说明浮层「积分已升级为家族币，余额已自动转换」。
