### 4.1A 家长任务与补勤卡机制

**家长任务（P0 · 家族币主动产出线）**：

| 项 | 规格 |
| --- | --- |
| 定位 | 亲子约定的核心触发点：做任务赚币 → 攒币兑约定，与夜航收益（被动线）构成双产出 |
| 创建 | 仅家长在小程序创建（模板 + 自定义）；任务信息同步云端 + 设备端 |
| 确认 | **确认权在家长**（现实任务设备无法验证）；孩子设备端可标「完成」转待确认态 |
| 到账 | 家长确认 → 币即时到账 → 设备端小可庆祝；待确认事项落消息中心 |
| 防刷 | 币只走家长确认，系统不按使用时长自动发币；每日任务日确认上限 1 次；币奖励建议区间 10-50 后台可配 |
| 红线 | 任务状态无负面终态；任务不可由系统替家长创建；不做任务排行榜等比较性展示 |

**补勤卡（P1 · 连签心智保护道具）**：

| 项 | 规格 |
| --- | --- |
| 获取 | 仅宝箱掉落（KidsHub 不发、不售卖、不课金——PRD 既有） |
| 使用 | 孩子在设备端一键使用；一卡补一天（缺勤天数 + 期间离线收益） |
| 小程序侧 | 道具区只读：持有数量 + 使用流水（家长可见，不可代用） |
| 数据口径 | 补勤覆盖当天单列「修复性使用日」副指标，绝不灌进主 KPI（与 Web 后台口径一致；产品无暂停模式，缺勤一律走补勤卡） |
| 防滥用 | 掉落概率与持有上限由云端配置；后台盯「补勤卡使用率」防灌水 |
