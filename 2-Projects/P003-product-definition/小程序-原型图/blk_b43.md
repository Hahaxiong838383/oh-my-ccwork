**📐 原型与交互 · 配网与建档（改造点）**

**交互逻辑（开发口径，全流程界面已开发，以下仅改造增量）**：

1. **异步建档浮层**：在「连接网络页-连接中」等待期间（实测 10-30 秒）弹出底部浮层「等待时填一下：孩子昵称 + 出生年月」，两个字段 + 「跳过」；填完 / 跳过都不打断配网主流程；
2. **跳过兜底**：跳过 → 云端从预设词库生成随机昵称（如「小航海家」）→ 首页保留「补全孩子信息」提示条；后续在「我的-孩子管理」可改；
3. **称呼下发**：建档成功（含随机兜底）即把昵称下发设备端，作为小可 D0 登舰的称呼来源——保证孩子第一次开盖小可就能叫出名字；
4. **埋点（新增）**：配网五步漏斗（扫码进入 → 蓝牙连接 → WiFi 配置 → 心跳成功 → 建档完成）每步上报 + 失败错误码；闸门 1（心跳+绑定+建档）/ 闸门 2（开盖+交互+>5min）双事件按 PRD 0.1 口径上报；
5. **失败兜底（已开发保留）**：蓝牙拒绝 / 位置拒绝 / 搜不到设备 / 已被绑定 / WiFi 失败各异常态沿用现有页面，新增「联系客服」入口在连续 2 次失败后出现。
