**3.3A 家长任务与道具（新增区块 · 亲子约定的核心触发点）**

家族币双产出线在此闭环：**被动线 = 夜航收益**（合盖自动），**主动线 = 家长任务**（现实行为赚币）→ 攒币 → 兑现亲子约定（花币）。创建约定时引导顺手建任务：「想换『去游乐园』？给孩子发几个任务攒币吧」。

| 模块 | 做什么 | 状态 |
| --- | --- | --- |
| 家长任务区 | 任务列表（进行中 / 待确认红点）+「+ 新任务」入口，位于待兑现区与亲子约定区之间 | **新增（P0）** |
| 新建任务 | 模板（阅读打卡 / 帮做家务 / 整理书包 / 练字一页 / 户外运动…）+ 自定义；字段：任务名 / 币奖励（建议 10-50）/ 频次（一次性 或 每日可重复） | **新增（P0）** |
| 道具区（补勤卡） | 显示孩子持有的补勤卡数量 + 使用记录；**使用在设备端由孩子完成**，小程序只展示不代用 | **新增（P1）** |

**交互逻辑（开发口径）**：

- **创建任务**：兑换 Tab「+ 新任务」→ 选模板或自定义 → 设币奖励与频次 → 创建即同步云端 + 设备端（小可告知孩子「妈妈给你发了新任务！」）；
- **完成判定（确认权在家长）**：路径① 孩子在设备端告诉小可「我完成了」→ 任务转「待确认」→ 家长小程序收轻通知（落消息中心，实时 1 条，不加推）；路径② 家长直接在小程序任务卡点「完成」。家长确认 → 家族币到账 → 设备端小可庆祝播报；
- **任务状态机**：进行中 → 待确认 → 已完成（币到账）；**无失败 / 拒绝负面态**，过期任务静默归档不批评孩子；
- **防刷红线**：家族币只由家长确认发放，**系统绝不按使用时长自动发币**；每日可重复任务每天最多确认 1 次；
- **与约定联动**：新建约定成功页提示「再发个任务帮 TA 攒币」一键带入新建任务；任务确认到账时若有进行中约定，提示「离『XX』还差 N 币」；
- **补勤卡（道具区）**：仅展示数量与使用流水（获取 = 宝箱掉落；使用 = 孩子在设备端一键补回缺勤天 + 期间离线收益，一卡一天）；补的天在数据口径单列「修复性使用日」，不进主 KPI。
