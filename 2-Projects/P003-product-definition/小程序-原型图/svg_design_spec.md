# P003 小程序原型图 SVG 生成规范（严格遵守）

## 设计语言（与已上线小程序一致）
- 画布：手机竖屏 `<svg xmlns="http://www.w3.org/2000/svg" width="390" height="844" viewBox="0 0 390 844">`
- 背景：#F7F8FA；卡片：白色 #FFFFFF，圆角 rx=16，无描边（可加极淡阴影色块模拟）
- 主色（橙）：#FF7A45；辅橙：#FFA940；浅橙底：#FFF3EC
- 文字：font-family="PingFang SC, sans-serif"；主标题 17/600 色 #1F2933；正文 14 色 #1F2933；辅助 12 色 #8C94A3；数字大字 26-32/700
- 状态色：成功绿 #52C41A；警示红 #FF4D4F；信息蓝 #4A9DF0；紫 #9B7BF0
- 状态栏：顶部 y=0-44，左侧 "9:41"（15/600），右侧画 3 个小矩形代表信号/wifi/电池
- 导航栏：y=44-88，标题居中 17/600
- 底部 TabBar：y=761-844，白底 + 顶部 1px #EEE 分隔线；**5 个 tab 等分**：首页 / 周报 / 兑换 / KidsHub / 我的（每个 tab：上方 20x20 圆角小方块当图标占位 + 下方 11px 文字）；**当前页 tab 用 #FF7A45，其余 #8C94A3**
- 内容区：y=96-750，左右边距 16，卡片间距 12

## 硬性要求
1. 纯 SVG：只用 rect / circle / text / line / path / polyline，禁止 image、外部引用、script；
2. 所有文字用 <text>，中文直接写；数字用真实示例值（贴近真实场景）；
3. 每张图输出为独立的 ```svg 代码块，代码块前一行写 `### 图N：文件名`；
4. 文字不能溢出卡片；布局留白充足；列表项 3-4 条即可示意；
5. 图标一律用简单几何形状占位（圆/圆角矩形/三角），不画复杂 path。
