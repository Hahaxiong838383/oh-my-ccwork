**📐 原型与交互 · 我的**

**交互逻辑（开发口径）**：

1. **页面骨架**：个人中心头 + 分组列表（孩子管理 / 视光报告 / 设备管理 / 消息中心 / 设置 / 使用帮助），复用现有结构，新增「消息中心」行（带未读红点）；
2. **孩子管理**：档案编辑（昵称 ≤10 字 / 头像 / 性别 / 出生年月 / 是否近视 + 左右眼度数）；**昵称保存时同步下发设备端**（= 小可称呼源，弹提示「小可会用新昵称称呼孩子」）；家族币记录入口；
3. **视光报告**（已拍板保留并接周报）：列表 + 新建（视光中心选择 / 时间 / 左右眼度数，自动按孩子档案带出年龄）+ 编辑 / 删除（删除二次确认）；保存成功提示「已纳入周报视力趋势」；
4. **设备管理**：设备信息（名称改名 ≤10 字 / 型号 / SN / 软件版本）+ 移除设备（二次确认，保留使用数据）+ **坐姿提醒间隔配置**（滚轮 20/30/45/60 分钟，保存即云端下发、设备端确认后生效——这是「参数预设下发」，不是实时遥控）；
5. **消息中心**：全部通知按时间倒序（夜航助攻 / 待兑现提醒 / 定向回告 / 周报），全部可重看；未读红点进入即消；点击各条 → 跳对应落点（兑换 Tab / 周报 Tab / 回告详情浮层）；
6. **设置**：权限管理（蓝牙 / 位置 / 通知开关状态展示与引导）；语言（本期仅简中，置灰）。
