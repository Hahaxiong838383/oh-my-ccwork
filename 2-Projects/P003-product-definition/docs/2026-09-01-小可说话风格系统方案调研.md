# 小可说话风格系统方案（可调 / 可成长 / 可自定义）

> 需求（川哥 2026-09-01）：小可的说话风格（话痨型/简洁型等）要能根据**用户要求**和**小可自己的人格成长**变化，可调整可自定义。
> 调研方式：GitHub 三大生态本地克隆读源码（证据标注到 file:line）+ Anthropic 研究。
> 状态：方案已定，**P0 已批准排期候选**（预期效果与预设模板详设见 §四）。

## 〇、结论

把「说话风格」从人设散文里拆出来，建成结构化**风格档案（style_profile，per-SN）**：维度滑杆 + 风格规则 + 示例对话三件套。用户调整与人格成长写同一份档案的不同字段，注入时实时渲染进 system prompt。业界三大生态（SillyTavern 角色卡 / Eliza / Letta）已验证做法的交集；P003 人格成长基建（特质向量+EMA+弹簧回拉+成长账本）已把「成长驱动」建完，本需求增量=风格维度化 + 用户写入口 + 护栏。

## 二、三层设计

### L1 · 风格档案（per-SN 新数据结构）

```
style_profile {
  dims: { verbosity 话痨度 1-5, liveliness 活泼度 1-5,
          humor 幽默度 1-5, initiative 主动话题度 1-5 }
  rules: ["回答尽量两三句话", ...]          // Eliza 式规则数组
  catchphrases: ["哇塞", "让我想想哦"]       // 口头禅
  address: { self: "小可", user: "小豆丁" }  // 称呼（对应 v3 nickname）
  examples: { voice: [...], local_audio: [...] }  // 分通道示例对话（mes_example）
  revision: N                                // 版本化可回滚
}
```

渲染：维度值 → 语体指令段 + rules + 2-3 条 examples 进 system prompt。**示例对话是风格锁定主力，维度数值是索引。**

### L2 · 双写入口（同一档案两个写者）

| 写者 | 通道 | 机制 |
|---|---|---|
| 用户显式 | 家长端：预设模板+维度滑杆+自定义口头禅/称呼 | 直写 profile，revision+1，30min 轮询口径热生效 |
| 用户显式 | 孩子语音：「你说话短一点」 | 意图漏斗加 style_adjust 一路 → 改维度 → 小可口头确认（确认话术=可感知反馈） |
| 人格成长 | insight/成长账本事件 → 维度 EMA 微调 | **全套在产基建复用**：EMA 省略、弹簧回拉、账本只写不读主链；成长引起的风格变化写账本，家长端可视 |

冲突规则：**用户显式设置=硬约束（设为 baseline），成长只在 baseline 附近漂**——弹簧锚点从出厂值换成用户设定值。

### L3 · 护栏（儿童产品分界线）

1. 安全语体红线（礼貌底线/适龄表达/禁词）在档案之外固定 prompt 段，任何组合改不掉（Letta read_only 思路）；
2. 成长漂移 EMA + 单日变化量封顶（防「睡一觉性情大变」恐怖谷）；
3. revision 版本化 + 家长端「恢复默认性格」一键回滚；
4. 重置/回滚不得触碰本地音频 revision 等合同冻结物（scope 语义先例）。

## 三、落地路径

- **P0**：style_profile 表 + custom-llm.ts 注入渲染段 + 家长端预设模板选择。不动成长系统。
- **P1**：维度滑杆 + 口头禅/称呼自定义 + 语音指令调风格 + 示例对话库配齐。
- **P2**：风格维度接人格成长（EMA+账本+家长端成长可视化）；本地音频文案生成读风格档案（招呼语随人格变，闭环）。

风险：维度指令与人设 prompt 配比需实测——太强会把小可压成参数机器人；P0 用真机对话样本做风格 A/B 后再放开全域。

## 四、P0 详设：预期效果与预设模板

### 预期效果（可验收口径）

1. **家长可感知**：家长端给设备选模板 → ≤30min 生效（轮询口径）→ 孩子问同一个问题，不同模板的回答**盲听可区分**（验收=同题三模板样本盲测区分率）。
2. **人设不丢**：任何模板下小可还是小可（世界观、称呼习惯、安全底线不变）——模板只调「怎么说」，不改「是谁」。
3. **随时可回**：一键恢复默认，revision 可追溯。
4. **零风险面**：不动 worker、不动端、不动人格成长主链；注入段 fail-open（档案读不到=现状人设）。

### 预设模板（P0 四档）

| 模板 | 定位一句话 | 维度组 | 风格规则要点 |
|---|---|---|---|
| **默认小可**（出厂） | 现状人设=平衡档 | 全维度 3 | 现有行为不变（对照锚） |
| **话痨小可** | 爱聊爱延伸的小话匣子 | verbosity 5 / initiative 4 | 回答后主动延伸一个相关话题或反问；爱举生活例子；口头禅使用频率高 |
| **安静小可** | 惜字如金的安静陪伴 | verbosity 1 / initiative 2 | 每轮 ≤2 句；不主动扯远；多留白多倾听；适合专注学习场景与内向孩子 |
| **搞笑小可** | 自带笑点的开心果 | humor 5 / liveliness 5 | 拟声词+夸张比喻；爱用「谐音梗冷笑话」；重要事实内容不牺牲准确性 |

同题对比示例（「小可，恐龙为什么灭绝呀？」）：

- 话痨：「哇这个问题超棒！最主流的说法是一颗大陨石撞了地球，扬起的灰尘把太阳都挡住啦，植物长不出来，恐龙就没饭吃了。对了，你知道吗，鸟类其实是恐龙的后代哦——要不要听听哪种恐龙变成了鸟？」
- 安静：「大陨石撞了地球，天变暗了，恐龙没了食物，就慢慢消失了。」
- 搞笑：「轰隆——！一颗超级大陨石『咚』地砸下来，灰尘把太阳遮得严严实实，恐龙们连饭都找不到啦。要我说，恐龙要是会写作业，说不定早就想出办法躲进地下室了，嘿嘿。」

（示例为方向性样例，P0 上线前按各模板配 2-3 条真实示例对话进 examples 字段。）
