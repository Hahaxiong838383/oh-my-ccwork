## 3. 建议（端侧，worker 不改）

1. **放行时机改到招呼语「声音结束」**：加载 WAV 时按能量裁掉尾部静音得到 audible_end，放行 = audible_end（最多 +50 ms），去掉 200 ms 尾音保护——这 0.3–0.6 s 正是缺字来源。招呼语尾巴若漏一点进上行，worker 精确回声库（内置 9 + 动态）和 v4 门兜底；招呼语文本短且已知，比丢用户前 3 个音节便宜得多。
2. 或**能量门代替固定尾音**：只在本地播放器正在输出可闻样本时置零，输出停止即放行。
3. UI 提示不用动（人不等 UI）。
4. 房 2「出」类 AEC 起始抑制：端侧若能把 AEC 抑制等级调低一档或缩短双讲检测窗（WebRTC APM 参数），播报中短命令首音节存活率会提高；不建议 worker 改 VAD/ASR。
5. 验收：提示音一停就说「说个长句测试一下」×3，worker 侧有声时长 ≥1.5 s、final 3/3 完整；快照里放行点与首个高能帧之间应有 ≥150 ms 的低能过渡（人先于放行开口的判据反过来就是 PASS 判据）。
