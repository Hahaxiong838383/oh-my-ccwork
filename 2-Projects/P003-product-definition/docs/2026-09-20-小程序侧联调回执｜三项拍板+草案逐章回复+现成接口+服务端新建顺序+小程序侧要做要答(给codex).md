## 1. 对草案的回复（按草案章节）
- §2 公共约定：不按草案，按服务端现状冻结——时间 epoch 毫秒 `*_ms` + 日期 `YYYY-MM-DD`（Asia/Shanghai）；JSON snake_case（camelCase 由你侧 DTO 层转）；错误 = HTTP 状态 + `{ok:false, error, message?, retry_after_s?}`；新列表接口 `?limit&cursor` → `{items, next_cursor, has_more}`；写接口 `Idempotency-Key`。ID：userId `acct-NN`、childId uuid、deviceId `public_id`（`dev_<16hex>`，路由只用它，SN 只展示）。
- §3 账号 / 儿童 / 归属：接受 N 孩子（cc 新增 children CRUD，含近视 / 度数 / 戴镜 / 头像 / profile_status；gender 冻结 male/female）。关系表简化为 `device.child_id` + 绑定历史，无多家长、无 role/canView 之类授权字段。儿童档案在服务端是两份（家长档 + 设备 brain 档），你只读写家长档，基础三字段由 cc 同步到设备。
- §4 设备 / 配网 / 控制：配网不是 BLE。阶段 A（家庭 Wi-Fi）在设备 SoftAP 本地页完成，小程序、你侧服务器、cc 都不参与，Wi-Fi 密码不经任何云端；阶段 B 小程序 `wx.scanCode` 得 `{sn, nonce, pk}` → 经你侧透传 confirm → 轮询 status。ProvisioningSession 里的 networkStatus / SSID 列表 / 密码 / 连续失败计数不在服务端。DeviceSettings 由 cc 开家长侧读写（坐姿提醒开关与间隔、语音开关与每日上限），`applied_revision` 设备回报前为 null。model 由设备上报，上报前 null；固件只有 APK 版本名。online = 最新快照 10 分钟内（已定）；「本次专注」由服务端推算。
- §5 使用记录 / 首页统计：原始事件不给小程序；今日 / 近 7 天走现成 dashboard；任意区间、日历、`active`（当天存在连续 ≥300 秒专注段）、`availability` 由 cc 新增设备日区间与孩子级汇总接口给；无数据 = null/`no_data`，不再用 0 冒充。

## 4. 你侧要做的
4.1 小程序服务器（BFF）
- 备案域名 + HTTPS；固定出口 IP 并告知 cc（白名单）。
- 微信登录：getPhoneNumber 的 code 用你侧 AppID/AppSecret 向微信换手机号 → 调 cc 伙伴登录（头 `X-Partner-Id` / `X-Partner-Key`，体 `{phone, wx_openid?, wx_unionid?, client}`）→ 得家长 JWT。伙伴密钥由 cc 经安全渠道单独给，不进仓、不进文档、不进聊天。JWT 到期用已存手机号再调一次伙伴登录静默换新。
- 每次调 cc：`Authorization: Bearer <家长 JWT>`；`X-Forwarded-For` **覆写**为终端用户 IP（不带则全体用户共用一个 IP 限流桶，短信发送每日 20 次的 IP 窗会拦全体）；`X-Request-Id`（≤96）；`User-Agent: <服务标识>/<版本>`。
- 错误透传：cc 的 4xx/5xx 与 `{ok:false,error,message}` 原样或映射后给小程序，不得把失败变 200 空态；429 尊重 `retry_after_s`。
- 缓存：dashboard / weekly-report / daily / wallet 按「账号 + 键」30–60 秒，写后失效；登录与写操作不缓存。
- 日志脱敏：SN 只末 8 位、手机号掩码、无 JWT、无伙伴密钥。
4.2 小程序
- DTO 层做 snake_case → camelCase 与毫秒 → 展示时间的转换；不在小程序内置任何 cc 密钥；不直连设备、不直连 cc。
- 页面 ↔ 接口对齐表（每个页面用哪个接口、哪个字段），先按 §2 现成接口接，cc 每上线一项你切一项，未上线的按附件 shape mock。
- 空态与失败分开：200 里的 null / [] 才是空态；HTTP 失败要可重试、不伪装「暂无记录」。
- 首页设备状态组合：`online && present===true` 学习中；`online && present===false` 未学习；`!online` 离线；`present===null` 未知。
- 文案红线：视力数据只说「记录与守护」，禁说治疗 / 改善 / 控制近视；不展示 `note`；默认昵称「家长+尾 4 位」展示层再脱敏或引导改名。
4.3 老数据
- 读写台老小程序若有积分余额，导出 `{phone 或 openid, balance, 最后变动时间}` 给 cc 一次性迁移（流水标 `migration`），格式与时间在你侧回执里定。
