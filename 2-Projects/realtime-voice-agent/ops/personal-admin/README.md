# 小可个人语音后台 · 飞牛 2

本服务面向单主人，复用 P003 的管理员鉴权、热词校验与 SQLite 草稿存储、四种衔接短语风格配置。它有自己的管理页、数据与凭据。旧 P003 管理页还包含家长、方舟和示例运营统计，个人实例使用专用首页。

## 本次交付

局域网入口为 `https://192.168.1.115:18783/`。在 Vaultwarden 查找「小可个人语音后台（飞牛2内网）」。初装使用带 NAS IP 的自签证书，SHA256 指纹为 `26:D2:F8:6C:E3:44:C9:FC:05:D8:CA:F2:09:98:6B:5E:EB:A3:1E:55:23:06:A1:A3:31:FF:E7:E5:42:3F:AA:BC`。用户自行配置 Lucky 时，可将此 HTTPS 地址作为上游，使用该实例的证书建立信任。公网管理入口使用 HTTPS 和后台管理员口令。按主人 2026-11-25 的设置，Lucky 的 `pa.hahaxiong.cc` 子规则使用默认黑名单模式，无需登记公司、家庭或移动网络的出口 IP。

运行目录在飞牛 `/vol1/1000/docker/personal-voice-admin`。Compose 发布到 NAS 的 LAN IPv4 地址；容器以普通用户运行、根文件系统只读。配置存在 `data/`；证书、私钥、管理员口令仅从 `private/` 只读挂入。实例配置与 P003 生产环境独立。认证 Cookie 要求 HTTPS，有效期八小时，退出立即失效。

进入首页可检查后台版本、读写五类热词草稿和四种旧配置概率。旧配置以草稿展示。启用运行时 Compose 覆盖文件后，后台回读北京签票和飞牛大脑的健康载荷，并能使用单独的诊断会话进行文字试问。Worker 状态采样单列。热词草稿以版本号校验并发编辑。备份 SQLite 时使用在线备份或停此实例后完整复制数据卷，避免漏掉 WAL。

| 个人记忆 | 查当前值、来源和更新时间，添加有明确语义的称呼、偏好、事实，更正或忘记精确的一条。原话不可核验时显示原因。 |

大脑的管理接口另用私人管理密钥。部署时同一份 64 位小写十六进制密钥分别只读挂到大脑和后台，允许服务用户读取。手机、Worker、网页均不领取该密钥。设备技术统计只读挂入私人日志库，仅对已登记的设备开放。备份回执由解密恢复并验证所有六个数据库的备份程序发布。

公司版的大脑、热词、语音、设备配置、日志、OTA 与分析入口在此按私人服务的能力实现。家长账户、公司设备运营、方舟知识库、公司发版和灰度实验由公司版管理。私人维护台只使用自己的登录、数据库、设备登记和供应商配置。

## 重建

依赖来自仓库 `2-Projects/P003GameDemo20260513/apps/server/package-lock.json`。在独立构建目录安装锁定依赖后，以 `SERVER_NODE_MODULES` 指向其 `node_modules`。在本目录执行 `ADMIN_BUILD=<新版本> ./build.sh`，再向飞牛传输并加载同标签镜像。现有部署的 Compose 用 `.env` 中的 `ADMIN_BUILD` 选定镜像。在运行目录用 `docker compose up -d --no-build` 更换此服务。回退时选回已验证镜像并确认数据格式兼容。运行目录中的数据与私密配置跨重建保留。

验收顺序为核对证书、检查 `/health` 的服务名、匿名访问 `/api/settings` 返回 401、浏览器登录保存配置并重载，最后退出后再次检查 401。浏览器和反代应保留同源请求；只读查询与写入均需登录，写入额外要求自定义请求头。

## 语音供应商

私人供应商文件由 `PERSONAL_PROVIDERS_FILE=/run/personal-providers/providers.json` 指定。运行时把飞牛目录 `/vol1/1000/docker/personal-voice-runtime/private/providers/` 整目录可读写挂到 `/run/personal-providers`，保存时在同一目录建立临时文件并原子改名，权限为 `0600`。`revision` 同时保护新增、编辑和选择；提交的版本落后时返回 409。

`active` 里的 `null` 分别表示继续使用个人 CPA、飞牛中文识别和飞牛五音色。选择云端合成后，通话音色页会说明飞牛五音色只在切回内置后生效，供应商页显示当前云端音色。改变当前选择，或编辑已被选中的配置，只在 Worker 已注册且没有通话时允许。新增和编辑未选项不受此限制。

接口只返回密钥是否已经保存。应用 ID 也按密钥处理。编辑时把密钥留空会保留原值。DeepSeek 固定走官方 `https://api.deepseek.com`，请求里不能带其他地址。豆包识别地址只接受两个官方 `openspeech.bytedance.com` 端点。响应和日志都不包含密钥或由密钥派生的值。文件不存在时读取返回 revision 0，且不会创建文件，因此不会改变现有通话默认。

`GET /api/providers` 返回 `{revision,profiles,active,fallback,fields}`。`POST /api/providers` 与 `PUT /api/providers/:id` 接收 `{revision,kind,driver,name,config,secrets}`。`PUT /api/providers/active/:kind` 接收 `{revision,id}`，`id` 可为 `null`。配置和密钥的键使用大写环境变量名。

## 配置工作室与通话音色

运行顶栏每五秒读取北京签票、个人大脑和 Worker 的通话占用。Worker 心跳失效时显示占用未知。刷新探针不会覆盖正在编辑的词表。词表可查看相对后台已保存草稿的增删。私人语音大脑读取独立的聊天/查询衔接语配置，详见下表。

音色列表直接来自飞牛合成服务。选择备选音色，点击「试听样音」播放固定中文样句，再点击「应用到通话」。这是此私人实例的全局设置，管理员在 Worker 空闲时可切换。后台使用原音色 ID 检查同时修改，写入后重新读取合成服务，显示实际选择。现有管理登录与同源写入要求同样适用于音色操作。通过 Lucky 使用受信任的 HTTPS 即可播放样音。

只读浏览器复测可设 `ADMIN_TEST_URL`、`CHROMIUM_PATH` 和 `PLAYWRIGHT_MODULE`，将管理员口令经标准输入传给 `node verify.cjs`。检查每个音色的 WAV 可解码、有声音，且试听前后当前音色一致，同时覆盖未登录、手机布局与退出。切换与语音通话的实机记录见本次发布回执。
