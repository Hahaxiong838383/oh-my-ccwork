使用端的设备凭据与管理员口令分开管理。在手机或 Web 页面选择「仅用文字」可直接聊天，默认关闭「允许小可记住这条消息」。北京直连试点仍使用专用 CA；通过 Lucky 的私人入口无需向手机导入该 CA。

后台的 Worker 状态来自该进程在北京注册后持续写入的只读心跳，实机返回「北京已注册 · 0/2 路占用」。后台提供语音识别热词等五类草稿、四种衔接短语概率。页面显示保存状态；Worker 加载回执需另外验收。诊断试问通过后台受限接口转发到个人大脑，使用独立会话并关闭长期记忆写入。未向普通语音设备授予管理员权限。

## 测试证据

- **完整语音通话。** 在 390px Chromium 走正式私人 HTTPS 入口，将独立合成的普通话录音「现在北京时间几点了」送入麦克风。网页显示原问与「现在是北京时间下午一点三十分」，回放轨收到 187 个 RTP 包，累计音频能量 0.329。静音、恢复、结束通过。随后用手机和 Air 两份设备凭据开两个独立 Chromium，会话分别收到 172 和 177 个包及正确的 13:31 语音回复。飞牛心跳记录同时占用 2/2 路。以上会话都经过真实识别、个人大脑时间工具和本地合成。13:42 在最终语音镜像上再次双路通话，Air 收到 175 个音频包，手机凭据对应的浏览器收到 163 个，两端都播报了正确时间。
- **语音搜索与打断。** 对浏览器麦克风输入「帮我查一下今天的央视新闻」，页面收到新闻播报、同一条字幕上的央视原文链接和非零音轨。另一次在新闻播报中插问时间，同一个房间的 Worker 把新闻音轨记为 `Aborted`，并返回新问题的时间答案。
- **音色与识别质量。** 早期试点中发现长静默后断流和尾音漏识，已修复。最终飞牛镜像在同一连接静默 32 秒后仍正确转写「价格太高的原因」，合成「今天天气怎么样」用时 105 ms，得到 1.482 秒非静音语音，回送识别逐字一致。此次采用本地华燕音色，原有演示的付费语音配置留待单独选择。
- **北京媒体链路。** Chromium 与飞牛临时探针经 UDP 和 ICE/TCP 双向传音，收发双方检查了非零音频能量。强制 TURN/UDP 测试使用两个独立 Chromium 客户端，每端发送 126 个 RTP 包、收到 125 个，并解码到对方测试音。匿名 TURN 分配返回 401。[接入层配置、测试及回滚记录](../ops/personal-edge/README.md)
- **C 版真实文字对话。** 390px Chromium 从 Lucky 进入，按「仅用文字」提问，取得 Python 3.14.0 的发布日期 2025-10-07 和可点击的 python.org 原始页面。浏览器同时校验可靠数据消息里的来源 URL 和页面链接。随后重放重复消息、停止回复并追问时间，均在同一房间完成。匿名和无效设备返回 401，跨站签票返回 403，普通设备无法调用房间管理。更新后，强制要求答复来自派单 Worker 的浏览器复测通过，之后在零活动房间时停用了过渡文字中继。
- **工具与个人大脑。** 时钟、天气、央视和通用网页搜索经过真实上游。通用搜索通过个人 CPA，验证了实际搜索调用、URL 引用和来源正文。取消与会话隔离测试通过。同镜像隔离实例以独立主人验证两次会话之间的记忆写回、来源消息 ID、成长账本以及下一轮提示词采用；正式库不预填测试人物。[个人大脑发布与复测](../ops/personal-brain/README.md)
- **数据恢复。** 已在六个 SQLite 库上逐库做在线备份，加密后解密到隔离目录，重开全部数据库并运行完整性检查。篡改副本未通过认证。恢复演练覆盖飞牛后台三库、大脑三库；北京设备库和部署凭据另行保管。[备份脚本与覆盖范围](../ops/personal-backup/README.md)
- **容量口径。** 3–5 台是目标设备数。短时传音、单工具调用或进房都不能证明五路同时通话的首响、丢包和稳定性；尚未进行五路 30 分钟语音压测。
