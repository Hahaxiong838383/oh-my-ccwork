# P003 停话、关房与恢复聊天：真人复测

请使用已安装现役版本的内测设备；服务端发布完成后执行，不要求本轮 OTA。记录设备 SN 末 8 位、北京时间到秒、说法、是否正在回答及实际结果。遇到失败保留端侧 trace 和录音，不先重装清日志。

用户已裁决：A1–A11、B1–B4、B6 关房；B5 退出倾听后留房。“停一下、等等、先听我说、等我说完”保留停当前回答。这里的“关机、静音”仅结束本次小可对话，不关读写台、不修改系统音量、不禁用以后唤醒。

|步骤|操作与自然说法|预期|
|---|---|---|
|1|唤醒后先普通问答；小可回答时说“小可你先闭嘴”“先不用说了”“安静一点”“你先退下吧”，每句分别重新唤醒测试|停止输出并结束当前房间；不要再长篇解释或继续旧回答|
|2|分别说“够了”“不用了谢谢”“今天先聊到这吧”“今天先聊到这儿吧”|结束当前房间，两种“这／这儿”说法一致|
|3|发起天气或搜索后说“不要查了”或“取消搜索”|停止该搜索及当前对话，不能等待结果回来又继续播报|
|4|进入倾听后，分别说“恢复聊天”“可以恢复聊天吗”“能不能恢复聊天”，然后同房问“三加五等于几”|退出倾听、保留房间，恢复普通问答；不能把恢复聊天当关房|
|5|普通聊天时说“恢复聊天”|不关房、不误发倾听退出操作|
|6|小可回答时说“先听我说”或“停一下”；暂停后再问一个问题|停止当前回答但留房，可继续问答|
|7|分别问“闭嘴是什么意思”“我不想吃饭，给我讲个故事”“老师说请安静是什么意思”|不因为句中出现退出词而关房；允许正常回答|
|8|每次真正关房后，再喊“小可小可”并问普通问题|新房能正常建立和回答；不续播旧答案，不出现旧房残留|

步骤 1、3、4 各至少两轮；其他各一轮即可。若 ASR final 与原话不同，要同时记录识别文字，区分声学识别与服务器意图判定。没有 ASR final 的轮次不能记成规则命中失败或通过。

退出通知后服务器保留现有约 2.5 秒有界收尾；不要把房间删除耗时等同停止音频耗时。需要关注的是叫停后仍有可听旧内容、未关房、误关、B5 无法同房再问。

本轮不测试系统定时静音；“安静模式四小时”不属于已实现能力。服务器合成音频与规则测试不能替代这份真人/Android UI确认。
