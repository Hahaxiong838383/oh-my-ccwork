# 停话自然变体补齐与验收

状态：开发中，未发布。2026-11-14。

## 目标与决策

用户不必背标准口令；明确让小可闭嘴、结束对话的自然短句应立即停止输出，并沿现有有界退出链关房。“停一下、先听我说”停止当前输出但保留会话；取消搜索和退出倾听仍走各自功能。不能用大部分关键词命中率代替完整意图，也不增加逐句 LLM 调用。

复用当前三池与后台词表。新增完整短命令语法：称呼/礼貌请求/语气包装＋明确核心动作＋有限句尾；保留否定、引用、条件、词义解释和后续任务。礼貌疑问“能不能别说了”是请求，“怎么让你别说了”是求助。暂不新增服务、模型或数据库。

比较过的方式：单纯增加整句只能覆盖列出的文本；宽松关键词/模糊相似度容易误关；每句语义模型带来等待和费用。采用规则泛化与真实语料回归，未覆盖含混表达保持原对话路径。

## 实施顺序

1. 固化三树 HEAD、运行进程/磁盘 SHA、词库摘要。新代码不能覆盖原池独有功能；20261113 的退出截止和搜索 job 完成删除必须保留。
2. Grok 查官方产品、开源语料、公开反馈，明确出处和合成标签，冻结开发集和独立保留集；原设备语料只保存在私有目录。
3. 先以现役代码跑漏例，再修改共享文本判定；提交、字幕出口、投机抑制使用同一判定。临时停话不关房、不再回答“好的”；最终语句才能触发关房。
4. 三池各自运行全套测试、旧语料、新自然变体及难负例。独立 Grok 用固定候选执行保留集并复审；失败保留且针对修复重验。
5. 隔离 RTC 音频验证真实 ASR→判定→停音/关房；包含正在回答时制止、礼貌请求、引用负例、停当前轮后继续问答。文本仿真不等于声学或安卓 UI 通过。
6. 通过后按原授权分池发布，空房守卫、逐池备份、明确运行 SHA；只变本次规则，不扩大灰度或更换 ASR/LLM/TTS。回读健康和稳定性，再交付可转发回执与测试语料。

代码标签：`rollback/p003-stop-variants-{listening,main,search}-pre-20261114`。
发布前另备当前二进制/配置/倾听声明，不能拿 20261113 发布前的旧程序当本次回滚点。按池恢复，保留现有有效服务身份和数据；不回灌数据库、不整树覆盖。

## 验收边界

- 原已验证停止/退出、搜索取消、倾听退出不能退化。
- 规则完成后的完整命令命中，不把半句前缀当关房指令；前缀最多抑制投机。
- 原生情绪表达、礼貌问句、重复词、语气词、称呼位置需覆盖；否定/引用/故事/条件/混合后续任务零误关为发布门槛。
- 开发集、保留集、旧真实语料分别报告数量与结果，不宣传为未知用户总体准确率。
- 未进行的真人实听、安卓界面、本地告别音验收单列。
