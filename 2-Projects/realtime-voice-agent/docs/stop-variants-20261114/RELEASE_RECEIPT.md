## 已实现的效果

- A1–A11、B1–B4、B6 统一关房。包含退下、闭嘴、别说了、安静、先不用说了、不要查了、取消搜索及既定结束表达；不是只中断声音后继续生成回答。
- B5 退出倾听后留房：恢复聊天、可以恢复聊天吗、能不能恢复聊天等。在已授权倾听状态下走原 proposal/确认流程，随后能同房聊天；不会当成整房退出。
- 没列入关房决策的纯“停一下、等等、先听我说、等我说完”仍停止本轮并留房。
- 常见称呼、礼貌请求、语气词和“这／这儿”等自然变体可匹配，无需逐字背标准口令。判定不新增 LLM 请求。
- 整句判定，引用、否定、词义问句和带后续任务的普通叙述不因包含关键词而关房。A11 指定残句只加入精确表，不推广成任意子串规则。
- 关房只结束本次小可会话，不是读写台关机、系统静音、定时静音或禁用下一次唤醒。
