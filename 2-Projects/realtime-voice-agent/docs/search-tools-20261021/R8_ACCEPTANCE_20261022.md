## 1. 选型与实现

已通过home-studio实际REA 6.7.0、独立Chromium152读取tool.lu和IP9，两场景证据complete且浏览器清理完成。tool.lu明确禁止把页面当API，故仅人工对照；采用IP9官方公开HTTPS GET，显式传入设备入口IP。无需Key、账号或付费。IP9免费每来源IP每分钟60次，代码限制30次；IPv4/IPv6公开样例已从HK成功取得北京/深圳城市。供应商准确率不作为本项目验收指标。

采集发生在**设备身份认证、灰度选择和会话票据自检之后**，仅当前名单内设备。已核canonical域名Nginx覆写X-Real-IP；代码还要求Node socket是loopback且Host精确匹配，不信任客户端XFF，不使用Worker/Brain出口IP。非目标设备不触发定位，首句合同不改。

定位异步执行，3.5秒总超时、16KiB上限、禁止重定向；同IP合并、成功缓存6小时、失败冷却60秒。原始IP只进入有界内存及IP9请求，不写新增数据库/日志，不放入JWT、LLM或后台展示；不把SN/用户正文发给IP9。IP9仅返回城市估计，不是GPS坐标，VPN/运营商出口可能偏差。

独立候选device-location.db按**完整SN＋本轮room**隔离，保存省市/状态/来源/观测/失效时间，最长1小时且不超过票据有效期。新会话取新的入口IP；异步旧请求不能覆盖新请求。跨设备、旧会话、过期位置不能复用。长会话换网后需退出重进；本轮没有承诺无请求时实时探知换网，也没有实现长会话每小时续定位。

Worker同步规则不做网络请求。未指定城市且天气/自动定位双开关有效时，提交auto_weather后台任务；Brain后台等本轮城市，再执行固定墨迹天气读取。明确说上海等城市时优先用明确城市。定位未知/失败/过期和未支持城市明确告知，不猜默认城市；控制/取消/改查/日期固定合同保留。

后台入口：Worker管理 → 搜索灰度 → 任务路由·热配置。新增自动定位独立开关，以及每台设备城市、来源、北京时间、状态、失败原因。草稿、预览、发布、回滚沿用版本机制；预览不实际定位。auto_location_enabled缺省关闭，R7旧配置保持兼容。当前发布版本 **r7-b4b722c50d1efbf635a1e06d / 修订15**；r7前缀是既有协议版本命名，不表示代码未升级R8。保留R7实测后的排除词，未重新发布工厂旧草稿。
