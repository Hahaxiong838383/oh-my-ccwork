## 改动

- Worker：修复“下不下雨”被解析为“下”、复合句活动部分被当作地名的问题。只剥离天气语法两端，保留真实地名；未知城市使用一般搜索，不能冒充本地。
- Worker：“该插／改插／该查”只在已知城市＋天气意图成立时识别为改查，不全局替换 ASR。
- Brain：增加高德 Web 服务适配器。线上地理编码确认省市、取得 adcode；不提交设备公网 IP 给高德，不做街道级定位。城市级 cache 5 分钟、单飞请求、短超时、限频、错误退避、城市及日期校验。预报依官方每日数次更新频率，不能沿用实况的新鲜度阈值。
- 固定天气路径：高德（启用且有 Key）→ 百度 → 原有可用墨迹城市。指标不支持时不捏造值。
- 后台任务：天气路径失败或无可靠证据后，最多补一次不带 Tool Calls 的一般搜索。仍保持原域名、时效、证据校验；没有可靠信息就明确告知。取消后不发起下一次请求，不发布超时的迟到结果。
- 天气主尝试 5 秒＋兜底 12 秒；其他搜索主尝试 10 秒＋兜底 7 秒，均在原有后台任务总期限内。没有在普通聊天路径增加外部请求或模型路由。
- 现有设备 IP9 城市定位保留；无法得到可信城市时不把云服务器出口当成设备所在地。
