## 怎么开始

1. 结束旧的小可语音会话，确认已退出，再重新进入。
2. 首句可以正常聊天；新增规则在会话内后台加载，通常约 5–10 秒。未拿到有效规则时保留明确“帮我查……”的保守识别，不阻塞普通聊天。
3. 先测“帮我查一下北京今天的天气”，再测不带查询动词的自然问法。另做一次“进入后立即问天气”，记录首句表现，这项仍是冷启动观察项。
4. 每条问完留出回答时间。查询中可继续聊天；结果应等空闲时补播。天气数据就绪快不等于语音立即播完。

天气首版覆盖北京、上海、沈阳、大连、广州、深圳、杭州；支持当前天气/温度、今明后天日预报和当前空气质量。缺城市应追问，**10 秒内**回答这七个城市之一可承接。其他城市、区县、下周、指定小时等走通用搜索，可能提示无法确认；不能借用默认城市或错误日期的数据。

## 可直接照说的用例

| 编号 | 操作与话术 | 预期表现 |
|---|---|---|
| T01 | 重进会话后立即说：“小可，今天北京的天气怎么样？” | 记录是否建立查询、是否追问、是否要求明确查询。首次加载阶段单列观察，不直接算整体通过。 |
| T02 | “小可，今天北京的天气怎么样？” | 规则已加载后，无需再加“帮我查”；应报告北京、今天的日期及天气，不说“等我长大才会查”。 |
| T03 | “明天天气怎么样？”听到城市追问后，10 秒内说“上海”。 | 先问城市；随后回答上海**明天**的日预报，不能变成北京或今天。 |
| T04 | “上海现在多少度？”再说“北京的空气质量怎么样？” | 分别回答上海当前温度、北京当前空气质量，带对应观测时间或明确无法确认。 |
| T05 | “帮我查一下火星为什么是红色的。”接着说“我今天画了一只小猫。” | 查询在后台继续；小可能接着聊小猫，空闲后补播火星结果。 |
| T06 | “帮我查一下中国第一颗人造卫星叫什么。”之后保持安静。 | 结果准备好后主动补播；不能一直只有“我查一下”没有后续。 |
| T07 | 在结果播报中说“我今天画了一只小猫。” | 结果停下并转入当前聊天；记录插话发生在刚开口还是播了一段后。 |
| T08 | T07 后说“继续刚才的搜索结果。” | 继续同一任务可用的剩余结果，不重新开一个无关查询。若已取消/过期，应如实说明。 |
| T09 | 先查询；随后说“不用查了，我们聊别的。” | 确认取消；后来不能突然补播已取消结果。取消与单纯插话分开测试。 |
| T10 | “帮我查一下火星为什么是红色的。”接单后说“改查上海明天的天气。” | 旧任务取消，新任务改成上海明天；不夹带旧火星结果。 |
| T11 | “故宫明天开放吗，帮我查一下。” | 建立开放时间查询；依据可靠资料作答并说明预约/临时公告限制，不能把未核实安排说成保证。 |
| T12 | 分别说“天气为什么会变化？”“三角形的内角多少度？”“烤箱的温度怎么调？”“北京天气不错。” | 作为普通聊天或知识问答处理，不因为“天气/温度/多少度”就自动报“我查一下”。医疗话题不要求现场试说私人病情。 |
| T13 | “不要查北京天气，我们聊小猫。” | 不建立北京天气查询，继续聊天。 |
| T14 | “帮我查一下最近中国航天的新闻。” | 有合格的近期来源才给答案；资料日期不合格时应明确无法确认。**服务端本轮此题未获取有效近期资料，不能算查询有效性通过。** |
| T15 | 查询接单后退出；重新进入小可，再发起一个新查询。 | 旧会话结果不应窜入新会话；新会话重新判断规则。窗口还开着时，重连仍是灰度体验。 |
| T16 | 查询后保持安静；另做一次结果刚开口便插话。 | 普通空闲应补播。极早打断在满足条件时最多自动重试一次；若已播一段，使用 T08 手动续讲，不要求无限自动重播。 |

**仍待现场验证：** 两台实际扬声器听感、首句是否丢词、安卓是否约 5 秒自行退出、长时间稳定性、查询内容准确性和每次冷启动规则加载。当前规则只覆盖已配置表达，不代表所有自然语言都能正确识别。新闻无可靠近期来源的降级不算有效新闻答案。

## 异常时怎么记录、怎么恢复

- 记北京时间到秒、设备 SN 后 8 位、实际软件版本、用例编号、具体测试话术。
- 分开填写：是否看到字幕、是否听到接单提示、是否听到最终结果、是否被打断、是否自动退出。方便时截字幕/页面状态，不上传口令或私人对话。
- 出现循环补播、持续无回复或异常退出，先说“取消搜索”并结束会话，暂停测试并反馈负责人。
- 要恢复现役普通链路，应由服务端关闭该设备灰度后再退出重进；**窗口内直接重连不会退出灰度**。到期后新会话自动回现役，已有候选会话由到期守卫结束。正式 23:59 的实际关闭需届时核查，不能提前写成已发生。
