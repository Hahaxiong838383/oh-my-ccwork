## 如何进入

结束当前小可对话，回到待唤醒状态后重新唤醒。已经进入旧会话的设备需要重新进入一次。先说一句普通聊天确认能正常听到，再按下表测试。窗口内单纯重连仍会进入灰度，不能把重连当作关闭灰度。

通用搜索会用“我查查／我找找／我搜搜”，天气用“查查天气”，新闻用“看看新闻”，问题不完整时问“想查什么”。它们表示准备查询，不表示已取得答案。结果很快、正在讲话或发生插话时，提示可能被跳过或打断；不要求每次一定听到完整衔接音。不会循环催促“请稍等”。

## 建议测试顺序

先连续测试1—6，再测试7—13。每项记下北京时间与听到的实际表现；不要只按屏幕显示判通过。涉及插话的项目主动打断，其余项目让小可说完再进入下一项。

| 编号 | 可直接说的话与操作 | 预期表现 |
|---|---|---|
| 1 普通聊天 | “我今天画了一只小猫。”再问“水为什么会结冰？” | 正常接话，不出现搜索衔接词；感觉不比此前更慢。可用另一台非灰度设备辅助对照。 |
| 2 天气 | “帮我查一下北京明天的天气。” | 通常先有短提示，随后说北京、明天对应日期、天气和温度；不把提示当结果。 |
| 3 科普 | “帮我查一下火星为什么是红色的。” | 通用短提示至多一次，后续回答火星红色原因；不重复“好，我查一下”。 |
| 4 新闻 | “帮我查央视今天的国内新闻。” | 新闻短提示，随后给可核实的新闻摘要；来源/日期不清或检索不到要如实说明。 |
| 5 场馆 | “帮我查一下故宫明天是否开放。” | 通用提示；回答对应日期与开放依据，未查证不保证。此项用于扩大真机内容覆盖，不代表本轮重新验过场馆数据。 |
| 6 澄清 | “帮我查一下。”听到询问后说“三角龙主要吃什么。” | 先问想查什么，再查询和回答；不空查、不把一个问题重复答两遍。 |
| 7 搜索中聊天 | “帮我查一下火星为什么是红色的。”接着说“我今天给小猫画了一顶帽子。” | 可以接着聊帽子；搜索在后台继续，不要求人停止聊天等结果。 |
| 8 空闲补播 | 接上项，等小可回应聊天后，自己保持安静 | 空闲时补充搜索结果；正在讲话时不抢结果播报，短提示不会晚到后反复插入。 |
| 9 插话与续讲 | 结果开始说后插话“我想给小猫画蓝帽子”，聊天结束后说“继续刚才的搜索结果。” | 结果被打断，先处理聊天；续讲关联原任务，不冒出更旧的问题。记录是否重复、漏句或听不清。 |
| 10 取消 | 发起查询后立即说“不用查了，我们聊别的。” | 停止旧任务，之后不突然补播旧结果；新聊天仍可用。 |
| 11 改查 | “帮我查一下火星为什么是红色的。”立即说“改查中国第一颗人造卫星的名字。” | 转查新问题，后续答东方红一号；不再播旧火星结果，旧提示不排队回放。 |
| 12 提示时插话 | 听见“我查查”等短句时立即说“先聊小猫。” | 提示可被打断，优先接话；不为了播完衔接词锁住对话。 |
| 13 退出重连 | 发起查询后结束对话，再重新唤醒，说“我画的小猫有蓝帽子。” | 新会话正常聊天，不补播上次会话的搜索结果。 |
