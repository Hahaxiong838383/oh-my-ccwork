## 怎么使用

先结束旧的小可会话，再重新进入，让后台取得本轮设备网络信息。可直接说“今天天气怎么样”“明天会下雨吗”“现在多少度”。正常定位成功时不应再要求先说城市。

明确说“上海明天天气”时，以上海为准，不被自动城市覆盖。定位结果只估计城市，可能受运营商出口、代理/VPN影响；结果会报出实际采用的城市，便于发现偏差。不代表精确坐标。

天气首版支持北京、上海、沈阳、大连、广州、深圳、杭州的当前天气、温度、当前AQI及今明后天。定位失败、过期或城市暂未支持时应明确说明，不借用服务器城市或其他设备的位置。长会话中切换网络后，请退出重进刷新；未验证无重连时自动识别网络切换。
