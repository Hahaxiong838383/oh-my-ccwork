## 新发现：配置了竞速，但备用路未正常工作

运行进程核实为race；COMPANION_KG未开启。20个诊断响应全部由DeepSeek获胜；火山路有18条HTTP400记录，其余在取得响应前被胜者取消或未记录到响应。

单独请求确认原Coding入口返回 **400 / InvalidSubscription**。同一凭据对标准模型目录GET成功，但对目录中同系非Retiring模型的最小请求返回 **404 / ModelNotOpen**。查询目录成功不代表模型已开通。凭据库同步成功后未找到名称匹配的火山/豆包/MiniMax备用配置；不据此断言用户没有其他账号。

未修改付费配置、开通模型、续订或切换线上模型。已向用户询问订阅状态；在恢复可用备用模型之前，不能宣称双路兜底已恢复。这个缺口说明当前备用能力不足，不足以独自解释历史每一个慢轮；与跨会话结果恢复是独立问题。
