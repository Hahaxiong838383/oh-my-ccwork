## 大脑如何工作

这项同时列为[与公司版的差距](私人小可产品与验收复盘-20261128.md#大脑运行机制对主人的可见程度)。首版复用记忆工作室、成长依据、通话详情和工具记录，增加两个互通的入口。

- **总览回答“平时怎么工作”。** 用一张可点的流程图说明主人原话如何进入识别和路由，何时直接回答、取用记忆、查询或调用模型，怎样合成语音；把通话后才发生的记忆抽取、反馈归因和长期更新画成旁支。点模块看它读什么、写什么、触发条件、当前配置及最近一次有证据的运行。单次风格、长期偏好和人格特质分别说明谁能改、何时生效、能否撤回。
- **通话详情回答“这一次怎么工作”。** 点一条回复先读一段人话摘要，再按需展开当轮路由、实际带入的记忆与原话、当时生效的风格及来源、工具结果与耗时、语音送达阶段，以及事后有没有形成记忆或成长事件。以房间、消息和事件标识关联；对缺少关联的工具调用保留“无法归到本轮”。点已关联的记忆或成长事件可纠正、忘记或撤回，并跳到后续通话核实影响。
- **证据标识。** 将“本轮实际发生”“有记录且未触发”“缺记录”“按当前配置预览”区分显示。模型输入中的事实只证明被送入；主人的更正、异步抽取和成长分别标注来源、前后值和适用范围。对已遗忘的事实沿用旧版本退役提示，避免在解释页重新复制正文。

| 主人从页面独立完成的验收 | 通过条件 |
|---|---|
| 查看一次“只这次简短点”，再开一通 | 能指出哪条风格只作用于该次回复、长期设置的值，以及下一通实际用了哪一种。 |
| 对照同通称赞讲法与换通报喜 | 前者能从特质变化跳回被评价的回答和原话；后者能核对上一通的讲法没有因此得到奖励。撤回前者后，能在后续回执核实该样例已退出当轮输入。 |
| 比较普通聊天、直接问已记事实和一次天气查询 | 分别辨认已证实选入零条、直接据证回答、调用天气工具。能点回记忆版本或天气来源，看出哪个阶段花了时间；尚无手机播放回执的阶段标明缺测。 |
| 打开没有回执的旧通话，再试一次选取预览 | 旧通话标为“未记录”；预览标为模拟，查看与预览均不增加记忆使用次数。 |

## 已验证的行为

- 记忆只引用能核实的主人原话。缺依据时回答不记得；更正和遗忘会影响后续召回。后台“忘记”作用于选中的长期记忆，历史聊天记录仍可单独回看。
- 本通明确评价“这种讲法我喜欢”才计入对应的讲故事回答。换一通报喜不会记在上一次故事头上。后台显示依据，能撤回仍生效的讲法样例、故事倾向调整。历史观察记录保留来由。[讲法反馈验收](personal-brain-growth-feedback-20261128.json)
- “只这一次”和长期风格分开，私人版已去掉切换冷却、每日换风格次数与每日联网查询次数上限。明确要求简短时一两句收住，聊雨后散步时按聊天处理，真正问天气仍走查询。[记忆与风格验收](personal-brain-memory-style-20261127.json)

## 管理台后续

- 记忆工作室已支持分类查看与搜索、查看原话、回看用过该条事实的回复、纠正、忘记、人工核验、处理冲突、标记约定已兑现。查旧轮次时显示当时的记录状态；已退役的版本隐藏旧值。历史原话按原通话保留。在缺少收据的历史轮次只显示未知。
- 抽取分析可查看运行结果、最近失败、排队数及来源。按原消息安全重试失败任务、推测偏好的长期排除规则、带截止日期的结构化约定仍待做。
- 五类词表支持预览差异、发布到下一通、查看房间读回和恢复以前发布的整套词表。仍待用同一麦克风和网络录制有无自定义词的识别、打断和退出对照。
- 工具与查询页能查看 Worker 最近轮次的分段耗时；手机端实际出声、工具请求的精确轮次关联、头像与安装阶段仍需补手机或工具上报。后续用快答、搜索、插话三种样本单独比较。
