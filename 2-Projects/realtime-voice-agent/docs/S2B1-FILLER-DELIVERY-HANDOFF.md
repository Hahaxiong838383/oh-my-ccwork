## 3. 选桶逻辑（源码：`rust-worker/src/filler.rs` @ `feat/rust-worker` `9cf08b843`，之后未再改动）

**按用户这一轮的文本命中关键词选桶，顺序即优先级，先命中先返回：**

| 序 | 桶 | 触发条件 |
|---|---|---|
| 1 | `greet` | 文本 **≤10 字** 且含：你好 您好 哈喽 嗨 早上好 中午好 下午好 晚上好 在吗 在不在 早啊 早呀 |
| 2 | `thanks` | 文本 **≤10 字** 且含：谢谢 感谢 多谢 辛苦 谢啦 谢了 |
| 3 | `emo_neg` | 难过 伤心 想哭 哭了 委屈 郁闷 烦死 好烦 太烦 气死 生气 好累 累死 太累 害怕 焦虑 压力好大 不开心 心情不好 无聊 |
| 4 | `emo_pos` | 开心 高兴 兴奋 太棒 太好了 太好啦 好爽 哈哈 |
| 5 | `story` | 强叙述：跟你说 告诉你 你猜 |
| 6 | `task` | 讲个 讲一 讲讲 说个 说一 给我讲 给我说 给我来 给我放 帮我 来个 来一 唱个 唱首 唱一 背个 背一 背首 念个 念一 念首 推荐 介绍 教我 陪我 翻译 写个 写一 |
| 7 | `story` | 我今天 我昨天 我刚才 我上次 我们老师 我们班 我妈 我爸 我朋友 |
| 8 | `ask` | 怎么 为什么 什么 哪 几 多少 是不是 吗 呢 好不好 行不行 对不对 谁 难道 `?` `？` |
| 9 | `opinion` | 我觉得 我认为 我感觉 |
| 10 | `gen` | 兜底 |

**顺序是有意的，别按字面重排**：

- `greet`/`thanks` 的 **≤10 字**门槛是为了让「你好我想问一下明天天气怎么样」落进 `ask`
  而不是 `greet`——开场问候只是句子的开头，不是这句话的意图。
- **`story`(强) 排在 `task` 前面**：「跟你说个事儿」含"说个"会被 task 抢走，所以强叙述先判。
- **`task` 排在 `ask` 前面**：「给我讲个故事好不好」同时含"讲个"和"好不好"，要走 task。

### 播不播 / 播哪条

- **概率门控**：全局默认 `0.9`；`greet`/`thanks` 两桶**覆盖为 0.5**（这两类场景结构性重复，
  每次都接会很假）。
- **打断轮必播**：真插话（interim 非空的 speaking→listening）之后 **5 秒窗**内的那一轮，
  概率强制拉到 `1.0`。理由是打断之后的沉默最难熬。
- **防重复**：最近 3 条**文案**的滑窗，选池时先排除；若排完为空则回退整桶。
- **空桶回退**：选中的桶没有片段时回退 `gen`；`gen` 也没有则本轮不播。
- **资产缺失静默降级**：manifest 不存在 / 读不出 / 格式不符 → 整个 filler 关闭，**主链路不受影响**，
  日志只有一行 `filler bank 资产缺失,承接音关闭`。

### env 开关（worker 侧）

| 变量 | 默认 | 说明 |
|---|---|---|
| `FILLER_ENABLED` | 开 | 显式设为非 `1` 才关 |
| `FILLER_DIR` | 仓内 `assets/fillers` | **生产显式指向 `/opt/voice-agent/fillers-colleague`** |

## 4. 🔴 端侧看不到承接音的文本 —— 这是设计，不是漏发

`pipeline.rs` 里承接音的消费点是：

```rust
if let Some((_ftext, fpcm)) = filler {
    track("", fpcm.len());        // 只登记样本偏移,文本传空串
    let _ = pcm_tx.send(fpcm).await;
}
```

文本绑到 `_ftext` 就**被丢掉了**，只有 PCM 入轨。连带三条后果，你按这个预期实现：

1. **没有字幕事件**。承接音播的那 1–3 秒，你收到音频但收不到任何对应文本。
   如果你的 UI 是"有声音必有字幕"，这里会出现一段空窗——**不要当成丢包去排查**。
2. **不进对话历史**。`push_assistant` 不会收到承接音文案，多轮上下文里没有它。
3. **字幕时间轴仍然对齐**。`track("", n)` 只推进样本偏移不推进字符，
   `sentence_spans()` 跳过空文本条目但保留样本推进——所以正文的逐句时间戳
   **不会因为前面插了承接音而整体偏移**。这块已经处理过了，你不用补偿。

否则一次会接两句。worker 侧关它一行 env（`FILLER_ENABLED=0`），我这边随时可以配合。
