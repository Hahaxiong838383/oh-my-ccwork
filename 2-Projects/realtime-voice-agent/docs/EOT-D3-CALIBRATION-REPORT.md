## 二、测量可信度（结论前先自检）

- 管线：eotbench 对拍锚定沿用（mel 位一致/概率位一致/官方数字 ±1pp 复现，原型报告 §五）；
  模型 sha256 与原型报告指纹一致复验。
- 弱标签口径：负类只用「干净负类」（恢复说话早于 turn_commit，排除 agent 接话诱发重说）；
  人工复核 38 条（文本+时序）：正类噪声 ≤8%（行为口径）、负类 ~15%（含空文本触发点）。
  噪声同等压低三模型读数，**相对比较公平**；0.952→0.705 的塌陷幅度远超噪声可解释范围。
- 分布形态 sanity：v3.2 非故障态（pos median 0.936 / neg 0.772，方向正确），是对负类无区分——
  47% 样本给 >0.9 的自信输出；新旧模型逐样本 Pearson r=0.347（各错各的，非同源失效）。

## 三、解读（本报告最重要的部分）

1. **真实自由对话的「话轮未完」停顿是纯音频模型的域外样本**：本批负类大量是
   「语法完整但语义要续」的句间停顿（audit 实例：「因为咱家没有设置完了之后…」→停顿→
   「反正我现在人家天天催…」）。chirp3 训练/评测里的「未完成」是 TTS 念的填充词构造，
   两者声学-语义形态不同。v3.2 的 0.952 只在它的分布里成立。
2. **旧模型同样无信息（0.683）**——当前判停体验实际由 MIN/MAX delay（0.40/0.8s）与
   VAD 静音门兜底，EOT 模型贡献有限。这解释了「项目目前比较稳定」的体感：模型没在管事，
   参数在管。**换模型不是当前体验的杠杆**。
3. **NO-GO 的边界**：判决对「当前数据分布」成立。最终儿童用户若以短指令为主
   （「给我讲个笑话」「换一个」「调成冷光」——本批正类里这类判对率高），
   答案可能不同。采集口继续开着，真实用户数据到量后可零成本重测（工具全在）。
