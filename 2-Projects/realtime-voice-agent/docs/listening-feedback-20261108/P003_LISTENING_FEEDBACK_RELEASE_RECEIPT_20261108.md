## 修复了什么

原ASR会把“小可，我讲完了，请说说你的看法”拆成“小可 / 我讲完了 / 请说说你的看法”三条final，旧倾听解析只认单条完整句，因此没有触发反馈。对旧5b3与连接修复de090的同WAV对照均复现，不能归因为本次连接修复引入。

现有明确反馈口令允许在固定5秒、256字节以内拼接，仍要求当前模式、授权和场景有效；普通故事不启动回复。新的SpeechStart不清除尚有效的口令前缀。拼不成口令、超时或失去上下文时，已经接受的故事原文按原顺序恢复，绑定原进入请求，不混入新一轮故事。唱歌场景仍保留开始说口令前的停顿要求。回声只比较完成后的整句，不因近期TTS包含“小可”或尾字“法”而误吞。

## 安卓同事真人复测

不需要为本修复先升级APK。使用当前已具备倾听能力的03800006设备，记录版本、北京时间、trace和实听结果。

1. 唤醒后说“小可，先听我讲个故事”，确认进入；连续讲述至少60秒，中间自然停顿，小可不抢答。
2. 故事末尾加入容易核对的新信息，再自然说“小可，我讲完了，请说说你的看法”。可短暂停顿让ASR分段；预期只回复一次、能提到刚才故事内容，之后继续倾听。不要把所有片段之间任意长的停顿当成已支持，当前拼接窗口固定5秒。
3. 分三轮分别测试“恢复聊天”“结束倾听恢复聊天”“小可结束倾听”；每次确认界面恢复普通聊天，同房问一个简单问题应有回复。
4. 倾听中只说“小可”然后停6秒，或说“小可”后继续讲另一句故事：应不触发反馈，故事字幕不丢失、不额外复制。
5. 关房后再次唤醒、问普通问题。若失败回传同一trace、实际口令、时间和音频/字幕表现，服务器对应核ASR→路由→Brain反馈→首PCM→发布链。
