# 停止整个对话与关房

状态：候选开发，尚未部署。

本次仅把明确结束整个对话的整句列入后台 exit 词表。停一下、等待、先听故事、缩短回答、换话题、引用、否定、停止搜索与退出倾听恢复聊天不进入全局关闭词库。不新增 LLM 分类调用。

退出命中优先于 interrupt；普通聊天在现有 commit 裁决后立即停止音频、投机及搜索，发送既有退出通知。在倾听模式先处理完整模式控制口令，再识别全会话关闭。2500ms 后进入 pipeline 收尾（既有 ASR 收尾最多额外 3 秒），复用 job 的 DeleteRoom 和清理重试；ACK/cancel/迟到结果不能延长关闭期限。普通暂停继续保留会话。

## 回退

先停止本轮发布，按各池自己的备份纪律 stop → 清理对应 EOT socket → 恢复原二进制/环境 → start，并核注册、进程 SHA、配置及稳定性。仅改本轮文件，不能还原整库或覆盖其他会话变更。后台 exit 词表通过原 API 重新发布旧词表生成新版本；搜索/倾听同步同一权威版本。原有 ASR 热词、赛马、设备范围、倾听与搜索开关不改。

语料原文、上下文和完整设备映射保存在受控目录，不随代码仓推送。公开测试工具只读取外部 JSON，输出数量和失败索引。
