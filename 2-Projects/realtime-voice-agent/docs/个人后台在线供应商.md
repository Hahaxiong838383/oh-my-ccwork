# 小可个人后台的在线供应商

主人可以为语言模型、语音识别、语音合成分别保存多份配置。个人后台维护飞牛 2 上的独立副本。改个人实例的名称、模型、音色或密钥，只写入个人实例。两套实例使用同一组厂商凭据时，额度、计费和厂商侧的启停仍属于同一个账号。

## 首次复制的内容

| 用途 | 后台名称 | 随配置复制的设置 |
|---|---|---|
| LLM | DeepSeek · 私人副本 | API Key 和模型 `deepseek-v4-flash`，请求发送到 DeepSeek 官方接口 |
| ASR | 豆包语音识别 · 私人副本 | 凭据、识别资源、二遍识别入口、断句窗口与顺滑设置 |
| TTS | 豆包语音合成 · 私人副本 | 凭据、合成资源、冷酷哥哥音色、语速 |
| TTS | 讯飞超拟人 · 私人副本 | APPID、APIKey、APISecret、凌小璇音色、语速与口语化程度 |

此次使用 P003 运行进程读取当前配置，经 SSH 写入飞牛。只有初次复制需要读取 P003。以后可以把个人配置中的密钥换成独立账号的密钥。替换个人副本里的值不会撤销厂商凭据。配置复制前，个人实例使用个人 CPA、本地识别、华燕合成。

## 后台操作

登录后打开「配置工作室 → 语音供应商」。点击已有配置可以修改，点击「新增供应商」可以为同一种服务保存另一组模型、音色或凭据。已有密钥的输入框保持空白，留空保存会沿用原值。保存一份备用配置后，在「对话模型」「语音识别」「语音合成」中的相应一栏选择并应用。三个选择各自独立。切换前先结束通话，等顶栏显示 Worker 已注册且占用为零。[打开个人后台](https://pa.hahaxiong.cc:8666/)

选用 DeepSeek 后，小可的个人大脑仍负责工具、记忆、人格和联网检索。通用网页搜索走个人 CPA 的搜索接口。选用云端 TTS 后，新通话使用供应商配置中的音色。切回「飞牛五音色」后，「通话音色」里设置的本地声音重新生效。

## 运行与恢复

飞牛私有文件位于 `/vol1/1000/docker/personal-voice-runtime/private/providers/providers.json`。保留同一目录挂载，使容器可以看到管理员原子保存的新版本。该目录用服务 UID 1000、权限 0700，文件权限 0600。密钥走服务器写入，接口只提供已设置状态。排障时检查挂载、权限、配置修订号及生效选项，勿直接打印私有文件或容器环境。

数据库的加密备份覆盖 6 个 SQLite 数据库。供应商凭据存于独立私有文件。若要连同自定义供应商配置恢复，需从单独保全的私有配置还原到上述目录，再检查属主、权限、当前选择和一次经过真实通话的收发。运行版本与旧版恢复入口见[配置工作室与五音色上线](配置工作室与五音色上线.md)。

## 2026-11-25 发布验收

通过公网 Lucky 入口，在 Chromium 里用合成麦克风问“现在北京时间几点了”。六次均经北京设备签票进入独立房间，得到正确的输入字幕、报时回复和非零音轨。同步核对 Worker 的供应商快照、实际音频交付和豆包最终识别结果。下表记录各次测试的浏览器收包与 Worker 合成量，包含开场白与回答。

| 语音识别 | 通话合成 | 浏览器收到音频包 | Worker 交付 PCM 字节 |
|---|---|---:|---:|
| 豆包 | 豆包冷酷哥哥 | 206 | 304,552 |
| 豆包 | 讯飞凌小璇 | 242 | 301,440 |
| 豆包 | 飞牛华燕 | 172 | 267,276 |
| 飞牛本地 | 豆包冷酷哥哥 | 225 | 340,832 |
| 飞牛本地 | 讯飞凌小璇 | 243 | 301,440 |
| 飞牛本地 | 飞牛华燕 | 170 | 264,158 |

- 公网后台实测了四份档案的编辑表单、密钥留空保留、桌面和手机宽度布局，以及退出后的 401。同一发布镜像的隔离后台通过真实 HTTP 新增四类配置、编辑、选择、切回内置、拒绝旧修订。实际有通话时切换合成返回 409，原通话完成。
- 个人大脑选中 DeepSeek 时，后台普通试问、北京时间与带 Python 官方引用的网页搜索通过。同镜像用独立临时数据库测试跨房间记忆抽取与回忆、源消息关联、风格反馈、成长记录和下一房间的回复风格。
- Worker 回归 656 项通过，2 项标记忽略。飞牛与北京 11 项发布实物已重新取证，3 项变更，418 份本地模型文件的清单摘要与基线一致。版本与构建来源见[实机发布清单](personal-provider-release-20261125.json)。
- 验收结束后，个人后台回读为个人 CPA、飞牛本地识别、飞牛华燕。P003 源字段与复制前逐项一致，两处取证的源进程均保持原 PID。测试用例为浏览器合成麦克风；此次没有手持实体手机进行主观听感或蜂窝弱网测试。
