## 3. begin_timeout的准确含义

现役`pipeline.rs`在以下条件同时满足时触发：首句ordered阶段、首句完成后回RTC策略开启、ordered状态仍Idle、输入循环启动超过`ORDERED_BEGIN_TIMEOUT_MS`（本次2500ms）。随后将首句标记超时，发送失败结果（`action=repeat_prompt`）及`session.input_phase`，切换到普通RTC识别。

本次起点为G3 11:36:23.428，触发为25.930，约2502ms。**不是TTS等待超时，不是服务端等了23秒后还没生成回答，也不是倾听模式退出命令。** 本代有效包数0不能单独证明安卓未发送：还要区分未发、旧连接发送、传输未到及Worker入口身份/代次过滤。
