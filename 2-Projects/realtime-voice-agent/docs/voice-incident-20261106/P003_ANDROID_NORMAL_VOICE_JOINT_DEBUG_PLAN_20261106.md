## 2. 双方各自记录什么

## 3. 第一轮怎么测（约15–20分钟）

固定一台设备、一个APK、一个网络和现有业务配置。测试前30秒开始采集，结束后再保留30秒。首先排查普通聊天，不用天气搜索作首轮输入。

| 顺序 | 操作 | 观察目标 |
|---|---|---|
| A | 从已关房状态语音唤醒，问“一加一等于几”；完整听完再关房，做5次 | 新建房、音频协商、首次正文是否正常；“新建房”不等于每次重启设备 |
| B | 同一个房间连续问5个普通问题，每次都等上一条回复完整结束 | 说完是否出声、是否流中卡顿；没有新讲话时不得无故abort |
| C | 关房后立即再次语音唤醒，做3次 | 老房/老计时器/旧连接代次是否干扰新房 |
| D | 语音进入倾听、讲述、说“结束倾听恢复聊天”，同房再问普通问题，做2次 | 倾听退出后的普通对话是否回归，不扩展重跑完整倾听矩阵 |
| E | 回复过程中，真人明确说“停一下，我换个问题”，做2次 | 既能正常主动打断，又能完成后续问答；不把这些预期取消当故障 |

A/B优先。只要首次出现“无声/明显慢/闪退”，马上记下时间和trace；保持现场，先导出该轮前后日志，不立刻重装、清数据或改网络。无声超过5秒就记异常，可继续观察自动恢复，最多30秒后按正常流程关房；30秒是诊断观察上限，不是可接受响应时长。不要反复连续喊“小可”或重复问题，把原故障与新一轮抢占混在一起。

第一轮不以MacBook TTS作为唯一结论。若需要自动化对照，另标记TTS播放起止，等待上一条小可回复结束，避免外放回声/重叠输入；不得将自动化与真人样本混算。

网络A/B只在原网络抓到完整失败后进行：同机同APK同问题，换热点复验，其他条件不动。热点通过只能说明网络路径相关，不能据此直接认定设备或服务器无问题。

## 4. 我们怎么据日志修

| 第一个明确断点 | 下一步处理 |
|---|---|
| SFU有对应offer但端侧没有收到 | 对齐同代信令连接，查服务端发送、旧连接丢弃、传输；服务端“生成offer”不等于已送达 |
| 端侧已收到，某步SDP操作未完成/报错 | 查该步SDK调用、线程/锁、被close/reconnect取消的原因；修精确分支 |
| 端侧answer本地发送成功，SFU未收到 | 查对应WebSocket代次与传输，不提前归责某一端 |
| SFU收到answer但应用失败 | 查服务端校验/状态/代次，并核客户端answer内容摘要；由明确错误确定改哪端 |
| 协商成功但音轨未订阅，或已订阅却无声 | 分开核订阅、下行音频包、解码、音频焦点和输出路由；TrackSubscribed不等于扬声器出声 |
| 用户已经安静，服务器仍反复pause/abort | 对齐现场口播、ASR事件和播放时刻，区分背景声/自回声/重复事件/状态机误取消 |
| 输出门超时后删房，恢复又失败 | 联合修恢复路径：未删房与已删房分别处理，保留用户主动退出；不简单把5秒改成30秒 |

如修复涉及恢复：由一个既有恢复入口统一协调，建议最多一次；SDK与业务层不能各自叠加重试，原轮总等待截止时间不能因换房重置。用户退出/新请求取代旧轮就停止旧轮恢复，旧代回调不得操作新房。修复回执必须明确原问题会续答还是提示重说，避免重复播出或只恢复连接却一直无声；预算数值与行为随候选实测固化，不在此次取证前改生产策略。

协商超时、输出门超时、用户等待分别记录起点和截止条件。历史5秒输出门与15秒协商超时来自不同故障记录，不能拼成同一轮因果链。

每次只改被证据支持的一处，并保留回滚点。使用同一用例完成修复前失败、修复后通过；有界重连可以作为恢复能力，但不能拿它掩盖每次首连都失败。日志不足时先补精确点，不靠反复扩大测试量碰运气。

## 5. 修到什么程度才收口

第一轮以抓到失败并形成两端同trace时间线为目标，不以“偶尔三次通过”为完成。

修复后的内测验收建议（诊断APK的复现结果与最终修复包的验收分开记录）：

- 原问题用例在同机同网络复验；至少20次普通问答，覆盖不少于5次新建房，以及同房、关房再唤醒、倾听退出后问答。主动打断另测，不混入普通问答失败率。
- 无无声、无意外关房、无无故取消；音频协商和播放链路均有证据。出现重连/恢复要计入原始尝试和总耗时，不能删掉失败重算成功率。
- 建议体验目标：用户说完到**正文实听**P95≤3秒。它是本次建议目标，尚未证明达标；给出每次样本、最大值和分段耗时，衔接语不计入正文。20次均成功时按耗时排序第19次取P95；有无声则本轮直接不通过，不只统计成功样本来掩盖失败。
- 至少在当天投诉设备复核一次完整用例；20次通过只代表这一轮内测验收，不宣称所有网络/全天绝不复发。若未复现、没有确定根因，只能标“本轮未复现”，不能标“已根治”。
