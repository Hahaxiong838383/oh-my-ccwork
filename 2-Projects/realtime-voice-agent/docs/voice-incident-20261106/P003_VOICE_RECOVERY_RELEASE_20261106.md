## 3. 安卓现在需要做什么

详见配套 [执行单](P003_ANDROID_VOICE_RECOVERY_IMPLEMENTATION_20261106.md)，最小交付为：

1. **按连接代次隔离状态。** Room/当前 Worker 改变时，同步失效旧 ready、旧 sender/observer、UI 一次性 ready 门；不能只以 trace 去重，也不能让旧异步回调操作新房。
2. **绑定当前输出轨。** 按 agent participant SID 与 publication SID 核订阅和音频 sink；补齐 SID 日志。旧轨、静音回调或 input_ready 均不能代替当前输出轨订阅证据。
3. **真正接通失败恢复。** 当前代 `begin_timeout → rtc` 后退出旧 thinking，提示一次，恢复当前麦克风和 idle；提示失败或恢复超预算时明确退出。不能只打 fallback 日志。
4. **保留提交边界。** 尚未发 begin 才允许安全迁移；已发 end/receipt_done、已 commit 或结果未知时，不自动重发原问句。连接和 publisher recovery 共用一次主动重建预算。
