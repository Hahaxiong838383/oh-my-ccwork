# 小可 · 暗夜剧场

三星 S24 Ultra 上的个人语音客户端，应用包为 `cc.hahaxiong.xiaoke.night`。首次打开，用个人语音设备凭据配对，允许麦克风后点「开始」。在密码库可找到「小可个人语音 · phone-01 设备凭据」。普通通话只需这一份设备凭据。配色会在本机保留。切后台结束本次通话，回到前台可再次开始。

## 通话

Android 管理权限、通话路由和 AES-GCM 设备凭据。WebView 统一持有播放焦点。界面和固定版本的 LiveKit/WebRTC 客户端随 APK 分发。签票、信令使用私人服务的 HTTPS/WSS 域名；音轨由北京转往飞牛个人 Worker。手机订阅 Worker 的回放，使用解码后的音量驱动头像。输入字幕接收同一段识别的增量修正，输出字幕随播报按句显示、接受被打断后的修订。开麦时可以直接插话。中央打断键发出当前房间的可靠控制包，等待 Worker 回执。断线或挂断后清理音轨、计时器和本轮状态。

## 日志与版本更新

右上角「维护」提供本机诊断、主动回传、版本检查和安装入口。日志只包含受支持的技术事件、匿名事件 ID、时间和应用版本，无对话正文、录音、访问票据或 API key。回传要经过设备认证，服务器确认后移除待传事件。间歇网络下可再次同步。长期凭据保存在 Android Keystore 保护的本机存储。

首次侧载完成后，应用在进入前台及系统安排的后台任务中检查更新；非计费网络可自动下载。安装前核对发布清单、文件大小、SHA-256、包名、递增版本号和已安装应用的签名。通过「维护 → 安装新版」交由系统确认，通话中不会弹安装。首版作为后续升级的签名基线；取消安装可继续用原版本。

## 构建

在同一检出先执行 `cd ../web/personal && npm ci --workspaces=false`。在本目录运行 `bash scripts/build.sh` 生成正式签名 APK。使用本机制定的 Android SDK、Android 36 平台、build-tools 和 JDK，支持脚本顶部的路径覆盖。保留本应用独立签名密钥以支持覆盖升级。构建输出在本目录 `build/`。APK 和发布清单按版本单独交付到飞牛，源码不含设备密钥、APK 或签名材料。

## 验证

`tests/online.cjs` 用本次打包的界面和 LiveKit 客户端接入正式个人语音房间。只在测试环境向麦克风送普通话样音；观察两路字幕、远端音量、打断、Worker 控制回执和挂断后是否有残留音轨。通过标准输入交给脚本设备凭据，通过环境设置 `LONG_WAV`、`NEXT_WAV`、`LIVEKIT_UMD`、`CHROMIUM_PATH`、`PLAYWRIGHT_MODULE`。脚本只输出技术指标。
