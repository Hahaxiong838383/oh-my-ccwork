# 小可 · 暗夜剧场

三星 S24 Ultra 上的个人语音客户端，应用包为 `cc.hahaxiong.xiaoke.night`。首次打开，用个人语音设备凭据配对，允许麦克风后点「开始」。在密码库可找到「小可个人语音 · phone-01 设备凭据」。普通通话只需这一份设备凭据。配色会在本机保留。切后台结束本次通话，回到前台可再次开始。

## 通话

Android 管理权限、通话路由和 AES-GCM 设备凭据。WebView 统一持有播放焦点。界面和固定版本的 LiveKit/WebRTC 客户端随 APK 分发。签票、信令使用私人服务的 HTTPS/WSS 域名；音轨由北京转往飞牛个人 Worker。手机订阅 Worker 的回放，让眼形和球体姿态随声音的节奏变化。麦克风驱动倾听动作，静音后停止响应本机声音。开启系统「减少动态效果」时，听、说仍有各自的静态姿态。输入字幕接收同一段识别的增量修正，输出字幕随播报按句显示、接受被打断后的修订。开麦时可以直接插话。中央打断键发出当前房间的可靠控制包，等待 Worker 回执。通话会核对房间中已经订阅的小可音轨；系统暂停回放时，点「恢复声音」可在原通话继续听。断线或挂断后清理音轨、计时器和本轮状态。

## 球面头像

球面上两只眼睛沿经度 ±18° 对称放置。眼部直接在球面局部坐标中生成，通过头部旋转一次投影到屏幕。转头时远眼自然收窄。说话主要靠语节、目光与轻点头表达，倾听一段话后会趁短停顿点头。

在头像或舞台空白处按住并滑动，视线先到、球头稍后跟上。松手短暂停留再回正，轻点头像仍会触发表情。字幕区可滚动，工具按钮可独立操作。

状态与节奏沿用 grokbot-web 的 39 项状态表，25 个表情编号映射到本应用绘制的正视眼形。参考数据和 BSD-3-Clause 许可随 APK 分发。球面眼位、眨眼和惯性参考 Grok Bot 动画解剖。 [grokbot-web](https://github.com/Coiggahou2002/grokbot-web) · [Grok Bot 动画解剖](https://github.com/ArvinYin1/grokbot-animation-anatomy)

## 日志与版本更新

右上角「维护」提供本机诊断、主动回传、版本检查和安装入口。日志只包含受支持的技术事件、匿名事件 ID、时间和应用版本，无对话正文、录音、访问票据或 API key。回传要经过设备认证，服务器确认后移除待传事件。间歇网络下可再次同步。长期凭据保存在 Android Keystore 保护的本机存储。

进入前台及定期后台任务会检查更新，在非计费网络自动下载。首页顶栏显示当前阶段，点开可查看版本、已收字节、总大小和下载进度。允许系统通知后，切到其他应用也能查看进度，点通知可回到更新面板。下载完成后校验大小和 SHA-256，再检查包名、递增版本号和签名。

点「安装新版」进入 Android 安装流程。首次需要授权安装来源，授权后返回可接续系统确认；取消后保留已校验的包，可直接重试。成功提示以系统回执或实际安装版本为准。通话中优先显示字幕，安装等挂断后进行。

## 构建

在同一检出先执行 `cd ../web/personal && npm ci --workspaces=false`。在本目录运行 `bash scripts/build.sh` 生成正式签名 APK。使用本机制定的 Android SDK、Android 36 平台、build-tools 和 JDK，支持脚本顶部的路径覆盖。保留本应用独立签名密钥以支持覆盖升级。构建输出在本目录 `build/`。APK 和发布清单按版本单独交付到飞牛，源码不含设备密钥、APK 或签名材料。

## 验证

`tests/online.cjs` 用本次打包的界面和 LiveKit 客户端接入正式个人语音房间。只在测试环境向麦克风送普通话样音；观察两路字幕、远端音量、打断、Worker 控制回执和挂断后是否有残留音轨。通过标准输入交给脚本设备凭据，通过环境设置 `LONG_WAV`、`NEXT_WAV`、`LIVEKIT_UMD`、`CHROMIUM_PATH`、`PLAYWRIGHT_MODULE`。脚本只输出技术指标。

用 `node tests/avatar.cjs [解包后的 assets 目录]` 可测试麦克风、播放音量、静音和减少动态时的实际画布像素。测试可以通过 `PLAYWRIGHT_MODULE` 和 `CHROMIUM_PATH` 选择已有的浏览器环境。
