# 上线前检查清单（微信小程序）

> 勾完这份再点「提交审核」。顺序很重要：带了 ✱ 的项不满足会直接卡住发布。

## A. 账号与主体

- [ ] ✱ 小程序已注册（邮箱未注册过微信公众平台），AppID 已知
- [ ] ✱ 主体已选定（个人 / 企业）；企业需营业执照
- [ ] 微信认证（企业通常需要；支付能力前提）
- [ ] 管理员微信可扫「公众平台安全助手」确认操作

## B. 备案（1–20 工作日，最早启动）

- [ ] ✱ 后台【去备案】提交：主体信息 / 主体负责人 / 小程序信息 / 小程序负责人
- [ ] ✱ 人脸核身完成（本人、浅色背景、不戴帽口罩耳机）
- [ ] ✱ 收到 12381 短信后 24 小时内在 beian.miit.gov.cn 完成核验
- [ ] 平台初审通过（1–2 工作日）
- [ ] 通管局审核通过，拿到备案号
- [ ] 涉及前置审批的类目已提交对应文件

## C. 小程序配置

- [ ] ✱ 服务类目与实际功能一致（选错必被驳回）
- [ ] ✱ 《用户隐私保护指引》已配置（否则隐私接口报错）
- [ ] 服务器域名已配（`request` / `uploadFile` / `socket`，必须 HTTPS + 443 + 已备案域名）
      → 用云开发可跳过
- [ ] 业务域名（如需内嵌 web-view）
- [ ] 小程序名称 / 头像 / 简介 / 截图等基础信息
- [ ] 版本号命名规范已定（如 `1.0.0` / `1.0.0-20261117`）

## D. 代码

- [ ] ✱ 主包体积 < 2MB，总包 < 20MB（分包已规划）
- [ ] 体验版走完主流程，无阻断
- [ ] 真机验证（至少 iOS + Android 各一台）
- [ ] `project.config.json` 里 `urlCheck` 与实际域名一致
- [ ] 无硬编码密钥 / token（grep 一遍 `key`、`secret`、`token`、`password`）
- [ ] 敏感接口有失败兜底（网络异常、权限拒绝）

## E. 上传与提审

- [ ] 代码已上传（`scripts/upload.mjs` 或 `wxdt-cli upload`）→ 后台「开发版本」可见
- [ ] 后台设「体验版」，邀体验成员验证
- [ ] 提交审核：填功能页面、测试账号（如需要）、类目、隐私说明
- [ ] 审核 1–7 天，留意站内信/模板消息
- [ ] 通过后发布：全量 或 分阶段（灰度）

## F. 发布后

- [ ] 线上版本可正常进入（扫码 / 搜索）
- [ ] 备案号在小程序资料页自动展示
- [ ] 小程序码已下载（推广用）
- [ ] 云开发环境已转付费（免费环境在发布后第 15 天到期）
- [ ] 监控/日志可用（云开发控制台 / 自建后端日志）
- [ ] 回退预案：后台可「回退」到上一线上版本

## G. 本机侧

- [ ] `~/.mycc-secrets/private.<appid>.key` 存在且 600
- [ ] IP 白名单策略已定（关闭 / 固定出口 / 只走 IDE 登录态）
- [ ] `/data/home-studio/artifacts/<项目>/` 可写
- [ ] `bin/wxdt-doctor` 全绿
