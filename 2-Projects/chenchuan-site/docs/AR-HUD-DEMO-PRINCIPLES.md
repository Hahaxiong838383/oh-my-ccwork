# AR HUD Demo · 锚定文档

> 短工期 demo 必有锚定文档，防过度工程。本文档是范围红线，超出范围一律 V2。
> 2026-05-21 · 川哥 + cc + codex + gemini team 模式启动

## 一句话定位

**打开站点 → 摄像头授权 → 用眼动 + 手势 + 表情控制模拟 AR HUD 座舱**

价值不是炫技，是让招聘者/客户 5 秒内意识到：「这哥们儿真的把多模态交互产品化过 4 代 HUD」。

## 范围（必须做）

| 模块 | 内容 |
|------|------|
| 路由 | `/lab/ar-hud-demo`（独立页面） |
| 三路检测 | MediaPipe FaceLandmarker（眼动 + blendshape）+ HandLandmarker（手势） |
| 背景视频 | 川哥提供 AI 生成的「司机视角前窗外」视频（D2 接入） |
| HUD overlay | 5 个 HUD 卡片：车速 / 导航 / 能耗 / 警示 / 媒体 |
| 交互 | 眼动→注视卡片高亮 / 食指捏合→拖动 / 皱眉→警示分级 / 微笑→收藏 |
| 兜底 | 拒绝摄像头权限 → 自动播放录屏 + 操作说明 |
| 入口 | 首页 Hero CTA「Try it now」+ 项目卡（全车窗 HUD）详情页内嵌 |

## 反范围（V1 不做）

- ❌ 多语言（仅中文，i18n 留 V2）
- ❌ 多场景切换（仅一个驾驶舱视图）
- ❌ 用户数据持久化（不存任何东西，纯前端体验）
- ❌ 后端 API（100% 浏览器端推理）
- ❌ 评分/排行榜/社交分享（V2 再说）
- ❌ 桌面端外的优化（移动端检测 → 直接播放录屏，不强求实时）
- ❌ 3D HUD（Three.js 太重，Canvas 2D 够用）

## 视觉风格

参考川哥真实产品（YA8 / V01 量产 HUD）：
- 主色：HUD 黄绿色 (`#A4E831` / `#7FE5FF`) + 黑底
- 极简线条 / 锐角 / 数字字体（JetBrains Mono / Geist Mono）
- 卡片半透明发光 + 微动效（hover/focus 加强）

## 性能门槛

| 设备 | 目标 FPS | 降级策略 |
|------|---------|---------|
| M1+ Mac / iPhone 14+ | 30 fps | 全功能 |
| 中端设备（>2020 年） | 15 fps | 降到单路眼动 |
| 老设备 / iOS Safari | 0 fps（不跑实时） | 自动播放录屏 |
