判读提醒

健康看 p2p，不要看丢包。 ping 10.10.10.1 到中继虚拟 IP 会稳定丢 10–30%，是已知的测量假象—— 同一时刻 TCP 跑 86 Mbps。判链路好坏看巡检里的第二列是 p2p 还是 relay。

控制台里设备端口一直在变是正常的。公司三台是对称 NAT， 这类 NAT 对每个目的地分配不同外部端口并周期重分配，底层通道并没有断。
