1. 方案目标与核心原则

把家里的 2 台电脑与公司的 3 台电脑组成一个私有虚拟内网，实现：

  • 任意设备互相访问（SSH、文件共享、远程桌面等）
  • 不依赖手动打开客户端 APP，开机即自动连接
  • 尽可能走 P2P 直连，最大化利用本地宽带带宽
  • 兼容 Mac 上已有的代理翻墙服务，不互相干扰
  • 自建节点，数据与发现过程完全可控
核心技术选型：EasyTier（去中心化 Mesh VPN）+ 野草云香港 VPS（作为私有共享节点）

选择 EasyTier 的原因：跨平台（macOS / Linux）、P2P 能力强、支持私有模式、可注册为系统服务、资源占用低。

数据流说明

  • P2P 直连（实线）：两端 NAT 打洞成功后，流量直接在两台设备之间传输，不经过 VPS，速度受本地宽带限制。
  • 发现与中继（虚线）：设备通过 VPS 互相发现；仅当 P2P 失败时，流量才经过 VPS 中继。
  • VPS 本身不强制参与业务流量，主要承担协调与兜底角色。

4. 野草云 VPS 部署（共享节点）

4.1 基础准备

sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget unzip ufw

# 开放必要端口
sudo ufw allow 22/tcp
sudo ufw allow 11010/tcp
sudo ufw allow 11010/udp
sudo ufw enable

4.2 安装 EasyTier

curl -fsSL "https://github.com/EasyTier/EasyTier/blob/main/script/install.sh?raw=true" | sudo bash -s install

# 验证
easytier-core --version
easytier-cli --help

4.3 启动共享节点（测试）

sudo easytier-core \
  --network-name YourNetworkName2026 \
  --network-secret YourStrongSecretHere \
  --private-mode true \
  --listeners tcp://0.0.0.0:11010 \
  --listeners udp://0.0.0.0:11010 \
  --hostname yecaoyun-node

确认无报错后 Ctrl+C 停止，再做成系统服务。

4.4 注册为 systemd 服务（开机自启）

sudo nano /etc/systemd/system/easytier.service

写入内容（请替换网络名与密码）：

[Unit]
Description=EasyTier Shared Node
After=network.target
Wants=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/easytier-core \
  --network-name YourNetworkName2026 \
  --network-secret YourStrongSecretHere \
  --private-mode true \
  --listeners tcp://0.0.0.0:11010 \
  --listeners udp://0.0.0.0:11010 \
  --hostname yecaoyun-node
Restart=always
RestartSec=5
LimitNOFILE=1048576

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable --now easytier
sudo systemctl status easytier

路径请用 which easytier-core 确认后替换。

5. 客户端部署（Linux / macOS）

5.1 Linux 客户端

安装方式与 VPS 相同，然后创建服务：

sudo easytier-core \
  -d \
  --network-name YourNetworkName2026 \
  --network-secret YourStrongSecretHere \
  --private-mode true \
  -p tcp://你的野草云公网IP:11010 \
  -p udp://你的野草云公网IP:11010 \
  --hostname company-pc1

同样写入 systemd 的 ExecStart，实现开机自启。

5.2 macOS 客户端

# 推荐 GUI 安装
brew tap brewforge/chinese
brew install --cask easytier-gui

# 或命令行方式
sudo easytier-core \
  -d \
  --network-name YourNetworkName2026 \
  --network-secret YourStrongSecretHere \
  --private-mode true \
  -p tcp://你的野草云公网IP:11010 \
  -p udp://你的野草云公网IP:11010 \
  --hostname home-mac

macOS 可用 launchd 实现后台常驻，或使用官方 GUI 的后台模式。

每台设备建议设置不同的 --hostname，方便在 easytier-cli peer 中识别。

6. 代理兼容配置（Mac 翻墙服务）

在 Clash / Mihomo / Surge 等规则最前面加入以下内容，让虚拟内网流量走 DIRECT，避免被代理劫持：

rules:
  - IP-CIDR,10.0.0.0/8,DIRECT,no-resolve
  - IP-CIDR,100.64.0.0/10,DIRECT,no-resolve
  - IP-CIDR,172.16.0.0/12,DIRECT,no-resolve
  - IP-CIDR,192.168.0.0/16,DIRECT,no-resolve
  # 后面再写你原有的代理规则...

这样既保证 EasyTier 虚拟网畅通，又不影响正常访问海外网站。

7. 组网后可实现的效果

基础连通

  • 所有设备互相 ping 通（虚拟 IP）
  • SSH / 远程桌面无需公网 IP
  • scp / rsync / 共享文件夹直接可用
  • 打印机、NAS 等可被任意设备访问

使用体验

  • 家 ↔ 公司 像同一局域网
  • P2P 成功时延迟低、速度接近本地宽带
  • 开机自动连接，无需手动操作
  • 断线后自动重连

8. 把一台设备作为 AI 开发主机

把性能最好、长期开机的一台（推荐 Linux）作为 AI / Claude Code / Cursor 主机，其他电脑通过虚拟网络远程使用。

推荐方式

  1. Remote SSH：其他电脑用 VS Code / Cursor 的 Remote-SSH 连接主机，代码与 AI 交互都在主机上执行。
  2. 共享目录：主机用 Samba/NFS 共享项目目录，其他电脑挂载后像本地一样编辑。
  3. tmux / zellij：在主机上保持长会话，任意电脑随时接续之前的 Claude Code 对话。
  4. 本地大模型：主机运行 Ollama / vLLM 等，其他设备通过虚拟 IP 调用 API。
因为走的是 EasyTier 虚拟内网，Remote SSH 与文件访问延迟通常很低，体验接近本地开发，同时可在家与公司之间无缝切换。

9. 验证与日常维护

验证命令

# 查看当前连接的 peer 与链路类型（p2p / relay）
easytier-cli peer

# 查看路由
easytier-cli route

# 测试连通性
ping 10.x.x.x   # 其他设备的虚拟 IP

服务管理（Linux）

sudo systemctl status easytier
sudo systemctl restart easytier
journalctl -u easytier -f          # 实时日志

看到其他设备的 hostname，且 cost 显示为 p2p，即表示直连成功。

10. 优化建议与注意事项

  • 网络名与密码必须足够复杂，并妥善保管。
  • 每台设备设置有意义的 --hostname，便于识别。
  • 野草云带宽通常 100Mbps 级别，对个人组网中继足够；真正高速依赖 P2P。
  • 若 P2P 成功率不理想，可在客户端额外添加官方公共节点作为发现备份。
  • AI 主机建议 ≥16GB 内存，并配合 tmux 使用，防止网络抖动导致会话丢失。
  • 定期用 easytier-cli peer 检查链路状态，确认多数为 p2p。
本方案完全自建、数据不经过第三方控制平面，适合对隐私与稳定性有要求的个人 / 小团队使用。
