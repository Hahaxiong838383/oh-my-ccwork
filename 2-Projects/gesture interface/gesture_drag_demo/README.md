# Gesture Drag Demo v3.9

## v3.9 新特性：标定点外扩 + 增量标定（免每次重标）

### 标定点外扩（边缘精度）
- 9 点从 20-80%/25-75% 外扩到 **10-90%/12-88%**：气泡可出现在画面边缘，旧覆盖下边缘全靠二阶多项式**外推**（误差放大区）；外扩把外推区变插值区，且边缘非线性只有被标定点"见过"才能被拟合
- 前提联动：`GAZE_PT_DEG_SCALE` 15→25（边缘 yaw 到 18°+，15 会削顶污染标定）
- expected 用统一映射 `x=(r-0.5)/0.6, y=(r-0.5)/0.5` 自动生成（与 card_expected_gaze/垂直门控同一约定）

### 增量标定（`calib_store.py`）
- **校准档持久化**：`~/Library/Application Support/GestureDemo/calibration.json`（锚点+系数+隐式样本；**删掉此文件=物理重置**，逃生门）
- **启动 3 点快验**（中心/左上/右下，约 3-5 秒）替代每次 45 秒全量标定：测旧档残差 → ≤0.28：快验点(权重 2.0)与旧 9 锚点合并重拟合（非线性形状由旧锚点保持，坐姿/距离级漂移被拉回）→ 超限（换摄像头/换房间）：自动转全量标定
- **元数据毒药防御**：backend / deg_scale / 标定点布局任一变更 → 旧档自动作废（threshold_dead_signal 教训预防）；档案损坏 → 静默回全量（fail safe）
- **隐式样本跨会话**：捏取样本带时间戳落盘，7 天保鲜期内回灌滑窗——「越用越准」跨越会话
- **失配哨兵**：换环境忘按 C 时，捏取样本连续 5 次被离群拒绝 → 主界面橙字提示「press C to recalibrate」
- 主界面左下角**常驻按键说明**（.app 无终端横幅，防遗忘）
- 新增 `test_calib_store.py`（7 测：往返/布局与后端不匹配弃档/损坏 fail-safe/保鲜过滤/回灌/快验微调数学）

|------|------|
| **C** | **一键重置+全量重标**：作废旧档 → 9 点标定 → 新档覆盖落盘（换摄像头/换房间用这个；快验屏内按 C 同样直达全量） |

## v3.8.1 修复：帧率恢复 + 低位气泡解封（v3.8 真机验收两问题）

- **垂直门控改布局几何推导**（修「中下气泡识别不准」）：v3.5 的 `BUBBLE_GAZE_Y_MAX=0.25` 是 legacy 垂直信号坏死年代拍的常数——换真信号后，屏高 62.5%~75% 生成的低位气泡被门控稳定封锁（注视它 gaze_y 实达 0.3~0.5）。现按「桌面顶线期望 gaze_y ± 0.10 余量」运行时推导（`AttentionSelector.set_layout`，1280×720 下分界 ≈0.58），布局变阈值自动跟；config 常数仅兜底
- **ptgaze 推理 CPU→MPS**（修帧率 13-15）：CPU 19.5ms 致处理超 33ms 帧间隔、摄像头节拍锁定丢帧腰斩；MPS 实测全链 55→17.5ms（输出数值与 CPU 逐位一致），不可用自动回退 CPU（`GAZE_PT_DEVICE`）
- **面部调试绘制默认关**（468 点绘制 5-8ms/帧的帮凶，按 F 仍可开）
- **气泡 dwell 改时间制**：锁定判据帧数→秒（标称 30fps 数学等价，旧测试语义不变），帧率波动不再拉长驻留手感（15fps 下 30 帧曾变 2 秒）；眨眼冻结时段不计入 dwell
- 新增 2 测：低位气泡新旧阈值对照解封（含拦截力保留）/ 15fps 下锁定时长恒定

## v3.8 新特性：ETH-XGaze 外观法信号源（路线B落地）

- **信号源换代**：raw gaze 从「手工几何融合（head/iris 加权）」切换为 **ptgaze ETH-XGaze resnet18** 外观法模型。AB 探针真人实测（`probe_ab_result.txt`）：垂直 SNR **0.52（手工，信号<噪声=坏死）→ 11.43（21.9 倍）**；同一静态图上手工管线帧间自抖 std 0.2、模型输出恒定——抖动根源实锤
- **回滚闸门**：`config.GAZE_BACKEND = "legacy"` 一行回退旧管线（双信号源并存）；git 锚点 `dd06afeaa`
- **交互层零改动**：9 点校准/隐式捏取校准/OneEuro/候选状态机/到位门全保留，只换信号源；FaceMesh 照跑（眨眼冻结/EAR/UI/confidence 不受影响）；模型侧偶发丢脸自动回退 legacy 顶帧
- 归一化定标：`x=-yaw/15, y=-pitch/15`（符号与量纲按川哥探针实测；scale 取 15 防边缘削顶）
- 模型文件收在 `models/`（face_landmarker.task + eth-xgaze_resnet18.safetensors，git 不入库、缺失自动下载自愈）
- 新增 `test_ptgaze_backend.py`（5 测：符号量纲/clamp/接管/丢脸回退/闸门）+ `assets/test_face.jpg` 测试资产
- 新依赖：ptgaze（拖 torch/timm）；**mediapipe 必须 ≤0.10.15**（0.10.35 起 legacy solutions API 被移除，1.x 彻底删除——装依赖时严禁自动升级）

## v3.7 新特性：到位门解耦（修中上点卡死）+ 注视稳定性三连

- **修 v3.6 回归「中上点永不点亮」**：到位锁存曾耦合 std 稳定判据——高噪声点位（看上排=虹膜贴上睑+IRIS_SCALE_Y 放大后钳位削顶）std 永不达标 → arrived 锁不上，而放宽机制只在到位后生效 → 死锁 12s 被剔除（模拟三 seed 复现，v3.5 同流能过）。**解耦**：到位只看位置（滑窗中心均值天然抗噪），std 只管样本质量，放宽全程有效
- **方向自愈**：位移幅度持续显著、仅方向与期望不符 → 超时弃方向留幅度（真不看的人幅度不过，拦截力不损失）
- **校准诊断日志**：每点判据快照落盘 `~/Library/Logs/GestureDemo-calib.log`（.app 双击 stdout 不可见，文件是唯一取证出口）
- **卡片锁定进度衰减不清零**（`CANDIDATE_PROGRESS_DECAY`，v3.4 气泡范式移植）——修「盯图标进度一直跳」主因：视线微抖/分数瞬跌曾把 8 帧进度硬清零
- **眨眼冻结**（`BLINK_FREEZE_ENABLED`）：眨眼帧沿用上帧候选快照——人均 3-4s 眨一次、每次 3-9 帧虹膜乱值，8 帧锁定几乎必然被打断；带连续冻结 15 帧强制恢复保险丝
- **隐式重拟合不再 reset OneEuro**（`set_calibration(reset_filters=False)`）——每 3 次抓卡重拟合曾让注视信号瞬断闪一次
- 新增 5 测：点2回归(三seed)/方向自愈/自愈不误放静止/卡片衰减/滤波保持

## v3.6 新特性：校准到位门（修「没看点也能完成标定」）

- **根因**：v3.3 FixationGate 只测「稳」（滑窗 std）不测「在看点」——稳定地看错地方 std 一样低，川哥实测不看校准点也自动完成（2026-08-30）；且不看点的人视线全程不动，比认真跟点的人（扫视期 std 高）完成得更快
- **到位门**：每个点须先检测到视线相对上一成功点参照位发生「方向一致的显著迁移」（滑窗中心位移 ≥ `CALIB_ARRIVAL_MIN_SHIFT` 且与 expected 位移 cos>0）才开始计合格样本；判据基于位置而非运动，绿圈期间提前扫过去也判对；首点参照 = 欢迎屏注视中位数（只查幅度）
- **未到位 UI**：进度环不涨 + 橙色「Look at the dot」提示（6s 后强化为 `>>> LOOK AT THE DOT <<<`），12s 仍未到位 → 该点剔除（灰点「Point skipped」），绝不拿没看点的数据兜底
- **降级收紧**：超时降级兜底池只收「位移判据通过」的帧；单点样本不足从「整体校准失败」改为剔除该点
- **拟合质量闭环**（`fit_calib_points` 纯函数可单测）：剔除点过滤（<5 点校准失败明示重做）、<7 点禁 poly2 防过拟合（`allow_poly`）、**LOO 残差离群剔除**（训练残差会被污染点"传染"给 measured 空间的无辜邻居而指错人，leave-one-out 才指向真凶）、MAE 超 0.15 验证屏红字「LOW QUALITY - press C to redo」
- 被剔除的点不进隐式校准锚点集；顺手修掉「脸太小 confidence=0 时把未赋值的 (0,0) 默认 gaze 喂进门控」的隐患
- 新增 `test_calib_quality.py`（6 测）+ `test_fixation_gate.py` 扩 4 测（含复现事故的负向测试：静止注视 → 零合格样本 + given_up）

## v3.4 新特性：气泡凝视驻留环（川哥提案）

- **气泡锁定改为 dwell 驻留交互**：3 帧（50ms 瞬锁）→ 30 帧（~0.5s），外围环形进度弧随凝视增长——灰底环 → 亮青弧 → 满圈进入橙色锁定态（Apple Eye Tracking Dwell Control 同款范式）

## v3.3 新特性：校准质量闭环（川哥提案）

- **质量门控校准**（`FixationGate`，calibration.py）：告别"固定 2 秒照单全收"——只有滑窗 std 判定"盯稳了"的帧才计入合格样本，攒满 30 个才算完成该点（扫视/走神/眨眼时 std 天然飙高，装不出来）
- **转圈闭环反馈**：点位外围进度环随合格样本增长——灰=没盯稳（不涨）、亮青=采集中、转满变绿+OK 才进下一点
- **防转圈卡死**：单阶段 6 秒没攒满 → 自动放宽稳定阈值（×1.25，最多 2 次）→ 仍不满降级通过并标记，绝不困住用户
- 删除了盲目 0.4s 预热（门控天然涵盖视线到位判定）；状态差时单点最长约 18s 兜底退出
- 新增 `test_fixation_gate.py`（4 测：稳定累积/漂移不计/中断复位/超时降级）

## v3.2 新特性：捏取即校准（调研驱动·路线C）

- **隐式在线校准**（`implicit_calib.py`）：每次 pinch 抓取卡片的瞬间 = 一个注视弱标签（视线必在目标卡片上），滑窗累积增量重拟合校准多项式——**越用越准**，自动吸收换坐姿/换距离后的校准漂移（Sugano 范式，IEEE THMS 2015）
- 标签噪声三防线：离群拒绝（盲抓不污染）+ 显式 9 点锚点权重更高（隐式只微调不推翻）+ 滑窗 FIFO 淘汰
- 关键工程点：采样用**未校准原始值**（`GazeResult.uncal_gaze_*` 新字段），防"校准套校准"复合漂移
- 显式/隐式共用同一拟合器（`fit_poly_with_affine_fallback`），行为一致
- 新增 `test_implicit_calib.py`（4 测：漂移修正实测 -59% / 离群拒绝 / 滑窗上限 / 映射往返）
- 开关与参数：`config.py` IMPLICIT_*（`IMPLICIT_CALIB_ENABLED=False` 一键关闭）

## v3.1 特性：注视精度升级（调研驱动·路线A）

- **二阶多项式校准**（含 xy 交叉项，联合输入）替代 per-axis 仿射：直接拟合"边缘压缩 + 垂直增益不足 + 看角落两轴耦合"的非线性（学界实证眼动非线性集中在屏幕顶部行与左右边缘）；拟合退化时自动回退仿射，MAE 择优

## v3.0 新特性：面部特征 + 眼动校准

- **2D 注视估计**：注视方向从水平单轴扩展到水平 + 垂直双轴（`gaze_x` / `gaze_y`）
- **9 点眼动校准**：启动时引导注视 3×3 网格校准点，最小二乘回归仿射参数（`calibrated = a × raw + b`，x/y 独立），提升注视精度；按 C 可随时重新校准
- **面部特征追踪**（`face_tracker.py`，复用 FaceMesh 结果零额外推理）：
  - 眼部：EAR（眼睛纵横比）、眨眼检测（帧确认 + 不应期）、眼睛开合度
  - 头部朝向：yaw / pitch / roll
  - 表情线索：MAR（嘴巴开合比）、眉毛高度
- **面部特征可视化**：按 F 切换面部特征调试图层

## v2.0 特性：注视预选（Gaze-Attention Pre-selection）

- **粗粒度注视方向估计**：MediaPipe FaceMesh + 虹膜关键点，实时判断用户注视方向
- **候选卡片高亮**：看向某个区域 → 对应卡片淡金色提示 → 持续注视 → 金色脉冲锁定
- **注视 + 捏住融合**：锁定的候选卡片优先被捏住抓取，无需精确对准
- **拖拽不被打断**：拖拽期间注视冻结，释放后自动恢复候选选择
- **全参数可配置**：所有阈值集中在 `config.py`，方便调试

## 画面信息说明

### 左上角：手势状态
- **FPS**：帧率
- **Hand**：手部检测状态（DETECTED / LOST）
- **Pinch Ratio**：拇指尖与食指尖距离比例
- **State**：当前状态（idle / hovering / pinching / released）
- **Grabbing**：是否正在拖拽

### 右上角：注视 & 注意力状态（按 G 切换）
- **Face**：面部检测状态
- **Direction**：注视方向（LEFT / CENTER-L / CENTER / CENTER-R / RIGHT）
- **Gaze X**：水平注视值 [-1, 1]
- **Confidence**：注视可信度
- **Head / Iris**：头部与虹膜方向分量
- **Mode**：注意力模式（free / candidate / dragging）
- **Candidate**：候选卡片 + 锁定状态
- **Lock Progress**：锁定进度条

## 参数调节

所有可调参数集中在 `config.py`：

### 手势参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `PINCH_ON_THRESHOLD` | 0.33 | 低于此值判定为"捏住" |
| `PINCH_OFF_THRESHOLD` | 0.45 | 高于此值判定为"松开" |
| `CONFIRM_FRAMES` | 3 | 连续几帧确认后切换状态 |
| `SMOOTHING_ALPHA` | 0.6 | 坐标平滑系数（越大越跟手） |

### 注视参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `GAZE_SMOOTHING_ALPHA` | 0.35 | 注视方向平滑（越小越稳） |
| `HEAD_WEIGHT` | 0.35 | 头部朝向权重（剩余给虹膜） |
| `HEAD_SCALE` | 2.5 | 头部偏移放大系数 |
| `IRIS_SCALE` | 1.8 | 虹膜偏移放大系数 |

### 候选选择参数
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `CANDIDATE_LOCK_FRAMES` | 8 | 连续多少帧锁定候选 |
| `CANDIDATE_RELEASE_FRAMES` | 12 | 连续多少帧释放候选 |
| `ATTENTION_SWITCH_MARGIN` | 0.15 | 候选切换迟滞余量（防抖动） |
| `ATTENTION_SCORE_SIGMA` | 0.12 | 高斯评分标准差 |

### 调参建议

- **候选切换太频繁**：增大 `ATTENTION_SWITCH_MARGIN` 或 `CANDIDATE_LOCK_FRAMES`
- **候选锁定太慢**：减小 `CANDIDATE_LOCK_FRAMES`（如 5）
- **注视方向抖动**：减小 `GAZE_SMOOTHING_ALPHA`（如 0.2）
- **注视反应太慢**：增大 `GAZE_SMOOTHING_ALPHA`（如 0.5）
- **捏住太灵敏**：调大 `PINCH_ON_THRESHOLD`（如 0.38）
- **卡片跳动**：调小 `SMOOTHING_ALPHA`（如 0.4）

## 技术原理

### 手势检测（v1.0）
1. MediaPipe Hands 检测 21 个手部关键点
2. `pinch_ratio = 拇指尖到食指尖距离 / 手腕到中指根部距离`
3. 迟滞机制：捏住阈值 < 松开阈值，避免边界抖动
4. 帧确认 + EMA 平滑

### 注视预选（v2.0）
1. **面部检测**：MediaPipe FaceMesh（含虹膜关键点 468-477）
2. **头部朝向**：鼻尖相对双眼中心的水平偏移比例
3. **虹膜朝向**：虹膜中心在眼白中的水平位置比例
4. **加权融合**：`gaze_x = 0.35 × head + 0.65 × iris`，EMA 平滑
5. **候选评分**：高斯函数评估卡片与注视方向的接近度
6. **帧计数锁定**：连续 8 帧最高分 → 锁定候选（金色脉冲高亮）
7. **迟滞切换**：新候选需超出当前候选 0.15 分才切换，防止抖动
8. **融合抓取**：pinch 时优先抓取锁定候选 → 回退到位置命中测试
