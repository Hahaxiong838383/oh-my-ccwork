# 爱视可 ERP M2.2：烧录与六项出厂测试方案 V0.1

> 状态：2026-08-06 已通过人工验收；M2.3 等待明确指令。

## 1. 阶段边界

M2.2 只交付固件烧录、失败重试、六项测试及完整历史，不执行质量门和成品入库。六项全部通过后，设备仍保持 `FLASHED`，等待 M2.3 人工验收闸门解锁。

## 2. 烧录规则

- 只有 `ASSEMBLED` 或 `FLASHED` 设备可以记录烧录；
- 每次尝试新增一条不可修改记录；
- 失败必须填写原因，设备状态不推进；
- 通过必须记录固件版本和 AI Agent 版本；
- 首次通过自动完成 `ASSEMBLED → FLASHED`；
- 重新烧录允许更新当前版本，但历史记录永久保留；
- 固件包校验值、烧录工具版本、工位和日志只保存引用。

## 3. 六项测试

1. `OPTICAL`：光学与照明；
2. `SENSOR`：传感器；
3. `FUNCTION`：整机功能；
4. `AI`：AI 能力；
5. `AGING`：老化；
6. `OQC`：出厂检查。

测试只允许在 `FLASHED` 状态执行。复测新增记录，当前状态以每项最新一次结果为准；失败必须填写原因，可附脱敏摘要、结构化测量值和外部原始数据引用。

## 4. 工作台

- HID 扫码枪、二维码或手工 SN 定位设备；
- 展示组装、烧录、六项测试和锁定质量门四步状态；
- 记录烧录通过/失败与最近烧录历史；
- 六张测试卡展示待测、通过、不通过和尝试次数；
- 测试弹窗录入模板版本、工位、摘要、测量 JSON 和数据引用；
- 六项通过后只提示“等待 M2.3”，不提供质量放行按钮。

## 5. 验收标准

- 未组装设备不能烧录；
- 烧录失败不改变设备状态，且必须保留原因；
- 烧录通过后自动写入版本并推进到 `FLASHED`；
- 未烧录设备不能记录测试；
- 六项测试均支持失败后复测，旧记录不可修改；
- 最新失败会覆盖当前项目状态，最新通过可恢复；
- 六项通过后设备仍为 `FLASHED`；
- 全新浏览器会话正常业务路径控制台 0 错误；
- M2.3 入口和质量放行不在本阶段提供。
