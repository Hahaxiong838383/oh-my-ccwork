## 2. 验收样本

| 对象 | 编号 | 初始状态 |
|---|---|---|
| 渠道订单 | `ASK-ORD-00015` | 已激活 |
| 外部订单号 | `M3-MANUAL-ORDER-001` | 天猫旗舰店 |
| 设备 SN | `ASK-000020` | 已激活 |
| 发货仓库 | `Stores - ASK` | 已出库 |

## 3. 主流程验收

1. 在销售履约工作台搜索 `ASK-ORD-00015`；
2. 确认订单显示天猫、`FLAGSHIP`、渠道 SKU、内部 SKU 和脱敏对象引用；
3. 扫描或输入 `ASK-000020`，点击“分配设备”；
4. 确认订单变为“已分配订单”，时间线新增“设备分配”，当前仓库仍为 `Stores - ASK`；
5. 点击“登记发货”，填写承运商和物流单号后提交；
6. 确认设备变为“已发货”，当前仓库显示“已出库”，时间线保留实际出库仓库；
7. 点击“登记激活”，填写不含手机号或邮箱的脱敏激活引用和客户引用；
8. 确认订单、设备和四步进度均显示“已激活”，时间线有分配、发货、激活三条不可覆盖凭证。

## 4. 列表与筛选

1. 点击“订单列表”；
2. 在“渠道订单号”中输入 `M3-MANUAL-ORDER-001` 并回车；
3. 确认列表只显示 `ASK-ORD-00015`；
4. 确认销售渠道、渠道范围、渠道 SKU、内部 SKU 和订单状态均为中文可读。

## 5. 负向抽查

- 对未分配设备直接发货应被阻止；
- 发货不填写承运商或物流单号应被阻止；
- 未发货设备直接激活应被阻止；
- 脱敏引用填写手机号或邮箱应被阻止；
- 脱敏原始报文引用填写手机号或邮箱应被阻止；
- 已生成的履约凭证不能修改或删除。
