# 爱视可 ERP M3：渠道订单、设备分配、发货与激活方案 V0.1

> 状态：2026-08-06 已完成部署、自动验收、浏览器验收和川哥人工验收。

## 1. 阶段目标

M3 将天猫、京东和线下经销订单转换为统一内部订单，以设备 SN 为核心完成库存设备分配、物流发货和设备云激活，并将所有动作保留为不可覆盖凭证。

## 2. 业务边界

- 支持 `TMALL`、`JD`、`DEALER` 三类渠道；
- 渠道 SKU 必须先映射到已批准的内部 SKU；
- `渠道 + 渠道范围 + 外部订单号` 保证订单幂等；
- 订单支持 1–200 台设备，履约数量按分配、发货、激活逐级派生；
- 只有 `STOCKED` 且 SKU 匹配的设备可以分配；
- 发货必须绑定已分配 SN、出库仓库、承运商和物流单号；
- 激活必须发生在发货后，只保存脱敏激活引用和脱敏客户引用；
- 本阶段不实现平台结算、退款、退货、经销商授信和正式财务库存过账。

## 3. 数据对象

1. `Aishike Channel SKU Mapping`：渠道 SKU 与内部批准 SKU 的受控映射；
2. `Aishike Channel Order`：统一渠道订单、数量和履约进度投影；
3. `Aishike Device Fulfillment Record`：分配、发货、激活三类不可修改凭证；
4. `Aishike Device Unit`：只保存由最新履约凭证派生的渠道、订单、物流和激活投影。

## 4. 状态推进

```text
STOCKED
  -> ALLOCATED   设备分配凭证
  -> SHIPPED     发货凭证
  -> ACTIVATED   脱敏激活凭证
```

禁止直接修改设备状态。每次推进必须同时生成真实履约记录和生命周期事件。

## 5. 人工验收标准

- 重复导入同一外部订单返回同一内部订单；
- 未映射渠道 SKU 不能创建订单；
- SKU 不匹配、非在库或超订单数量的设备不能分配；
- 未分配设备不能发货，发货缺少物流信息不能提交；
- 未发货设备不能激活，邮箱或手机号不能作为脱敏引用保存；
- 收货对象、原始报文、激活和客户引用均不能包含邮箱或手机号；
- 分配、发货和激活记录不能修改或删除；
- Sales Manager 可维护映射和订单但不能履约，Stock Manager 可分配和发货但不能激活，System Manager 只能执行激活入口；
- 岗位动作验收必须在事务中真实执行并回滚，临时用户、映射、订单和履约记录不得残留；
- 一个页面可查看订单、设备、仓库、物流、激活和生命周期完整历史；
- 全新浏览器会话在桌面和手机端无横向溢出，正常路径控制台 0 错误。
