# 爱视可 ERP M2.3：质量门、成品入库与设备追溯方案 V0.1

> 状态：2026-08-06 已获川哥指令启动开发。

## 1. 阶段目标

M2.3 将 M2.2 的烧录与六项测试结果转化为可审计的质量放行、成品入库和仓库调拨凭证，并提供围绕设备 SN 的统一追溯界面。

## 2. 质量门

- 只有 `FLASHED` 设备可以执行质量判定；
- 六项测试最新结果必须全部通过；
- 每次判定新增一条不可修改、不可删除的质量放行记录；
- 驳回必须填写原因，设备保持 `FLASHED`，整改后重新新增判定；
- 通过记录自动驱动设备进入 `QC_PASSED`，禁止直接修改状态绕过质量凭证。

## 3. 成品入库与调拨

- 只有 `QC_PASSED` 设备可以执行首次成品入库；
- 首次入库必须选择目标仓库，自动驱动设备进入 `STOCKED`；
- 在库设备可从当前仓库调拨到另一仓库；
- 来源仓库必须等于设备当前仓库，来源和目标不能相同；
- 每次入库或调拨新增一条不可修改、不可删除的库存移动记录；
- 设备档案只保存由最新库存移动派生的当前仓库和最近库存凭证引用。

## 4. 全链路追溯

质量与入库工作台按 SN 汇总：

1. SKU、BOM、生产批次、工单和 SN 生成批次；
2. 固件与 AI Agent 版本、全部烧录历史；
3. 六项测试的最新状态与全部复测历史；
4. 质量放行与驳回历史；
5. 成品入库与仓库调拨历史；
6. 设备生命周期事件时间线。

## 5. 数据边界

- ERP 只保存脱敏摘要、结构化测量值和外部日志引用；
- 质量与库存凭证是爱视可设备级业务台账，不伪造 ERPNext 财务库存数量；
- 后续与 ERPNext 标准 `Stock Entry`、渠道订单和发货单联动时，以本阶段设备凭证作为 SN 级校验依据。

## 6. 人工验收标准

- 六项未全部通过时不能执行质量判定；
- 质量驳回保留原因，设备状态不推进；
- 质量通过后自动进入 `QC_PASSED`；
- 未质量通过不能成品入库；
- 首次入库后自动进入 `STOCKED` 并显示当前仓库；
- 仓库调拨必须从当前仓库转出，历史不可覆盖；
- 任意 SN 可在一个页面查看生产、质量、库存和生命周期完整历史；
- 全新浏览器会话正常路径控制台 0 错误。
