# 爱视可 ERP M2.3 人工验收指引

## 验收入口

- 工作台：`http://aishike.localhost:18081/desk/aishike-quality-console`
- 可操作样机：`ASK-000015`
- 当前预置状态：已完成烧录，六项测试 `6/6` 通过，尚未质量判定、入库或调拨。

## 建议操作顺序

1. 输入或扫描 `ASK-000015`，确认页面显示“已完成烧录”和六项测试 `6/6`；
2. 点击“驳回整改”，填写任意明确的驳回原因并提交；
3. 确认设备仍保持“已完成烧录”，追溯区域新增一条质量驳回记录；
4. 点击“质量放行”，确认设备自动进入“已通过质量门”；
5. 点击“成品入库”，目标仓库选择 `Finished Goods - ASK`；
6. 确认设备自动进入“已入成品库”，当前仓库正确显示；
7. 点击“仓库调拨”，目标仓库选择 `Stores - ASK`；
8. 确认当前仓库更新为 `Stores - ASK`，质量、入库、调拨及生命周期时间线均保留完整历史。

## 应当看到的限制

- 质量放行前，“成品入库”和“仓库调拨”不可操作；
- 质量驳回后设备状态不推进，必须新增质量判定；
- 入库后不能再次执行成品入库；
- 调拨时来源仓库由系统读取，目标仓库不能与来源仓库相同；
- 质量和库存历史记录不能修改或删除。

## 其他样本

- `ASK-000002`：已完成驳回、放行、入库和调拨，可查看完整结果；
- `ASK-000003`：已组装但未烧录，可验证测试和质量门锁定状态。
- `ASK-000016`：已完成真实浏览器端驳回、放行、入库和调拨闭环，可查看第二组完整结果。
