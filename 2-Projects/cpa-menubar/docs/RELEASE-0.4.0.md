# CPA Menu 0.4.0 (12) — 原生窗口与统一弹层

本记录保留首轮窗口改造及回滚基线。后续用户验收发现 Codex 关闭浏览器后没有取消/超时出口，已由 [0.4.1 (13)](RELEASE-0.4.1.md) 接续修复；当前应安装 0.4.1，而非本轮中间包。

## 范围

- 仅修改本机 macOS App 与安装/回滚脚本；日本 CPA、Bridge、Router、API Key 与账号调度不在本次变更范围。
- `MenuBarExtra(.window)` 改为 `NSStatusItem` + 自主管理的 `NSPanel`。窗口可接收键盘焦点，首次鼠标点击可进入交互；控制器长期持有窗口，关闭不自动释放。
- 添加订阅、清除 Token、移除账号、重置卡、xAI/Codex 授权进度共用单一弹层控制器。底层控件被禁用并从辅助功能树隐藏，不能点击穿透或叠加两个确认。
- 普通浏览点击外部收起；确认和在途操作期间保持窗口。授权时 `Esc` 或明确收起只隐藏窗口，不取消 OAuth。xAI 仅在用户明确点击“取消授权”时取消；Codex 保持原有浏览器回调流程。
- 确认默认焦点与回车动作落在取消按钮。弹层按内容高度收紧，超出屏幕可用高度时才滚动；主浮窗正常尺寸为 400×560。
- 菜单栏悬浮提示和浮窗底部显示 `v0.4.0 (12)`。

## 回滚基线

旧稳定版本为 **0.3.8 (11)**。首次安装保存的基线目录：

```text
/Users/rayman.chen/Library/Application Support/CPAMenuBar/Backups/20260921-000531-42961
```

目录时间戳由本机时钟按 UTC 生成；以 `release-receipt.json` 中的版本和二进制 SHA-256 为版本真值，不依赖目录排序猜测版本。

目录内包含：

- `CPA Menu.app`：旧版本完整应用包。
- `binary.sha256`：旧版可执行文件的 SHA-256。
- `release-receipt.json`：新旧版本、Build、Bundle ID、可执行文件哈希及安装状态。
- `rollback-app.sh`：独立回滚入口；只终止 `/Applications/CPA Menu.app/Contents/MacOS/CPAMenuBar` 对应进程，校验备份后恢复旧包。

先验证，不会停止或替换当前应用：

```sh
"/Users/rayman.chen/Library/Application Support/CPAMenuBar/Backups/20260921-000531-42961/rollback-app.sh" --verify-only
```

需要回滚时，先确认无进行中的授权、扣卡或账号移除操作，再去掉 `--verify-only` 执行。回滚前保留当前 Bundle；回滚不触及 Keychain、偏好设置、服务器或 OAuth 刷新后的凭据。

后续同版本验收迭代也会生成备份，其中 `previous.version` 可能是 `0.4.0`；如需退回旧窗口方案，应使用上述明确的 `0.3.8` 基线，而不是盲用最新备份。

## 验证记录

- Swift 测试：17 项 XCTest + 17 项 Swift Testing，共 34 项通过；新增 13 项覆盖单弹层、外部点击保护、Esc、授权收起/重开、后台状态不抢焦点、NSPanel 所有权及多屏坐标边界。
- Release 构建通过；安装包和回滚包均通过 `codesign --verify --strict`。
- 已安装 `0.4.0 (12)`，真实服务数据正常刷新。原生辅助功能树可读取窗口、控件和版本号，不再出现此前的读取超时。
- 原生“添加订阅”和“清除 Token”二次确认已打开并取消；未点击任何扣卡、清除 Token、移除账号的最终确认。
- 实机发现初稿弹层留白偏大，已改为测量内容高度后限高滚动；紧凑弹层截图与默认取消按钮焦点已验证。
- 显式按钮键盘聚焦增强已纳入 0.4.1，原生辅助功能验证默认焦点为“取消”，Tab 可移到“取消确认”，Esc 返回账号页。用户明确表示浏览器已关闭、等待无法退出后，才通过升级清理该次悬空等待；不得中断仍在正常进行的授权。
- 新增/重置/删除的服务端契约未改。真实 OAuth 网页往返、卡消费及账号移除不能由单元测试替代业务验收；本轮不代用户消费或变更账号。
