# CPA Menu 0.4.1 (13) — Codex 授权可取消与有界等待

## 问题与修复

0.4.0 已替换为独立 NSPanel，但 Codex 仍沿用旧的 `isAuthorizing` + 本地回调监听：关闭浏览器不会发送 OAuth 回调，且没有本地取消按钮或截止时间，因此长期停在等待授权。只修窗口焦点不足以修复这条业务生命周期路径。

本版提供：

- **取消授权**：取消本次启动/交换请求及超时任务，释放 1455 监听，清除本次内存 URL/state/截止时间，恢复“添加订阅”。不退出、删除或撤销原有账号。
- **重新打开授权网页**：仍在本次等待期内时复用当前 URL，不创建额外会话。
- **暂时收起**：只隐藏窗口；用户重新打开后继续看到当前授权状态。
- **5 分钟截止时间**：启动网络请求、等待浏览器和回调交换共用本次等待期限；到期释放资源并显示可重试的超时结果。
- **迟到结果隔离**：每次尝试使用独立 generation；取消或开始新尝试后，旧网络结果、旧监听器和旧 OAuth state 不得改变新任务。
- **严格回调匹配**：仅接受 `/auth/callback`、唯一且匹配的 state，以及 code/error。favicon、错误 state 或缺少字段的请求返回 400，但不停止正确授权的监听。
- **原生键盘聚焦**：弹层按钮显式可聚焦，取消为默认焦点和回车动作；Tab 可导航，Esc 取消普通确认，授权中 Esc 仅收起。

关闭浏览器不能可靠代表用户放弃登录，本版不窥探或操控浏览器窗口。明确取消和超时是退出机制。若回调已送至服务器，服务器可能先完成授权；本机取消不会撤销已经完成的远端结果，需要刷新账号列表确认。
