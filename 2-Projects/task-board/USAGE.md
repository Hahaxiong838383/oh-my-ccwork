# 任务看板 · 使用指南

> 一个跑在你电脑上的任务看板。你在网页上能拖拽、增删改任务；如果你用 Claude Code 或 Codex 写代码，它们也能自动帮你往看板里填任务。
>
> **不需要注册、不需要联网、不需要数据库。** 所有数据存在本地一个文件里。

## 1. 它能帮我做什么

一句话：**把你脑子里、聊天里、代码里散落的"待办"，统一到一个看得见的看板上。**

它解决三个场景：

| 场景 | 没有它 | 有了它 |
|---|---|---|
| 你想到一件事要做 | 记在脑子里，忘了 | 网页上加一条，列在看板上 |
| 你让 AI 写代码 | 做完就做完，没记录 | AI **自动**在看板上建任务、标进度、标完成 |
| 你同时做几个项目 | 任务混在一起分不清 | 每个项目独立看板，一键切换 |

**核心特点：**
- 🖱️ **人在网页上能直接操作**：拖拽卡片改状态、点按钮编辑/删除、弹窗填全部字段
- 🤖 **AI 能自动维护**：Claude Code / Codex 接到任务时自动建卡、完成时自动标记
- 📁 **纯本地**：数据就是 `tasks.json` 一个文件，可以用 git 管理、用网盘备份
- 🚫 **零依赖**：不用装数据库、不用配环境，有 Node.js 就行

## 2. 第一次使用：5 分钟跑起来

### 准备工作

**只需要装 Node.js**（版本 18 或以上）。

- Mac：打开"终端"，输入 `node -v`。如果显示 `v18.xx` 或更高，就 OK
- 没装的话，去 [nodejs.org](https://nodejs.org) 下载安装包，一路下一步

> 不知道怎么打开终端？Mac 上按 `F4` 搜索"终端"或"Terminal"。

### 三步启动

**第 1 步：打开终端，进入项目目录**

```bash
cd /Users/pan/ZCodeProject/task-board
```

（把路径换成你实际放 `task-board` 文件夹的地方）

**第 2 步：启动服务**

```bash
node server.mjs
```

看到这两行就说明成功了：

```
[task-board v3] 服务已启动 → http://localhost:8788
[task-board v3] 项目: /api/projects | 任务: /api/tasks | 复制: /api/tasks/:id/copy-to/:pid
```

**第 3 步：浏览器打开**

访问 👉 **http://localhost:8788**

你会看到一个看板，长这样：顶部有项目下拉、搜索框、新增按钮；下面四列（Backlog / Todo / Doing / Done）；顶部一行统计数字和进度条。

> ⚠️ **重要：必须用浏览器访问 `http://localhost:8788`，不要双击 `index.html` 文件打开！**
> 双击打开的话，页面按钮会没反应（浏览器安全限制）。

### 怎么停掉服务

在终端按 `Ctrl + C`（同时按 Control 键和 C 键）。

## 3. 看网页：日常用法

### 加一条新任务

1. 点右上角紫色按钮 **「+ 新增任务」**
2. 弹窗里填写：
   - **标题**（必填）：一句话说清要做什么，比如"实现登录页"
   - **状态**：backlog（以后做）/ todo（准备做）/ doing（正在做）/ done（做完）
   - **优先级**：P1（高，红点）/ P2（中，黄点）/ P3（低，紫点）
   - **备注**：背景、阻塞原因、完成说明
   - **关联文件**：相关的代码文件，逗号分隔
3. 点 **「保存」**

### 改任务状态（三种方式）

**方式 1：拖拽（最顺手）**
- 鼠标按住一张卡片，拖到另一列（比如从 Todo 拖到 Doing），松手即可

**方式 2：左右箭头按钮**
- 鼠标移到卡片上，底部出现按钮 `←` `→`，点一下就在相邻列之间切换

**方式 3：编辑弹窗**
- 点卡片上的「编辑」按钮，在弹窗里改状态

### 编辑 / 删除任务

- 鼠标移到卡片上，底部出现按钮组
- 点「**编辑**」改任何字段
- 点红色「**删除**」删除任务（会弹确认框，防误删）

### 搜索

右上角搜索框，输入关键词，按标题、备注、任务编号（如 T-001）实时过滤。

### 看进度

页面顶部统计栏实时显示：

```
● Backlog 1   ● Todo 0   ● Doing 2   ● Done 5   ■ 总计 8   ▓▓▓▓▓▓▓░░░ 62%
```

- 四个状态各一个数字
- 紫色「总计」
- 右边进度条 = 完成数 ÷ 总数，紫绿渐变

任务一变化，数字和进度条立刻更新（页面每 3 秒自动刷新一次）。

### 快捷键

| 按键 | 作用 |
|---|---|
| `Esc` | 关闭弹窗 / 下拉菜单 |
| `Cmd + Enter`（Mac）<br>`Ctrl + Enter`（Win） | 在编辑弹窗里快速保存 |

## 4. 多项目管理

### 为什么需要多项目

如果你同时做几件事——比如一个个人网站、一个学习项目、一个工作项目——任务混在一起会乱。每个项目有独立的任务列表，互不干扰。

### 切换项目

点顶部左侧的项目下拉（带色点的那个），列出所有项目，点一个就切过去。

### 新建项目

1. 点项目下拉
2. 点最下面的 **「+ 新建项目」**
3. 填写：
   - **项目标识**：英文小写，比如 `my-website`（用作内部 id）
   - **显示名**：中文也行，比如"我的网站"
   - **颜色**：选一个色，卡片左侧会显示这个色的色条
4. 点「创建」，自动切换到新项目

### 复制跟进（核心功能）

**场景**：你在项目 A 做到一半，临时要切到项目 B，但又想把 A 里没做完的事"带过去"继续跟。

**操作**：当你切换项目时，如果当前项目有 **正在做（doing）** 的任务，会自动弹出一个窗：

```
切换到「我的网站」
要把以下进行中的任务复制到新项目跟进吗？（原任务会保留）

☑ T-002  实现登录页
☑ T-005  优化首页样式

[复制选中]  [不复制]  [取消]
```

- 勾选要带走的任务
- 点「**复制选中**」→ 这些任务会**复制一份**到新项目（原项目里的任务**保留不动**）
- 复制过去的任务状态重置为 `todo`（准备做），备注里自动注明"跟进自 原项目-T-xxx"

三个按钮的区别：
- **复制选中**：勾选的任务复制到新项目
- **不复制**：只切换项目，不带任务
- **取消**：不切换了

### 删除项目

目前网页上没有删除项目的按钮（防止误删）。如果确实要删，让 AI 帮你（见下一节），或者用命令行：

```bash
curl -X DELETE http://localhost:8788/api/projects/项目标识
```

⚠️ 删项目会把这个项目下的**所有任务**一起删掉。

## 5. 让 AI（Claude Code / Codex）帮你管任务

这是这个看板最强大的地方：**你跟 AI 说"帮我做 X"，AI 会自动在看板上建任务、跟踪进度、标记完成。** 你不用手动维护。

### 支持哪些 AI 工具

| 工具 | 支持情况 | 怎么用 |
|---|---|---|
| **Claude Code**（命令行） | ✅ 全自动 | 把项目目录打开即可 |
| **Codex** | ✅ 自动 | 把项目目录打开即可 |
| 其他 AI 工具 | ⚠️ 可手动调用 | 通过命令行 curl 调 API |

### 用 Claude Code（推荐）

**前提**：先确保看板服务在跑（见第 2 节）。

**第 1 步：在这个目录里启动 Claude Code**

```bash
cd /Users/pan/ZCodeProject/task-board
claude
```

> 为什么必须 `cd` 进这个目录？因为 Claude Code 只读取"当前目录"下的 `.claude/` 配置（Skill 和 Hook 都在里面）。在别的目录启动，它看不到这些配置。

**第 2 步：正常对话就行**

```
你：帮我加一个深色模式切换按钮
```

Claude Code 会自动：
1. 在看板里**创建**一条任务"加深色模式切换按钮"，状态 `doing`
2. 开始写代码
3. 写完后把任务**标记为 `done`**，记录改了哪些文件

你打开 http://localhost:8788 就能看到这条任务从 Doing 列移到了 Done 列。

**为什么会自动这么做？** 因为项目里配了两个机制：
- **Skill**（`.claude/skills/`）：告诉 AI"接到任务时要先在看板建一条"
- **Hook**（`.claude/hooks/`）：每次你发消息时，强制提醒 AI 按规则维护看板

### 用 Codex

Codex 读的是项目根目录的 `AGENTS.md` 文件（已经配好了）。同样在这个目录启动 Codex：

```bash
cd /Users/pan/ZCodeProject/task-board
codex
```

然后正常对话，Codex 会按 `AGENTS.md` 里的规则维护看板。

### AI 的行为边界（重要！）

| 你说的话 | AI 会怎么做 |
|---|---|
| "帮我实现登录页" | ✅ 建任务 + 做事 + 标完成 |
| "修复这个 bug" | ✅ 建任务 + 修复 + 标完成 |
| "今天天气怎么样" | ❌ 不建任务（这不是开发任务） |
| "看板现在有几条任务" | ❌ 不建任务（只是查看） |

**判断标准**：你的消息是不是要求 AI "动手做某件具体的事"。是→建任务；否→跳过。这样看板不会被闲聊污染。

### 如果 AI 忘了建任务怎么办

虽然配了 Hook 强制提醒，但 AI 偶尔可能"漏掉"。两个补救办法：

1. **直接命令**：在 Claude Code 里输入 `/task-add 实现搜索功能`（项目里预置了这个命令）
2. **手动在网页加**：打开 http://localhost:8788 点「+ 新增任务」

### 让 AI 在"任何项目"里都能更新这个看板（可选）

默认配置只在 `task-board` 这个目录里生效。如果你想**在别的项目目录**里用 Claude Code 时，也能让它更新这个中央看板，把这段加到全局配置 `~/.claude/CLAUDE.md`：

```markdown
## 任务看板
本地有一个任务看板：http://localhost:8788（数据在 /Users/pan/ZCodeProject/task-board/tasks.json）
做开发类任务时，通过 curl 调 API 维护它：
- 开始：curl -X POST http://localhost:8788/api/tasks -H 'content-type: application/json' -d '{"title":"任务名","status":"doing"}'
- 完成：curl -X PATCH http://localhost:8788/api/tasks/T-001 -H 'content-type: application/json' -d '{"status":"done"}'
```

## 6. 常见问题

### Q：页面按钮点不动 / 拖不动？

**99% 是浏览器缓存了旧页面。** 解决办法：

1. **硬刷新**：Mac 按 `Cmd + Shift + R`，Windows 按 `Ctrl + Shift + R`
2. 还不行，地址栏访问 `http://localhost:8788/?v=2`（加参数必定绕过缓存）
3. 确认地址是 `http://localhost:8788`，**不是**双击 `index.html` 打开的

### Q：打开页面显示"加载失败 / 连接被拒绝"

说明服务没启动。回到终端：

```bash
cd /Users/pan/ZCodeProject/task-board
node server.mjs
```

### Q：终端关掉了，页面还能用吗？

不能。服务跑在终端里，终端关了服务就停了。

**想让它在后台一直跑**（关终端也不影响）：

```bash
# Mac/Linux：后台运行，日志写到 server.log
nohup node server.mjs > server.log 2>&1 &

# 停掉后台服务
lsof -ti:8788 | xargs kill
```

### Q：端口 8788 被占了怎么办？

换个端口启动：

```bash
PORT=9000 node server.mjs
```

然后访问 `http://localhost:9000`。

### Q：数据会丢吗？

**不会。** 所有数据存在 `tasks.json` 这一个文件里。只要这个文件在，数据就在。建议：
- 用 git 版本管理（`git init` 后提交）
- 或定期复制 `tasks.json` 到网盘

### Q：能在手机上看吗？

可以，前提是手机和电脑在**同一个 WiFi** 下。

1. 电脑上启动服务时用：`node server.mjs`（默认监听所有网卡）
2. 查电脑局域网 IP：终端跑 `ipconfig getifaddr en0`（Mac）
3. 手机浏览器访问 `http://你的IP:8788`，比如 `http://192.168.1.5:8788`

> ⚠️ 这样同一 WiFi 下的人都能访问，家庭网络没问题，公共 WiFi 慎用。

### Q：怎么改任务的创建时间或 ID？

不能改。ID 是自动生成的（每个项目从 T-001 起按顺序），创建时间用 `updatedAt` 字段自动维护。这是为了保证数据一致性。

### Q：AI 建的任务我没想要，怎么删？

打开网页，找到那张卡，鼠标移上去点红色「删除」按钮。或让 AI 删：`curl -X DELETE http://localhost:8788/api/tasks/T-001`。

## 7. 数据在哪？怎么备份？

### 数据文件

**所有数据都在一个文件里：**

```
task-board/tasks.json
```

结构长这样（你不用记，备份就行）：

```json
{
  "version": 2,
  "currentProject": "local-board",
  "projects": {
    "local-board": {
      "name": "看板本体",
      "color": "#6366f1",
      "tasks": [
        { "id": "T-001", "title": "...", "status": "done", ... }
      ]
    }
  }
}
```

### 备份方法

**方法 1：直接复制文件**

把 `tasks.json` 复制到 U 盘、网盘、邮件附件——随便哪里。恢复时覆盖回来就行。

**方法 2：用 git（推荐程序员）**

```bash
cd task-board
git init
git add tasks.json
git commit -m "备份任务"
```

每次想备份就 commit 一次，历史版本都能找回。

**方法 3：让 AI 备份**

跟 Claude Code 说："帮我备份一下 tasks.json"，它会复制一份带时间戳的副本。

### 迁移到另一台电脑

1. 把整个 `task-board` 文件夹复制到新电脑
2. 新电脑装好 Node.js
3. `cd task-board && node server.mjs`
4. 打开 http://localhost:8788，所有任务都在

### 数据安全提醒

- `tasks.json` 是**纯文本**，任何人拿到文件都能看。别把敏感信息（密码、密钥）写进任务备注里
- 看板服务**没有密码保护**，同网络的人能访问。只在个人电脑 / 家庭网络用
