# 双模式执行体系

## 模式说明

### 模式1: 闲聊模式 (Chat Mode)
- 保持现状不变
- 直接与用户对话，不调用外部工具
- 适用于：日常问答、简单查询、闲聊

### 模式2: 工作模式 (Work Mode)
- 多智能体协同系统
- 严格遵循四层闭环流程
- 适用于：复杂任务、功能开发、bug修复

## 切换规则

当用户描述的任务包含以下特征时，切换到工作模式：
- 需要实现具体功能
- 需要修改代码
- 需要多步骤完成
- 涉及多个文件
- 需要测试验证

## 触发关键词

工作模式触发词：
- "开发"、"实现"、"创建"
- "修复"、"bug"、"重构"
- "任务"、"项目"
- 任何复杂技术需求

闲聊模式触发词：
- "聊聊"、"解释一下"、"什么是"
- 简单问答

## 工作模式：四层闭环流程

### Layer 1 规格与合同（Claude 负责）
- SPEC.md - 规格说明
- AC.md - 验收标准
- ARCH.md - 架构设计
- EXAMPLES.jsonl - 示例数据

### Layer 2 并行产出
- Codex：主实现
- Gemini：对照实现 + 边界case

### Layer 3 自动化验收
- 单元测试
- 示例数据对比
- 静态检查

### Layer 4 最终裁决（Claude 负责）
- 审查测试覆盖
- 合并最佳方案
- 输出最终 REVIEW
