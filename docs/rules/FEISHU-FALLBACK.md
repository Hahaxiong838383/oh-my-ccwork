# FEISHU-FALLBACK: 飞书通知发送降级规则

| 字段 | 值 |
|------|-----|
| 优先级 | P3 |
| 权重 | 0.35 |
| 是否常用 | 可选 |
| 是否必选 | 可选 |
| 触发条件 | 发飞书通知遇到 HTTP 429 限速 / tell-me skill 失败 |

## 动作

**立即切换到 open-feishu-mcp 的 `send_message`，不重试原方法。**

## Why

- 飞书 webhook 限速窗口约 1 分钟，重试只会进一步堆积
- open-feishu-mcp 走另一条 OAuth 通道，不共享限速桶
- 重试浪费 cc 的反应时间，老板等不到通知

## 反模式

- 看到 429 → 等几秒再发 ← 错，限速窗口很长
- 把消息切短再发 ← 错，跟长度无关，是频次问题
