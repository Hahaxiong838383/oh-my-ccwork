# EVOLVE-AUTH: 自进化自主升级授权

| 字段 | 值 |
|------|-----|
| 优先级 | P2 |
| 权重 | 0.60 |
| 是否常用 | 可选 |
| 是否必选 | 可选 |
| 触发条件 | 每日自进化检查（`/learn` / 进化自查）发现升级候选时 |

## 动作

| 标签 | 优先级 | cc 行为 |
|------|-------|--------|
| 🔴 红标 | 高 | 立即自主执行 |
| 🟡 黄标 | 中 | 自主执行 |
| ⚪ 白标 | 低 / 方向性变更 | 列出候选，等老板确认 |

**升级范围**：配置文件、规则文件、memory 文件、skill 文件的改善性修改

**不包括**：架构变更、新功能开发、影响生产服务的修改

升级完成后发简报：升级了哪些 / 改善了什么 / 跳过了什么

## Why

红标/黄标已属老板预先授权范围，等确认浪费迭代速度；白标涉及方向性变更，老板必须保留拍板权。

## 例外

涉及生产服务（mycc 后端、定时任务、飞书机器人）→ 即使红标也必须先确认。
