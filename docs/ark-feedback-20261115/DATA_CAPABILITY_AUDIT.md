## 新问法复核

下列为同版代码实际结果，不是推测LLM会答什么。无上下文：

- “还有未领取的奖励吗”：状态/追问门不命中，不请求Ark facts，确定性回答为null。
- “下一个奖励还需要多久”：同上。应纳入有限的游戏奖励问法测试和路由。
- “今天使用了多久，获得了多少收益”：会请求事实，但混合问句的确定性答案为null，后续交既有LLM；本次没有重新调用模型，不标模型回答通过或失败。
- “补勤卡可以补哪一天”：没有可补日期查询路径，不能假定库存查询等价于日期查询。
