## 发布中的两次失败记录

1. Brain 首次切换在健康恢复后过早检查倾听 ready，触发自动回滚；旧文件/配置/健康已核。Codex修正发布脚本为有时限等待异步心跳，Grok复核通过；第二轮实际记录 ready 从 false 到 true，历时约5秒，随后全部断言通过。产品业务代码未因此改动。
2. 倾听首个合成SN探针因不在现有白名单且缺灰度派单合同而被拒收：active=0，无assignment、无音频输入。日志文案“at full capacity”不能据此认定资源耗尽。保留FAIL；改用正式开发测试身份签票后成功，没有扩大设备范围。

原失败及回滚证据完整保留，没有覆盖成“全程一次通过”。
