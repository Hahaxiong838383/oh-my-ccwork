# 对外归档的证据口径

本目录的 `SHA256.json` 校验当前归档字节。发布时完整私有证据清单的 SHA-256 为 `c36dce88062a4ccb5c428306167c9872bf633ef4cc083f664130343cbfa1d8db`，供内部复核原件。

- 两份 `LIVE-SEARCH-*.json` 中同一已创建的生产搜索任务共用一个匿名编号。三份 `NODE22-*.log` 的房间、响应与任务编号也已匿名化，同一原始编号在归档中始终使用同一别名。
- `RED-*.log` 将本机用户主目录替换为 `$HOME`。匿名化保留事件时序、测试结果与失败细节。
- `candidate/MANIFEST.json`、发布记录中的生产源码与探针指纹仍对应上线时的原始文件。归档另将搜索运行测试的设备夹具换成未登记且无历史签票的合成编号。已留存的原始测试回执对应当时使用的夹具。
