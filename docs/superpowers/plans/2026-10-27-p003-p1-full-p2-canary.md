授权：用户要求开启 P1 全部存量及新增内测设备，P2 开发并在原两台测试，Worker 管理后台区分两个页面。沿用 Brain/Worker 原分支，本人实现，不合 main。

## 实施范围

- P1 使用正式 Brain 的设备台账、人格与记忆；仅 active 且已开通账号、完成原设备认证的设备有资格。明确 `all_registered` 模式覆盖未来新增设备；空名单不解释为全开。后台可关闭总闸、排除单机。
- P1 使用正式 Worker 已有语音链路和容量，搜索网络工作仍在后台。新增搜索账本、路由与定位数据使用独立文件，不回灌灰度数据库，不覆盖原画像或历史。P1 为持续内测，无自动续窗脚本。
- P2 保留独立候选 Worker/Brain、原两台完整 SN（BJP00326070803800006、BJP00326060100100004）和原截止时间；仅 P2 允许 Tool Calls + 受控 Fetch，主服务绝不因 tools 标志启用 P2。窗口到期回 P1。
- 后台“搜索灰度”下分 P1 全量内测 / P2 双设备灰度；状态、范围、版本、任务概况、问题与路由发布作用域分开。灰度状态不能当全量健康，配置开启不能当真人实听。
- P2 沿用已有有界执行器：一次搜索、至多一次本次结果内公开 HTTPS 来源正文抓取；最多两轮工具规划、两轮答案生成/复核、20 秒总预算。记录脱敏工具名/结果，拒绝未知工具、改查询、未知来源与私网 URL。

## 回滚原则

优先关闭受影响层：P2 关闭后新会话进入 P1，P1 关闭后保留普通聊天。退代码/必要配置，不回灌整库、画像、历史或额度。保留旧 P2 绝对截止与 timer；改变 P1 不延长 P2。现有会话不热迁移，必要时通知退出重进；生产部署先核空闲再切。
