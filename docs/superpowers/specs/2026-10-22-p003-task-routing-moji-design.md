# P003 后台任务路由与墨迹天气接入设计

状态：分析与首版设计已完成，代码验证通过、尚未部署；2026-10-22 用户已授权先完成 REA 官网分析和路由设计，再由 codex 亲自实施。此文件不是部署或验收通过证明。

## 目标与边界

小可识别明确查询和完整的实时问题，建立可取消、可替换、可续讲的后台任务；任务运行时继续普通聊天，结果只在安全空闲窗口播报。后台可以编辑触发表达和排除规则、预览命中结果、按已授权完整 SN 发布和回滚，无需每改一个词就重新部署。

沿用 Brain/Worker 两个独立工作树及当前分支，不合并 main。首句音频合同、设备认证、生产普通聊天、非目标派单保持既有行为；P2 总闸不因新增天气来源自动开启。当前测试设备与截止必须在部署时现场重读，本文不延长窗口。

## 事实与问题

1. Worker `search_policy.rs` 已有同步纯函数路由和有限上下文承接，问题是表达式写死；新增机制应升级此路由，而非增加另一个会提交任务的模型。
2. 现有后台 SearchSession 已异步处理提交、幂等重试、轮询、接单确认、取消、补播、续讲；保留这一执行权威。
3. R6 对“今天北京的天气”“天气”实测没有建任务，普通回复仍说“等我长大”。任务识别、候选能力说明和旧人设兜底需要一致修复。
4. 当前通用搜索用网页发布时间过滤天气；持续更新天气页的发布时间不能代表实况和预报时效。
5. home-studio 实际安装 REA 6.7.0，属于网站/应用分析工具，不是 TRAE CLI，也不是一个需要选择语言模型的 Codeg 对话智能体。已通过其独立浏览器场景访问官网；静态抓取未展示的天气组件在浏览器加载后真实出现。

## 方案选择

| 方案 | 代价与问题 | 决策 |
|---|---|---|
| 不断追加硬编码关键词和 site 域名 | 每次构建部署；难预览与回滚；城市、日期错误仍存在 | 不采用 |
| 每句话先调用路由 LLM 再聊天 | 增加前台等待和模型依赖；任务承诺容易与真实账本脱节 | 不作为首版 |
| 同步规则路由＋有限上下文＋异步执行器 | 可解释、可测试、热迭代；模糊表达追问，不伪装全语义理解 | 采用 |

## 运行路径

ASR committed → 候选资格/窗口 → 控制指令与否定保护 → 当前规则快照 → 普通聊天、追问或后台任务。

路由不访问网络，不等待新模型。一次输入只提交一个任务；普通聊天不新建查询。查询提交成功才播“我查一下”；提交失败/不确定分别报告真实状态。搜索中“我画了一只猫”继续正常聊天，不取消后台查询。结果复用已有 DeliveryGate、播放回执、插话与重播限制。

优先级固定为：有效取消/改查/续讲 → 引用、条件句、否定与个人信息保护 → 显式查询 → 已发布自然问法规则 → 普通聊天。可编辑规则不能覆盖鉴权、窗口、工具许可和控制指令保护。

天气缺城市时询问“想查哪个城市的天气？”，10 秒内只承接下一句属于首版七城的城市回答；中途普通聊天、否定、取消或超时清除待补参数。不从服务器 IP、地图默认点或旧个人记忆猜城市。时间按北京时间解释今天/明天/后天；不支持的日期范围明确降级，不能拿今天替代明天。

## 配置与后台

配置包含 schema、不可变版本、规则 ID、启用状态、优先级、任务类型、匹配方式、触发词、排除词、必要参数与已实现来源选择。限制总规则数、词长、配置体积和匹配次数；不允许任意正则、脚本、模型提示词或任意 URL。

后台“搜索灰度”增加：

- 规则编辑：天气自然问法、通用显式查询表达、排除表达；内置保护规则只读说明。
- 话术预览：输入一条或有限上下文，显示动作、规则、城市/日期、追问原因；预览不提交真实任务。
- 草稿与发布：保存草稿 → 结构校验及固定反例回归 → 选择已准备的完整 SN → 发布；不得借发布配置扩灰度名单或开窗。
- 版本状态：候选数据库中的已发布版本、Worker 最近确认版本及时间分开显示；Brain 逐请求读取版本，任务记录固化实际使用版本，不虚构独立的 Brain 加载时间；无在线会话时显示待设备加载。
- 回滚：选择历史有效版本再次发布，保留操作者、时间、版本摘要；不删除历史证据。

持久化使用候选专用配置存储；后台写入与版本发布采用事务/原子操作并带 expected revision，拒绝并发覆盖。Worker 每 5 秒后台刷新，校验后在音频 tick 上应用内存快照并确认；候选 Brain 逐请求从独立 SQLite 读取发布快照。拉取失败保留最近有效版本；初次无有效配置回保守内置路由。查询建立时固化路由版本和来源策略，热更新不把进行中的任务改成另一种查询。窗口硬限制始终独立生效。

预览程序与 Worker 直接编译同一份 Rust 路由源码，后台通过固定可执行路径与有界 stdin 调用，无第二套 TypeScript 匹配器。正式发布前的回归不能只验证“配置格式合法”。

## 天气来源

先做个人测试，限定墨迹公开可读的天气内容，不购买商业 API，不依赖账户或绕过访问限制。REA 已确认官网公共天气端点；实现固定适配器，首版限定北京、上海、沈阳、大连、广州、深圳、杭州，支持今明后天日预报、当前实况、当前AQI；其它城市/时间转通用搜索，缺城后仅七城短回答可承接。官网展示的数据接口只代表网站内部协议，不能冒充官方稳定开放 API。

天气执行器返回结构化证据：来源 URL、城市标识及名称、抓取时间、数据更新时间、预报有效日期、温度/天气等。只抽取已验证字段，使用短模板生成播报，不把整页广告/脚本交给对话模型。城市或日期不匹配、更新时间缺失/过期、异常页面、超时、429、解析失败均不得伪造成功。

固定来源白名单、无认证公开 GET、禁止跨域重定向、响应大小上限、严格超时、有限缓存和单飞合并；不批量遍历全站。缓存按城市、日期、指标和来源版本隔离，过期不冒充实时。通用问题继续 DeepSeek 搜索。固定天气适配器独立标识，不能启用通用 fetch_page 或 Tool Calls 来暗中突破 P1。

## 验收

- 正例覆盖自然问法、显式查询、同义词、城市/日期、拆句追问；主题覆盖天气、新闻、开放时间、科普、价格/汇率等。
- 反例覆盖心情比喻、否定、引用、条件句、天气知识、个人信息、普通聊天；取消/改查/续讲在热更新后仍按实际任务处理。
- 配置覆盖非法体积/字段、权限、并发发布、非灰度设备、拉取失败、旧版本保留、窗口过期、回滚、预览无副作用。
- 天气覆盖跨午夜、未来/历史错误日期、同名城市、默认地图点、无更新时间、缓存过期、来源不可用与取消中断。
- Rust 完整测试和 Linux 构建；Brain 搜索/认证/隔离回归；真实浏览器后台操作；候选环境合成 RTC 音频＋字幕＋metrics＋任务完成证据。
- 合成探针通过与真人扬声器实听分开。首句音频丢词、端侧离房原因仍需各自证据，不能因本功能上线宣布解决。

## 部署与回滚

部署前读取现役/候选 PID、哈希、资源、任务和剩余测试时间，建立新的 R7 回滚点。先测试与候选替换，校验完整产物哈希再安装；后台共享服务仅发布管理界面及必要控制模块，不整树覆盖生产。候选活跃测试时不强行打断，空闲再发布。

失败先关闭新配置或回滚上一有效版本；严重故障关候选派单及搜索，让设备退出重连回现役。旧会话不会自动迁移。二进制回滚恢复本次备份，保留最新业务数据库；禁止整库/整 env 回灌。到期机制和绝对截止继续有效，不因重启续期。

## 已冻结的首版协议

配置示例（完整默认值以 `src/tools/search-routing-defaults.json` 为准）：

```json
{"schema":1,"weather_enabled":false,"rules":[{"id":"natural-weather","enabled":true,"priority":100,"action":"weather","mode":"contains_any","triggers":["天气","下雨"],"exclude":["为什么","心情"]}]}
```

规则≤32条，每条触发/排除短语各≤32条、每词≤32字符；优先级0–1000，动作为search/weather/chat，匹配prefix/contains_any/contains_all。`weather`表示识别后尝试固定天气适配器，不支持参数继续通用搜索。版本为规范化配置SHA256前24位加 `r7-`；发布事务绑定完整SN与expected_revision。既有控制词/否定/引用保护不允许编辑覆盖。

CLI输入 `{config,utterances:[{text,at_ms,reset?}]}`，stdin≤64KiB、预览HTTP最多32句、每句≤128字符、子进程1.5秒超时；输出 `{ok,decisions:[{action,rule_id,reason,query,weather}]}`。版本通过认证Worker接口GET `/v1/internal/search-tasks/routing` 下发，POST `/routing/ack`确认真正应用；提交任务可选携带 `{routing:{version,rule_id,weather?}}`。已接单任务永久固化来源，发布后旧版本新接单仅15秒宽限且必须有该SN发布历史。

天气GET仅两个固定端点、先验城市再取数据；单次3秒/总6秒、128KiB、5分钟缓存、30秒失败冷却。缓存命中仍重新校验观测/预报时效；日期严格往返校验，不能把2月30日自动转换成3月日期。
