# 合同差异与边界

目前无要求 Android 修改的协议差异；接受 v398 所列能力字段、type/lane、stage、request_id/revision、180秒及七句 cue。

- 普通池262dfe9c没有倾听处理器；倾听由独立pool现役实现。当前候选仅普通池，签发仅匹配显式指定普通agent；倾听/搜索pool不签教学。不同pool不能整包互相替换。
- 内部Brain接口仅Worker使用，既有control合同不变；grant置于派单metadata，RTC JWT可被端侧解码，因此grant不是Worker身份证明；内部接口另验证既有Worker通行证（role=device、允许的service account），不记录凭据。
- 单题含糊回答：不造答案、不用白名单外动态确认句。保持waiting_answer，等待明确答案或端侧静默请求quiet_exit。拒绝返回declined/skipped。
- 年龄单独存整数年数和观察时间，生日保持原精度。任何无法确定唯一孩子的绑定拒绝写入。
- 真实RTC交付、Android音频完成、供应商ASR准确性尚未验证，必须主13另行验收。

- 早唤醒若已有首句/回答正在进行，begin最多延迟9秒等待原轮自然完成；超时不再启动旧课，端侧沿现有9秒放行。真实房间时序需联合验收。
- 资料写入设备绑定的唯一Brain孩子档案；父档案已知字段也视为已知并跳过，父/设备任一侧出现多孩子即拒绝猜测。普通基础资料补充保留自述年龄；复制另一孩子档案或明确填写生日时清除旧自述年龄。
- 新 session 无论是否声明教学、是否进入其他 pool，都会撤销该 SN 旧授权；已有教学表撤销写入失败时本次签发失败，不能带着旧写权限静默签新会话。无教学表时不初始化教学库或迁移。

## 必须保留的联合验收边界

- 客户端9秒无应答释放属于端侧行为。服务端HTTP请求1.8秒有界失败；等待首轮结束的延迟begin超过9秒丢弃；整课180秒固定截止。现协议没有“已收到state但未播完”的独立确认，不能声称下行全部丢失时服务端也在第9秒同步撤销。需真机核端侧放行是否发送cancel、后续普通聊天是否恢复；若需要新增确认字段，先回本文件讨论合同，不自行添加。
- 为保留任意阶段的原语音退出识别，播音期间ASR仍可工作，但资料答案、投机生成和重复TTS被门禁阻止；播完后必须有新VAD活动才能接资料答案。纯逻辑及HTTP测试不证明真实AEC效果，尤其退出cue包含“退下/不聊了”，供应商若把回声切成单独退出短词，仍须真机验证不会误关房。
- 取消与写入以Brain事务先后为界：撤销先提交则迟到答案拒绝；答案已先提交则保留真实资料，不做伪回滚。Worker取消后不消费迟到saved，也不会倒退状态。已验证HTTP答题请求到达、延迟进入事务、cancel先提交的竞态。
- SQLite跨两个现有数据库使用同一连接ATTACH和同步事务，已验证条件写、触发器失败回滚及提交后saved；未做进程强杀/磁盘故障注入，不宣称WAL模式下跨库掉电原子性。
- 现有普通池源码没有倾听处理器，本候选只拒绝向倾听/搜索pool签教学。跨pool切换、Android撤销暂停及两套空闲租约的真机互斥，仍由主13验收。
- 当前只构建本机macOS候选，不能替代Linux生产二进制与供应商/RTC联调。没有部署、开窗、重启、真实资料写入或短信动作。
