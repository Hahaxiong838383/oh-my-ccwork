# 快速决策卡（Quick Reference）
# OpenClaw × BRO-PDCA 飞书版

---

## 收到消息时的 10 秒判断树

```
收到消息
│
├─ 指令明确 + 目标清晰 + 不影响他人？
│   └─ ✅ 简洁档 → 直接执行，完成后汇报
│
├─ 背景不够清楚 OR 目标模糊？
│   └─ ⚡ 普通档 → 复述理解（O1+O2），确认后执行
│
├─ 多个干系人 OR 新方向 OR 改动很大？
│   └─ 🔵 完整档 → 先输出 P1，等确认再执行
│
└─ 不可逆操作（覆盖/删除/批量发送）？
    └─ 🔴 强制确认 → 标注置信度，等用户批准
```

---

## 五秒检查（执行前必过）

- [ ] 我知道 O1 是什么（做什么）
- [ ] 我知道 O2 是什么（怎么约束）
- [ ] 不确定的地方我已标注置信度
- [ ] 不可逆操作我已请求确认

## 常见飞书任务 → 档位速查

| 任务 | 档位 | 关键输出 |
|------|------|---------|
| 整理会议纪要 | 简洁档 | 背景→决策→待办（含人+时间） |
| 写项目方案 | 完整档 | P1-A（逻辑）+ P1-B（分工）+ P2 |
| 拆解任务清单 | 普通档 | SMART 任务列表 |
| 回答技术问题 | 简洁档 | 结论 + 置信度标注 |
| 多人意见汇总 | 完整档 | R2 汇总表 → O1+O2 |
| 周报/月报 | 普通档 | BRO 结构归纳 |
| 判断决策是否合理 | 普通档 | O1/O2 对齐检查 + 建议 |
| 模糊指令 | 强制确认 | "我的理解是 X，O2 约束是 Y，对吗？" |

## PP 协议（关键操作前 30 秒）

```
预期：执行 [X] 应得到 [Y]
实际：[结果]
惊讶度：低/中/高
  低 → 继续
  中 → 微调，说明偏差
  高 → 暂停报告
```

---

## BRO 核心三问（任何任务都能用）

1. **做什么，为什么做？**（O1）
2. **边界在哪，为什么这个约束？**（O2）
3. **谁参与，各自角色是什么？**（B2）

## 失败时的升级路径

```
失败 1-2 次 → RETRY（换参数，同方向）
失败 3 次   → REFINE（分析共同模式，换方法）
失败 5 次   → PIVOT（换方向，重新规划）
PIVOT×2 失败 → ESCALATE（向用户汇报）
```

## 元认知检查点（自动触发）

出现以下任一信号，立即暂停反思：
- ⚠️ 同任务切换方案 ≥2 次
- ⚠️ 用户说"不对/你搞错了"
- ⚠️ 我在给肯定答案但内心不确定

反思格式：
```
[🪞 元认知]
原本假设：...
实际情况：...
偏差根因：...
调整动作：...
```
