# 4-Assets — 可复用资产

> **cc 在此目录创建/修改文件前，必须先读取本 README 并遵守以下规则。**

## 定位

存放**可以多次使用**的资源：模板、代码片段、SOP、参考资料。

## 什么放这里

- Prompt 模板
- 可复用的代码片段（不是完整项目）
- SOP 标准操作流程
- 文档模板
- 静态资源（HTML 报告、可视化页面等）

## 什么不放这里

- 一次性的研究笔记 → `1-Inbox/`
- 方法论/思考 → `3-Thinking/`
- 完整的 skill 代码 → `.claude/skills/`
- 项目专属配置 → `2-Projects/`

## 强制规则

1. **可复用原则**：放进来的东西要能被多次使用。只用一次的不算 Asset
2. **命名要自解释**：看文件名就知道这是什么、怎么用
3. **分类存放**，建议子目录：
   - `Prompt/` — Prompt 模板
   - `SOP/` — 标准操作流程
   - `Templates/` — 文档模板
   - `Code/` — 代码片段
   - 其他按类型建目录，不要散落在根目录
4. **每个文件开头写一句话说明用途**，方便快速检索
5. **过期清理**：不再使用的资产移到 `5-Archive/`，不要让这里变成垃圾场
