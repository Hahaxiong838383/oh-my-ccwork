# 5-Archive — 历史归档

> **cc 在此目录写入前必须先读本 README。**

## 定位

已完成或已失效内容的最终去处。**只进不出，不在这里继续工作**。

## 命名与结构

按来源目录分子目录，文件加归档日期前缀：

```
5-Archive/tasks/YYYY-MM-DD-<原文件名>.md
```

保留原文件名便于回溯；日期是**归档日**，不是创建日。
用 `git mv` 移动，别 `cp + rm` —— 前者保得住 git 历史。

## 什么才算"可以归档"

只有**确实完成或确实失效**的才归档。判据是去核实事实，不是看文件放了多久：

- 任务文件写着"待评审""挂起"→ **不归档**，那是活的状态
- 停滞几个月但状态是"待执行"→ **不归档**，那是积压不是完成
- 声称完成的 → 先验证：文件说的那件事在现实里真做完了吗

2026-08-01 首批归档的两个都是这样核实的：`HOME-AGENTS-draft` 查到
`~/AGENTS.md` 已存在且内容比草稿更长（已落地）；`dev198-etc-environment-proxy`
查到 `/etc/environment` 里那个死代理地址已 0 处命中（已解决）。

## 不放这里

- 还在推进的 → 留在 `tasks/` 或 `2-Projects/`
- 需要被检索复用的方法论 → `3-Thinking/`
- 可复用资产 → `4-Assets/`
