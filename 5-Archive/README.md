# 5-Archive — 历史归档

> **cc 在此目录创建/修改文件前，必须先读取本 README 并遵守以下规则。**

## 定位

存放不再活跃但有参考价值的内容。归档不是删除，是"冷藏"。

## 什么放这里

- 已完成/已放弃的项目（从 `2-Projects/` 移入）
- 周记/月记归档
- 过期的计划和旧版文档
- 历史工作日志
- 不再使用的脚本和资产

## 什么不放这里

- 正在活跃使用的任何东西（那应该在对应的活跃目录）
- 可以直接删除的垃圾（没参考价值就别归档）

## 强制规则

1. **分类存放**，现有子目录：
   - `周记/` — 每周复盘归档
   - `legacy-docs/` — 旧版文档
   - `legacy-scripts/` — 旧版脚本
   - `daily-logs/` — 每日日志
   - 项目归档直接用原项目名建目录
2. **归档时标注来源和日期**：文件开头加一行 `> 归档自 X-目录，日期 YYYY-MM-DD`
3. **归档是单向的**：一般不从 Archive 移回活跃目录。如果需要重新激活，在原目录重建
4. **工作日志命名**：`work-log-YYYY-MM.md`（按月合并，不要一天一个文件）
5. **周记命名**：`周记-YYYY-WXX.md`（如 `周记-2026-W12.md`）

## 巡检提示

此目录不需要频繁关注。cc 在归档操作时进入，归档完就走。
