## 一、PixPin 功能全景

PixPin 是截图 + 贴图 + 标注三位一体的桌面效率工具（Windows 主力 + macOS 10.15+），名称源自 Pixel Pin。

### 1.1 截图引擎（3 个模式）

**静态截图**
- 触发：Ctrl+1 / 托盘 / 命令行
- 窗口/UI 元素自动检测（Accessibility 级别，支持父子层级滚轮切换）
- 区域选择 + 像素级微调（方向键 + 修饰键）
- 截图中实时能力：OCR（Shift+C）、QR 码检测、颜色取色（RGB/HEX 切换）
- 截图后操作：贴图（Ctrl+2）、保存（PNG/JPG/BMP/WebP）、复制剪贴板
- 圆角/阴影/边框后处理
- 截图历史 + 区域记忆

**长截图**
- 选区 → 滚动 → 自动拼接
- 方向切换（垂直/水平）
- 裁剪工具 + 自动裁剪（会员）
- 实时预览缩略图
- 限制：仅静态内容、单滚动区域、需特征丰富内容辅助匹配

**屏幕录制**
- 输出格式：GIF / WEBP / MP4
- 帧率可调
- 音频采集：麦克风 + 系统声音
- 录制中：暂停/恢复、实时标注、延迟启动
- 回放：时间轴拖拽、速度调节、格式切换
- 会员：鼠标/键盘操作记录叠加、录后剪辑、快速录制模式

### 1.2 贴图系统（6 类）

**图像贴图**
- 来源：截图 / 剪贴板 / 图片文件
- OCR 文字识别（选中/复制/拖拽）
- 表格识别 → Excel
- 公式识别 → LaTeX
- QR 码检测
- 翻译
- 图像处理：旋转（90°）、翻转、灰度、反色、亮度、裁剪

**文本贴图**
- 纯文本 + HTML 格式渲染
- 文本选择模式
- 忽略格式选项
- 可配字体/颜色/背景

**文件贴图**
- 文件/文件夹显示
- 拖放到其他应用
- 右键打开/定位/复制路径
- 多文件同时贴

**颜色贴图**
- 识别：HEX / RGB / 逗号分隔 / 命名色
- 格式转换 + 复制
- 拖放输入

**LaTeX 贴图**
- KaTeX 级渲染
- 导出 SVG
- 复制 MathML
- 复制 LaTeX 源码
- 插入 Word（Office Math Object）

**贴图通用能力**
- 移动/缩放/透明度（Ctrl+滚轮）
- 锁定（L）/ 置顶（T）/ 鼠标穿透
- 阴影颜色状态指示（蓝活跃/灰非活跃/橙锁定/绿穿透）
- 缩略图模式（R）
- 颜色取色器（Alt）
- Ctrl+拖放到其他应用
- 标题（F2）
- 关闭后历史保留（默认 10 条）
- 贴图分组：独立管理、颜色标签、快捷键切换（Ctrl+~）、计数显示

### 1.3 标注工具（13 个）

| 工具 | 快捷键 | 特殊能力 |
|------|--------|---------|
| 矩形/椭圆 | Shift+1 | 填充/描边、圆角 |
| 直线/折线 | Shift+2 | 多段折线 |
| 箭头 | Shift+3 | 多种箭头样式、虚线、双击加注释文字 |
| 序号 | Shift+4 | 自动递增编号、手动调整 |
| 铅笔 | Shift+5 | 自由绘画 |
| 荧光笔 | Shift+6 | 半透明高亮 |
| 马赛克/模糊/智能擦除 | Shift+7 | 画笔/矩形模式、强度可调、智能擦除=离线 ML inpainting、自动马赛克批量匹配 |
| 文字 | Shift+8 | 多行文本输入 |
| 橡皮擦 | Shift+9 | 擦除标注 |
| 聚光灯 | Shift+0 | 暗化周围、高亮焦点、透明度/大小/边框可调 |
| 水印 | — | 自定义水印叠加 |
| 放大镜 | — | 局部放大 |

通用：撤销/重做（Ctrl+Z/Y）、颜色面板、透明度、线条粗细（滚轮）

### 1.4 AI / 识别（5 项）

- **OCR**：完全本地离线、9+ 语言（中日韩法德俄西意葡等）
- **表格识别**：图片中表格 → Excel 数据（会员）
- **公式识别**：图片中公式 → LaTeX 代码（会员），支持多公式批量、Word 插入、SVG 导出
- **QR 码/条码**：自动或手动检测，支持工业条码（Code128/EAN13/UPCA/Code39/DataMatrix/PDF417）
- **翻译**：图片翻译 + 文本翻译，19+ 语言，AI 大模型驱动，支持自配 API

### 1.5 自动化

- **脚本引擎**：基于 JavaScript 语法，可操作截图/贴图/系统 API
- **命令行**：`pixpin.exe -r "script"` / `-f "file"`
- **自定义动作**：快捷键 → 脚本绑定、程序级屏蔽

### 1.6 设置系统（14 页）

系统（语言/自启/管理员/剪贴板格式/代理/桌面工具栏）、账号、外观、截图配置、贴图配置、保存配置、标注配置、快捷键/动作、内置快捷键、鼠标行为、全局鼠标操作（会员）、工具栏自定义、翻译配置、脚本

### 1.7 会员专属功能

- 智能擦除
- 多语言 OCR
- 表格识别
- LaTeX 公式识别
- 录屏鼠标/键盘记录 + 剪辑
- 全局鼠标操作（Win+拖拽截图/贴图）
- 翻译
- 保存预览（实时编码预览）
- 云配置同步
- 箭头双击注释
- 自动裁剪
- 自动马赛克同步

## 二、技术架构

```
┌──────────────────────────────────────────────┐
│              Tauri Shell (Rust)               │
│  ┌────────────────┐  ┌─────────────────────┐ │
│  │ Screen Capture  │  │   Pin Manager       │ │
│  │ ScreenCaptureKit│  │ (NSPanel 多窗口管理) │ │
│  │ + Accessibility │  │                     │ │
│  └────────────────┘  └─────────────────────┘ │
│  ┌────────────────┐  ┌─────────────────────┐ │
│  │ Recording       │  │   Script Engine     │ │
│  │ AVFoundation    │  │ (boa_engine/deno)   │ │
│  │ + FFmpeg        │  │                     │ │
│  └────────────────┘  └─────────────────────┘ │
│  ┌────────────────┐  ┌─────────────────────┐ │
│  │ OCR / AI        │  │   Global Hotkey     │ │
│  │ Apple Vision    │  │ + System Tray       │ │
│  │ + CoreML        │  │ + CGEvent tap       │ │
│  └────────────────┘  └─────────────────────┘ │
├──────────────────────────────────────────────┤
│          React Frontend (TypeScript)          │
│  截图选区 UI / Canvas 标注引擎 / 贴图渲染     │
│  设置面板 / 录屏回放 / 历史管理               │
└──────────────────────────────────────────────┘
```

### 关键技术选型

| 能力 | macOS 实现方案 | 难度 |
|------|-------------|------|
| 截图 | ScreenCaptureKit (macOS 12.3+) via Rust FFI | 中高 |
| 窗口/元素检测 | Accessibility API (AXUIElement) | 高 |
| 长截图拼接 | 自研图像拼接算法（特征匹配 + 仿射变换，或 OpenCV 绑定） | 高 |
| 屏幕录制 | ScreenCaptureKit + AVFoundation + FFmpeg | 高 |
| 贴图浮窗 | Tauri 多窗口 + NSPanel (always-on-top) | 中 |
| 鼠标穿透 | NSWindow.ignoresMouseEvents | 低 |
| 标注画布 | HTML Canvas 2D / Fabric.js | 中 |
| 马赛克/模糊 | Canvas ImageData 像素操作 | 中 |
| 智能擦除 | CoreML + Inpainting 模型（本地离线） | 高 |
| OCR | Apple Vision Framework (VNRecognizeTextRequest) | 中 |
| 表格识别 | Vision + 自研网格检测 或 开源模型 | 高 |
| 公式识别 | LaTeX-OCR 模型（本地推理） | 高 |
| LaTeX 渲染 | KaTeX (前端) + SVG 导出 | 低 |
| 翻译 | 外部 API (DeepL / Google / LLM) | 低 |
| QR/条码 | Apple Vision (VNDetectBarcodesRequest) | 低 |
| 脚本引擎 | boa_engine (Rust 纯 JS 引擎) 或 deno_core | 中 |
| 全局热键 | CGEvent tap via Rust FFI | 中 |

## 四、风险清单

| 风险 | 影响 | 缓解方案 |
|------|------|---------|
| Tauri 多窗口管理上限 | 贴图需几十个独立浮窗 | 测试 Tauri v2 多窗口极限；备选：直接用 objc2 crate 管理 NSPanel |
| macOS 权限授权 | 屏幕录制 + 辅助功能需系统弹窗 | 首次使用引导页 + 权限状态检测 |
| 长截图拼接精度 | 特征匹配失败 → 拼接错位 | 研究 PixPin 可能用的 ORB/SIFT 特征点算法；备选集成 OpenCV |
| 智能擦除模型体积 | Inpainting 模型可能 >100MB | 选用轻量 CoreML 模型 + 首次使用按需下载 |
| ScreenCaptureKit 版本门槛 | 仅 macOS 12.3+ | 回退方案：CGWindowListCreateImage（macOS 10+）|
