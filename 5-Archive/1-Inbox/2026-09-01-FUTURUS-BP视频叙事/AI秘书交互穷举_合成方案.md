## 一、统一交互引擎（投资人一眼记住的内核）

所有场景跑同一个**四拍微交互协议**——这就是「强化学习」被你亲眼看见的样子：

> **① 轻探 Probe** 余光区抛一个最低成本的暗示 → **② 读 Sense** 多模态读你的反应 → **③ 悟 Learn** 当场把反应变成训练信号、重构意图 → **④ 改推 Re-serve** 立刻换成你此刻真正需要的。

**点睛洞察（三家共识）**：**「第一次推错」不是 bug，是它最聪明的一刻**——一次失败的试探 = 一个训练样本。把"广告推错"重构成"AI 在当面学习你"，是整个叙事的灵魂。gemini 一句话总结："懂什么时候**不**赚钱，才是真智能。"

## 二、AI 的「武器库」：试探形态 + 反馈信号（四家合并最全版）

### 1. 轻探形态（AR 怎么"轻"到可被忽略）
| 形态 | 余光区呈现 | 打扰度 |
|---|---|---|
| 光影渐显 POI | 道路两侧楼体卡片淡入 0.8s | 最低 |
| 建筑级映射 | 远处商场外墙像投影浮现品牌微光 Logo | 低 |
| 天际线点亮 / 情绪渲染 | 楼顶图标轻亮；天空泛暖橙/冷蓝（情绪试探） | 极低 |
| 路牌叠化 | 现实空白路牌"长出"一句关怀语 | 低 |
| 导航光带分叉 / 路径微变色 | 路面光带预览"拐去X"，一段变品牌色=顺路不绕 | 低 |
| 声纹光球轻语 / 呼吸涟漪 | 光球随经过的店面泛品牌色水波 + 极轻一句 | 低 |
| **倒计时光环** | 岔路前出现"可选窗口"，过点即如风化消散 | 趋零 |
| **撤退式 / 静默试探** | 无反应自动折叠成一粒光点，不追问 | 趋零 |
| 注意力阶梯 | 先极淡暗示 → 有兴趣才展开细节 | 自适应 |

### 2. 反馈信号源（这就是 RL 的 reward 来源；被动隐式 > 主动显式）
- **视觉/微表情**：目光停留时长、快速掠过、二次回看、扭头看 POI、瞳孔放大(兴奋)、皱眉(焦虑)、眯眼(刺眼/困)
- **驾驶微操**：油门松开几毫米(犹豫)、脚悬刹车(意向)、是否减速/靠右、方向盘微偏(下意识靠近/远离)、是否维持原路线
- **生理/声纹**：心率突增、深呼吸/叹气、喉结吞咽(饥饿/恶心)、哈欠、含糊嘟囔、肠鸣音(麦克风)
- **空间/社交**：副驾后仰(排斥)、后排呼吸均匀(睡着)、看腕表频次、整理领带/照镜子(仪态)
- **环境上下文**：时间/天气/路况/拥堵、导航目的地、剩余电量油量、停车难度、日历日程
- **历史/记忆**：常去品牌、忌口、预算、路线习惯、家庭日程、购物清单
- **物品识别(机器视觉)**：后排健身包、副驾合同、车上已有伞 → 反推真实待办
- **智能家居/IoT**：家中摄像头/猫碗提醒、未读消息
- **沉默本身**：不看、不回、不减速 = "不需要"；AI 学会**越用越少打扰**

> **理由**：探针轻到可无痛收回、反馈以被动信号为主，用户才不会因"推错"而烦——这正是它与传统广告的本质区别，也是"不打扰还能赚钱"成立的前提。

## 三、三家共识 = 高置信内核（被反复独立想到 = 这条线最稳）

四个引擎独立收敛到的同一批场景骨架，是最该进概念片/BP 的安全牌：

1. **咖啡/早餐试探 → 赶时间 → 改派公司楼下免排队取**（时间压力，"人不动服务动"）
2. **健身房/重口餐饮试探 → 疲惫/心率高 → 改推休息·慰藉·轻食**（生理优先压倒消费）
3. **接娃/家庭场景 → 改推家庭/亲子/儿童服务**（社交关系优先级）
4. **充电/续航 → 改推"边吃边充/有空桩"综合方案**（任务确定性，多目标最优）
5. **倒计时/撤退式试探 + 沉默=答案**（克制；不打扰是高级感前提）

## 四、精选场景矩阵（去重后跨四家最强 16 个，每个=两拍故事+信号+维度+理由）

> 全部遵守：余光区·不挡视野·像光影·声纹光球不拟人脸·失败试探不惩罚。

### A. 晨间高压通勤
**A1 咖啡空间瞬移**（晨/CBD/赶会）｜星巴克绿标楼体浮现，司机瞥一眼皱眉看表 → AI 把美式改派公司大堂"到楼即拿"，绿标化作流光飞向写字楼。｜信号=目光短停+看表+日历会议｜维度=时间压力｜理由=品牌抓回流失订单+投资人看到"跨空间资源调度"变现。
**A2 想听不想看**（晨/环路/战斗态）｜光球泛播客彩色涟漪，司机空中一挥手 → 彩色消散转白光"今日财经简报"。｜信号=手势拒绝+视线锁前方｜维度=当前任务态｜理由=证明 AI 有"知趣退下"的素养。

### B. 午间工作 / 商务
**B1 体检后轻食**（午/CBD/刚体检）｜常去川菜馆剪影亮起，司机摸了摸胃没看 → 改推低油轻食+空位。｜信号=体检日程+手势+目光回避｜维度=健康节律｜理由=广告从"诱导消费"变"照顾你"。
**B2 合同识别→伴手礼**（午/拜访客户）｜先亮咖啡，司机瞄了眼副驾合同 → AI 悟出商务拜访，咖啡切成礼盒光纹。｜信号=目的地=客户公司+合同识别｜维度=社交/商务礼仪｜理由=品牌进"高价值场景"而非普通曝光。
**B3 仪态升级**（见客户前/整理领带）｜常吃快餐 AR 亮，司机拉下遮阳板整领带 → 切前方高端商务酒廊。｜信号=整理仪容微动作｜维度=身份/场合切换｜理由=通过仪态判断消费升级，高客单转化。

### C. 疲惫 / 深夜归巢
**C1 改主意的烧烤**（深夜/社区/累）｜常吃烧烤摊楼体映出烤肉粒子，司机咽口水却打大哈欠 → 粒子消散"回家洗澡吧，烤肉出浴室时送到门卫"。｜信号=吞咽+哈欠｜维度=疲惫压倒口腹之欲｜理由=真管家不让你受累还促成交易。
**C2 后排健身包→洗衣**（晚/商场）｜试探运动品牌折扣，司机没看却瞥后排衣袋 → 改推社区洗衣柜空位。｜信号=物品识别+目光方向｜维度=生活管理｜理由=从消费偏好转向"真实待办"。
**C3 归家仪式 IoT**（晚归/离家3km）｜超市打折 AR 司机无视、车速放缓 → 光球转蓝"已开启浴缸放水、空调26度"。｜信号=对促销零反应+车速放缓｜维度=下班潜意识｜理由=打通车机×AIoT 的故事。

### D. 家庭与关系（懂你→懂你爱的人）
**D1 挽救纪念日**（傍晚/忘记日子）｜街角砖墙 AR 玫瑰悄然绽放，司机一愣猛看日历 → "她最爱的餐厅还有座，花直接送到桌上"。｜信号=瞳孔骤扩+视线在日历花朵间跳｜维度=社交记忆/救场｜理由=用户直呼救命，品牌超高溢价转化。
**D2 安睡的后排**（午后/接娃）｜开心乐园餐 AR 刚要浮现，AI 发现后排孩子睡着 → 动画如沙消散转静音，标出生鲜自提点。｜信号=后排均匀呼吸+后视镜一瞥｜维度=车内弱势群体最高优先｜理由=最具温度的科技克制。
**D3 父母来访清淡口味**（接站/常去火锅）｜试探火锅，司机摇头"爸妈吃不了辣" → 改推清淡老字号+近门车位。｜信号=语音拒绝+接站日程｜维度=代际偏好｜理由="懂你"延展为"懂你爱的人"。

### E. 情绪 / 健康 / 安全（身体比嘴更诚实）
**E1 治愈深海**（深夜/吵架后游荡）｜经过影院爆裂动作片 AR 弹出，车内死寂沉重呼吸 → 熄灭全部广告，挡风变深海投影+大提琴+发光水母。｜信号=粗重呼吸+长沉默+无目的游荡｜维度=极度脆弱时的情绪干预｜理由=把车变成"精神避难所/第三空间"。
**E2 内急直达**（长途/座椅扭动）｜路边小卖部 AR 弹出，司机频繁扭动 → 屏蔽所有广告，路面直接画蓝粗线通向最近最干净洗手间。｜信号=高频座椅摩擦/扭动｜维度=最迫切生理三急｜理由=痛点最高峰提供服务，忠诚度拉满。
**E3 故障恐慌安抚**（夜/胎压报警）｜修理厂 AR 刺眼弹出，司机慌乱抓手机 → 压下红光变温和黄"只是右后轮慢漏气，已限速，够开回家，修理工明早登门"。｜信号=慌乱找手机+心率飙升｜维度=信息差恐慌｜理由=化身机械专家，卖高昂售后套餐。

### F. 出行 / 城市探索 / 物理魔法
**F1 反热榜本地小馆**（外地/收藏网红店）｜网红店排队光带亮，司机看队伍叹气 → 改推本地人常去小馆+可停巷口。｜信号=叹气+排队长度+停车难｜维度=旅行品味/耐心阈值｜理由="更懂此刻的我"，非大数据粗暴热榜。
**F2 墨镜物理魔法**（正午/迎光刺眼）｜Ray-Ban 墨镜广告试探弹出，司机眯眼伸手拉遮阳板 → 挡风玻璃在阳光直射区**像素变黑形成虚拟遮阳贴，随头动而动**。｜信号=眯眼+伸手拉遮阳板｜维度=纯物理生理痛点｜理由=**AR 不只展示信息、还能改变物理环境体验**——AR-HUD 独占的光学硬件级壁垒。

## 六、产品效果 & 投资人理由（为什么这套打动人）

1. **强化学习可视化**：把"推错→改对"演成 AI 当面变聪明，胜过任何"我们有 AI"的话术。
2. **飞轮闭环**：每次轻探+反馈 = 1 个训练样本 → 越用越准 → 越准越像服务 → 越离不开。
3. **广告天花板被突破**：够准时推送=刚好你需要，用户**欢迎**广告——传统广告生意做不到。
4. **数据护城河**：别人没有你独有的"试探-反馈"意图序列，炼不出你的模型。
5. **变现纵深**：C 端(餐饮/零售/娱乐) + B 端(可开票停车/伴手礼/商务酒廊/OTA酒旅) + 增值服务(上门洗车/售后/陪诊) + 硬件壁垒(光学遮阳)。
6. **克制即信任**：懂"不推什么"(安睡后排/感官降噪/沉默撤退) → 让商业推荐更可信，溢价更高。

## 七、概念片高光镜头 · Top 6（四家票选 + cc 合成排序）
