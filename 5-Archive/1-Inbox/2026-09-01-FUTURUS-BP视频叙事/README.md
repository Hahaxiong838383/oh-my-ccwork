## 叙事内核（两拍递进）

1. **第一拍（地基）**：高阶自驾释放注意力 → AR 广告放驾驶余光区，不挡视线像光影 → 用户不烦、品牌买单 → 本身能赚钱。
2. **第二拍（升华）**：意图 AI=贾维斯在余光区试探 → 看你反应做强化学习 → 越来越准 → 精准到「广告即服务＝刚好你需要」→ 越用越懂、离不开（飞轮）。
- 贾维斯形态：底部 HUD 中控的声纹光球语音助手，不拟人脸。
- 三大护城河：AR 光学专利 / 意图模型权重领先 / 跨 OEM 中立。与车企数据共享、三赢。

## 写实交互模型 v3（当前定稿方向）

固定机位第一视角下，把「试探→反馈→学习→改推」演明白，三条硬约束：
- **砍生命体征**（易被质疑）；**不拍脸**；**相机固定不能动**。
- **注视**靠景深虚化（给观众的镜头语言，不是 AI 传感器）；**反馈只用语音**（有回应=准/不准）。
- **AR = AI 用全车摄像头看见的世界 + 你的特征，主动算出来指给你看的真东西** → 它标的都是前方真实存在的店/楼/充电站，不用变魔术。
- 学习写实化：旧标注安静淡出 → 改标另一个真实 POI → 用「下次更准」证明记忆，不堆粒子特效。
