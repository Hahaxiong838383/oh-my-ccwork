# 07 · ISO 方法论 —— 目标导向的方案推导与验证框架

> **来源**：2026-06-04 与川哥协作，从一次实战（给硬科技公司 Futurus 写"打动顶级美元基金"的 I505 产品定义）中提炼，经 team 互评（cc 草案 + grok 证伪 + gpt 结构 + gemini 对标）三轮打磨定稿 v1.0。
> **配套 skill**：`.claude/skills/iso-method/`（`/iso`）
> **一句话定位**：一个"强约束方案求解器"——把"想方案"变成"解方程"。

---

## 何时用 ISO（使用场景）

任何 **"我有一些资源/能力（I），想达成某个目标（O），该拿出什么方案（S）"** 的问题：
- 产品定义 / 公司战略 / 商业模式设计
- 求职 / 转型 / 城市选择等个人重大决策
- 科研选题 / 公共政策设计 / 工程方案选型

**不要用 ISO 的场景**（见第 6 节适用边界）：目标本身是价值判断、资源离目标太远、混沌无因果律领域、连目标都不知道的双盲探索。

---

## 0. 它独特在哪（为什么不是换皮）

市面框架要么太软（设计思维易发散），要么太硬（MECE 只挑错不生成方案），要么太理想（第一性原理普通人无从下手）。ISO 的生态位是——**承认人的智力和资源都有限，把 I（你的牌）和 O（去掉形容词的判据）当两块铁板，在中间把方案"夹"出来。**

拆开看每个零件都不新（O 校准像假设驱动、倒推像变革理论、完备审计像 MECE）。**新在组装方式**：市面方法论通常只管一段（OKR 只定方向、MECE 只挑错、设计思维只发散）。ISO 是少数把 **「生成方案 + 证明方案是解 + 闭环验证」** 拧成一条完整闭环的。

---

## 1. 核心结构（十步闭环）

```
0. 定框      谁要达成、谁说了算、边界在哪、不做什么
1. O0        写下初始目标 → 把形容词翻成可观察判据
2. O 校准 ★  判据必须外部锚定、可证伪、有评判主体（破"循环论证"的命门）
3. 盘 I      信息/资源/能力/约束，分"普通牌 vs 独有牌"，标证据等级
4. O1 校准   用 I 校准 O 的边界——可收窄范围，但不许偷偷降低标准
5. 架 S      在 I∩O 交集生成多个候选（含零方案、反向方案）
6. 三门验解  ┐ 有效性：S → O（方案真能达成目标吗）
             │ 可行性：I → S（凭你的牌做得出来吗；竞争场景下再问"是否非你不可"）
             ┘ 优选性：S vs 替代（在声明的搜索范围内，它最好吗）
7. 完备审计  横向查漏：O / I / 替代 / 风险 / 假设，有没有漏项
8. 定版      锁定 S_n + 执行动作 + 关键假设 + 验证信号 + 失败标准
9. 闭环验证  看客观行为信号，分阶段，对照预设的"失败长什么样"
10. 迭代     按验证结果进下一版 O/I/S（螺旋逼近，不是一锤定音）
```

★ = 三个引擎独立指出的同一个命门，最关键。

---

## 2. 三处最硬的严谨性设计（经得起推敲的核心）

### ① O 校准门——破"循环论证"
**问题**：判据是你自己定的，方案又去命中你自己定的判据，会自说自话。极端例子：把"打动投资人"翻译成"PPT 里出现 3 个热词"，方案完美命中——正确地做了错误的事。
**破解**：判据落地前必须过三关——
- **外部锚定**：至少一个独立来源（行业基准 / 真实利益相关者 / 历史案例 / 失败库）确认；
- **可证伪**：能被客观数据或第三方观察反驳；
- **有评判主体**：明确"谁说了算"（投资人？用户？市场？），判据按他的标准定，不按你的偏好定。

> 这一步把"O 当作给定输入"升级成"O 必须先自证为真"——没有它，下游做得再漂亮也可能是高效地奔向错误目标。

### ② "优选性"必须声明搜索范围——破"伪最优"
"胜过所有替代"是伪命题，"所有"不可枚举。优选性结论必须附**枚举边界声明**："在【什么时间/信息/假设】下，对比了【哪几个】替代，本方案最优"。把"全局最优"诚实降级为"声明范围内最优 + 风险评估"。

### ③ "完备性"不与前三门并列，而是横向审计——破"MECE 不清"
三门验解（有效/可行/优选）是**纵向递进**，完备性是**横向审计层**，专查 O/I/替代/风险/假设五类漏项。逻辑链：
> **O 真 → S 能成 → 我能做 → 比别的好 → 没漏 → 可验证**

## 3. 回炉诊断树（四门没过，精准回到哪一步）

| 挂在哪 | 回到 | 改什么 | 禁止动作 |
|---|---|---|---|
| O 校准不过 | 回 1/2 | 重定评判主体、判据、阈值、权重 | 不许用模糊形容词糊弄 |
| 有效性不过 | 回 5 | 改方案机制、补因果链 | 不许删掉难命中的判据 |
| 可行性不过 | 回 3/5 | 补资源、换路径、缩边界 | 不许假设资源会自动出现 |
| 优选性不过 | 回 5 | 换更优替代、组合方案 | 不许用偏好冒充论证 |
| 完备审计不过 | 回对应层 | 漏谁补谁 | 不许跳过漏项硬推 |
| 闭环验证不过 | 回诊断 | 分清执行错/机制错/判据错 | 不许自我安慰式解释 |

## 4. 心法

- **双向收敛**：O 自上而下拆判据，I 自下而上供弹药，S 在交集被"夹"出来。好方案是被两头卡出来的那个点，不是随便落在交集里的任意方案。
- **约束即创造**：约束不是限制，是创造的脚手架。两头钉得越死，中间的解越精准。

口诀：**钉死两头夹方案，四关验过才算数。**

## 5. 与已有方法论的关系（对标）

| 框架 | 重叠 | ISO 的差异 |
|---|---|---|
| OKR | KR ≈ O 的判据 | OKR 只定方向、不管方案怎么推 |
| 第一性原理 | 都回归底层真实 | 第一性原理无边界重构、极耗算力；ISO 尊重现有约束 |
| MECE / 金字塔 | 完备审计用 MECE | MECE 是静态分类；ISO 是动态求解器 |
| 假设驱动 | 都目标导向 + 验证 | 假设驱动靠经验猜方案；ISO 把方案"卡"出来 |
| Theory of Change | 都从终点倒推 | ToC 默认资源可协调、不讲壁垒；ISO 带竞争博弈色彩 |
| Jobs-to-be-Done | Job ≈ Intent | JTBD 纯需求端；ISO 双向夹击（还看独有牌）|

**结论**：ISO 是"强约束策略求解器"，独特价值＝**约束即创造**——把"想方案"变成"解方程"。

## 6. 诚实的适用边界（为什么不号称"绝对万能"）

| 失效场景 | 为什么 |
|---|---|
| **O 本身是个错误的目标** | ISO 只保证"高效抵达 O"，不保证"O 该不该追"。价值判断主导的目标它管不了；O 校准门只能挡一部分。 |
| **I 与 O 根本无交集** | 资源离目标太远，ISO 会卡死。此时该"补牌/换目标"，不是硬求解。 |
| **混沌、缺因果律的领域** | 短期炒股、早期艺术创作——没稳定判据，"最优"无意义。 |
| **双盲探索期** | 连 O 是什么都不知道（如基础科学的意外发现），需要无目的发散和运气。 |

**适用声明**：ISO 适用于 **I 和 O 可被定义、存在可观测反馈、决策环境相对可建模** 的问题——覆盖绝大多数产品·战略·职业·工程决策，所以"足够通用"，但不"无所不能"。诚实标边界，反而让它经得起推敲。

## 7. 一页 checklist

- **定框**：谁要达成？谁验收？边界和"不做什么"是什么？
- **写 O**：形容词翻成判据了吗？每条判据有来源、阈值、时间窗、失败样子吗？
- **校 O**：判据是外部锚定、可证伪的吗？评判主体明确吗？
- **盘 I**：哪些是事实哪些是假设？哪些是独有牌？哪些是不能靠意志突破的硬约束？
- **架 S**：每个机制命中哪条 O？真调用了独有牌吗？拿掉独有牌还成立吗？
- **三门**：S 能达成 O（有效）？凭 I 做得出（可行）？比替代好（优选，附搜索范围）？
- **审计**：判据/替代/风险/假设，有没有漏？
- **验证**：用什么客观行为信号判断成败？早期噪音和后期真信号怎么分？失败回哪层？

## 区分：事实 vs 判断

- **事实**：本方法论由 4 个 AI 引擎互评产出；三引擎独立指出"O 校准缺失"是最大漏洞。
- **判断**：ISO 的独特价值在"组装方式"而非单个零件——这是 gemini 对标后的论断，未经长期多领域实践检验，属可证伪假设，用得多了应回来更新本节。
