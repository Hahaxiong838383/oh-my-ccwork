# 3-Thinking — 认知沉淀

> **cc 在此目录创建/修改文件前，必须先读取本 README 并遵守以下规则。**

## 定位

存放经过提炼的**方法论、深度思考、认知升级**。这里是"结晶"，不是"草稿"。

## 什么放这里

- 总结出来的方法论（如 BRO-PDCA）
- 对某个领域的深度分析和判断
- 值得反复参考的认知框架
- 重要的技术决策和背后的思考

## 什么不放这里

- 未经提炼的草稿/笔记 → `1-Inbox/`
- 操作手册/SOP → `4-Assets/`
- 项目专属文档 → `2-Projects/`

## 强制规则

1. **命名格式**：`序号-主题.md`（如 `01-BRO-PDCA方法论.md`）
2. **入库标准**：文件必须有明确的结论或可操作的框架，不是流水账
3. **定期回顾**：方法论不是写完就扔，有新实践时应该回来更新
4. **与 Inbox 的区别**：Inbox 是粗糙捕捉，Thinking 是精炼结论
5. **引用规范**：如果 CLAUDE.md 或其他文件引用了这里的内容，修改时注意同步

## 质量标准

一篇好的 Thinking 文档应该：
- 能让 3 个月后的自己快速理解
- 有具体的使用场景和操作步骤
- 区分"事实"和"判断"
