# Habitica 产品设计拆解（游戏 + 生活 + 学习）

> 2026-11-18。任务分支 `research/habitica-product-design`。
> 方法：注册真实账号抓 API（非破解）+ 读公开前端包 + 读官方开源仓库（HabitRPG/habitica，浅克隆 232MB）。
> 说明：Habitica 客户端/服务端开源，产品逻辑可直接从源码验证，不需要逆向破解；本文所有数值均标注源码或 API 依据。

## 一、一句话与核心循环

**把「待办清单」变成「RPG 角色养成」**：现实完成任务 → 角色获得经验/金币 → 升级/买装备/养宠物 → 更有动力做下一件事；没做每日任务 → 角色掉血 → 损失厌恶驱动回归。

```
现实任务（Habit / Daily / Todo / Reward）
   ↓ 完成
经验 XP + 金币 GP + 任务价值变化 + 暴击/掉落
   ↓
升级（属性点）/ 买装备 / 宠物坐骑 / 技能
   ↓
更强 → 能做更难的任务 / 组队打 Boss / 参加挑战
   ↓
每日结算（未完成 Daily 掉血）→ 明天继续
```

## 二、任务模型（产品骨架）

| 类型 | 语义 | 计分 | 关键设计 |
|---|---|---|---|
| Habit 习惯 | 想多做/少做的事，可 + / − | 双向 | 无「完成」态，鼓励频率 |
| Daily 每日任务 | 每天/每周固定 | 完成加，漏做扣 | 有 streak，连续天数加成 |
| Todo 待办 | 一次性 | 完成加，可撤销 | 有截止日，逾期变红 |
| Reward 奖励 | 用金币兑换的自我奖励 | 花金币 | 把「休息/游戏」变成奖励 |

任务有 **value（-47.27 ~ 21.27）**：越常完成越「绿」（收益递减），越常失败越「红」（惩罚加重）。公式：`delta = 0.9747^value`（见 `website/common/script/ops/scoreTask.js`）。

## 三、数值系统（可验证）

- **等级**：`toNextLevel(lvl)`：1–4 级为 `25*lvl`，5 级 150，之后 `round((lvl²*0.25 + 10*lvl + 139.75)/10)*10`；**满级 100**（`statHelpers.js`、`constants.js`）。
- **经验**：`exp += round(delta * (1+INT*0.025) * priority * crit * 6)`。
- **金币**：`gp += delta * priority * crit * (1+PER*0.02)`；有 streak 时再乘 `1 + streak/100`，且最少 +1。
- **掉血**：漏 Daily 时按 `delta * (1-CON/250) * priority * 2` 扣 HP（最低 10% 系数）。
- **属性**：STR 增伤、INT 增经验、PER 增金币、CON 减伤；每级 1 点。
- **职业**：Warrior / Rogue / Healer / Mage 四系，各有技能与法力（MP）；技能消耗 MP，影响任务/队伍。
- **暴击与掉落**：完成任务有暴击倍率与随机掉落（蛋、食物、任务卷轴）。
- **新号实测**：Lv1、HP 50、MP 10/30、XP 0、toNextLevel 25、金币 0、职业 warrior（注册后 API `/user`）。

## 四、收集与养成（长期目标）

- **宠物 90 种、坐骑 90 种**：靠掉落蛋 + 食物孵化/喂养；
- **任务卷轴 120 个**：组队副本，Boss 有血量，队员每日任务完成度决定伤害；
- **成就 96 个**、装备/外观/背景、季节活动限定；
- 收集系统把「每天做一点」变成「长期图鉴」，解决习惯类产品的厌倦问题。

## 五、社交结构（留存放大器）

| 层 | 机制 | 作用 |
|---|---|---|
| Party（小队） | 共享任务板、副本 Boss、组队加成 | 同伴压力 + 共同目标 |
| Guild（公会） | 兴趣/主题社区、聊天 | 归属感 |
| Challenge（挑战） | 官方/用户发起的任务竞赛，赢家得宝石/装备 | 内容生产 + 目标感 |
| Group Plan | 小队订阅（$9/月，含 3 人） | 团队商业化 |

## 六、节奏与留存

- **每日 cron 结算**：未完成 Daily 扣血、重置 checklist、计算 streak；可开「睡眠模式」免罚；
- **Streak**：连续完成天数，金币加成 1%/天，断签清零——最直接的损失厌恶；
- **季节活动**：万圣节/冬季等限定宠物与副本，制造「错过等一年」；
- **订阅提醒/周报**：邮件与推送把用户拉回；
- **无广告**，商业化靠宝石与订阅（见下）。

## 八、信息架构（前端路由）

`/`（任务面板）、`/inventory`（items/equipment/stable）、`/shops`（market/quests/customizations/seasonal/time）、
`/party`、`/challenges`、`/groups`（公会）、`/user/profile|stats|achievements`、`/hall`（赞助者/贡献者）。

任务面板是绝对核心；商店/图鉴/社交都是围绕「任务产出」的消费与目标层。

## 九、对「词途」的启示（家庭学习场景）

**值得借的**

1. **把学习任务做成 Daily**：听写 1 组、练字 1 页 = 每日任务；完成给 XP/金币，连续打卡给 streak 加成；
2. **金币要有真实出口**：兑换「玩游戏 20 分钟 / 周末电影 / 选晚餐」——Reward 类型是闭环关键；
3. **收集系统**：字帖印章、宠物/徽章、单元 Boss（单元测试=副本），让孩子有长期图鉴目标；
4. **家庭 Party**：爸妈也建角色，家庭任务板（倒垃圾/阅读），共同打一个「周末 Boss」；
5. **任务价值/难度**：简单的听写给少一点，难单元给多一点，避免「刷简单任务」。

**按川哥 2026-11-18 决策：以下可以借鉴**

1. **掉血/体力**：保留「漏做 Daily 掉体力」的损失厌恶，但 0 体力 = 强制休息/断连击，不做永久死亡，家长可关；
2. **四职业/技能/法力**：做轻量学习化职业（战士=坚持、法师=记忆、游侠=速度、牧师=复习），技能只影响学习收益，不做战斗；
3. **宝石**：家庭版先做「家长发放的奖励券」，可换外观/宠物/补签；真实内购以后再说；订阅后议；
4. **一级入口要克制**：Habitica 是「任务/背包/商店/队伍/挑战/帮助」6–7 个一级入口；词途建议最多 5 个（今天/练习/冒险/错词/我的），把角色、背包、商店、Boss 收进「冒险」，不要为每个系统单开 Tab。

## 十、可落地到词途的三步

1. **0.15**：听写/练字完成 → 金币 + 经验 + 连续天数；「我的」加「兑换」页（家长配置奖励）；
2. **0.16**：单元 Boss（每单元一个收集目标）+ 徽章墙；家庭任务板（简单版 Party）；
3. **0.17**：周报（家长视角）+ 季节限定字帖/徽章，形成「错过等一年」的节奏。
