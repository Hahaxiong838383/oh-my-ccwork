# AGENTS.md — 多智能体协同规则

> Claude Code 不自动加载此文件，cc 在需要时可主动读取。
> 完整规则见 `multi-agent/RULES.md`。

## 角色定位

| 角色 | 定位 | MCP 调用 |
|------|------|---------|
| cc (Claude) | 规划、决策、编排 | — |
| codex (OpenAI) | 写代码、改仓库、跑测试 | `mcp__x__ask_codex(...)` |
| gemini (Google) | 搜资料、写报告、调研 | `mcp__g__ask_gemini(...)` |

## 路由规则

| 任务类型 | 路由 | 示例 |
|---------|------|------|
| 代码实现、批量改仓库 | → codex | "实现登录功能"、"重构这个模块" |
| 调研、知识库同步、论文 | → gemini | "调研 XX 技术"、"同步到知识库" |
| 规划、决策、编排、其余 | → cc | "设计架构"、"帮我看看这个" |

路由由 `autoRouteEngine()` 自动判断，也可手动指定。

## 强制规则

1. **大任务（>10 分钟）必须拆分** — 分发给 codex/gemini 并行执行，cc 只编排不硬啃
2. **cc 不负责批量实现** — cc 做规划和关键决策，写代码交给 codex
3. **所有引擎都必须遵守文件归档规则** — 向 `0-System/` 到 `5-Archive/` 写入前，先读该目录的 `README.md`

## 正式项目模式（按需启用）

对于大型正式项目，可启用四层闭环流程，详见 `multi-agent/RULES.md`。
日常任务不需要 SPEC/AC 四件套，直接干就行。
