# 小可私人版发布与排障

2026-11-25 的已验基线为 mycc 标签 `release/personal-voice/2026-11-25-local-five-voices`，指向 `3a88bb3d`。11 项运行实物见项目 `docs/personal-studio-release-20261125.json`，各自的运行镜像和源码提交分别核对。回退时使用对应服务的镜像和发布配置；Git 标签用于找回源码，不会自动回退容器、私有配置或数据库。

- Lucky 返回 403 时从用户实际网络验证域名、端口、TLS 与页面正文。私人配置工作室的子规则恢复为默认黑名单，公司出口可直接访问。改规则从单条完整 GET 起步，整条回读比较仅目标字段改变。匿名设置接口应为 401，再经相同出口实际登录读取状态、退出并复测旧会话。
- 音色生效以合成服务回读、真实通话的 Worker 音色回执和浏览器非零音轨三者为准。固定问句可做 ASR 回送检查。试听不修改配置，通话占用或心跳未知时不应用。修改后重启读回，验证选择持久化。
- P003 的签票、管理、供应商配置和发布物与私人实例独立。当主人要求复制供应商配置时，仅从明确的 P003 配置只读取需要字段，写入飞牛私人实例的独立存储，再核对源配置未变。密钥不出现在页面回读、Git、日志、回执和记忆中。

## 在线供应商的维护

个人后台是供应商目录的唯一写入端。Worker 和个人大脑按目录只读挂载，便于观察原子替换后的新修订。飞牛创建私密文件时显式设置并回读 0600。编辑时保持密钥输入框为空可保留已有值。个人大脑负责 DeepSeek、工具和记忆，Worker 按房间固定识别和合成的选择。

验收在线语音时组合两种识别与三种合成，从 Lucky 发起真实通话，同时核对输入字幕、回复字幕、Worker 的供应商名称与 PCM 交付、浏览器收到的非零音轨。测试结束后回读原来的三个选择。使用临时数据库验证模型切换后的跨房间记忆和成长，正式画像保留主人的真实数据。[供应商操作与实测](../../../../2-Projects/realtime-voice-agent/docs/个人后台在线供应商.md)

## 暗夜剧场的表情、查询追问与延时

**听声音核对表情。** 用个人后台当前选中的讯飞音色合成一句含提问、重音和停顿的话，仅记录回包字段名、音频帧数和首包耗时。V1.0.5 的抽样回包只含音频帧信息。客户端从当前句子的文字估计语气，远端音轨的实际音量变化驱动眼形与停顿；更换供应商或音色后重新核对字段。Worker 根据已播放的采样数发送分句字幕（`SG_a<轮次>_<句序>`），开始时发 interim，结束时发 final。收到即可显示，出声时应用对应表情；手机另估句长会把字幕和表情一起拖晚。用同一段中文音频比较新旧包的眼形类别，再验静音时字幕可读、问句出声时出现疑问表情、插话后旧句无法恢复。对应客户端测试是 `android-personal/tests/avatar.cjs` 与 `playback.cjs`。

**按原话连续测查询。** 从同一个房间先说「今天天气怎么样」，再说「就看看北京的呗」。验第二句确实进入天气工具，同时回读城市、目标日期、预报和出处。另开房间单说城市、原房间换话题后重试，验证上下文不会串用。V1.0.5 房内追问的有效期最长为 90 秒。A 股用「今天股票市场怎么样」接「那 A 股呢」，核对指数、来源以及行情自身的时间，开盘前也应播数据上的日期。按该轮的 ASR 原文、工具路由、来源数量及错误原因依次定位；澄清城市和回答能力范围时，空来源是预期结果。对已提交的联网任务，再核对 `answered`、`no_evidence` 或执行错误。独立天气备源要从飞牛运行环境验证同一站点、发布日期与目标日。最后另选一个需要网页检索的开放问题，核对答复引用的原文页面。

**把首声和正文分别计时。** 同一轮对齐停说、ASR 定稿、检索拿到有效来源、模型首个可朗读句、TTS 首包、客户端首个非静音音频与正文字幕。首声可能只是「我来查一下」；若要报告正文开始发声的时间，用远端音轨定位正文。保留计时起点、样本数以及测的是哪个环节。比较快速模式与默认推理时，同模型、同题目成对测量；语音房另存整轮指标。最后用正式 APK 内资产接入个人房间，验证有声、插话取消回执和下一问，再分别记录模拟器升级结果与 S24 实机反馈。

首次验证的数据和版本见[暗夜剧场 V1.0.5 发布回执](../../../../2-Projects/realtime-voice-agent/docs/personal-s24-query-prosody-release-20261127.json)。

## 私人版语音退出与挂断

## 安卓头像命名与实时换色

- 中文名只用于展示。在 `android-personal/assets/appearance.js` 维护头像、材质与表情的中文名，保留存盘的 `family`、`variant` 和原作者署名。同名皮肤保留可辨识的编号，例如「湖蓝（102）」。覆盖升级前先在旧版选定一个具体形象，升级后核对同一个 ID 和新显示名。
- 圆盘选择色相与饱和度，明暗单独调节。沿用 `color-wheel.js` 与 `night.js` 的预览和保存回调。手指按住移动时，直接更新主头像材质，保留纹理、明暗和眼睛。松手时保存并同步一次。拖动期间收到后台配色，继续显示手指所选颜色；取消拖动或切后台时恢复到最近已提交的颜色。未自定义过的头像保留原配色。
- 从 OTA 下载签名 APK 并解包，在 `android-personal/` 运行 `node tests/appearance.cjs <解包目录>/assets`。安卓验收用「番茄红电视」和带编号的「湖蓝（102）」分别覆盖两套渲染。等头像材质显示后按住色盘从红拖到绿，在抬手前采样**主头像区域**的像素，再抬手并重启应用核对保存色。回执里分别记录自动化覆盖范围、设备型号和使用者原话。[V1.0.13 发布与验收记录](../../../../2-Projects/realtime-voice-agent/docs/personal-s24-palette-v113-release-20261127.json)
