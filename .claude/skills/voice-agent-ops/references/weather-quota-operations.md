# 外部天气接口与调用额度

用于语音后台接入天气数据源、显示调用配额或允许管理员手工补额。具体供应商、额度、时限和设备范围从用户授权、最新部署记录与现场取得；本参考不授权扩设备、购买或重启。

## 接入与降级

- 若产品只需大致天气/位置，保留可信城市粒度和简短结果。字段更多不等于产品需要精确定位或分钟级预报；不能把云服务器出口 IP 当设备位置。
- 在实际服务器、实际适配器和既定超时内验证 Key、城市、日期与输出。另一个脚本很慢而运行时客户端很快时，分别保留结果；尚未定位机制不能据此延长普通聊天等待或改全机 DNS。
- 固定源失败/无可信结果时，可在原后台任务总预算内尝试一次一般检索；有来源给简短答案，无依据明确说明。取消后不补发迟到结果，正常聊天不等待查询。
- 隔离验证目录保留 package.json 的模块类型及真实依赖关系。ESM/CJS 装置错误先修环境，保留原失败；不能当作业务回归已过或直接跳过 Linux 检查。

## 本地额度的口径

若没有官方余额查询接入，界面给出的结果是**本系统估算**。明确初始值来自谁、统计起点、覆盖哪些服务、是否覆盖其他应用和是否重置；额度会变化，历史截图不能当当前余额。

| 项目 | 记录和处理 |
|---|---|
| 天气、城市编码等不同服务 | 按供应商计费类别分别计数，不把相关请求都扣到同一池 |
| 实际发出的请求 | 在发送前持久预占；按约定保守计入超时、拒绝、未知结果，区分结果类别 |
| 缓存与合并请求 | 缓存命中/复用在途结果不新增扣次；先找已有结果/在途任务，再判断新请求是否有额度 |
| 仅剩一次时的后加入者 | 已计费在途任务可继续共享，即使余额刚变成零；拒绝的是新增上游请求 |
| 手动追加 | 输入新增数量，保留历史消耗；请求幂等，响应丢失重试不能再次加额 |
| 校准剩余 | 与追加区分；核当前版本，防止覆盖刚发生的请求或另一管理员修改 |
| 周期额度 | 周期未确认时不假设每天/月初刷新；提供明确人工校准途径 |

账本保存种类、数量、状态和必要审计，不保存 Key、用户正文、原始音频或不必要的位置。测试消耗也入账；计数启用前补录的请求注明补录时间和原证据来源。接口成功、资料校验、任务完成及真人听到分别报告。

## 后台与回滚

- API 服务端核管理员权限、整数/范围/请求体、幂等键与并发版本，不能只靠隐藏按钮。读取失败清除旧余额；写入结果不确定时保留同一请求供安全重试，退出/换账号使旧请求失效。
- 真实浏览器检查有效余额、追加/校准、失联重试和窄屏；仅模拟 API 通过不能声称线上页面已生效。真实账号校验只输出脱敏结果。
- 候选新增数据库路径须进入原隔离保护，覆盖逃逸和符号链接；不能因计量新增路径放松其他库的隔离。
- 回滚恢复本轮代码和指定配置键，保留当前业务与额度账本、新购买/校准记录、凭据及期限；不恢复旧数据库“顺便重置”用量。后台路由随主进程重启时检查空闲窗口，并告知登录会话可能失效。
- 发布文件、实时开关/凭据生效、官方调用成功和真人体验分层验收。历史测试支持哪些结论写清，归档不再次消费真实接口或重跑语音矩阵。
