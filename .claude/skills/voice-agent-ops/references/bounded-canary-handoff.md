# 限时语音灰度：延窗、产物与验收交接

用于指定设备后台搜索灰度、延长测试窗口、候选 Worker 传输与后台状态交接。规则是操作方法，不是当前线上状态；每次执行重读最新授权、计划、回执及实际运行证据。

## 授权与身份

- 云端授权用完整 MCU SN / Device Bearer sub；末8位仅展示，ADB 序列号不能代替。用户已确认的信息不反复索取；版本同时标来源和最近上报时间，无法现场验证则明确说明。
- 新明确授权可以修订旧时长/基线要求，记录覆盖了哪条旧限制。其他设备普通聊天对照可用于体验比较，不能冒充同机 P95 验收。延窗不等于开放 P2、扩大设备或增加日额度。
- P1 Search 与 P2 Tool Calls＋受控 Fetch 分别开关、分别取证；真实 API 成功不等于真机听到。搜索空名单按关闭处理，不套用其他模块空名单全开的历史规则。

## 延窗前逐层对撞

1. 读取最新部署源清单、二进制 SHA256、配置、PID/重启数、活跃 job 和资源余量；保留现役及候选独立回滚点。Git HEAD 不是整树已部署证明。
2. 核对生产签发策略、候选 Brain 请求校验、Worker metadata 校验、后台展示的时长上限；代码上限与配置截止都满足新授权才可延长。Rust 改动须重新 Linux 测试、构建和 ABI 验证。
3. 完整 SN 名单、generation、绝对截止在各侧一致，重启/续租不能刷新截止。所有前置通过才最后启用生产派单；依赖步骤先检查退出码和结构化结果，不把发起命令当完成。
4. 首句合同、认证、非目标派单保持；独立 agent、候选进程、数据库/目录/定时任务/旁路 socket 与 HTTPS 入口均要核查。共享入口只发布本次文件，未改路径哈希对撞，不能整树覆盖不同生产基线。

## 产物传输必须成为安装门禁

- 构建清单绑定已测试源码、完整产物 SHA256、字节数和 ABI。上传到 staging；目标端 **assert 字节数及完整 SHA256**，失败退出，不 stop/安装/启动。只打印 hash 或看到文件存在不算验证。
- 网络慢优先断点/压缩传输；差分仅在目标旧产物完整 SHA 与差分基底相同时适用。应用到新 staging，恢复后完整新 SHA 必须等于已测试产物，再原子替换。差分是传输优化，不替代测试；为生成基底重建旧版后，恢复新版源码与产物。
- SSH host key 不符先停该通道并核实身份；不得关闭 StrictHostKeyChecking 或盲改 known_hosts。记录网络故障与产品故障的区别，不为传输随意改生产网络。
- 编排优先 JSON/显式参数，禁止对脚本做无边界的短词替换（例如 END 会误伤 CALENDAR）。安装失败保持关闭，恢复后重新取证。

## 到期必须处理已有会话

- 新派单、候选请求各自拒绝过期；Worker watchdog 结束已存在房间；持久系统 timer 作为独立兜底。timer 关闭逻辑只匹配该窗口的 deadline/generation，避免旧任务误关新窗口，并支持失败重试和幂等。
- 毫秒截止转秒级 OnCalendar 不能向下取整后提前执行一次 not_due 就永久漏关；统一整秒或向上取整。使用绝对时间并检查时区、Persistent、AccuracySec、失败重试配置。
- 短窗演练必须覆盖：不提前关、到期关配置、已有 RTC 断开/job归零、重复执行、新窗不受旧timer影响。短窗成功不能提前写正式未来截止已发生。
- 旧会话不会热迁移。窗口开启时普通重连仍进候选；故障先关生产派单、候选搜索/工具和 Worker window，再让设备退出重进现役。必要时无候选 job 后恢复本次文件/产物，保留最新业务数据，禁止整库/整env回灌。

## 后台与回执

- 待测设备选择与实际派单分开；开窗期间禁止换设备。保存接口 strict body 仅允许选择字段，不顺带接受 enable/期限；后端验证 admin 权限，不能只隐藏按钮。
- 展示部署核验记录、健康/租约、有效窗口、设备最近自报版本各自的时间和含义；满载/无租约不能推断设备离线。release-status 记录不等于实时二进制校验。
- 前端请求失败清空旧状态；退出/换账号时旧请求不可回填；只在可见页轮询。真实浏览器验证窄屏布局、权限、错误态，测试选择器问题单独归因。
- 回执区分“代码已部署 / 窗口已开 / 待真机验收”。合成 RTC 音频、服务端 delivered/completed 均不能证明扬声器实听。
- 实际开窗后给持有人写北京时间起止、目标完整 SN/展示后8位、版本证据、P1/P2、未验证项、退出重进步骤、可照读话术、预期及反馈模板；内部部署细节放技术记录。
- Air Downloads 交付核传输后 SHA256，旧回执备份避免误发。项目 README、项目记忆与新回执保持一致，历史记录顶部加时间范围与最新入口，不能抹掉旧失败证据。

## 下次接手

先看项目最新 MEMORY/回执，现场核有效期限再安排测试；窗口过期不自动续开。按时间、SN、房间/任务ID对齐真人反馈与服务端阶段，优先验证搜索中聊天、空闲补播、插话/续讲、取消/改查、退出重连；不索取凭据或原始用户正文。
