# 后台搜索与语音延迟验收

适用于给实时语音加入后台搜索、修改任务路由或优化TTS后，排查聊天变慢、重复回答、取消后补播与异常退出。具体版本、SN、开窗状态和阈值以当前项目记录及运行证据为准；本文不授权部署、重启或扩大灰度。

## 优先目标与证据分层

P003当前取舍是普通聊天响应无明显回退。搜索接单、取数及结果播报不能让普通聊天等待远程查询；为搜索碎片设置的等待不能套用到每句聊天。先测各阶段耗时再选优化，不用缩短ASR判停、扩大首句追补或延长承接音来掩盖另一层的问题。

| 证据 | 能支持的结论 | 仍不能支持 |
|---|---|---|
| 单测、构建、ABI | 已覆盖逻辑及目标运行环境检查通过 | 真实ASR时序、真人体验通过 |
| provider成功、任务completed | 取数/账本完成；还须检查内容、来源、日期、取消时序 | PCM已收、扬声器听到、答案正确 |
| Worker发布PCM、合成客户端收到音频/字幕 | 对应探针链路传输与接收成立 | 物理设备首词、扬声器、唤醒/退出状态机通过 |
| 带北京时间和设备信息的真人反馈 | 对应场景的设备体验证据 | 未测试的场景或长期P95通过 |

探针exit0只表示工具运行成功。验收按场景组合路由、任务ID/revision、账本转换、内容和PCM/字幕断言；主动断连场景的0音频可以是预期，不能套用“每项必须有音频”。保留失败迭代，成功版本与证据单独绑定。

## 重复回答：按会话时序复现

- 先对齐同room的ASR临时/提交、路由动作、任务和播放。一个搜索任务加一轮前台聊天也会重复答，不能只查“是否创建两个任务”。
- 复现用原始分段顺序和间隔，包含澄清→裸主题→谓语尾、无续句、无关聊天、新搜索、取消、改查、热配置替代、插话与重连。仅给路由器完整句或只测天气不能覆盖真实输入。
- 用合成RTC再现时保留实际ASR间隔；预设停顿不等于识别提交间隔。固定等待通过一条样本不代表覆盖在途续句。
- 若用等待合并，仅限明确搜索上下文且任务尚未提交；观察音频/临时ASR/待提交文本，设置不会随噪声刷新的一次性绝对截止。普通聊天、取消和新查询须有独立退出路径。边界以实现合同为准，勿承诺任意分片都可拼接。

R12参考：600ms真实反馈暴露双回答；1200ms暂存方案在1851ms合成RTC仍失败。最终无续句1200ms、存在续句输入时最多等到绝对5000ms；这是该版本的参数，不是通用ASR阈值。

## 延迟：必须看实质回答

至少分开记录：停说→ASR提交、提交→路由、提交→正文首帧、承接音首帧、文本就绪→首个PCM（含等待预连接）、句间停顿/underrun。服务端正文首帧也不等于设备听到。

- 检查计时器是否晚于`prewarm.take().await`开始，避免把预连接等待漏掉。旧口径缺阶段时，回到统一日志锚点重算，不直接比较两个同名指标。
- 前后使用相同音频字节/哈希、同身份和链路；标出基线是现役还是上一候选、冷/热轮及执行顺序。输入数、ASR提交数、正文轮数、无首帧轮及取消/覆盖原因全部保留。
- 小样本中位数/最大值仅是描述性结果；8样本经验P95不能作为稳定P95。候选前后优化通过，不能推导成“搜索相比未加搜索现役零开销”。
- 受限备用握手只缓解单路长尾，不能保证两路同时慢时不慢。核对只在慢连接触发、并发限额、不排队、取消时future/socket/permit释放；等待中的JoinHandle不能移出Drop清理所有权而被detach。
- 承接音用完整语义短句，保留插话轮策略；变短后可能露出空隙，需同时看正文首帧与句间停顿，不能只报中位数改善。

## 异常退出：不要倒置因果

沿设备control cancel/trace/seq→MUTED→participant disconnected→Worker清理对齐；跨端时钟有偏差时优先关联ID，不直接比较未校准时间。服务端ClientInitiated或先收到端侧cancel只能定位边界，不能独自确定安卓触发原因。

未出现相应ASR提交或搜索任务时，不能归因搜索超时。保留“未解决”，让端侧核唤醒入口、上传、静音计时及退出状态机；不得为了掩盖退出忽略合法cancel、改变退出权威或首句合同。

## 真机测试期间的运维边界

- 只做归档或查询状态时，不顺手跑RTC探针、提额度、缩短窗口演练、重启或重开灰度；主动测试另按已授权范围及现场占用协调。活跃jobs非0可能是真人在测，不是健康故障。
- “窗口已开”“待真机验收”分别记录时间。窗口内退出重进仍进候选；恢复现役需先关闭相关灰度闸，再退出重进。未来截止尚未发生，不写成已实测到期。
- Git提交/推送、运行产物和设备版本各自绑定证据；OTA自报带时间，不充当现场APK核验。文档提交不等于再次部署。
- 公开记录只保留关联ID、阶段时间、哈希、数量和结论；原始用户正文/音频及凭据不进入Git。
