# 语音灰度：计时归属、连接优化与发布收尾

用于后台任务混入普通对话计时、SSE协议优化、首音故障恢复和灰度回滚。范围、门槛、设备与期限从本轮计划及现场取得，本文不增加测试预算或操作授权。

## 计时归属与纠正

- 用同房间、实际ASR输入、唯一commit和turn/response关联正文。跨房恢复另关联task/revision/句游标。查询迟到尾句、上一轮正文和后台结果可能落入当前聊天时间段，不能仅按时间段计数；这些旧输出仍保留，额外回复的体验问题另行判定。
- 用正文时间减since_turn反推开始时，先核字段定义、日志时钟精度，再按commit区间归属。时间容差只处理记录精度，不设置“开始必须在几毫秒内”的性能上限；慢启动、慢回复、多正文歧义和缺正文不能因不利结果而被排除。
- 纠正报告写明：错误机制、原报告摘要、协议版本/冻结时点、哪些原门失败、哪个纠正门通过、每个样本的归属变化。原报告和失败留存；中途修正不称采样前预注册。阈值、尝试预算和运行产物保持既定约束，不能挑快轮或追加样本凑绿。
- 先用旧回复混入、延迟启动、慢正文、下一输入、后台结果、缺/多正文和整数时钟等已有夹具验证归属。没有唯一对应证据则记不确定或缺失，不靠接近的时间硬配多房间日志。

## 时延、成功率与实听分开

- 分别报告发送音频结束→提交、提交→正文首PCM、客户端收取及物理听到。发送WAV尾可能有静音；配对差值的P90也不是两臂P90相减。正文门通过不覆盖ASR、预连接等阶段的全部长尾。
- 探针正常退出、查询answered、引用核验、完整播放和真人听到分别给分母。上游500、invalid_answer、已ready而不再inflight都保留；后者不能当搜索中负载样本，也不能直接算查询失败。
- 跨房恢复记录实际游标。首句未完整结束时从0恢复，只证明该断点可恢复，不能推导成非零游标从不重复。候选provider重启后的unknown不是真实成功，旧成功也不自动代表新进程已经发出请求。

## 有边界的连接与首音优化

- 改HTTP/2前核客户端构建feature、ALPN和真实认证SSE的实际协议；TLS探针返回404只证明协议协商。全局依赖feature可能影响其他HTTP客户端，候选开关与非目标客户端的协议行为都要核实。
- SSE取消应传播到上游并释放资源；验证取消流、后续正常流及不完整回复的落库结果。协议协商成功、连接复用成立、普通聊天性能达标是不同证据，不从单次快响应推导HTTP/2解决所有延迟。
- 首PCM总预算涵盖解析/连接/预热等待；已出首音的长回答不能套同一个总时长截断。失败提示与正文分开计数，一次失败不反复播提示。现场DNS根因未定位时保留未知，不凭一次预热慢轮修改全机DNS。
- 环境配置重写后核实际进程收到的中文值；systemd环境中的字面\u转义不能当正确中文。保留既有UTF-8启动审计，回滚只改本轮键，不能整份恢复旧JWT、期限或业务配置。

涉及外部天气 Key、调用额度和手动补额时，另读[天气接口与调用额度](weather-quota-operations.md)。

## 发布、止损与交接

- 发布前重新取得R1、资源/活跃会话、运行SHA、完整SN与带上报时间的版本；只对已通过前置的授权范围部署。依赖步骤顺序执行，SSH超时先查远端同一进程，不启动重复控制器。
- 回滚分为停止新增派单、已有会话退出、空闲后回退产物、核验后决定是否重新开放。停新增入口不应被“必须先空闲”堵住；不能复用只认安装前环境摘要的发布暂停步骤处理安装后状态。保持最新凭据、数据、额度和原期限。
- 以原计划必需检查为发布路径，额外诊断列待办；用户要求交付时不继续扩张与本轮前置无关的实验。测试不通过仍如实保留关闭/阻塞，不用紧迫性绕过门槛。文档归档不用重跑整套RTC或改真人开关。
- 开放后记录实际生效时间、运行产物、正反鉴权/派单、稳定观察和未验项目；合成验证服务收尾只涉及其自有范围。Air回执核传输后哈希；原两设备窗口更新不伪造新开窗或新期限。
