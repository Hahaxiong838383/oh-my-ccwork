# OK笔记 NAS 维护

维护用户现有应用中心安装。先读 `~/home-lan/CLAUDE.md` 和 `2-Projects/P01-家里局域网与飞牛/README.md`；若该仓不在本机，使用本 skill 的版本参考和发布快照定位资料，不凭历史 IP 选择设备。

只要求了解或审查时保持只读；下文变更流程仅适用于已有授权的拟议变更。

## 先确认当前对象

核对实际 NAS、应用包版本、容器 package.version、image ID、应用中心 Compose、挂载、有效环境变量和用户实际访问网址。`latest`、配置文件内容、旧报告都不能代替运行时状态。凭据只记录密码库条目/路径，配置读取采用遮蔽值或字段白名单。

fnOS 管理优先现有 `trim-cli` skill 和官方 OAuth。若当前 profile 刷新失败，记录具体错误，不循环刷新或重建登录。已获授权的 SSH 与原应用中心 Compose 可作为维护通道；保留应用中心管理归属。未授权的 SSH 或缺失 OAuth 不是自动获得权限的理由。

## 判断缺功能的四个层面

- **本地许可与能力**：看 `license/status` 的 capabilities 和实际路由，不能只看 `enforced=false`、套餐名称或 `features=["*"]`。
- **服务配置**：分别核查 AI、ASR、邮箱、OAuth、SMTP 和公网映射；能力开放不会补齐 provider、模型、凭据或云资源。
- **客户端能力**：对实际网址检查安全上下文和 `getUserMedia`；`MediaRecorder` 存在不代表可录音。区分 Web、Tauri 和原生 App；解析反代配置失败不证明没有 HTTPS。
- **实际结果**：flag 为 true、按钮出现、HTTP 200 均不是业务已可用的充分证据；用非空结果、数据落盘或可见行为验收，并记录未测分支。

处理 3.2.0 时按需读 [版本证据与接口](references/oknote-3.2.0.md)。其他版本重新追踪分支，不照抄旧参数。拿不到匹配产物时可继续客户端和运行时只读排查，但保留参数语义未证实的边界，不凭旧版值修改新版。

## 从发布物找依据

用户要求 REA 或结论依赖已发布包时使用 `reverse-engineer-anything`；普通完整源码分析无需额外启动 REA。

只取程序产物，排除 data/config/legacy。记录版本、bundle SHA、source map 来源与恢复文件哈希；恢复 source map 不等于取得完整 Git 仓。大 bundle 触预算时依据报告的 gap 缩小到相关作者模块，保留原证据及选择范围；不要把 13 个文件解析通过写成全部 164 个文件都解析通过。

从功能入口追踪到能力判断、配置解析和实际服务调用。优先核实已有部署参数；用户已授权的可逆配置经验证后继续执行，不因参数名称含 license 就反复请求相同授权。记录本地模式与官方账号/云资源权益的区别。

## 变更与验收

1. **先算相邻影响**：解除能力限制可能同时改变注册人数、AI 共享策略或存储上限。根据当前任务处理有效行为变化；不要从一次案例推导“总要关注册”“总要 disabled”或“总要升级 latest”。
2. **准备可恢复备份**：SQLite 一致性快照要与独立正文/导图/版本/附件、配置和持久密钥一起考虑。选择短暂停机或经过证明的在线一致性流程；不能只复制运行中的 DB 而忽略 WAL。含密钥归档留 NAS 受限目录，校验成员/哈希与还原 DB 完整性；标明是否实际启动恢复过应用。
3. **先用隔离对照验证分支**：同镜像、独立数据、合成账号/内容；非网络功能可禁外网。比较原配置与目标配置下同一请求，解析参数以实际路由为准。隔离通过不替代生产验证。
4. **沿原部署链生效**：检查环境变量优先级及 Compose 渲染结果，变更只包含预期字段。需要重建时保持既有 image ID，除非任务明确包含升级。准备回退，只恢复本轮目标字段，避免旧 `.env` 覆盖后来密钥或新配置。
5. **独立回读生产**：确认新进程启动时刻、有效 caps、健康载荷、数据数量/文件哈希、认证失败负例及受影响策略。优先现有正常会话/正式 API 凭证；不要把历史临时维护 JWT 方法固化成默认登录方式。

真实 AI、ASR、邮箱或云调用的验证要符合当前服务选择及数据发送范围；优先合成内容。缺少必要信息时继续完成独立工作，仅询问尚缺的服务/密码库条目/入口，不代选外部服务，不以真实私人笔记或邮件试跑。

交付区分“静态推断 / 隔离操作 / 生产回读 / 用户端到端”。归档改动、备份/回滚、已验与未验；共享记忆写当前事实和待办。Git 只提交任务内脱敏资料与自有脚本，原始闭源程序、用户数据、凭据和含密钥备份留本地。
