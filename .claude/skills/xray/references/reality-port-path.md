# VLESS / REALITY 特定端口不可达

适用于手机 v2rayNG 或其他客户端旧节点突然超时、同一服务器其他端口仍可达的情况。
先区分 TCP 路径、REALITY 认证和目标站业务；本指引不默认更换客户端、协议或凭据。

## 定位到证据能支持的层

| 观察 | 能证明什么，以及下一步 |
|---|---|
| 服务 active、端口 LISTEN | 仅证明服务器进程与监听。核客户端实际地址/端口、服务器和云防火墙，继续从使用端验证 |
| 服务端收 SYN 并发 SYN-ACK，但无第三次 ACK | 不能证明客户端收到回复。客户端同时间抓包，并用同接口可达端口作正对照；默认只保留包头，避免收集载荷 |
| 客户端有出站 SYN、没有入站回包，正对照正常 | 定位为回复未抵达该捕获点；结合第三地同端口测试区分路径差异。不能据此点名运营商、GFW 或具体触发规则 |
| 经已有 SSH 管理链路转发至原后端，原 REALITY 参数认证成功 | 原后端与认证在该测试路径可用；不证明原公网端口恢复，也不证明手机网络可达 |
| 新端口转发同一后端，使用端完成真实代理请求 | 证明该使用端的新入口可用；手机恢复需手机实际验证或用户明确反馈，不能拿开发机结果替代 |

记录证据时间与使用网络；故障开始时间、具体丢包设备未知就保留未知。
按 IP 直连时发生在 TCP 握手前的故障，不因修改 DNS、SNI 或密码而得到针对性修复。
同一 IP 多端口也可能影响路径选择，不能把“换端口成功”直接写成“确认精准封禁”。

## 增加入口时保留原后端

在已授权修复范围内，可用独立 TCP 转发新增入口，复用原 REALITY 后端，无需中断其既有连接。
先核新端口未占用、现有转发工具可用，再保存旧进程身份、配置摘要、监听和防火墙基线。
只增加明确的新规则；部署后再次回读原服务与新入口，而非仅查看安装命令退出码。

- 客户端端口之外的 UUID、flow、SNI、公钥、shortId 等取现网真值，不从名称猜测或擅自轮换。
- 私钥或密码不放 argv/日志；内存生成客户端配置。必须落盘的导入 URI 用 700 目录/600 文件，禁止进入 Git 或记忆正文。
- socat 这类回环 TCP 转发会令后端看到来源 127.0.0.1；原客户端 IP 审计应在公网入口进行。不要为恢复源 IP 擅自启用未经后端支持核验的 PROXY protocol。
- systemd `After=` 只排序，不会拉起另一个服务或等待其就绪；`enabled` 是自启配置，真实重启才是冷启动验收。
- `Restart=on-failure` 只处理转发主进程失败；后端不可达、某个子连接失败或线路受阻，并不会因此自动换节点。
- 回退只移除本次新建 unit 与精确防火墙规则；不用可能已变化的 UFW 数字序号，不触碰原服务。回退会断开使用新入口的客户端。

本次可复用产物见[备用入口目录](../../../../2-Projects/vps-proxy/racknerd-reality-altport/README.md)。
里面的端口与服务名属于具体部署，维护时核现场，不当成所有服务器的默认参数。

## 验收与探针自身

最终验证须通过实际 REALITY 客户端：记录目标、状态、耗时、有效正文和出口。
端口通、伪装证书正确、HTTP 空壳 200 均不足；同机客户端/服务器出口相同的场景，另用客户端路由日志证明走过代理。
多分流环境核探针与目标的实际路由一致；网页正文通过不代表视频吞吐或所有 APP 都正常。

Xray 使用 memfd 或无扩展名配置时显式指定 `-format json`，先确认客户端启动成功。
探针参数、配置解析错误不能记成节点故障。临时转发与客户端记录精确 PID，结束后核身份清理，避免 `pkill -f` 匹配自身 SSH 命令。
验证通过后不要为收尾重复测速、重启生产或换凭据；新反馈再针对性检查。

## 冗余与电视边界

降低再次中断的影响要有跨 IP、跨协议候选，并从实际使用网络发起有效代理请求；同 IP 多端口只能覆盖部分故障。
切换要有失败确认、健康候选验证和恢复防抖，避免频繁切回坏线路。
手机 v2rayNG 自动切换能力取决于实际版本与配置，先核后承诺；导入两个节点不等于已有自动兜底。

电视关机时，ADB/ARP 不通不构成代理故障。用户要求跳过则记录待开机验证，不唤醒设备补测试。
服务器 HY2 在监听、手机已恢复，也不能替代电视实际 DNS、选择器、连接与前台播放验收。
迁电视端口先盘点主代理、视频候选和 DNS 兜底的全部引用，再读
[电视启动事务与运行真源](tv-dns-coldboot.md)：同步配置、release/SHA、manifest 和回退组，不能只改 config 而让下次启动被旧事务拒绝。

现场证据与已知限制见[2026-10-27 排查报告](../../../../2-Projects/vps-proxy/2026-10-27-RackNerd手机节点连接排查与备用入口.md)。
