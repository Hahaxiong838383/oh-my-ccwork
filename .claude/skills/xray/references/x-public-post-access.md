# X 定向分流与公开帖子读取

用于 Mini/DSH 访问 X、核验 ZGO、或判断“代理可用但页面/抓取不可用”。节点名、端口和部署路径是2026-10-19实证，不是其他设备的默认配置。

## 当前证据优先于 Bot 旧结论

- 仅输出当前入站协议/地址、出站tag及相关规则，不打印整份含凭据配置。用户说ZGO时，既查标签也核对受限配置中的实际端点；标签不含某关键词不能证明节点不存在。
- 按请求时间核对access.log的真实出站。HTTP CONNECT可能记为 `//x.com:443`，SOCKS可能记为 `tcp:x.com:443`。出口城市不能替代节点身份，通用IP探针也不能替代目标域名自己的路由日志。
- CONNECT成功、目标HTTP状态、浏览器内容渲染、登录状态、取得哪些帖子分开报告。网页200可能只是SSR外壳；浏览器失败不能推出所有公开接口均不可用。

Mini案例：原X规则走 `HK-HKT-A`，实际已有 `admin-dmit-ZGO-不限速`；隔离该出站实测可达后，仅新增X域名规则，保留其他社交站点与模型路径。不要把“某次没看到tag”写成永久事实。

## 只给抓取进程代理，保留模型直连

1. 用户要求DSH/模型直连时，X抓取子进程显式用现有HTTP入口；不执行全局switch、不设系统代理、不改整个DSH的HTTP_PROXY或默认出站。
2. 环境可能有 `NO_PROXY=*`。curl指定 `--proxy` 后仍用 `--noproxy ""` 清除该命令的绕过列表，不删除全局NO_PROXY。负测注入不可用环境代理与NO_PROXY，确认工具仍按显式参数走局部代理。
3. 已实测HTTP CONNECT正常而SOCKS失败时，保留已验证协议，不因端口相同就互换。浏览器使用其proxy配置，Chromium加 `--disable-quic`；这不是登录凭据，也不保证X允许访客请求。
4. 改分流时：私有备份、候选配置校验、核对无并发修改，再把限定域名规则放在会截获目标的规则之前；重载对应Xray服务后用真实请求日志验出站，并核对其他配置等价。不要为改X路由重启DSH Host。
5. 节点密钥只在本机私有配置复用；隔离探测配置0600，结束删除。回滚删除本次精确规则，避免整份历史备份覆盖后来的修改。

## 选择能交付所需内容的通道

| 需求/现象 | 处理 |
|---|---|
| 已知单条公开帖子链接 | 可先用X官方oEmbed读取嵌入文字；验证作者与非空正文，不执行返回HTML/脚本 |
| 浏览器访客403或加载失败 | 保留失败事实；单独测试官方公开接口，不绕验证码、不伪造Cookie |
| 搜索、时间线、受保护或登录态内容 | 单帖工具不支持；需要可用登录或授权数据接口，不能冒称已恢复，也不擅自开通付费通道 |
| 429、访问拒绝、删除或空widget | 明确失败；不无限重试、不把空壳当成功、不转向绕过权限的接口 |

官方依据：[X oEmbed](https://docs.x.com/x-for-websites/oembed-api)。嵌入文字不保证包括长文全文、媒体详情或完整指标；使用前按当前文档/响应复核。

Mini 已部署工具（无需Cookie或付费Key）：

```bash
/usr/bin/python3 /Users/rayman.chen/local/deepseekbot/tools/x-read.py \
  https://x.com/jack/status/20
```

源码：[x-read.py](../../../../2-Projects/deepseekbot-deploy/tools/x-read.py)。只接受HTTPS的X/Twitter单帖URL，剥离跟踪参数，拒绝任意域名、URL凭据、主页和搜索；显式HTTP代理、保持TLS验证、限制请求时间/响应体，不自动重试。成功返回 `ok/author/text/url`，失败非零退出，调用方须检查 `ok`。

## 交付给 Bot 以亲跑验收收口

用户只要求发消息时，以送达为完成边界；用户要求直接解决时，教程发出或Bot回复“已记录”不等于运行成功。应完成最小修复和工具部署，再让指定Bot执行同一只读样本，核对真实返回，并读回其记忆中的命令、结果和限制。不要无授权派工或发给其他人。

DSH CLI用 `send --body-stdin --message-id human-<UUID>` 保留确定消息ID；超时先 `send-status` 查结果，不重复投递未知状态的请求。仅在用户已授权的通信范围内使用。

实证：[Mini X修复与验收](../../../../2-Projects/deepseekbot-deploy/X-ACCESS-20261019.md)。两条公开帖实读、继承NO_PROXY的负测及4项本地单测通过；幕僚长亲跑、别名URL成功、主页拒绝并记录自身记忆。未登录浏览器、搜索和时间线仍有缺口，不将该案例写成“全部X通道恢复”。
