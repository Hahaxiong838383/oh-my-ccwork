# P003 管理后台：模块标签与并行静态发布

用于 Worker Brain 等单 HTML / DOM 内 Vue 页面出现功能纵向堆叠，或与后端功能分支并行调整布局时。沿用既有页面/API；此指南不要求所有页面固定四个标签。

## 页面层级和状态

- 页面导航、页内功能模块、设备详情子标签使用各自状态。全局模块不以“未选择设备”作为显示条件，切回全局模块也不清空设备选择。
- 租户总览下钻同时选择设备和切到设备模块；保留原详情子标签、加载与清理逻辑。
- 有未保存表单时，用保留组件/状态的切换方式；DOM 内 Vue 可使用真实容器的 `v-show`。切回时不要无条件重新拉配置、清空密钥输入或重置草稿。
- 刷新针对当前模块：只读总览直接刷新；会覆盖草稿的读取先确认或走原 dirty 保护。保存继续复用既有API、CAS和权限检查。
- 首次进入、切模块、登录失效后原页重登录共用加载入口。普通切换只补缺失数据，重登录按当前模块重新加载；loading也应匹配当前模块。
- 长内容页保持顶部标签可达；窄屏标签可横向滚动，设备详情子标签可换行。补 tab/tabpanel、方向键和清晰焦点态。

## 行为验证

| 场景 | 应看到的结果 |
|---|---|
| 切换模块 | 只显示当前模块，选设备及详情子标签不丢失 |
| 编辑后离开再回来 | 倾听/LLM等草稿仍在；明确刷新取消后也保留 |
| 总览点击租户 | 正确进入该设备详情，无需再手动切模块 |
| 登录过期后重登 | 原模块恢复加载，不依赖导航值变化触发watch |
| 滚动与窄屏 | 顶部标签可操作，详情子标签不挤出容器 |
| 旧业务动作 | 保存、冲突、恢复、空密钥保留及权限合同不变 |

组件fixture通过不能代替整站渲染：完整HTML还有模板嵌套、全局变量及导航生命周期。可先让浏览器加载候选HTML并读取真实只读API，阻断登录以外的业务写请求；保存/冲突等写行为在临时Hono/SQLite验证。凭据经现有安全渠道进入内存，不放argv、截图、日志或仓库。发布后再用真实公网HTML验证导航和加载。

项目已有 `apps/server/scripts/brain-tabs-ui.cjs` 和 `listening-admin-ui.cjs` 可复用；按脚本环境参数使用已有Playwright/Chromium，凭据通过stdin提供。

## 与运行链路并行发布

- 另一会话正在改Brain/Worker时，从已发布页面锚开独立UI工作树，只改布局及相关fixture，不携带另一树未提交运行代码。
- 先读当前线上HTML比较基底；存在差异时按生产/基底/UI提交三方合并，重新验证最终文件；从固定commit导出待发文件。
- 静态admin HTML可单文件原子替换，无需重启Brain/Worker或全量web build。即时备份旧文件及旧/新SHA；回滚先确认目标仍为本次版本，避免覆盖后续发布。
- 复核公网字节、实际交互、服务PID/重启数和未涉及源码。回执区分自动化验证、用户视觉确认和完整功能/真机验收。
- 将UI提交交给运行链路会话，在安全提交点合入。**通知成功不代表合入完成**；以祖先关系/文件内容/双方回执核实，下次整页发布前再检查。

恢复案例：项目文档 `docs/P003_BRAIN_TABS_20261030.md`（2026-10-30用户确认布局符合预期）。地址、进程、配置和发布锚以当次核验为准，不把历史值固化为默认值。
