# IPO 市场每日调研报告

定时任务自动生成 IPO 市场每日调研报告，发送到指定邮箱。

## 触发方式

- 定时任务自动触发（每日 08:00 和 14:00）
- 手动触发："/ipo-report"

## 报告内容要求

### 1. 今日 IPO 市场概览
- 全球 IPO 市场动态
- 重大 IPO 事件
- 市场情绪分析

### 2. 热门行业分析
- 科技、医疗、消费等热门行业 IPO 趋势
- 行业估值水平
- 投资热度分析

### 3. 重点公司案例
- 近期上市/拟上市公司分析
- 定价区间和募资规模
- 投资者反应

### 4. 市场数据
- 上市数量统计
- 募资规模统计
- 平均估值倍数

### 5. 投资建议
- 行业配置建议
- 风险提示
- 机会展望

## 输出格式

生成 HTML 格式的邮件报告，包含：
- 图表和数据可视化
- 清晰的章节结构
- 专业的市场分析

## 发送邮箱

- 收件人：13911184569@163.com
- 主题：📊 IPO 市场每日调研报告 - {日期}

## 技术实现

1. **数据采集**：调用 collect skill 的 rss-ipo collector 获取 TechCrunch IPO/融资/科技相关新闻
2. 使用 ipo-market-team 团队进行分析
3. 生成 HTML 报告
4. 调用邮件发送服务发送
5. **自动发送飞书通知，带报告原文链接**

### 数据源

- **rss-ipo**：TechCrunch RSS，过滤 IPO、融资、并购、科技、AI、汽车、AR/MR 等关键词
- 数据路径：`1-Inbox/_collect/{日期}/rss-ipo.json`

## 飞书通知（自动）

- 定时任务自动执行，无需用户确认
- 发送内容：报告摘要 + 报告原文链接
- 需要配置飞书 webhook（目前缺失，需要用户提供）

## 报告原文链接

报告生成后：
1. 保存到 `1-Inbox/IPO-报告-{日期}.md`
2. 飞书卡片中包含此文件的链接

## 注意事项

- 报告需要图文并茂
- 数据需要注明来源
- 保持专业、客观的分析风格
