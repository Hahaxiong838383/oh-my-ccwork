# IPO 市场团队工作实施计划

## 一、整体工作目标

### 战略目标
通过系统化的资本市场传播体系建设，确保公司在 IPO 过程中建立行业权威形象、传递清晰的投资价值逻辑、实现品牌认知度和美誉度的全面提升，为上市估值提供有力支撑。

### 量化目标
- 核心投资故事覆盖目标受众触达率 ≥ 80%
- 行业媒体正面报道占比 ≥ 90%
- 核心 Q&A 库覆盖率达 100%（基于历史投资者问答收集）
- 上市传播战役全网曝光量 ≥ 5000 万
- 上市首日品牌搜索量提升 ≥ 300%

## 四、责任角色分配矩阵

| 角色 | 主要职责 |
|------|----------|
| project-manager (项目协调人) | 整体进度管控、任务分配与协调、里程碑评审组织、风险识别与升级、交付物最终验收 |
| market-analyst (市场研究分析师) | 市场规模分析 (TAM/SAM/SOM)、行业趋势研究、资本市场 Q&A 库建设、投资者关注点分析、竞品动态追踪 |
| competitor-analyst (竞品分析专家) | 竞争对手传播策略分析、竞争定位研究、敏感问题应对准备、差异化优势提炼、可对标公司分析 |
| copywriter (文案撰稿人) | Equity Story Deck 撰写、创始人故事开发、高管演讲稿撰写、新闻稿与媒体通稿、社交媒体内容创作、Master Message Doc 编撰 |
| data-analyst (数据分析师) | 核心数据梳理与分析、数据可视化图表设计、投资者素材包整理、单位经济模型构建、数据故事资产库管理 |
| brand-strategist (品牌策略师) | 品牌定位与叙事升级、视觉系统设计管理、媒体关系建设、上市仪式策划、危机预案制定、静默期策略制定 |

## 五、关键成功因素

1. **跨角色协作效率**：确保市场研究，内容创作，数据分析，品牌策略之间的信息流畅通
2. **法务合规意识**：静默期前后严格遵守监管要求，避免合规风险
3. **快速响应能力**：上市期间舆情变化快，需具备快速响应和决策能力
4. **内容一致性**：所有对外内容保持统一的品牌调性和信息口径
5. **时间节点控制**：IPO 时间表刚性较强，需严格按照里程碑交付

| 时间风险 | IPO 时间表调整 | 保持任务灵活性，建立可调整的缓冲期 |

| 舆情风险 | 负面报道出现 | 7×24 小时监控，快速响应机制 |
| 资源风险 | 关键人员变动 | 建立文档交接机制，避免单点依赖 |
| 执行风险 | 媒体排期冲突 | 提前预约，建立备选媒体清单 |
