# IPO Manager

> 专门管理 IPO 市场团队的进程和任务

## 功能

### 1. 启动团队
```
/ipo start
```
启动 IPO 市场团队工作流

### 2. 查看状态
```
/ipo status
```
查看当前团队状态和任务进度

### 3. 停止团队
```
/ipo stop
```
停止所有运行中的任务

### 4. 查看任务
```
/ipo tasks
```
列出所有待处理和进行中的任务

### 5. 报告
```
/ipo report
```
生成每日 IPO 市场报告

### 6. 危机处理
```
/ipo crisis
```
进入危机处理模式
