# 1-Inbox — 收集箱

> **cc 在此目录创建/修改文件前，必须先读取本 README 并遵守以下规则。**

## 定位

快速捕捉想法、灵感、研究过程、待处理的素材。这里是**暂存区**，不是最终归宿。

## 什么放这里

- 临时想法、灵感闪现
- 研究过程中的笔记和素材
- 外部资料的初始收集（论文、文章摘要等）
- 还没想好放哪里的东西

## 什么不放这里

- 已经有明确结论的内容 → `3-Thinking/`
- 可以直接复用的模板/代码 → `4-Assets/`
- 正在推进的项目文件 → `2-Projects/`
- 系统状态和记忆 → `0-System/`

## 强制规则

1. **命名格式**：`YYYY-MM-DD-主题.md`（如 `2026-03-22-RAG架构调研.md`）
2. **定期清理**：Inbox 内文件超过 7 天未处理，应提醒川哥决定去向
3. **清理出口**：
   - 有价值的结论 → 提炼后移到 `3-Thinking/`
   - 可复用的资产 → 整理后移到 `4-Assets/`
   - 形成项目 → 在 `2-Projects/` 建目录
   - 没用了 → 直接删除或移到 `5-Archive/`
4. **不要让 Inbox 超过 20 个文件**，超了就是欠债

## 巡检提示

cc 每次进入此目录时，扫一眼文件数量和最旧文件日期，超过阈值主动提醒。
